# 사농공상 윷놀이 음악

## 달빛 뜰 (Moonlit Courtyard)

`moonlit-courtyard.wav`는 위스토리 윷놀이를 위해 새로 구성한 선율·편곡·합성 음원입니다. 다른 게임의 멜로디, MIDI, 녹음, 음원 샘플을 사용하지 않았습니다. 특정 게임의 음악을 재현하지 않고, 한국풍 고전 게임의 차분한 마을 분위기와 현·관·타악의 질감을 참고했습니다.

- 12/8박자, 점4분음표 84 BPM, G·A·C·D·E 중심의 오음 선율
- 서로 다른 8마디 구절 세 개, 총 24마디 / 약 68.57초
- 현을 뜯는 음색, 숨소리가 섞인 관악 선율, 낮은 현 공명, 양면 북을 연상시키는 타악, 절제된 종소리
- 실제 가야금·대금·장구 녹음이 아닌 수학적으로 합성한 음색
- 32,000Hz, 16비트, 스테레오 PCM WAV / 약 8.78MB
- 곡 끝의 현·잔향을 시작 부분에 순환 합산하여 반복 경계가 이어지는 구성

재생 원본은 `scripts/generate-yut-audio.py`입니다. Python 3와 NumPy가 필요합니다. 저장소 루트에서 `python scripts/generate-yut-audio.py`로 재생성합니다. 고정 난수 시드 `20261018`을 사용하며 `audio-manifest.json`에 생성 결과의 길이, 크기, peak, RMS, 클리핑 수와 SHA-256을 기록합니다.

## 앱 재생 계약

공용 `useWeplayMusic`을 `useYutMusic`에서 재사용합니다. 명시적인 시작·참가·음악 버튼 조작 후에만 재생하며, 플레이어가 막히거나 음원 로딩이 실패하면 음악 버튼으로 재시도합니다. 재생 오류는 게임 진행을 막지 않습니다. 고정 볼륨은 0.28이고 기존 충무공과 같은 기기별 소리 설정을 사용합니다. 탭이 숨겨지거나 화면을 떠나면 일시정지하고, 비활성 체험·경로 전환에서 두 배경음악이 겹치지 않도록 공용 플레이어 소유권을 확인합니다.

스튜디오 인트로는 독창적인 W 표식과 WESTORY / WEPLAY 타이포를 사용하는 무음 애니메이션입니다. 기본 2.4초, 동작 줄이기 설정에서는 정적인 0.7초이며 건너뛰기·Escape로 즉시 종료할 수 있습니다. 인트로가 끝난 뒤 게임·대기 화면을 마운트하여 진행 시간이나 유료 게임을 미리 시작하지 않습니다.
