# 사농공상 윷놀이 시각 자산

- `moonlit-village.svg`: 이 게임을 위해 좌표와 색을 직접 설계한 원본 픽셀 풍경. 달, 산, 기와집, 버드나무, 돌다리와 등불을 정수 좌표의 사각형·계단형 경로로 표현했습니다. 기존 게임의 이미지·지도·캐릭터를 가져오지 않았습니다.
- `catalog.svg`: 같은 원본 풍경의 4:3 카드용 구도입니다.
- `YutArt.tsx`의 네 인물: 20×28 격자의 원본 픽셀 캐릭터입니다. 선비의 갓, 농부의 삿갓, 장인의 머리띠·망치, 상인의 짐을 각각 구분합니다. 직업별 게임 능력 차이는 없습니다.
- 글꼴: Galmuri11, `fonts/OFL-1.1.txt` 참조. 화면은 제공된 웹폰트를 사용하며 다른 게임의 로고나 타이틀 문자를 복제하지 않습니다.

인물·풍경의 저해상도 격자와 절제한 색상은 고전 한국 온라인 RPG의 시각적 분위기를 참고한 것입니다. 특정 게임의 UI 배치·문구·고유 캐릭터·도형·음악을 재현하지 않습니다. BGM 저작·편곡 정보는 별도 오디오 문서를 따릅니다.
