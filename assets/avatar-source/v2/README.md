# Westory 2D avatar source art

Created 2026-10-29 with the built-in OpenAI `image_gen` tool after the user selected an original-illustration 2D replacement. These are original generated component sheets, not screenshots of implemented functionality. No real student/teacher photos, records or credentials were inputs. The sole visual reference supplied to the sheet generations was the newly generated Westory concept (school polo, Joseon robe, hanbok); the user's game screenshot informed the verbal request for a compact side-part silhouette but was not supplied as a sheet input. No external game sprite/mesh/texture is copied into the app.

The production layer registry is `scripts/avatar-2d-art-registry.json`. It records original sheet SHA256s, explicit cell crops, skin/hair palettes, item mappings, placements and pose joints. Never overwrite a sheet and silently accept a new hash. Inspect the new artwork, update its registry and rebuild layers and previews together.

## Prompt set

Shared direction: original Korean casual-game chibi paper-doll art; clean tapered dark outlines, restrained flat cel shading, front view, transparent background, isolated components, no labels, no checkerboard or drop shadows. The illustrated concept is the style reference; no 3D appearance. Preserve clean attachment areas and consistent proportions.

The two later standalone corrections use only the original body sheet (heart hands) and an assembled original Westory character (headphones) as references. The source atlas is not loaded at runtime. Cropped/recolored transparent WebP parts and the explicit manifest live in `public/avatar/v2/`. Eyes, garment accents and hair ribbons are separate from skin/hair recoloring. Static catalog captures are generated by the same 2D renderer as the studio.

```powershell
node scripts/build-avatar-2d-assets.mjs --spec scripts/avatar-2d-art-registry.json
node scripts/render-avatar-item-previews.mjs
```

Quality acceptance includes actual assembled characters at UI sizes, all poses and item categories; a valid image file or matching hash alone does not establish a good fit.
