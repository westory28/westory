정확한 요청 프롬프트와 모델 설정은 `prompts.json`에 기록했다. 포즈 순서는 기본·인사·응원·생각·하트·반복 기본이다. 고개 갸웃은 기본 몸과 기존 머리 그룹 회전을 사용한다. 원본의 투명 영역 RGB는 제거 대상 배경이 아니며 알파 채널을 보존한다.

당시 원화를 등록·분리하던 `register-avatar-outfits`와 `build-avatar-2d-assets` 도구는 미니미 전환으로 삭제했다. 현재 `scripts/render-avatar-item-previews.mjs`는 새 픽셀 작화 함수로 모든 품목의 미리보기를 만든다.
