정확한 요청 프롬프트와 모델 설정은 `prompts.json`에 기록했다. 포즈 순서는 기본·인사·응원·생각·하트·반복 기본이다. 고개 갸웃은 기본 몸과 기존 머리 그룹 회전을 사용한다. 원본의 투명 영역 RGB는 제거 대상 배경이 아니며 알파 채널을 보존한다.

`scripts/register-avatar-outfits.mjs`는 기존 목·허리·발목 기준으로 원화를 등록하며 새 원화의 피부 영역을 목·손에 한정해 주황색 학교 문양을 피부색으로 바꾸지 않는다. `scripts/build-avatar-2d-assets.mjs`로 의상과 무손실 피부 마스크를 생성하고 `scripts/render-avatar-item-previews.mjs`로 모든 선택지 미리보기를 갱신한다. 원본은 개발 자료이며 앱은 필요한 WebP 레이어만 읽는다.
