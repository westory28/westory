## 명부 승인 정책과 추가 실증

사용자는 신규 학생 등록을 **교사가 명부를 확인한 뒤 승인**하는 방식으로 확정했습니다. 새 프로필은 PENDING으로 생성하며, 교사가 학급·번호·이름을 확정한 후 현재 학적과 빈 Wis 계좌를 준비하고 APPROVED로 전환합니다. 중간에 실패하면 APPROVED_PENDING_ACCOUNT에서 이어서 처리합니다. 초기 지급은 하지 않으며, 승인 전 수업·성적·파일·업무 명령 접근과 학생의 자기 승인·승인 표시 제거를 차단합니다. 승인 정보가 없는 기존 학생은 보존합니다.
