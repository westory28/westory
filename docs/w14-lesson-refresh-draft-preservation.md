# 수업 자료 재조회 중 답안 보존

같은 계정·학기·단원에서 config 객체나 제목, 동등한 lessonOverride가 바뀌면 수업을 다시 읽으면서 본문 DOM과 학습지 답안 state를 초기화하던 문제를 수정했습니다.

## 동작

- 동일한 자료를 다시 읽는 동안 기존 편집 화면과 답안, 저장 revision, 진행 중인 요청을 유지합니다. 제목은 따로 갱신하고 이미 복원한 답안을 다시 읽지 않습니다.
- 조회 실패는 현재 화면 위에 안내와 재시도를 표시합니다. 늦게 도착한 이전 조회 결과와 다른 답안 문맥의 응답은 적용하지 않습니다.
- 자료 동일성에는 revision뿐 아니라 본문, 빈칸 정의, PDF 페이지, 핵심포인트, 각주·영상·링크 관련 내용을 포함합니다. revision 0인 legacy 자료도 내용이 다르면 구분합니다.
- 자료 내용이 달라지면 이전 자료 기준의 새 답안 저장·핵심포인트 찾기·보상 요청을 잠급니다. 새 자료를 자동으로 적용하거나 답안 revision을 새로 채택하지 않습니다.
- 확인한 자료가 비공개이거나 조회 결과가 없거나 읽기 권한이 거절되면 기존 본문을 숨깁니다. 결과 없음만으로 삭제라고 단정하지 않습니다.
- 본문을 내리기 전에 현재 본문 입력과 여러 PDF 페이지 답안을 합쳐 보존합니다. `내 답안 내려받기`는 학생이 작성한 값만 TXT로 저장하며 자료 HTML, 정답 정의, 계정 ID, 판정 상태를 넣지 않습니다. 자료 변경 후에는 답안을 보관하고 수업 목록에서 자료를 다시 열도록 안내합니다.
- 이미 전송된 저장의 늦은 성공은 이전 요청의 결과라고 구분합니다. 자료 확인 잠금과 보존된 초안은 풀지 않습니다.
- 저장하지 않는 교사 미리보기는 실제 자료 변경 시 새 자료를 반영합니다. 동등한 객체 교체 때문에 입력을 지우지는 않습니다.

## 구현 경계

LessonContent의 세션별 loadedLesson과 자료 상태를 사용합니다. 자료 재조회로 answerContext를 바꾸지 않으며 계정·학기·단원이 바뀔 때는 각 세션을 분리합니다. StrictMode의 effect 정리·재실행에서도 조회 전에 유효한 세션이 준비되도록 합니다.

공용 LessonWorksheetStage에는 `corePointInteractionDisabled` 선택 속성만 추가합니다. 기본값은 false이고 학생 풀이 버튼에만 적용하므로 교사 편집과 정상 풀이의 효과는 유지됩니다. 자료 변경 잠금일 때 버튼 클릭 효과와 새 기록 요청이 함께 차단됩니다.

## 검증과 한계

실제 LessonContent·LessonWorksheetStage를 실행하고 Firebase·조회·저장 응답만 제어하는 기존 브라우저 harness를 확장했습니다. localhost 외의 네트워크는 차단합니다.

재조회 중 DOM/state 유지, 실패·중복 재시도, 동등한 override, 제목 갱신, 자료 변경, 공개 중단·결과 없음·권한 거절, 늦은 저장·조회, 저장 payload와 revision, 내려받은 TXT 내용, 여러 PDF 페이지, legacy 자료, StrictMode의 직접 자료/비동기 조회, 미리보기를 확인합니다. 기존 핵심포인트·초기 답안 조회 복구 검사도 함께 실행합니다. 실행 횟수와 배포 증거는 작업 기록에 남깁니다.

실제 Google 로그인, 실제 SDK 초기화 전체와 Staging 학생 저장·보상 수용을 의미하지 않습니다. 별도 중첩 전체 화면과 부모 화면의 초안을 합치는 동작은 이번 범위에서 검증하지 않았습니다. 결과 불명 저장 A 뒤에 새 입력 B를 했을 때 원래 명령 ID·payload를 복구하는 Gateway 작업도 남아 있습니다. 서버 CAS를 완화하거나 읽기로 미확정 쓰기를 해결하지 않습니다.

Functions, Rules, 의존성, 운영 환경은 변경하지 않습니다.
