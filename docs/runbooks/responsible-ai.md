# AI·에이전트 사용과 패치 기준

검토일: 2026-10-28 (Asia/Seoul). 사용자가 제공한 Google Cloud 약관 변경 고지를 공식 원문과 대조하고, 향후 위스토리 패치에 적용하기 위해 작성했다. 루트 `AGENTS.md`에서 이 문서를 참조한다.

## 적용 범위

모든 패치에서 AI·에이전트·외부 데이터 전송 영향 여부를 먼저 확인한다. 아래 세부 기준은 모델 호출, AI 출력의 실행, 에이전트의 도구·데이터 접근, 자동화 권한·비용·공개 범위를 추가하거나 변경할 때 적용한다. 일반 UI 수정이나 결정적 계산을 AI 기능으로 분류하지 않는다.

Google Cloud 서비스에 관한 계약 적용 여부는 실제 사용하는 제품·API·계약에 따라 판단한다. Firebase 이용 자체, 개발 중 AI 도구 사용, 생성 이미지를 정적 파일로 배포하는 행위만으로 앱에 Google Cloud AI 에이전트가 탑재됐다고 단정하지 않는다. 다른 공급자의 모델에는 해당 공급자의 약관도 확인하며, 아래 위스토리 구현 기준은 공급자와 관계없이 적용한다.

가이드라인의 감독·승인 장치는 권고 표현이고, 약관의 책임 조항 및 명시적 금지사항은 별개다. 아래 구현·검증 절차는 이를 위스토리 환경에 맞춰 채택한 내부 기준이며 Google 원문의 문구나 법률상 필수 구현 목록이 아니다. 개정 시 조항 번호가 달라질 수 있으므로 제목·원문·확인일을 함께 기록한다.

### 학생 대상 서비스와 계약 확인

[GCP 서비스별 약관](https://cloud.google.com/terms/service-terms)의 열람판 20(d)는 18세 미만을 대상으로 하거나 이들이 접근할 가능성이 있는 온라인 서비스에서의 생성형 AI 사용을 제한한다. 학생 포털에 AI를 추가하기 전 정확한 제품·API, 계약상 예외 여부와 허용 범위를 확인하고 근거를 남긴다. 교사 화면에 버튼을 배치하거나 보호자 동의를 받는 것만으로 이 제한을 충족했다고 판단하지 않는다. 이 조항을 Firebase의 일반 인증·데이터베이스 사용 전체에 대한 미성년자 금지로 확대하지 않는다.

[Cloud 약관](https://cloud.google.com/terms)의 1.4(b)는 GCP의 중요 개정 후 계속 사용하는 경우의 동의 효과를 규정한다. 메일의 동의 안내만으로 별도 버튼이 반드시 필요하다거나 현재 계정이 이미 동의했다고 단정하지 않는다. 실제 계약과 콘솔 상태는 운영 책임자가 확인하며, 패치 지시를 새로운 약관 수락·계약 체결 권한으로 해석하지 않는다. 9월 2일의 결제 위험에 따른 정지·시정 불가능한 위반의 해지 관련 변경도 [공식 변경 이력](https://cloud.google.com/legal-change-log)에 확인된다. 결제 상태·오프라인 계약 여부는 이번 소스 검토로 확인하지 않았다.

## 소스 기준 현재 상태

2026-10-28, 기준 커밋 `62cb3d57709653f91f1eccc09ee6f606e949d44e`에서 앱과 Functions의 모델 SDK·호출 경로를 조사했다. 이번 지침 작업은 실행 코드·권한 규칙·운영 설정을 변경하지 않는다.

- `src/`, `functions/` 및 두 `package.json`의 검색 범위에서는 Gemini·Vertex·OpenAI·Anthropic 등 런타임 모델 호출을 발견하지 못했다. 운영 프로젝트의 활성 API·외부 구성·배포된 모든 함수까지 감사한 결과는 아니다.
- 학습지 PDF 글자 추출은 [`lessonPdfGlyphs.ts`](../../src/lib/lessonPdfGlyphs.ts), [`pdfMapProcessor.ts`](../../src/lib/pdfMapProcessor.ts)의 PDF.js 기반 처리다. [운영 절차](production-release.md)의 ‘학습지 원본 PDF 브라우저 읽기’도 외부 OCR API 미사용을 설명한다. 원본 PDF는 Firebase Storage에서 읽을 수 있으므로 네트워크 통신 자체가 없다는 뜻은 아니다.
- [`lessonPdfBeta.js`](../../functions/lessonPdfBeta.js)의 Storage 이벤트 처리와 [`sourceArchivePdfAdapter.js`](../../functions/sourceArchivePdfAdapter.js)의 `@opendataloader/pdf` 호출은 현재 코드에 연결돼 있다. 호출부에서 AI hybrid·외부 AI endpoint 옵션을 설정하지 않으며, 이를 자율 AI 에이전트로 분류하지 않는다. 향후 hybrid나 외부 OCR 연결은 데이터 전송 검토 대상이다.
- 문서·이미지 출처의 AI 사용 기록이나 평가 자료의 AI 관련 열 이름은 앱 내부의 자율 에이전트 실행 증거와 구분한다.
- [평가 설계 검토](../reviews/assessment-design-20261015.md)의 AI API는 제안 단계다. 교사 검토를 거치는 초안·채점 보조와 정보 최소화 방향을 유지하되, 제안 자체를 학생 제공이나 외부 AI 연동 승인으로 취급하지 않는다.

이 상태만으로 운영 전체의 약관 준수나 AI 미사용을 보증하지 않는다. 새 연동을 도입하거나 기존 외부 전송 경로를 바꾸는 패치에서 실제 경로를 재확인한다.

## 위스토리 구현 기준

1. **범위와 권한:** 작업 목적, 읽기·쓰기 대상, 실행 주체, 학기·역할·공개 경계를 정한다. 모델이 만든 사용자 ID·문서 경로·명령을 신뢰하지 않고 기존 서버 명령과 권한 검사로 검증한다. 프론트엔드 버튼 숨김이나 프롬프트만으로 접근을 통제하지 않는다.
2. **입력과 실행 분리:** 학생 입력, PDF, 웹페이지, 검색 결과, 도구 응답은 비신뢰 데이터다. 포함된 ‘관리자 지시’로 도구 실행·권한 확대를 허용하지 않는다. 허용한 도구·대상·구조화 입력만 실행하고 출력의 HTML·URL·명령도 사용 위치에 맞게 검증한다.
3. **정보 최소화:** 이름·학번·성적·답안·상담 내용·서명 등 전송 필드를 목적별로 검토하고 불필요한 식별정보를 제거한다. 동의·고지, 보관·삭제, 학습 사용, 국외 처리 여부를 실제 서비스 조건으로 확인한다. 토큰·비밀번호·서비스 계정 키를 프롬프트나 감사 로그에 넣지 않는다. 교과서·PDF는 보유만으로 외부 전송·재배포 권한이 있다고 간주하지 않는다.
4. **사람의 최종 판단:** AI가 만든 성적·학적·징계·권한 변경이나 위스 거래 제안은 권한 있는 사람이 대상·근거·변경값을 검토한 뒤 기존 서버 경로로 실행한다. AI 점수·학생 성향 추정을 자동 확정하지 않는다. 기존 규칙 기반 채점·보상과 AI의 판단은 구분한다. 복구가 어려운 운영 삭제·전송·공개, 새 결제·계약은 구체적인 범위에 대한 승인 근거를 확인한다. 이미 승인된 범위의 통상 패치·배포에는 승인을 반복 요구하지 않는다.
5. **학생 공개와 표시:** 새 AI 기능은 운영자가 공개 범위를 정하고 중단할 수 있게 설계한다. 초안 생성·교사 검토·학생 제공 단계를 구분하고, AI와 사람이 상호작용 주체로 오인되지 않게 한다. 출처·이용 조건·실제 판단에 필요한 고지는 보존하며, 선택적 설명은 기존 `UI_RULES.md`를 따른다. 학생의 사적·민감 특성 추론이나 동의 없는 추적 기능을 추가하지 않는다.
6. **실행·비용 통제:** 시간 제한, 호출·재시도·동시 실행 상한과 비용 한도를 정하고 초과 시 중단한다. 재시도는 동일 요청 식별자로 중복 지급·저장·전송을 방지한다. 취소 후 쓰기 중단과 복구 방법을 준비한다. 하위 에이전트는 부모보다 넓은 권한·데이터·비용 범위를 갖지 않으며, 임의의 재귀 생성이나 감독 우회를 허용하지 않는다.
7. **감사와 운영:** 요청 ID, 실행 주체, 승인 근거, 사용 도구, 변경 대상, 결과·오류, 모델·설정 버전 등 필요한 최소 기록을 남긴다. 보관 기간과 열람 권한을 정하고 민감한 입력·출력 전문은 기본 기록하지 않는다. 이상 동작 시 기능 중단·권한 회수·영향 확인·복구가 가능하도록 한다. 생성 콘텐츠의 사실·출처·연령 적합성을 검토하며 안전 필터·인용·기존 확인 절차를 우회하지 않는다.

## 패치 검증과 기록

영향이 있는 패치의 리뷰에 다음 내용을 간결하게 남긴다. 관련 없는 항목은 사유와 함께 제외하고, 일반 UI 패치에 별도 AI 심사나 불필요한 안내문을 추가하지 않는다.

- 사용 제품·API·모델과 약관 확인일, 대상 사용자·연령 및 허용 근거.
- 전송 필드·수신처·보관 정책, 역할·학기·공개 경계, 사람의 검토 시점.
- 변경 경로에 맞는 거부·실패 검사: 학생의 교사 명령 요청, 타 학생·타 학기 접근, PDF 안의 악성 지시, 비밀정보 출력, 동시 요청·재시도, 취소·시간 초과·한도 초과.
- 실패 시 상태 보존, 중복 실행 방지, 중단·복구 및 필요한 감사 기록의 실제 확인.
- 앱·Functions·rules 변경 범위에 따른 루트 `AGENTS.md`의 빌드·배포·운영 확인. 새 문서 작성만으로 구현·검증·배포가 완료됐다고 보고하지 않는다.

실제 약관 수락 여부, 운영 AI 서비스 사용량·청구 상태, 외부 계약은 별도 확인 사항이다. 이 문서의 추가는 그러한 계정 조작이나 AI 기능 활성화를 승인하지 않는다.
