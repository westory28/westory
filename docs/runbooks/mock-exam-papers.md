# 모의고사 시험지 출제

교사 평가 관리 → 문제 등록 → 모의고사에서 초시(1회), 복시(2회), 전시(3회)를 출제한다. 학생 공개 대상·제한 시간·응시 횟수는 기존 평가 설정에서 관리한다. 회차를 지정한 시험지는 해당 회차의 전체 문항을 문항 번호순으로 사용한다. 학생마다 문항을 임의 추출하지 않는다. 회차를 지정하지 않은 과거 문제은행은 기존 동작을 유지하며, 회차 시험지가 등록된 뒤에는 지정 회차만 새 시험지 출제 대상으로 사용한다.

직접 등록에서는 회차·문항 번호·배점·필요한 쪽 나누기를 지정한다. 객관식은 서로 다른 선지 다섯 개를 작성하며, 짧은 선지부터 같은 길이는 가나다순으로 정렬된다. 정답은 선지 번호가 아니라 선지 원문으로 저장하고, 선지 이미지도 해당 선지와 함께 이동한다. 배점은 0.01~100, 소수 둘째 자리까지 지원한다. 동일 회차의 문항 번호는 중복할 수 없다. 새 쪽은 해당 문항 앞에서 시작한다.

`시험지 미리보기`는 현재 목록 조건에 맞는 문항을 읽어 실제 시험지 렌더러로 보여준다. 회차 선택으로 한 시험지씩 확인하며 정답·해설은 접힌 영역에서 확인한다. 검색·단원 필터가 켜져 있으면 내보내기와 미리보기에도 그 필터가 적용된다.

## JSON으로 패치한 문항 등록

`JSON 양식`을 내려받거나 `JSON 내보내기`로 기존 문항을 추출한 후 내용을 편집한다. `JSON 가져오기`에서는 형식 검증과 전체 시험지 미리보기까지만 진행한다. 교사가 `문항 저장`을 누르면 기존 학기별 교사 저장 명령을 사용한다. 같은 ID는 현재 조회한 revision을 기준으로 수정하고, 다른 ID는 새 문항으로 등록한다. 기존 문항을 삭제하지 않으며 새 회차의 학생 공개를 자동으로 열지 않는다. 이미 공개한 회차는 문항 저장 후 최신 정의로 갱신하므로 저장 전에 미리보기를 확인한다.

```json
{
  "version": 1,
  "questions": [
    {
      "id": 202611060001,
      "type": "choice",
      "examRound": "round_1",
      "paperOrder": 1,
      "points": 4,
      "paperBreakBefore": false,
      "question": "발문을 입력합니다.",
      "passage": "자료 원문을 입력합니다.",
      "options": ["첫 선지", "둘째 선지", "셋째 선지", "넷째 선지", "다섯째 선지"],
      "answer": "첫 선지",
      "explanation": "정답의 근거를 입력합니다."
    }
  ]
}
```

- `id`: 장기간 유지할 고유한 양의 정수. 내용 수정 때 ID를 바꾸면 기존 문항이 남고 새 문항이 추가된다.
- `examRound`: `round_1`, `round_2`, `round_3`. `paperOrder`: 1~200 정수.
- `type`: JSON 입력은 `choice` 또는 `word`. 객관식 정답은 다섯 선지 중 하나와 정확히 일치해야 하고, 단답형 정답은 UTF-16 20자 이하다.
- `image`, `choiceOptionImages`: HTTPS 이미지 주소 또는 PNG·JPEG·WebP data URL. 선지 이미지 배열은 선지 배열과 같은 길이로 작성하고 없는 위치는 `null`로 둔다.
- `concepts`, `cognitiveProcess`, `familyId`, `derivedFromQuestionId`, `reviewLessonId`, `misconceptionTags`: 기존 학습 분석용 메타데이터를 보존한다. `refBig`, `refMid`, `refSmall`은 관련 단원 ID다.
- 파일은 1~200문항·6MB 이하이며 정규화한 문항은 92KiB, 한 회차는 480KiB 이하로 사전 확인한다. 서버의 불변 스냅샷 용량 검증을 최종 기준으로 사용한다. 큰 이미지는 줄이거나 이미 허용된 HTTPS 이미지 주소를 사용한다.

중간 저장 실패 시 성공한 문항 수를 표시하고 `남은 문항 저장`으로 이어간다. 성공한 문항은 반복 저장하지 않으며 기존 명령 영수증을 통해 응답 유실 재시도를 처리한다. 동시 수정으로 revision이 달라지면 목록을 다시 확인한다. 같은 회차의 기존 문항 번호를 맞바꾸려면 먼저 사용하지 않는 번호로 한 문항을 이동한 뒤 차례로 수정한다.

이미 제출한 시험지·답안·점수는 응시 시점 스냅샷을 사용한다. 나중에 문제은행을 수정해도 제출 기록을 새 문제로 바꾸지 않는다. JSON 내용은 교사가 검토할 출제 자료이며 프로그램 실행 지시로 취급하지 않는다. 이 기능은 외부 AI 호출을 추가하지 않는다.

## 검증

- `node scripts/verify-mock-exam-authoring.mjs`: 선지·정답·이미지 동시 정렬, 배점, ID·회차·번호·형식·용량 검증, 메타데이터 내보내기/가져오기.
- `node scripts/verify-mock-exam-authoring-browser.mjs`: 실제 교사 편집기와 합성 서버로 직접 등록·JSON 미리보기·저장 실패와 재시도·읽기 전용·390/768/1280px 확인. 운영 학생·시험 자료를 사용하거나 변경하지 않는다.
- 전체 서버 채점·학생 제출·마이페이지 통합 검증과 운영 배포는 현재 패치의 공통 검증 기록을 따른다.
