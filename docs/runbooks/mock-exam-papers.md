# 모의고사 시험지 출제

교사 평가 관리 → 문제 등록 → 모의고사에서 초시(1회), 복시(2회), 전시(3회)를 출제한다. 학생 공개 대상·제한 시간·응시 횟수는 기존 평가 설정에서 관리한다. 회차를 지정한 시험지는 해당 회차의 전체 문항을 문항 번호순으로 사용한다. 학생마다 문항을 임의 추출하지 않는다. 회차를 지정하지 않은 과거 문제은행은 기존 동작을 유지하며, 회차 시험지가 등록된 뒤에는 지정 회차만 새 시험지 출제 대상으로 사용한다.

`문제 등록`에서 회차·문항 번호·배점과 문항을 입력한다. 객관식은 서로 다른 선지 다섯 개를 작성하며, 짧은 선지부터 같은 길이는 가나다순으로 정렬된다. 정답은 선지 번호가 아니라 선지 원문으로 저장하고, 선지 이미지도 해당 선지와 함께 이동한다. 단답형 정답은 20자 이하이며 배점은 0.01~100, 소수 둘째 자리까지 지원한다. 동일 회차의 문항 번호는 중복할 수 없다.

`미리보기`는 선택 회차의 전체 문항을 실제 시험지 렌더러로 보여준다. 목록 검색이나 관련 단원 필터로 문항이 숨겨져도 미리보기에서는 빠지지 않는다. 전체 회차를 선택한 경우 미리보기 안에서 회차를 바꾸며 정답·해설은 접힌 영역에서 확인한다. 미리보기는 자료를 저장하거나 학생 공개 상태를 변경하지 않는다.

페이지 수와 문항 배치는 글꼴·자료·이미지의 실제 높이에 따라 자동으로 조정한다. 문항은 단이나 쪽 사이에서 잘리지 않으며, 한 단보다 긴 문항은 페이지 높이를 늘려 보존한다. 수동 쪽 나누기는 사용하지 않고, 과거 문항에 저장된 쪽 나누기 값도 배치에 적용하지 않는다. JSON 가져오기·내보내기·양식 기능은 제공하지 않는다.

문항 저장은 기존 학기별 교사 저장 명령을 사용하며 공개 중인 평가는 최신 정의로 갱신한다. 이미 제출한 시험지·답안·점수는 응시 시점 스냅샷을 사용한다. 나중에 문제은행을 수정해도 제출 기록의 문항이나 채점 결과를 바꾸지 않는다. 이 기능은 외부 AI 호출을 추가하지 않는다.

## 일러스트 문항 제작 기준

사용자 지시(2026-11-07)에 따라 이후 제작·수정하는 시험용 일러스트에도 다음 기준을 항상 적용한다. 이 기준은 자료 이미지 제작 기준이며 앱의 AI 호출·학생 공개·기존 제출 기록을 변경하는 지시가 아니다.

- `(가)`, `(나)` 등 빈칸의 너비는 표시 기호 자체가 아니라 그 자리에 들어갈 **정답 원문**을 실제 본문 글꼴·크기·장평·자간으로 조판해 측정한다. 테두리 바깥 너비는 정답의 조판 너비에 공통 좌우 안쪽 여백을 더한 값으로 정한다. 인명뿐 아니라 지명·제도·사상 등에도 같은 원칙을 적용한다. 글자 수만 곱하거나 모든 문항에 같은 너비를 쓰지 않는다.
- 빈칸 안에는 `(가)` 등의 기호만 수평 가운데 정렬하고, 정답 자체는 학생용 이미지에 넣지 않는다. 조사는 테두리 밖에 둔다. 빈칸 너비를 바꾼 뒤 어절 단위 줄바꿈과 말풍선 크기를 다시 계산한다.
- 교사·해설자 등 인물이 자료를 가리키며 설명하면, 그 자료를 **TV·모니터·슬라이드 화면·칠판·게시 자료 등 장면 안의 매체**에 담는다. 설명자의 시선·손짓·지시봉 방향과 매체 위치를 맞추고 역사 장면을 공중에 떠 있는 실물처럼 나란히 놓지 않는다.
- 예시의 삽화와 설명자 비율을 따른다. 설명자를 구석의 작은 장식으로 만들지 않으며, 말풍선 꼬리는 실제 화자를 향하게 하고 얼굴·손·핵심 자료를 가리지 않게 배치한다.
- 한 묶음의 문항은 같은 본문 글꼴·크기·행간·장평·자간과 왼쪽 안쪽 여백을 사용한다. 각 말풍선은 실제 줄 수와 글자 너비에 맞춰 조절하고 필요한 최소 여백만 둔다. 짧은 문구에 긴 문구용 빈 말풍선을 그대로 사용하지 않는다.
- 발문·선지와 가운데 자료 이미지를 구분해 제공한다. 글상자·빈칸·말풍선은 제작자가 직접 완성 이미지에 조판하며, 사용자에게 한컴 등에서 배치나 크기를 다시 맞추도록 요구하지 않는다. 문구는 별도로 복사할 수 있게 제공한다.
- 납품 전에 모든 문항의 정답 너비 측정, 기호 가운데 정렬, 어절 보존, 원문 일치, 매체 안 자료 표시, 손짓 방향, 인물 비율, 말풍선 여백과 가림을 각각 확인한다. 미공개 문항·정답·개인 자료는 제작 지침과 함께 공개 저장소나 학생용 서비스에 올리지 않는다.

## 검증

- `node scripts/verify-mock-exam-authoring-browser.mjs`: 실제 교사 편집기와 합성 서버로 직접 등록·전체 시험지 미리보기·자동 페이지 배치·읽기 전용·390/768/1280px 확인.

검증에는 운영 학생·시험 자료를 사용하거나 변경하지 않는다.
