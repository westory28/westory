# 학생 접속 운영 기준 (2026-09-12)

사용자 최신 지시: 학생 접속은 닫아 두며, 사용자가 열어 달라고 명시적으로 요청하기 전에는 열지 않는다. 배포·학기 전환·검증 완료를 이유로 자동 해제하지 않는다. 기존 2학기 전환 보고서의 접속 재개 상태보다 이 지시를 우선한다.

- 운영 프로젝트: `history-quiz-yongsin`
- 제어 문서: `site_settings/student_maintenance`
- 이번 요청 직후 확인한 상태: `enabled: true`, `revision: 7`, `bypassUids: []`
- 관리자 화면: `#/teacher/settings?tab=student-access`
- `enabled: true`는 학생 접속 **닫힘**을 의미한다.
- 변경은 기존 관리자 계정의 명시적 확인 버튼에서만 실행한다. 서버 관리자 권한·최근 본인 인증·애플리케이션 세션·App Check 검증을 유지한다.
- 열기·닫기 모두 예외 학생 목록을 비운다. 닫기 후 다시 열기 전까지 차단을 유지하며, 기록은 삭제하지 않는다.
- 저장 응답이 유실되면 자동으로 다시 실행하지 않는다. 현재 상태를 서버에서 다시 조회한 뒤 판단한다.
- 관리 화면의 열기 동작 검증은 외부 연결이 차단된 합성 fixture에서 수행한다. 운영 학생 접속을 열어서 검증하지 않는다.
