# 이용약관·개인정보 처리방침 개정 검토 — 2026-10-28

## 현재 상태

이 폴더의 `terms.html`, `privacy.html`은 당시 **미공개 검토안의 보관본**이다. 최종 문서는 `src/content/legal/terms.html`, `src/content/legal/privacy.html`이며, 공개·운영 반영 기록은 `docs/reviews/legal-policy-publication-20261028.md`를 따른다. 아래의 게시 전 확인사항과 보호조치 검증은 작성 당시의 조사 기록이며, 최종 판단·해결 여부는 새 게시 기록에 정리한다. 초안을 `public/`이나 기본 정책으로 연결하지 않는다.

`terms.previous.html`, `privacy.previous.html`은 이날 공개 문서에서 읽은 이전 전문이다. 원본 수정 시각과 SHA-256은 `previous-manifest.json`에 남겼다. 이 파일들은 새 정책이 아니라 개정 전후 검토용 보관본이다.

운영자의 답변:

- 방재석 개인 운영. 학교운영위원회 승인, 에듀집 개인 제작 서비스 등재.
- 만 14세 미만 보호자 동의는 학교에서 학운위 승인으로 대체하여 운영.
- 별도 개인정보 처리위탁 계약·협약이나 학교 방침의 수탁자 기재는 없고 학운위 승인만 받음.
- 학생 계정·학습·성적 기록은 **용신중학교 졸업일까지 보관**하도록 운영자가 확정(2026-10-28). 초안 제6항 및 약관 제12조에 반영했다. 처리 목적이 먼저 끝난 자료, 조기 이용 종료와 법령상 별도 보존은 구분한다.

현행 기준은 2026-10-28 현재 시행 중인 개인정보 보호법(2026-09-11 시행, 법률 제21445호)이다. 2027-03-09 시행 AI 관련 특례는 적용 근거로 사용하지 않았다.

## 게시 전 해결할 사항

1. **처리 주체와 근거**: 현재 정보만으로 개인 운영자의 처리를 학교의 법정업무로 일괄 분류하지 않는다. 학교가 개인정보처리자가 되어 적법하게 업무를 위탁하는 구조라면 실제 계약·지시·공개·감독 범위를 마련해야 한다. 개인 운영 구조를 유지한다면 각 목적에 적용되는 동의 또는 다른 적법한 근거를 구분해야 한다. 이를 단순 약관 문구로 소급 변경하지 않는다.
2. **만 14세 미만**: 동의를 근거로 하는 처리는 법정대리인의 동의·확인이 필요하다. 현재 가입란의 학생 자기확인만으로 검증된 보호자 동의로 보지 않는다. 닉네임 가입도 결합하여 식별 가능하면 개인정보 처리에 해당한다. 학교 승인 사실만으로 위법 여부를 단정하지 않되, 보호자 동의의 포괄 대체 근거가 확인됐다고 기록하지 않는다.
3. **보유·파기**: 목표 기간은 용신중학교의 실제 졸업일까지로 확정했다. 현재 방침의 ‘학년도 종료/교사 정리 시’ 및 가입문 ‘즉시 또는 1년’보다 길어지는 동의 기반 정보는 개인정보 보호법 제15조제2항에 따른 기간 변경 동의를 반영해야 한다. 전학·탈퇴 등으로 목적이 먼저 끝난 정보와 졸업 후 정보는 지체 없이 파기하고, 법령상 보존은 해당 항목·법령·기간을 특정한다. 원본/파일/이전 학기/백업 정리 절차와 보안 로그별 최소기간은 여전히 확정이 필요하다. 이 패치에서 운영 학생 자료를 삭제하거나 기존 동의 기간을 연장하지 않았다.
4. **국외이전**: 실제 수신자·국가·처리/보유 조건 및 거부방법을 완성해야 한다. Vercel 현재 팀 플랜은 Hobby로 확인됐다. Pro/Enterprise에 관한 DPA의 processor 조항을 현재 계약으로 단정할 수 없다. 공급자의 글로벌 시설 목록을 학생 정보가 이전되는 모든 국가로 복사하지 않는다.
5. **기존 가입문과 실제 수집 범위**: 기존 가입 동의문은 가명·닉네임 중심인데 실제로 학교 이메일·실명도 사용한다. 단순 방침 수정만으로 과거 동의 범위 문제가 해결됐다고 표시하지 않는다. 구체적인 동의가 필요하다면 목적·항목·기간·거부권/영향을 구분하여 개정하고, 필요한 대상과 기능에 한정한 절차를 설계한다.

학교에 확인할 내용(아직 발송하지 않음):

> 위스토리는 개인 제작·운영 서비스로 학운위 선정 승인을 받았으나, 별도 개인정보 처리위탁 계약과 법정대리인 동의 절차는 없습니다. 학생 계정·학습·평가 자료 처리에 대해 학교를 개인정보처리자로 하는 위탁 구조를 적용할 수 있는지, 적용할 경우 위탁 범위·문서·관리감독·국외 처리 요건과 항목별 보존기간을 확인 부탁드립니다. 학운위 심의가 법정대리인 동의를 대신한다는 별도 근거를 적용하고 있다면 해당 법령·교육청 지침의 조항도 확인 부탁드립니다.

## 현행 공개 문서와 실제 코드 대조

- 실제 본문은 Firestore `site_settings/terms`, `site_settings/privacy`의 `text`다. 소스의 기본 문구만 바꾸면 운영 본문은 바뀌지 않는다.
- 기존 이용약관은 무료 서비스·외부 장애에 관한 넓은 면책과 모든 콘텐츠의 교사 귀속 문구가 있다. 개정안은 관계 법령에 따른 책임과 원저작자·학생의 권리를 구분한다.
- 기존 개인정보 방침의 ‘학교 교육활동 절차’와 ‘학교 규정·감사’는 개인 운영의 일괄 처리·보존 근거로 쓰지 않는다.
- 기존 방침은 프론트엔드 호스팅을 Firebase Hosting으로 설명하지만 실제 운영은 Vercel이다.
- 기존 방침은 평가 서명이 이의 포기가 아니라고 정하나 화면은 이의 없음에 동의하도록 요구했다. 해당 문구를 수정하고 서명 완료 화면에서도 공개 연락처로 문의할 수 있게 한다. 서명 데이터·반려·서버의 온라인 추가 신청 제한은 바꾸지 않는다.
- Firebase Analytics가 동의와 관계없이 자동 초기화되며 다른 코드에서 해당 export를 이용하는 호출은 찾지 못했다. 자동 초기화를 제거한다. 기능별 학습 기록·보안/App Check·인증은 유지한다. 과거 쿠키나 수집 데이터가 자동 삭제됐다고 주장하지 않는다.
- 이번 패치에는 AI 실행이나 새 외부 전송을 추가하지 않는다. `docs/runbooks/responsible-ai.md`의 새 전송·연령 제한 검토 기준을 유지한다.

## 동의·로그인 판단

- 방침의 문구 정비·연락처 정정·권리보호 보완마다 전체 학생 재동의를 요구하는 것은 아니다.
- 개인정보 보호법 제15조·17조 등에 따라 동의를 받은 사항의 변경이라면 필요한 동의를 별도로 받는다.
- 이번 보유기간의 ‘학년도 종료 → 졸업일’ 연장은 단순 문구 정정과 구분한다. 학생별 기존 동의 내용·기간을 확인하고, 연장 동의가 필요한 정보에 한정하여 새 기간·목적·거부 시 영향을 고지한다. 만 14세 미만의 동의가 필요한 처리는 법정대리인 동의·확인을 거친다. 연장에 동의하지 않았다는 이유만으로 모든 기본 학습 기능의 로그인을 일괄 차단하거나 기존 기간을 넘어 보관하지 않는다.
- 제22조에 따라 비동의 처리의 근거와 항목, 필수·선택 처리를 구분한다. 계약 이행이라는 문구만으로 모든 학습·공개·분석 처리를 묶지 않는다.
- 이번에 정책 버전만으로 기존 `privacyAgreed`를 초기화하거나 전체 로그인 차단을 추가하지 않는다. 필요한 법정대리인 동의를 학생의 ‘동의합니다’로 대체하는 팝업도 추가하지 않는다.
- 동의 절차를 추가할 경우 실제 문구·버전·대상·일시와 동의 주체 확인을 기록하고, 방침 열람·권리행사·탈퇴 문의는 로그인 제한 밖에서도 가능해야 한다.

## 보호 조치 검증

2026-10-28 보유기간 후속 수정은 위 초안·검토 문서만 변경한다. 학생 데이터·학적·동의 기록·파기 기능 및 운영 Firestore 본문은 변경하지 않는다. 이전 공개 문서와 해시 보관본은 그대로 보존한다. 문서 변경의 HTML 구문, 잔여 미정 문구, diff를 확인하며 앱 빌드·배포로 문서가 게시됐다고 보고하지 않는다.

- `npm run build` 통과: TypeScript, 인증·세션·학기 보관 및 기존 prebuild 검사 포함. 수행평가 XLSX의 `hair` 테두리 회귀 검사 통과.
- `verify-performance-score-contracts.mjs`, `verify-score-objection-client-contracts.mjs`, 변경 TS/TSX Prettier, `git diff --check` 통과.
- 실제 `ScoreConfirmationView`를 기존 테스트의 가상 학생·서비스로 렌더링하여 방재석 Chrome 프로필에서 확인. 운영 학생 데이터나 서명을 만들지 않음.
- 390×844, 768×900, 1280×900, 1366×768에서 문서 가로 넘침 없음. 서명 완료 시 `정정·이의 문의` 링크와 44px 높이, 정기시험 서명창의 권리 보존 문구 확인. 포털 탐색 구조 변경 없음.
- 기존 전체 브라우저 테스트는 최신 공통 헤더의 WebP 로더·서비스 모의 export 누락으로 실행되지 않았다. 임시 수정은 되돌렸으며 테스트 파일은 커밋하지 않는다. 변경된 실제 점수 컴포넌트만 분리한 로컬 fixture로 위 화면 검증을 수행했다. 전체 브라우저 회귀 테스트 통과로 보고하지 않는다.
- 소스에서 Analytics 실행 경로를 재검색하여 타입 import와 번들 분류 설정만 남음을 확인. 인증·App Check·학습 기능의 기록은 변경하지 않음.
- 원본/개정 HTML 구문 검토와 법적 문구 재검토 완료. 초안은 공개 경로에 포함하지 않는다.
