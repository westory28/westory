## 적용 범위

- 학생·교사, 데스크톱·모바일의 30일 배지와 수동 연장 버튼, 관련 CSS·표시 상태를 삭제한다. 프로필·알림·로그아웃은 유지한다. 새 디자인 토큰이나 컨테이너는 없다. 사용자 요청에 따라 DESIGN.md의 기존 countdown/extension 표시 계약도 갱신한다.
- 유효한 세션의 화면 진입·복귀, 신뢰된 wheel·touchstart·keydown을 활동으로 추가한다. 기존 입력·클릭·포인터 활동도 유지한다. `scroll`은 자동 스크롤도 발생시키므로 활동으로 등록하지 않는다.
- 기간이 지난 세션을 재방문으로 되살리지 않는다. 숨겨진 탭, 정기 검사, 다른 탭의 저장소 이벤트는 활동으로 갱신하지 않는다. 만료 처리 직전에 현재 사용자·인증 시각·공유 만료값을 다시 검사한다.
- 활동 저장은 기존 30초 제한을 유지한다. 활동마다 추가 토큰/서버 요청이나 React 상태 갱신을 하지 않는다. 60초 정기 검사는 표시를 렌더링하지 않고 로컬 만료값만 확인한다.
- 읽기는 되지만 저장 공간 부족으로 쓰기가 실패하면 현재 페이지에서 갱신값을 유지한다. 다른 탭의 변경·삭제·새 로그인은 우선하며 저장 복구·로그아웃 시 임시 상태를 지운다.

Login, AuthContext, authStartup, Firebase persistence, 서버 세션 프로토콜, 민감 작업 재인증, 역할/학기/학생 승인·공개 권한, Functions와 rules는 변경하지 않는다. 일반 작업에 재인증을 추가하거나 실패한 쓰기를 자동 재전송하지 않는다. 기존 `sessionExpiry` 마이그레이션과 이전 학기 읽기 전용 창 예외도 유지한다.
