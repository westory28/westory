# 학습지 글자 선택 규칙 분리 — 2026-10-12

## 문제와 변경

기존 `selectLessonTextDrag`는 문자 선택과 빈칸의 이웃 획 보호를 동시에 수행했다. 따라서 읽을 수 있는 글자도 빈칸 마스크를 만들지 못하면 드래그 표시와 답안이 함께 사라졌다. 선택한 글자들의 높이로 간격을 판정하여 부분 범위에 따라 기준이 달라질 수도 있었다.

- 원본 PDF에서 얻은 글자를 페이지별로 고정된 줄·문자 순서·간격 기준에 배치한다. 배열과 페이지별 인덱스를 캐시한다.
- 포인터의 시작·끝을 문자 중심을 기준으로 한 캐럿 인덱스에 대응시키고 그 사이의 연속 글자만 선택한다. 단어·조사·고유명사 목록이나 예외 분기는 없다.
- `selectLessonText`와 `selectLessonTextDrag`는 문자 선택만 반환한다. 마스크 획 정보의 유무나 가림 성공 여부가 선택 결과를 바꾸지 않는다.
- `createLessonTextBlank`는 드래그 완료 후 한 번 호출하며 선택 문자·순서·답안을 변경하지 않는다. 기존 이웃 획 보존과 정밀 다각형 계산은 유지한다.
- 안전하게 가릴 수 없으면 저장하지 않고 파란 선택 표시와 선택 문자를 유지하며, 빈칸 생성 실패 이유를 표시한다. Escape·새 드래그·페이지/도구 전환으로 해제한다.
- OCR에서 기존 빈칸 위를 드래그할 수 있다. 움직이지 않은 클릭과 키보드 활성화는 기존 편집을 유지한다. 드래그 후 시작점으로 돌아와도 클릭으로 바뀌지 않으며 다른 포인터가 현재 드래그를 종료할 수 없다.

AI·외부 OCR API·백엔드·저장 형식은 변경하지 않았다. 학생 빈칸은 기존 저장된 사각형/정밀 경계를 그대로 사용한다.

## 검증

- `npm run build`: 타입 검사, 학기 보호, 원본 엑셀 테두리 검사, 학습지 관련 회귀, Vite 빌드 통과.
- 원칙 검사: 자간·겹침·문장부호 높이·문자 치환·입력 배열 순서·드래그 방향을 바꾼 11,568회 드래그와 2,631회 사각형 선택 통과. 실제 `춘추관`의 모든 연속 부분 문자열 포함.
- 가림 실패 6조건에서도 원래 선택값 보존. 기존 실제 글자 162회, 공유 획 14조건, 정밀 다각형 211조건 등 안전 회귀 통과.
- 독립 검토에서 발견한 큰 장식 글자와 작은 본문이 섞인 줄의 수직 범위 오류를 수정하고, 해당 본문 12글자 정·역방향 24회 통과.
- Stage 검증: 드래그 중 마스크 생성 0회/완료 후 1회, 실패 시 선택 표시·문자·이유 보존, 기존 빈칸 클릭/드래그 구분, 준비 중 편집, 시작점 복귀, 다른 포인터 종료 차단, 키보드 편집 통과.
- 저장·재열기, 교사 제시, 학생 정오답 마스크, 역사교실 전달 회귀 통과.
- 실제 브라우저: 원본 학습지의 `춘추관`에서 `춘추` 드래그 성공. 학생 화면에 빈칸 뒤 `관` 유지. 기존 `이인좌의 난` 빈칸 위 `이인좌` 드래그와 단순 클릭 편집 성공. 선택 중 `이 → 이인 → 이인좌`, `춘 → 춘추` 실시간 표시 확인.
- 학생 프레임 390·768·1280px에서 정밀 경계와 입력 표시 확인.

## 범위

검사는 공통 원칙의 회귀 확인이며 개별 단어를 허용 목록에 등록하지 않는다. 현재 원본 데이터에는 명시적 공백/문자 advance가 없으므로 실제 글자 위치와 줄 높이로 단어 간격과 떨어진 표 셀을 구분한다. 기존 1.5배 줄 높이보다 큰 간격의 연속 선택 제한은 유지한다. 모든 스캔 PDF나 완전히 겹친 글자의 안전한 가림을 보장하지 않으며, 인식된 글자 선택과 안전한 빈칸 생성의 결과를 구분한다.
