## 구현 범위

교사 문항 등록에서 단원 선택 바로 아래에 성취기준을 선택한다. 단원의 가장 세부적인 이름이 하나의 기준에 대응하면 자동 연결하고, 대단원만 선택했거나 여러 기준이 걸리면 선택을 요청한다. 교사가 직접 바꾼 값이나 명시적으로 해제한 값은 자동 연결이 덮어쓰지 않는다. 문항의 목표 A–E와 예상 난이도는 학생의 성취수준과 별도 필드로 저장한다.

모의고사 학급 상세의 `성취기준 분석`에서 전체 분포, 문항 통계, 수준별 선택 선지, 성취기준별 배점 가중 성취율, 사전 근거, S–P표를 제공한다. 긴 표는 표 영역에서 가로로 이동한다. 문항 선택은 현재 상세 팝업 안에서 응시 당시 문항·이미지·지문·정답·해설을 보여 주고 분석으로 복귀한다. 과거 원문이 없고 현재 문항만 확인할 수 있는 경우 이를 표시한다.

고정·추정 분할점수나 표본 내 순위로 A–E를 자동 배정하지 않는다. 학생별·성취기준별 수준은 재구성 준거와 모의고사 이전의 확정된 진단·형성평가 근거를 교사가 확인해 별도 분석 프로필로 저장한다. 미응시·미확인·근거 부족은 E가 아닌 미분류다. 학습지 채움률과 채운 칸의 정오답은 따로 제시하며, 채움만으로 이해·설명·추론 성취를 인정하지 않는다.

예상 정답률은 해당 학생의 같은 성취기준·목표수준·난이도인 사전 문항에서 산출하고, 대응되는 학생·문항의 실제 정답률과 비교한다. 같은 문항 또는 문항 계열, 힌트 여부 불명, 시점·버전·준거 불명 기록은 독립 예상 근거로 사용하지 않는다. 근거 수와 대응 학생 수를 함께 표시한다. 빈칸 기록은 수정할 수 있는 현재 상태라는 한계를 유지한다.

## 데이터·권한·배포 범위

- 새 분석은 기존 `getQuizClassAnalysis`의 명시적 `achievement` 모드에서 학기·학급·시험 회차 범위를 확인한 후 조회한다. 평소 학급 목록 조회에 추가 읽기나 캐시 쓰기를 넣지 않는다.
- `saveAchievementProfile`은 기존 세션을 검증한 교사·관리자에게만 허용한다. 현재 학기·학급 소속·첫 모의고사 시각·사전 확정 결과·준거 버전·수정 리비전을 서버에서 검증한다. 동시 변경은 충돌로 반환한다.
- 저장 경로는 `semester_achievement_profiles`이며 기존 성적·보상·서명·이의 처리 상태를 변경하지 않는다. 다른 준거나 변경된 근거에 대한 프로필은 재확인 대상으로 표시한다.
- 원본 문항은 출제 당시 불변 스냅샷을 사용한다. 동일 스냅샷은 응답 사전으로 중복 제거하고 클라이언트에서 복원해 이미지·지문을 보존한다. 버전이 없을 때는 완전한 불변 원문과 sourceHash가 있는 경우에만 원문의 해시로 식별한다.
- 새로운 AI 호출, 에이전트 실행, 외부 학생 자료 전송, 학생 공개 범위·로그인·rules 변경은 없다. 기존 교사 평가 기능 안의 분석 유지보수다.
- 운영 `executeCommand` 원본은 조사 기준 커밋의 런타임 소스와 같음을 확인했다. `getQuizClassAnalysis`는 같은 저장소의 이전 평가 코드가 배포되어 있었으며 최신 운영 executeCommand 소스와 대조했다. 선택 배포 대상은 `executeCommand`, `getCommandStatus`, `getQuizClassAnalysis`다.
