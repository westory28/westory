# 독도 지도 표시 보강 — 2026-10-15

## 변경

- 원본 장부에서 좌표 미확정·범위형으로 분류됐던 독도를 공식 동도 좌표를 가진 `island`로 지도 선별 단계에서 복원했다. 원본 교과서 인용과 원본 위치 기록은 수정하지 않았다.
- 한국사와 지구본의 기본 지리에 `독도 · 대한민국` 점·배지를 우선 표시한다. 단원·시대 필터에 없는 상태에서 눌러도 필요한 필터를 해제하고 1900년 칙령 제41호 설명으로 이동한다. 세계사 평면 목록에는 추가하지 않았다.
- 동도·서도 및 부속 섬의 해안선 86개를 독립 ODbL 자산으로 추가했다. OSM 좌표는 순서 반전 외 그대로이며 원래 작은 섬 윤곽만 대체한다. 윤곽을 확대해 영토 면적으로 표현하지 않는다. 작은 축척의 가독성은 점·배지로 보완한다.
- 출처·라이선스와 way/version/timestamp 기록을 도움말 다운로드에 연결했다. 지형 JSON은 gzip 15.87KB, 기록 JSON은 gzip 1.27KB이다.

## 근거

- [해양수산부 독도의 주소와 위치](https://www.mof.go.kr/doc/ko/selectDoc.do?bbsSeq=27&docSeq=20937&menuSeq=929): 동도 37°14′26.8″N / 131°52′10.4″E, 서도 37°14′30.6″N / 131°51′54.6″E.
- [국사편찬위원회 대한제국 칙령 제41호](https://contents.history.go.kr/front/hm/view.do?levelId=hm_122_0020): 1900년 10월 25일 재가, 27일 관보 게재와 울도군의 독도 관할.
- [국회도서관 독도의 위치](https://dokdo.nanet.go.kr/dokdo/front.dokdo?menu=position), [외교부 독도의 구성 및 위치](https://dokdo.mofa.go.kr/kor/introduce/location.jsp): 현재 주소와 섬 구성.
- 해안선 원본·가공 기록은 `src/data/atlas/dokdo-islands.sources.json`, 재생성 도구는 `scripts/build-history-atlas-dokdo.py`에 있다. 지도에 표시하는 한국어 명칭·관할은 공식 한국 자료에 따르며 해안선 데이터와 분리했다.

## 검증

- `npm run build`, `npm run format:check`, `npx tsc --noEmit`, `git diff --check` 통과.
- 선별 데이터 140곳(한국사 61·세계사 79), 역사 설명 284개, 유효 관련 연결 83개. 원본 2,639곳 장부 보존.
- 실제 컴포넌트 로직으로 평면 지도 밀집 배치 10개, 지구본 draw 상태 12개, 필터 밖 클릭과 과목 전환·물결 강조·뒷면 숨김을 검사했다. 기존 카메라·지역·출처 검증도 통과했다.
- 모든 해안선의 원좌표를 OSM snapshot과 대조했다. 공식 동도·서도 지점 모두 육지 안에 있으며, 구면 계산 면적 약 192,739㎡로 실제 비례를 유지한다. 이는 OSM 해안선 면적이며 공식 고시면적을 대체하는 수치가 아니다.
- Chrome 실제 화면 1440px에서 한국사 기본 독도 배지와 점 클릭, 320px에서 독도 설명·위치 물결·배지 강조 및 고려 필터 해제 후 1900년 이동을 확인했다. 320px 지구본 세계사 선택 중 독도 배지를 Enter로 선택하면 한국사로 이동했다. 768px에서 설명과 지도 배치 및 키보드로 반대편 회전 시 배지 숨김을 확인했다.
- 로컬 화면 증거: `output/dokdo-local-korea-320.jpg`, `output/dokdo-local-globe-768.jpg`. 학생·교사 공통 렌더러만 변경했고 인증·권한·서버 저장 경로는 변경하지 않았다.
- 독립 리뷰에서 발견한 출처 기록의 배포 연결 누락을 수정했다. 빌드 산출물에 지형·출처 JSON이 모두 포함됨을 확인했다.
