## 반영 내용

게임 안의 일반 문구·숫자·버튼은 연성체, 판정·결과 제목은 독도체를 사용한다. 둘 다 SIL OFL 1.1 무료 글꼴이며 원본 저작권과 라이선스 전문을 파일 및 WOFF2 메타데이터에 보존한다. 외부 글꼴 서비스 호출은 추가하지 않는다. 자세한 출처·고정 해시·글리프 검사는 [글꼴 검토](rhythm-fonts-20261115.md)에 기록했다.

`지화자 좋다!` > `얼씨구` > `좋다` 순으로 판정 글자를 크게 표시하고, 미스는 주홍색 `어이쿠`로 표시한다. 결과 화면에도 같은 글꼴·크기 순서·색을 적용한다. 높이 360px 이하에서는 결과 제목과 점수를 나란히 배치하고 곡 선택 패널을 위로 정렬해 시작·재도전 버튼을 가리지 않는다. 포털 제목과 교사 공개 제어는 기존 공통 글꼴을 유지한다.

노트의 판정 구간 중 손·타격 종류·시점이 맞지 않는 입력은 0점 미스로 처리하고 콤보를 초기화한다. 잘못 친 뒤 220ms 안에 다시 치면 미스이며 대기 시간이 다시 시작된다. 계속 연타하면 다음 노트까지 놓친다. 정상적인 연속 입력에는 간격 제한을 두지 않는다. 첫 판정 구간 전과 마지막 판정 구간 후의 연습 타격은 벌점이 없다. 놓친 노트도 미스로 계산하며 정확도 분모는 노트 수와 전체 판정 수 중 큰 값이다.

## 검토에서 보완한 경계

1. 가까운 뒤 노트를 먼저 고르면 휘모리의 정상적인 늦은 입력이 앞 노트를 놓칠 수 있었다. 판정 구간 안의 가장 앞선 같은 손·종류 노트를 우선 처리한다.
2. 이전 곡의 늦은 일시정지 실패가 새 곡을 중단하지 않도록 플레이어와 세대 값을 확인한다. 재개 실패 시 해당 플레이어를 정리하고 곡 선택에서 다시 시작할 수 있게 한다.
3. 오디오 재개가 4초 제한 뒤 늦게 성공해도 이전 연결을 닫는다. 이미 시작한 새 곡의 오디오 연결은 보존한다.

독립 검토자는 세 수정 모두 재검증했고 차단 사항이 없음을 확인했다.

## 검증

- 코어: 4곡·3장단 전체 노트의 정확한 입력, +159/+160ms 늦은 입력, 139~160ms 시차 변화, 잘못된 손·종류, 연타 지속/회복, 점수·콤보를 검사했다. 220ms보다 빠른 정상 노트도 모두 처리한다.
- 실제 오디오 클래스: 재개 실패·시간 초과·늦은 성공·새 곡 교체·종료 경합을 합성 AudioContext로 검사했다.
- 브라우저 10그룹 통과: 실제 게임·진입 컴포넌트·Web Audio를 사용하고 계정과 공개 서비스만 합성했다. 판정별 글꼴·크기·색, 실제 키 연타, 회복·정지·재개·재도전, 회전 후 터치, 점수 이동 효과, 장단·곡의 선택 색, 작은 화면의 버튼 가림을 검사했다. 1440×1000, 1280×900, 768×1024, 390×844, 320×760, 844×390에서 통과했고 브라우저 오류·외부 요청은 0건이었다.
