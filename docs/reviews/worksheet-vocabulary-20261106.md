# 현재 학습지 중심 사전·지도 보강

확인일: 2026-11-06. 작업 기준과 당시 운영 커밋: `d691a922f1b1ab5164ca0a5dc8c4b369cf9d8d68`.

현재 설정과 활성 학기 포인터에서 2026년 2학기를 확인했다. 학기별 `lessons`의 PDF 학습지 13개 모두 현재 교육과정에 연결되어 있었고, 루트 레거시 `lessons`는 비어 있었다. 저장된 PDF 글자 영역 2,109개와 교사가 지정한 빈칸 475개(고유 답 346개)를 대조했다. 제목·빈칸만 살핀 이전 검토에서 더 나아가 저장된 본문 전체의 지명·제도·인물·독해 어휘를 검토했다. 원본 PDF 이미지의 재판독이나 새 OCR을 수행한 것은 아니다. 파일별 제목·범위·해시는 [조사 기록](worksheet-vocabulary-source-20261106.json)에 남겼다.

## 수록 판단

새 역사·독해 용어 112개와 지명 4개, 총 116개를 추가했다. 기존 항목 13개에는 지명 설명·분류·출처 또는 검색 별칭을 보강했다. 카탈로그는 3,377개에서 3,493개(역사 1,237개·지명 2,256개), 출처는 5,270건이 된다. 기존 항목의 ID·지도 연결·출처는 모두 보존했다.

- 신문고, 책봉, 재조지은, 병마절도사, 공법, 결수, 탁지지 등 학습지의 핵심 개념과 본문 속 인물·제도를 보강한다.
- 상소, 보급로, 전황, 의례, 탐관오리 등 독해를 돕는 말도 짧은 독자 풀이로 수록한다. 일반어를 조선에만 한정하거나 특정 지역의 용어로 분류하지 않는다.
- 기존 표제어·별칭과 대조하고 기존 항목의 ID·지도 연결·출처를 보존한다. 교과서 대조를 거친 기존 풀이도 유지하며, 이번에 검토한 지도 지명 13곳만 필요한 풀이·별칭·시대·지역·출처를 보강한다.
- 숫자, 쉬운 낱말, `소수`·`동국`·`조선왕조`·`경신` 같은 빈칸 조각을 모두 표제어나 별칭으로 만들지 않는다. 온전한 용어와 조각이 혼동될 때에는 독립된 개념인지 판단한다. 전랑은 이조 전랑의 단순 별칭으로 만들지 않는다.
- 신문고는 이용 절차·내용의 제한을 함께 설명하고, 주초위왕의 나뭇잎 이야기는 전승으로 구분한다. 결은 고정된 넓이로 환산하지 않는다. 세도 가문은 같은 본관의 모든 사람과 동일시하지 않는다.

지도는 사르후·육조거리를 새로 등록하고 11곳의 기존 원본 지점을 표시 대상으로 복구했다. 전체 표시 지점은 374개에서 387개가 된다. 사직·당포·사르후·육조거리는 사전에도 새 지명 항목이 생긴다. [지점별 근거](worksheet-atlas-20261106.md)에 역사 설명과 좌표 출처, 근사 대표점의 한계를 구분했다. 사르후는 조선군의 심하·부차 전장과, 규장각은 현대 서울대 규장각한국학연구원과 구별한다.

## 검증과 반영

`npm run build`의 필수 검증에 `verify-history-dictionary-worksheets.mjs`와 `verify-history-atlas-worksheets.mjs`를 연결했다. 사전 검색·출처·ID 보존, 모호한 별칭, 시대·지역 분류, 지도에 표시되는 지명과 사전 연결, 원본 지점·세계사 보존을 검사한다. 원본 유지 여부는 작업 전 카탈로그와 별도로 비교한다.

학생·교사 지도는 `node scripts/verify-portal-design.mjs --kind=map`으로 320·390·768·1280·1366·1440px 폭에서 확인했다. 지정 Chrome 프로필의 로컬 검증 화면에서 학생 사전의 신문고와 출처, 교사 사전의 재조지은, 지도의 사르후·대마도 검색·설명을 확인했다. 지도와 사전의 기존 화면 구조·디자인 토큰은 변경하지 않는다. 최종 112개 용어의 독립 내용 검토, `npm run build`, `npm run format:check`를 통과했다.

지명 생성에는 `node scripts/build-history-dictionary-places.mjs --worksheet-references-only`를 사용하고 이어 `node scripts/build-history-dictionary-classification.mjs`를 실행한다. 이 제한 모드는 관련 없는 기존 지명이나 출처를 다시 작성하지 않는다. 내용 증가에 맞춰 사전 항목 수와 출처 수의 엄격한 검증값을 갱신하고, 압축 크기 한도는 380,000바이트에서 400,000바이트로 조정한다.

운영 사전은 기존 동기화 도구로 계획을 먼저 확인하고 `sourceHash`·`planHash`를 지정해 관리 대상 항목만 생성·수정한다. 원본 문서의 버전 조건과 스냅샷 전체 재검증을 유지하며 삭제하지 않는다. 프론트엔드는 검증한 main 커밋의 Vercel 배포를 승격하고 `www.westory.kr`에서 두 기능의 실제 조회를 확인한다.

## 영향 범위

기존 사전·지도 콘텐츠의 통상 유지보수이며 인증·권한·학기 처리·Functions·rules·저장 위치·이용자와 공개 대상은 변경하지 않는다. 런타임 AI 호출·에이전트 기능·새 외부 전송을 추가하지 않았다. 학생 명단·답안·성적·서명·단어장·교사 등록 단어를 변경하지 않았다. 업로드 학습지의 본문 전문과 다운로드 토큰 URL은 추적 파일에 포함하지 않으며, 새로 만든 토큰 포함 임시 조회 파일은 삭제했다.
