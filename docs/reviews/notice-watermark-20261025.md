# 알림장·개발자 일지·워터마크 검증

## 범위

- 신규 일반 이미지 등록에 공통 Westory 워터마크 적용. `We` 파랑, `story` amber, 오른쪽 하단.
- 학습지 PDF·페이지·각주, PDF 지도 페이지, 수행평가 확인 서명 제외. 저장된 문항 이미지 재압축은 워터마크 중복 합성 제외.
- 개발자 일지 1536px 공통 너비, 반응형 목록, 안내 글 본문과 편집의 표·이미지 보존.
- 알림장 신규 안내 2건과 재오픈 이미지 교체는 운영 자료로 별도 등록. 원본 문제나 정답은 공개하지 않음.

## 확인

- 실제 브라우저 공통 이미지 처리 15건 통과: 알림장 비율/배경, 개발자 일지, 상품 상세/미리보기, 투명 자료/지도, 문항 신규/재압축, 로고 로딩 오류와 재시도.
- 기존 application-session 검증 20건, 위스 상점 클라이언트 17건 통과. 합성 transport만 사용.
- 실제 안내 글로 390·768·1280·1920px 화면 가로 넘침 없음. PC 목록 5열, 본문 글줄 최대 48rem, 대표 이미지/표는 가용 너비 사용.
- 편집→미리보기→저장 후 표, 이미지, 본문 class와 표 접근성 속성 보존 확인. 일반 글의 기존 카드뉴스 배치 유지.
- 공고문·문제지 PDF와 시험범위 원본 이미지 대조. 수행평가 일정은 등록된 10개 반 주간 일정과 대조.

## 운영 등록 대상

- 수행평가 글: `#/developer-log/notice-performance-20261026`
- 전 교과 시험범위 글: `#/developer-log/notice-exam-2026-2-2`
- 신규 알림장은 각 글에 연결. 재오픈 알림장은 이미지 필드만 교체하고 기존 공개 대상·순서·연결 설정 보존.
- 게시 스크립트는 활성 학기/작성자/대상 문서 확인, 이미지 해시 검증, 기존 알림장 백업, 원자적 문서 등록과 변경 시각 선행 조건을 사용. 이전 이미지 삭제 없음.
