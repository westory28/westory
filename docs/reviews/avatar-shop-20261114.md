# 아바타 상품 관리와 카탈로그 확장

## 변경 범위

- 관리자 설정을 `아바타 아이템 관리`로 표시한다. 작은 카드에서 이름·가격·남자/여자/공용 분류·설명을 개별 저장한다. 저장 왼쪽의 학생 미리보기는 학생과 동일한 카드·상세를 사용하며 서버에 쓰지 않는다.
- 다른 카드의 초안을 보존하고 변경 없는 저장을 막는다. 서버 충돌 응답의 최신 revision을 반영한 뒤 명시적으로 재시도한다. 응답 유실 뒤 동일 저장은 추가 쓰기 없이 성공한다.
- 학생 목록은 이미지 중심의 작은 카드, 로컬 검색·성별 필터와 선택 상품 상세를 제공한다. 상의·하의·신발은 몸과 다른 옷이 없는 단독 이미지다.
- 카탈로그 2와 기존 ID·보유품·선택을 유지하며 41개에서 87개로 확장했다. 신규 항목은 헤어 12, 표정 6, 상의 10, 하의 8, 신발 6, 염색 4개다. 참고 이미지의 분위기를 바탕으로 기존 픽셀 렌더러에서 만든 고유 도안이다.
- 성별 분류는 표시·탐색용이며 `characters`의 체형 호환과 구분한다. 기존 남색 치마의 여자 체형 제한과 학교복 6종 무료 정책을 유지한다. 새 아이템은 명시된 체형과 공통 관절을 사용한다.
- 픽셀 윤곽·명암과 고해상도 표시를 개선했다. 정적 프리뷰 171장의 합계는 90,652바이트다. 저장된 프로필 썸네일은 사용자가 아바타를 다시 저장할 때 갱신된다.

## 데이터와 운영 경계

기존 전역 상품 설정 문서와 callable을 확장한다. 교사 권한 검사 후 설정 문서를 한 번 읽고 변경 시 한 번 쓴다(교사 권한 문서 읽기는 별도 1회). 무변경·동일 재시도는 쓰기 0회다. 학생 studio 기존 응답에 메타데이터를 포함하므로 검색·필터·미리보기에 추가 서버 조회가 없다. 실제 구매·소유권·잔액·영수증·학기 검증은 기존 서버 경로를 유지한다. 운영 학생 자료를 테스트 목적으로 수정하지 않는다.

외부 AI 호출·에이전트 기능·개인정보 필드·외부 전송·학교 도입 및 공개 범위·인증 권한 변경은 없다. 기존 서비스의 상품 관리와 외형 유지보수다. 기존 작업 폴더의 성적 관련 변경은 보존하고 최신 `origin/main`의 별도 작업 폴더에 이번 패치만 통합한다.

## 검증

- 기본 앱 빌드와 전체 Functions check 통과. 서비스/helper 검사, 아바타 단위 52개 및 실제 Firestore 에뮬레이터 12개 시나리오 통과.
- 관리자 320/390/768/1280/1366px에서 개별 저장·초안 보존·충돌·오류 재시도·학생 미리보기·키보드 포커스 복귀·투명 헤더·이미지 잘림 없음 확인.
- 학생 320/390/768/1280px, 양 체형 167개 선택 경로, 구매·저장 실패 후 재시도·무변경 저장 차단·이름/설명/성별 적용·로컬 필터·긴 캐릭터 이름 확인. 실제 운영 구매 대신 합성 adapter를 사용한다.
- 전신 79,488조합, 피부색 누출 96개, 단독 이미지 독립성 111개, 하의/신발/포즈/피부색/체형 2,484조합을 검사했다. 픽셀 알파·몸통 빈틈·캔버스 경계·렌더러 종료를 검증하고 대표 착용 시트를 시각 검토했다.
- 관리자 고정 높이 상품 이미지의 밑단 잘림과 긴 사용자 지정 캐릭터 이름의 가로 넘침을 발견해 수정했다.
- 증거: `output/avatar-shop-20261114/`의 settings·studio·빌드/서버 로그, `output/avatar-wardrobe-20261114/`의 검증 보고서·착용 시트.

## 운영 배포

운영 원본을 확보해 12개 리전별 대상의 원본 212파일을 감사했다. 가격 관리 2개는 3파일, 아바타 6개는 4파일, 공개 아바타 투영 4개는 2파일만 바꾸며 원본 index/package/lockfile·실행 자원·권한·위스 조회 양 리전을 보존한다. `prepare-avatar-shop-release.mjs`와 `verify-avatar-shop-release.mjs`로 격리 배포본과 실제 export, 신규 아이템 구매·저장·상품 이름 원장 기록을 검증했다. Firestore/Storage rules와 삭제 트리거는 변경하지 않는다.

배포 로그와 운영 메타데이터·소스 대조 결과는 `output/avatar-shop-20261114/release-audit/post-deploy-verification.json`, Vercel 반영 상태와 운영 화면 확인은 같은 evidence 폴더의 최종 운영 보고서에 기록한다.
