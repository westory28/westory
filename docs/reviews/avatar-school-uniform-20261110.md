# 용신중 기본 의상·판매 정책·관리자 이모지

기준 checkout `C:\westory`, 시작 커밋 `3fc2bf3f82f3523de875661781a0a5f45f4cf60d`, main과 origin/main 일치, 기존 미추적 `output/`·`tmp/`는 제외한다.

## 요청과 구현

- 기본 선택은 용신중 흰색 하복 상의와 반바지다. 흰색·네이비 하복 상의, 하복 반바지, 동복 후드 집업·반집업·긴바지의 6종을 무료로 제공한다.
- 새 동복은 참고 사진의 회색 원단·민트 세 줄·긴바지 발목 고무줄과 제공된 용신 마크를 반영한다. 각 상의는 기본·인사·응원·생각·하트별로 팔과 손이 이어진 원화이며 고개 기울임·헤어·모자 처리도 유지한다. [원본과 정확한 프롬프트](../../assets/avatar-source/school-20261110/README.md)를 보관한다.
- 생성 참조는 학교 로고와 기존 자체 생성 아바타 원화뿐이다. 참고 사진 속 인물은 외부 서비스에 전달하지 않았으며 앱 런타임 AI·외부 전송·개인정보 항목을 추가하지 않는다.
- 일반 상하의는 유료이며 기존 양수 가격을 유지한다. 기존 무료 일반 상의·하의는 각각 160·100위스가 최초 가격이다. 학교복 무료·일반 의상 유료는 서버·학생 화면·관리 가격 화면에서 동일하게 적용하고 관리자는 유료 의상의 양수 가격을 수정할 수 있다. 기본 신발과 헤어·장식 등은 기존 정책을 유지한다.
- 관리자 마이페이지는 표시용 이모지 이름·설명을 제거하고 현재 선택과 선택지를 44px 원형 배지로 표시한다. 접근 가능한 이름·선택 상태·키보드 포커스·저장 계약을 유지하고 교사 전용 컴포넌트와 CSS만 수정한다.

## 호환·읽기·쓰기 경계

`avatarCatalog.json`의 `defaultClothing`과 `freeClothingItemIds`가 클라이언트·서버의 공통 계약이다. 기존 프로필을 무효화하지 않도록 catalogVersion은 1을 유지하고 pricingPolicyVersion 2로 구매 견적을 구분한다. 기존 0원 override는 읽기 시 정규화하며 가격 문서를 운영 migration으로 다시 쓰지 않는다. 구 클라이언트나 가격 확인이 없는 유료 구매는 차감 전에 새 가격 확인 오류로 거부한다.

기존 저장 모습은 형태와 해시를 먼저 검증하고 서버가 저장한 선택을 보유 목록으로 복구한 뒤 신규 구매·저장에 현행 가격을 적용한다. 기존 구매 품목·영수증·저장 썸네일을 보존한다. 현재 저장 썸네일은 사용자가 명시적으로 아바타를 저장할 때만 바뀐다. 새 폴링·목록 전체 조회·아이템별 추가 읽기는 없다.

## 운영 반영 경로

Functions는 검증한 소스와 운영 원본을 대조한 뒤 다음 이름만 선택 배포한다: `getStudentAvatar`, `getAvatarStudioState`, `purchaseStudentAvatarItem`, `saveStudentAvatar`, `getTeacherMyPage`, `saveTeacherAvatar`, `getAvatarCatalogPricing`, `updateAvatarCatalogPricing`, `getWisRankingPreview`, `getWisEconomyState`, `getWisEconomyStateFast`. `getWisEconomyState`의 서울·미국 두 리전을 모두 보존한다. 이모지 저장 함수·삭제 trigger·rules는 변경하지 않는다.

백엔드 배포 확인 뒤 main을 푸시하고 Vercel의 해당 커밋을 Production으로 승격한다. 운영 도메인 자산 지문과 방재석 Chrome의 기본 하복·동복 포즈·작은 이모지 배지·가격 정책 표시를 읽기 위주로 확인한다.
