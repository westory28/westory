# 위스토리 사전 콘텐츠와 출처 검증

확인일: 2026-10-18 (한국 시간)

## 수록 범위

- 역사 용어 133개: 운영 사이트에서 교사가 등록한 2026년 2학기 프린트의 제목·빈칸 핵심어를 확인한 뒤, 관련 제도·사건·문화 용어를 중심으로 편집했다.
- 지명 2,240개: 기존 역사 지도 출처 자료를 재사용했다. 현재 지도에 표시되는 지명 344개를 모두 포함한다.
- 합계 2,373개다. 지도 원본 지명 2,639개 가운데 설명이 없는 라벨 또는 별도 이용 조건 검토가 필요한 사전 발췌 399개는 사전 카탈로그에서 제외했다.
- 학생 이름·답안·등록 단어·학급 정보는 정적 데이터에 포함하지 않는다. 운영 데이터베이스에 콘텐츠를 추가하거나 기존 학생 단어장을 변경하지 않는다.

자료 안에서 사용한 `6조`, `3사`, `천상열차`, `영창`, `인목`, `소현`, `봉림대군` 등은 정식 표제어의 검색어로 연결했다. `사병`은 사적인 군대, `의정부`는 관청, `가례`는 예법서라는 수업 맥락을 구분했다. 단순 동음이의 문서를 그대로 뜻풀이로 사용하지 않는다.

`재조지은` 등 이번에 확인한 오픈 자료에서 충분한 근거를 확보하지 못한 단어는 임의로 출처를 붙여 수록하지 않았다. 모든 프린트 단어의 자동 수집·자동 갱신 기능을 구현한 것은 아니다.

## 외부 자료와 이용 조건

2026-10-18에 다음 공식 안내를 확인했다.

- [위키미디어 이용약관 7항](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use#7._Licensing_of_Content): 위키백과 텍스트의 재사용, 원문 링크를 통한 저작자 표시, 변경 사항 고지 및 동일 조건 배포 요건.
- [CC BY-SA 4.0 한국어 안내](https://creativecommons.org/licenses/by-sa/4.0/deed.ko): 저작자·출처·라이선스 표시, 변경 고지, 동일 조건 공유.

신규 역사 용어의 근거는 한국어 위키백과의 공개 API로 실제 문서와 개정판 ID를 확인했다. 필요하면 본문까지 읽어 문맥을 대조했다. `historyDictionaryCore.ts`의 각 항목은 사용한 원문 제목과 `oldid`를 기록한다. 학생이 읽기 쉽도록 요약하고 문장을 다시 구성한 뜻풀이에는 **CC BY-SA 4.0**을 적용한다.

지도에서 가져온 위키백과 발췌·요약은 기존 `historyAtlasReferenceDefinitions.ts`와 개별 지도 프로필에 기록된 2026-10-15 확인 개정판을 사용한다. 이번 작업에서 기존 1,949개 원문을 모두 다시 조사했다고 주장하지 않는다. 현재 화면에 표시되는 지명은 더 자세한 기존 검토 설명을 우선하며, 나머지에는 출처 개정판이 기록된 설명을 사용한다.

모든 위키백과 기반 항목에 다음을 유지한다.

1. 원문 제목과 `위키백과 기여자` 표시
2. 해당 개정판으로 연결되는 원문 링크
3. `CC BY-SA 4.0`과 라이선스 링크
4. 발췌·요약·한국어 번역 등 변경 내용
5. 확인 날짜

기존 위스토리 자체 지도 설명은 별도로 구분한다. 교과서·박물관·기관 자료를 참고해 작성한 요약에는 기존 근거 URL과 교과서의 PDF 쪽수·인쇄 쪽수를 보존한다. 이 참고 자료를 위키백과 자료 또는 CC BY-SA 자료라고 일괄 표시하지 않는다. 한국민족문화대백과사전의 한 줄 원문을 모은 `historyAtlasEncyclopediaDefinitions.ts`의 fallback은 새 카탈로그 생성 시 사용하지 않는다. 같은 기관을 참고한 기존 위스토리 자체 요약은 작성 주체와 참고 자료를 구분하여 연결한다.

위키백과에서 가져온 뜻풀이의 라이선스는 앱 코드 전체나 학생의 직접 작성 글에 적용한다고 표시하지 않는다. 뜻풀이를 다른 화면에 복사·내보낼 때는 `getHistoryDictionaryCatalogSource()`로 출처와 이용 조건을 함께 보존할 수 있다.

## 재생성과 검증

```text
node scripts/build-history-dictionary-places.mjs
node scripts/verify-history-dictionary-catalog.mjs
```

첫 명령은 기존 지도 자료에서 지도 실행 코드·좌표·지형을 제외한 카탈로그를 생성한다. 사전은 이 파일을 지연 로드하며 Firebase 조회 성공 여부와 무관하게 검색할 수 있다. 핵심 역사 용어는 수업 맥락과 원문을 대조해 수동 편집하므로 지도 재생성 명령이 덮어쓰지 않는다.

검증은 ID 중복, 뜻풀이 없는 메타데이터 혼입, 모든 항목의 출처, 위키백과의 개정판·저자·라이선스·변경 고지, 지도에 표시되는 344개 장소 포함 여부, 검색 우선순위와 공백·전각 문자·단축어 검색, 동음이의 오매칭, 독립 실행 및 압축 크기를 검사한다.
