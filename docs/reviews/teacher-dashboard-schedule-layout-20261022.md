# 교사 대시보드 학사 일정 표시 (2026-10-22)

- 교사 주간 일정만 수정한다. 학기별 일정 조회, 저장, 권한, 학생 화면은 변경하지 않는다.
- 대시보드의 기존 최소 높이 `clamp(620px, calc(100dvh - 140px), 880px)`과 오른쪽 알림장·위스 순위의 높이로 전체 높이를 정한다. 일정 열의 `contain: size`로 일정 내용이 grid 높이에 영향을 주지 않게 하고, 두 행을 차지하는 일정 열은 위스 순위 하단까지 늘린다. 1120px 미만에서는 size containment를 해제하고 기존 한 열 흐름과 목록의 336px 상한을 유지한다.
- 테두리와 8px/12px 고정 여백을 가진 바깥 표면 안에 별도 스크롤 목록을 둔다. 날짜 선택과 검색에 사용하는 ref 및 상대 위치 기준도 안쪽 목록으로 이동한다.
- 선택·hover 배경에는 기존 8px 모서리를 사용하고 키보드 포커스 테두리는 행 안쪽에 둔다. 인접한 일정 행 사이에는 4px 간격을 둔다.
- 학년·반 및 분류 배지의 120px 제한과 메타데이터 축소를 해제한다. 날짜·교시의 한 줄 표시와 제목의 가변 폭, 기존 좁은 화면 배치를 유지한다.
- 기존 surface, border, muted, ring 색과 간격·모서리·높이를 재사용한다. 제목·탭·필터 카드, 내부 메뉴, 안내 문구를 추가하지 않는다.

- 최초 패치에서 검색 결과 없음, 빈 주간 목록, 읽기 오류와 키보드 선택을 확인했다. 이번 보정은 CSS 두 속성과 행 간격에 한정한다.
