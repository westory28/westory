## 15시 예약 공개 독립 검증

- `node scripts/verify-student-quiz-entry-browser.mjs --scheduled-only`와 기존 전체 검사 모두 통과했다.
- 320/390/768/1280/1440px에서 `/student/quiz?tab=mock&round=round_3`가 전시를 바로 선택하고 23문항·35분을 표시한다.
- 서버 기준 2026-11-11 15:00 전에는 비활성 `Coming soon`과 회색 그림, 이후에는 컬러 그림과 입장 버튼을 표시한다. 기기 시계가 서버보다 1시간 빠르거나 느린 경우도 확인했다.
- 모바일 탭 복귀(`visibilitychange`)·페이지 복원(`pageshow`)에서 표시가 갱신된다. 시간 경계와 복귀로 설정 2회·개인 응시 상태 1회 외의 추가 서버 조회나 응시 시작은 발생하지 않았다.
- 선행 회차 미제출과 재응시 불가 학생은 15시가 지나도 입장할 수 없다. 응시 시작은 입장 버튼의 명시적 클릭에서만 요청한다.
- 실제 학생 알림장 컴포넌트의 이미지 버튼을 키보드로 눌러 전시 화면으로 연결되는 것을 확인했다. URL은 정해진 내부 경로로만 구성하며 외부 URL·스크립트·상위 경로 입력을 거부한다.
- 리뷰 보완 후 예약 전 조회 실패→오류·공개 시각 동시 표시→명시적 재시도 성공을 확인했다. 재시도는 개인 응시 상태 조회 1회만 추가하고 설정을 다시 읽지 않는다. 재시도 성공 후에도 15시까지 입장은 차단되며 정각에 정상 전환된다.
- 대문자·앞뒤 공백이 있는 ` ROUND_3 ` 직접 링크와 알림장 회차도 `round_3`으로 정규화되어 전시로 연결된다. 알림장 이미지 대체 텍스트는 안내 원문을 보존하고 빈 원문은 `알림장`으로 표시한다.
- 페이지 머리말의 computed style은 투명 배경·`position: static`·최소 높이 0·그림자 없음이었다.
