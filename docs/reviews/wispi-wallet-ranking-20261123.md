# 위스피 지갑·랭킹·연결 복구 (2026-11-23)

기준 커밋은 `2924a27bc0eef64717d029d776660812b8cf3511`이다. 작업 전 Vercel 운영 도메인도 같은 커밋임을 확인했다. 메뉴·사이트맵과 공용 더보기는 [메뉴 검증 기록](menu-order-20261123.md)을 함께 따른다.

## 변경과 경계

- 학생 지갑은 왼쪽 계좌 입출금, 오른쪽 본인 보유 주식·현재가·매수/평가 금액·평가 손익으로 배치한다. 이미 받은 본인 계좌와 가격을 사용한다. 보유 주식이 있고 마지막 조회가 30초 이상 오래된 채 지갑에 진입하면 기존 공유 조회를 한 번 갱신하며 이후 폴링하지 않는다. 조회 시각을 표시하고 좁은 화면은 한 열로 전환한다.
- 보유 수익률 랭킹은 전날 한국 시각 23:59 기준을 유지한다. 전체는 50위까지, 선택한 학급은 투자 중인 학생 전체를 서버에서 정렬·필터한다. 현재 보유 주식과 양수 원가가 있는 학생을 대상으로 한다.
- 첫 목록과 더보기는 최대 10행이다. 전체·우리 학급 버튼과 개별 학급 선택을 제공한다. 선택하지 않으면 해당 범위 상위 5명의 그래프, 선택하면 개인 그래프를 오른쪽에 표시한다. 학급에서는 학급 내 순위를 사용한다. 종목 상세 목록은 응답에서도 제거하며 구버전 상세의 호환 필드는 빈 배열이다.
- 목록 마지막 행의 공용 더보기는 전체 폭·44px 이상·블러 없이 표시한다. 스크롤과 그래프 선택은 다음 페이지를 요청하지 않으며 더보기에서만 요청한다. 교사 투자 현황의 기존 표시 단위는 유지한다.
- 15초 동안 서버 스냅샷이 없다고 실제 세션 폐기로 처리하던 경로를 고친다. 지연 중 공통 로고 로딩을 표시하고 늦은 서버 응답을 받을 수 있게 유지한다. 일시 네트워크 오류는 750/1500ms 간격으로 최대 두 번 재연결하며 이후 명시적인 재연결을 제공한다. 실제 권한 거부·세션 폐기·계정 전환은 즉시 차단한다.
- 읽기 재시도만 추가했다. 입출금·주문·지원금 명령을 자동 재실행하지 않고 기존 요청 ID, 영수증, 불확실한 응답 복구를 유지한다. 미사용 탭·숨긴 화면·오프라인·계정/학기 전환에서 기존 경계와 해제를 유지한다.

## 서버 조회·쓰기와 캐시

- 순위 원본은 기존 현재 학기 투자 보드와 전날 계좌에서 집계한다. 모든 학급 투자자의 최소 순위행을 분리 저장하고 첫 5명의 그래프만 일일 집계한다. 개인별 전체 체결 원장을 매일 모든 학생에 대해 읽도록 확장하지 않는다.
- `entries`의 `classKey ASC, globalRank ASC` 인덱스로 학급을 서버 필터하고, 순위 커서와 `limit(10)`을 사용한다. 전체 조회 후 브라우저 필터, 50명 선조회 후 화면에서 10명 표시, 자동 더보기는 사용하지 않는다.
- 다음 페이지의 합성 실측은 권한/현재 학기/집계 메타데이터 10문서 + 순위 10문서 + 현재 학적 슬롯 10문서 = 30문서 읽기, 0쓰기다. 마지막 페이지는 실제 행 수에 따라 줄어든다. 필드 projection은 전송량을 줄이며 문서 읽기 건수 절감으로 계산하지 않는다.
- 최초 기본 그래프 5건은 저장한 그래프 문서를 읽는다. 그 밖의 그래프는 요청한 학생의 전날 계좌·시장·체결 원장만 읽어 재구성한다. 이 별도 이력 조회 비용을 목록 30읽기에 포함한 것으로 보고하지 않는다.
- 서버 그래프 캐시는 학기·집계일/버전·순위별, 최대 128건·30분이다. 같은 계산은 합치며 오류는 저장하지 않는다. 캐시를 사용해도 매 요청 세션·현재 학기·시장 공개·현재 학적을 검사한다. 개인 그래프 캐시 적중은 권한 10 + 순위 1 + 학적 1 = 12읽기, 0쓰기다.
- 클라이언트 그래프 캐시는 해당 랭킹 화면의 계정/학기·일자·필터 범위 안에서만 유지한다. 범위 변경과 화면 해제 시 폐기하고 지연 응답은 AbortSignal로 버린다. 날짜 경계에서 다시 읽는다.
- 일일 게시에는 전원 최소 순위행 저장 비용이 추가된다. 400행 이하 묶음으로 준비한 뒤 포인터를 원자적으로 전환하므로 500명 임의 제한이 없으며, 완료 후 이전 집계 문서를 정리한다. 학생 계좌·거래·성적·공개 설정에는 쓰지 않는다.
