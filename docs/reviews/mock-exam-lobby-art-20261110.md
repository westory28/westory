# 모의고사 입장 일러스트와 밝은 파란 화면

- 기준: `e98e6ad4`의 학생 `QuizIndex` 입장 화면. 교사 화면, 응시·저장·채점·공개 권한, 학기 경로 및 legacy 조회는 변경하지 않는다.
- 기존 알림장의 `performance-02.webp` 인물 비율·윤곽선, `reopen-01.webp`의 밝은 분위기를 참고했다. 알림장의 장식적 관복은 고증 근거로 사용하지 않았다.
- 내장 ImageGen으로 제작하고 방향·관모·옷깃을 수정했다. 사용자 복식 재검토 요청 후 세 장면의 응시복을 옅은 하늘색·흰색 도포로 다시 수정했다. [생성 및 수정 프롬프트](mock-exam-lobby-art-prompts-20261110.json)를 보관하며 초기 프롬프트의 검은 응시복 지시는 폐기된 이력으로 표시한다. 최종 자산은 `src/assets/mock-exam/{chosi,boksi,jeonsi}.webp`이며 960×720, alpha 유지, 각각 168,560 / 175,916 / 190,070바이트다.
- 이미지 생성은 개발 중 정적 자산 제작에만 사용했다. 학생 정보·교과 원문을 외부 AI에 전송하지 않았으며 앱의 런타임 AI·에이전트·외부 API 호출은 추가하지 않는다.

## 고증과 표현 범위

- 초시는 지방 향시를 상징하는 고을 시험장이다. 초시에는 관시·한성시·향시가 있으므로 모든 고을에서 일률적으로 치렀다고 설명하지 않는다. [한국민족문화대백과 초시](https://encykorea.aks.ac.kr/Article/E0057022)
- 복시는 한성의 관청 시험장을 상징한다. 성균관·장악원·한성부·예조·사부학당 등에서 시험 장소를 나누었다. 특정 현존 건물의 복원도는 아니다. [과거](https://encykorea.aks.ac.kr/Article/E0004562)
- 세 장면의 응시자는 **조선 후기 유생복**을 시각 기준으로 삼았다. 옅은 하늘색·흰색 도포, 곧은 깃과 넓은 소매, 겹친 뒷자락, 실띠와 검은 유건을 표현한다. 전통문화포털은 후기 과거시험장에서 유건을 착용했고 정조대에 도포가 유생복으로 정착했으며 주로 청색·흰색이었다고 설명한다. 옅은 하늘색의 정확한 색조는 사용자 참고 사진에 따른 삽화 표현이며, 모든 시기·시험 단계에 동일한 지정복이 있었다고 주장하지 않는다. [전통문화포털 유생복](https://www.kculture.or.kr/clothes/code/943/menu/923/idx/62/currentPage/5)
- 전시는 궁궐 전정에서 국왕을 향한 응시 장면이다. 왕은 붉은 곤룡포와 익선관, 시관은 둥근 깃 단령과 사모로 응시자와 구분했다. 급제 뒤의 어사화·홍패는 넣지 않았다.
- **전시 그림은 국왕 친림과 필기 과정을 한 장에 압축한 상징 장면이다.** 세종실록 의례에서는 왕이 사정전으로 돌아간 뒤 답안을 작성한다. 이 기록은 의례와 삽화의 차이를 밝히는 데만 사용하며 후기 도포의 근거로 사용하지 않는다. 특정 연도·순간의 의례 복원도가 아니며 귀여운 인물 비율과 간략한 건축·장식 역시 교육용 양식화다. [세종실록 문과전시의](https://sillok.history.go.kr/id/wda_20005038)
- 미색 한지, 붓털이 있는 붓, 낮은 돌벼루, 별도의 고형 먹을 표현한다. 현대 필기구·공책은 넣지 않는다. [문방사우](https://encykorea.aks.ac.kr/Article/E0019481)

### 복식 검토 정정

초기 검토는 생원·진사 **합격 후 방방의**의 흑단령 설명을 문과 전시 응시복에 확대 적용했다. 그 판단을 철회한다. 세종실록의 ‘청의·연두건’만으로 초안의 검정색을 특정할 수 없으며, 1741년 영조실록에는 관학 유생의 거재·부거 때 홍단령을 유지하도록 한 기록도 있다. 검정색이 조선 과거 전체의 정답이었다거나 반대로 어느 때나 불가능했다고 단정하지 않는다. 재현 사진 역시 전 시기의 제도를 증명하는 자료로 취급하지 않는다. [유복](https://encykorea.aks.ac.kr/Article/E0041463), [영조실록 17년 4월 8일](https://sillok.history.go.kr/id/kua_11704008_003)

## 화면과 비용

- 공통 제목·탭과 기존 회차 선택 구조를 유지하고 기존 primary-soft / border-blue / primary-text / primary 색을 사용한다. 게임 장면은 기존 단일 입장 영역 안에 배치한다.
- 선택 회차 한 장만 로드한다. hover·키보드 focus-visible·누르기에만 300ms CSS transform을 사용하며 반복 애니메이션·JS 타이머·포인터 추적은 없다. 동작 감소 설정은 이동·확대·회전을 끈다.
- 이미지 캐시는 개인 정보 없는 내용 해시 정적 자산의 브라우저/CDN 캐시다. 계정·학기·권한 결과를 이 캐시에 넣지 않는다. 자산 변경은 새 URL이며 이미지 오류는 자동 재시도하지 않는다.
- 기존 현재 학기/본인 응시 상태 조회·오류 재시도·공개/선행회차/재응시 제한을 보존한다. 효과의 추가 서버 조회·쓰기 수는 모두 0이다. 전송량 감소와 Firestore 문서 읽기 감소를 혼동하지 않는다.
- 작은 상태·항목 글자도 남색 primary-text를 사용한다. 가장 옅은 파란 배경 기준 대비는 9.52:1, 흰 글자/파란 주 버튼은 5.17:1이다.

- `npm run build` 통과(기존 대형 chunk 경고 포함). 배포할 파일만 복사한 `e98e6ad4` 기준 별도 worktree에서도 빌드 통과했다.

- 하늘색·흰색 도포로 수정한 최종 자산으로 같은 브라우저 검사를 다시 통과했다. 모바일·태블릿·데스크톱에서 장면 잘림·버튼 가림이 없으며 검증 화면은 로컬 `output/mock-exam-lobby-20261110/`에 보관한다.
- 모의고사 탭 전 overview 0회·이미지 0회, 첫 진입 overview 1회·선택 이미지 1회. 회차 선택·효과에서 overview 추가 0회, 효과에서 이미지 추가 0회. 설정 문서 2개와 기존 학기·본인 조회 경계를 유지한다.
- 이미지 503 오류에도 대체 텍스트와 시험 입장 가능, 이미지 실패 요청 1회·overview 1회로 반복 요청 없음. 콘솔 오류·외부 요청·가로 넘침 0건.
- Chrome 운영 확인 프로필은 `방재석`이다. 교사 계정은 학생 경로에서 교사 대시보드로 정상 복귀하므로 학생 실계정의 운영 응시는 실행하지 않는다. 운영 도메인의 배포 커밋·자산 반영과 합성 학생 브라우저 검증을 구분한다.
