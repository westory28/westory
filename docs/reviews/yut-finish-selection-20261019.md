# 윷놀이 완주 판정과 말 선택

마지막 출발 발판 `o20`과 완주 상태 `finish`를 별도 이동 칸으로 세어 정확한 도착에 추가 던지기가 필요했다. 이제 마지막 발판에 도착하는 같은 이동에서 완주 처리한다. 이동 애니메이션은 마지막 발판과 완주 위치를 모두 포함하고 초과 칸 수는 소비하지 않는다. 기존 저장 상태의 `o20` 말도 다음 이동에서 완주 가능하다.

두 독립된 말이 모두 나가 있으면 각 던지기 결과마다 이동할 말을 선택한다. 업힌 말은 한 그룹으로 보고, 말 하나만 나가 있으면 그 말을 기본 선택한다. 선택한 말에 합법적인 완주 경로가 있으면 던지기 연출·이동 유예가 끝난 뒤 목적지 선택 없이 이동 명령을 보낸다. 숨김·대화상자·동기화 오류 중에는 자동 이동하지 않는다. 같은 차례·말의 자동 요청은 한 번만 시도하고 실패하면 결정 버튼으로 재시도한다. 감정표현 갱신은 말·경로 선택을 초기화하지 않는다.

학생·교사 공통 게임, 로컬 미리보기와 온라인 서버에서 같은 코어를 사용한다. 학기·공개·가입·세션·방 revision·요청 영수증·보상 정책은 유지한다. 운영 저장 소스와 `commandYutRoom`의 의존 소스를 LF 정규화해 비교했고 코어 수정만 차이임을 확인했다. Firebase 배포 대상은 `commandYutRoom` 하나다.

검증은 코어 경계 600조합을 포함한 단위 검사, 로컬 전체 게임, 실제 React 화면의 명시적 말 선택·정확/초과 완주·연출 대기·동기화 재렌더 중복 방지, Functions 전체 검사, Firestore 에뮬레이터의 callable/보상 영수증 재시도, 앱 빌드로 수행한다. 운영 데이터로 경기·보상을 만들지 않는다.
