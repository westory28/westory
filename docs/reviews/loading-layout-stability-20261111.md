# 컨테이너 로딩 배치 안정화 (2026-11-11)

알림장 응답 뒤 조작 영역이 추가되면 인접 학사 일정의 높이와 대기 중인 로고 위치가 바뀌었다. 1440px 교사 대시보드 합성 재현에서 알림장은 46px, 일정은 약 16px 커지고 일정 로고는 약 8px 내려갔다. 좁은 교사 영역에서는 게시물 연동 배지가 추가될 때 조작 영역이 36px 더 커졌다.

알림장 이미지·조작 영역·연동 배지의 공간을 처음부터 확보한다. 학생 페이지 선택은 한 행에서 스크롤하며, 1119px 이하 일정 목록은 기존 최대 높이 336px을 로딩·빈 상태에도 유지한다. 학생 일정은 기존 내용을 밀어내지 않는 Overlay를 사용한다. 같은 컨테이너의 후속 로딩에는 이전 로고의 완료 잔상을 만들지 않고, Overlay의 margin은 부모의 자식 간격 규칙과 분리한다.

사용자 요청에 따라 컨테이너 로딩의 흰색 덮개를 제거하고 투명 배경과 blur(4px)만 사용한다. 종료 효과에도 같은 배경이 적용된다. 전체 화면 로딩, 글자별 튀기와 색 채우기, 동작 줄이기 설정에서의 로고 애니메이션은 기존 계약을 유지한다. 서버 조회·구독·쓰기·폴링과 외부 AI 전송을 추가하지 않는다.

검증:

- `npm run build`: 공용 작업 트리 및 기준 HEAD `596cedc5`에 이번 파일만 적용한 격리 작업 트리에서 실행.
- `node scripts/verify-dashboard-loading-browser.mjs`: Edge 55조건 통과. 390·768·1280·1440px, 알림 0·1·5개와 연동 유무, 데스크톱 가용 너비 800·850·900px을 검사했다. 대기 중인 일정 로고 위치 변화는 0px이며 패널·제목·조작 영역의 위치와 높이는 1px 이내로 유지됐다.
- `LOADING_BROWSER_ENGINES=msedge,webkit node scripts/verify-loading-state-browser.mjs`: 두 엔진 통과. 투명 배경과 4px 블러, 로딩 종료, 단계 전환, 부모 간격, 컨테이너 범위·입력 보호·정리, 동작 줄이기를 확인했다.
- 기존 알림장 캐러셀 28조건과 일정 대시보드 12개 너비 검사를 통과했다.
- 방재석 Chrome에서 합성 대시보드의 알림장·일정 완료 버튼을 직접 조작해 패널 높이와 남은 로고 위치가 유지됨을 확인했다. 색이 있는 컨테이너에서도 흰색 덮개 없이 원래 색과 블러가 표시됐다.

대시보드 자동 검사는 실제 양쪽 알림장·일정 컴포넌트와 교사 Dashboard를 사용하며 학생 대시보드 외곽과 순위에는 합성 셸을 사용한다. 서버 요청은 차단되어 0건이고, 완료 전후 구독·설정 조회 횟수는 증가하지 않았다. 이미지는 합성 16:9이며 기존 모바일 원본 비율 전환을 제거하지 않는다. 실물 모바일 기기 검증을 뜻하지 않는다.

원본 결과와 화면은 `.superloopy/sessions/dashboard-loading/evidence`, `.superloopy/sessions/loading-jitter/common-transparent`, `.superloopy/sessions/loading-jitter/week-schedule`에 기록한다.
