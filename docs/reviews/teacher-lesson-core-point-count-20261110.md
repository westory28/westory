# 교사 수업 자료 핵심포인트 합계

- 기준: `b4e50cdaea319681f0ae6901bd3cfa829e488340`, 2026-11-10.
- 교사 PDF의 `목록 → 시험` 탭 안에 `공개 자료 핵심포인트 총 N개`를 표시한다. 공개된 전체 자료 기준이며 담당반별 학생 합계와는 다를 수 있다.
- 최신 학기 자료가 있으면 해당 단원의 레거시 자료를 제외한다. 최신본이 비공개·삭제되었어도 이전 공개본을 다시 포함하지 않는다. 빈칸·각주는 제외하고 학생 학습지와 동일하게 너비·높이가 양수인 시험 표시만 센다.
- 조회 중·실패 시 숫자를 숨기며 실패에는 키보드로도 실행할 수 있는 `다시 확인`을 제공한다. 성공한 빈 목록만 0개로 표시한다.

## 조회와 권한

- 기존 `getStudentVisibleLessons`의 `view: core-points`만 추가했다. 기존 상세·목록·진도 응답과 세션, 학생 학기·수강·학급 공개 검사를 유지한다.
- 정확한 전체 합계를 위해 학기/레거시 목록을 각각 조회하되 unitId·공개·삭제·시각·배정반·핵심포인트 필드만 선택한다. PDF·OCR·본문·빈칸·각주는 읽지 않으며 응답에는 unitId와 개수만 포함한다. 필드 선택은 전송량을 줄이며 문서 읽기 건수를 줄이지 않는다.
- 시험 목록을 처음 열 때 1회, 이후 핵심포인트 수 또는 공개 상태의 저장 성공 후 1회만 호출한다. 화면 최초 진입이나 빈칸·각주 목록만 열 때는 합계 조회가 없다. 단원 이동·초안 편집·제목만 저장에는 추가 호출하지 않는다. 중복 재시도를 합치며 이전 계정·학기·저장 이전 응답을 폐기한다. 공유 캐시·폴링·추가 쓰기는 없다.
- 정적 학기 보관본에서는 새 호출/합계를 표시하지 않는다. 목차 노드 삭제는 기존대로 교육과정 트리만 변경하므로 자료 합계를 바꾸지 않는다.
- AI 호출·외부 AI 전송·권한·공개 범위·성적·답안·rules는 변경하지 않는다.

## 디자인과 검증

- `education-web-design-system`, `UI_RULES.md`, `DESIGN.md`를 따르며 기존 `TeacherSubNavigation`/공통 목차와 파랑·중성 텍스트·간격을 재사용한다. 새 카드나 디자인 토큰을 추가하지 않았다. 수업 자료의 계층 목차는 기존 허용 예외다.
- 서버 read-budget 검사 8개: 최신/비공개/삭제/legacy, 유효 표시, 501개 전체 합계, 최소 projection, 세션 차단, 학급 경계, 오류·재시도.
- `node scripts/verify-lesson-loading.mjs`: 실제 편집기 컨트롤러 7묶음 통과. 요청 횟수·저장 후 갱신·빈 목록·오류·재시도·계정/학기 전환을 포함한다.
- 수정 TS/TSX Prettier 검사와 `git diff --check` 통과. `npm --prefix functions run check` 통과.
- CUA 합성 자료 화면에서 70개/0개/오류/Enter 재시도 복구 및 단원 이동 시 호출 유지 확인. 390px 설정(스크롤바 제외 375px), 768px, 1280px, 1440px에서 합계 가독성·줄바꿈·가로 넘침을 확인했다. 실제 학생 정보나 운영 자료는 테스트로 수정하지 않았다.
- 동시 작업 중인 다른 화면의 미완성 타입 오류를 분리하기 위해 기준 커밋에 이번 6개 변경 파일만 적용한 worktree에서 `npm run build` 전체 검증을 통과했다. 기존 큰 번들 경고 외 오류 없음.

## 운영

- 배포 전 운영 함수의 studentLessonAccess 원본, scoreWorkflowGuard, sessionAuthority, studentMaintenance 및 런타임 의존성이 기준 소스와 일치함을 확인했다. package.json 차이는 검사 스크립트이며 dependencies/engines는 동일하다.
- `getStudentVisibleLessons` 하나만 운영 Firebase에 배포 완료. 다른 함수·rules는 배포하지 않았다.
- 사용자가 확정한 그림의 알림장/공지는 `notice-core-points-20261110`으로 연결했다. 공지 본문은 `수업 자료에 있는 핵심포인트 70개를 찾아보세요!`이며 버튼은 첫 소단원 `u-1789561583911`의 학생 학습지 주소를 가리킨다. 교사 계정은 기존 학생 포털 접근 제한을 그대로 따른다.

## 표시 위치 정정

- 사용자 지정 위치는 PDF 도구의 `목록 → 시험`이다. 수업 자료 목차에 넣었던 합계와 관련 props는 제거했다.
- 시험 탭을 누르면 공개 자료 합계를 표시하고, 같은 탭의 회색 개수는 `이 자료 6개`처럼 현재 자료의 시험 표시 수만 보여 준다. 빈칸·각주 탭에는 전체 공개 자료 합계가 나오지 않는다.
- 계정·학기 격리, 저장 성공 후 갱신, 오류·재시도는 유지한다. 서버 함수·공통 학습지·학생/교사 제시 화면 변경 없이 교사 전용 패널과 호출 시점만 바꿨다.
- 실제 컨트롤러 검사에서 시험 목록을 열기 전 0회, 최초 사용 1회, 재열기·단원 이동 추가 0회, 오류·재시도·저장·학기/계정 변경 경계를 확인했다.
- 위치 정정 후 `npm run build`, 편집기 컨트롤러 검사, 변경 TS/TSX 포맷, diff 검사를 통과했다. CUA에서 390/768/1280px 시험 목록 합계, 빈칸 탭에서 숨김, 트리 표시 제거, 오류 후 Enter 재시도 복구를 확인했다.
