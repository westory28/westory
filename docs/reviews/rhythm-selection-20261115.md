# 덩기덕 쿵더락 선택 화면 후속 정정

확인일: 2026-11-15. 기준 커밋: `96366981604f72a71b0ad737fb92525cf9f5f3e8`.

## 변경

- 곡 버튼에는 제목만 표시한다. 곡 번호·분위기 설명·BPM은 제거하고 글자를 PC 26px, 짧은 가로 화면 18px로 확대했다.
- 선택한 곡은 원래 오방색 현판과 체크로 표시한다. 다른 곡은 회색으로 보이지만 실제 비활성화하지 않아 클릭·키보드로 바꿀 수 있다. `aria-pressed`는 선택 상태와 일치한다.
- 장단 이름은 중모리 장단·자진모리 장단·휘모리 장단으로 바꿨다. 기존 난이도 ID·음표 생성·음악 속도·판정은 변경하지 않았다.
- 게임 안의 제목과 카탈로그 표지는 `title-logo.webp`를 사용한다. 한글 ‘덩기덕 / 쿵더락’ 손그림 붓글씨이며 대체 텍스트를 제공한다. 별도 고해상도 PNG를 보존한다.
- 시작 버튼은 별도 `start-plaque.webp`의 주홍/금색 현판으로 강조한다. 패널 전폭과 92px/64px 높이, 28px/22px 글자다. 일시정지·결과 버튼은 그대로다.
- 첫 시각 검토에서 큰 시작 버튼의 하단이 선택 패널에 잘리는 것을 발견했다. PC 곡 행 높이와 간격을 조정하여 전체 버튼이 들어오게 했고, 테스트에서 버튼 전체가 패널 안에 있는지 확인한다.

## 검증·범위

`npm run build`의 사전 검사·타입 검사·전체 빌드와 `npm run format:check`를 통과했다. 마지막 CSS 간격 조정 후 Vite 빌드를 다시 통과했다. `scripts/verify-rhythm-browser.mjs`의 실제 게임/Web Audio 검증 9그룹은 1440×1000, 1280×900, 768×1024, 390×844, 320×760, 844×390에서 통과했다. 제목만 표시·확대 글꼴·세 장단 이름·회색 곡도 선택 가능·단일 체크·색상 변경·시작 버튼 전체 노출·로고 대체 텍스트·8개 그림 로딩을 추가 확인했다. 기존 타격·회전·결과·재도전·진입1조회/연주0조회도 유지한다.

이미지 생성에는 일반 로고/버튼 프롬프트와 기존 게임 일러스트만 사용했다. 학생 개인정보와 학습자료를 전송하지 않았고 앱의 런타임 AI·인증·권한·조회·저장·Functions/rules에는 변화가 없다. 학생 공개는 기존 비공개 상태를 유지한다. 원래 checkout의 사용자 미완료 파일은 수정하지 않는다.
