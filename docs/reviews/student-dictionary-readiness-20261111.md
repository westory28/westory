## 수정한 결함

1. 기본 ‘사전 찾기’만 이용해도 개인 단어장 구독이 열렸다. 이제 ‘내 단어장’이 활성화된 동안만 구독한다.
2. 학습 도구의 사전 팝업을 닫아도 방문한 컴포넌트가 남아 구독이 유지됐다. `active`를 전달해 닫을 때 해제하며, 컴포넌트 자체는 유지해 작성 중 초안을 보존한다. 숨겨진 기본 사전과 부가 질문 서비스의 조회도 활성 상태를 따른다.
3. 단어장을 지연 조회할 때 이미 저장한 단어의 뜻풀이를 빈 초안으로 열지 않도록 첫 조회 결과로 복원한다. 저장된 목록을 확인하는 동안과 조회 오류가 있는 동안 수정·저장을 막고, 오류 시 이전 목록을 감춘다. 재시도에 성공하면 작업을 계속할 수 있다.
4. 팝업 제목 영역에 전역 `header`의 흰 배경·sticky·최소 높이가 적용됐다. 사전 팝업에 한정해 투명 배경·정적 위치·그림자 없음·최소 높이 초기화를 적용했다.

계정·학기 전환 시 단어·뜻풀이·오류·대기 중 선택을 초기화한다. 해제한 구독의 늦은 응답은 현재 화면에 반영하지 않는다. 탭 이동·팝업 닫기에는 초안과 검색 조건을 유지한다.

## 공용 영향과 제한

- 교사 `ManageHistoryDictionary`는 `active`를 전달하지 않아 공용 CatalogBrowser의 기본값 `true`로 기존 동작을 유지한다. 기존 교사 탭별 지연 로딩 회귀도 통과했다. 변경한 팝업 헤더 선택자는 학생 Controller에서만 사용한다.
- 캐시는 공개 기본 사전만 대상으로 하며, 기존 서버 승인·버전 확인과 계정/인증 epoch 검사를 생략하지 않았다. 개인 단어장·서버 쓰기 권한·과거 학기 읽기 전용·명령 충돌 방지는 유지한다.
- 기존 학습지 출처는 제목/페이지를 안내하며 수업 문서 ID 링크를 제공하지 않는 자료도 있다. 이 작업에서 추정 ID로 새 수업 링크를 만들지 않았다. 기존 질문 문맥 링크, 출처 링크, 실제 수업 경로와 사전 사이의 뒤로 복귀를 검증했다.
- 서비스 런타임의 AI 호출·외부 자료 전송은 추가하지 않았다. 실제 학생 저장·점수·서명·요청 처리 상태를 변경하지 않았다. 대량 동시 접속 부하 시험과 실제 휴대폰 OS의 가상 키보드 검증은 수행하지 않았으며, 이번 결과는 로컬 브라우저 fixture와 서버 회귀 검사 범위다.
- 커밋·배포는 이 하위 작업에서 수행하지 않았다. 최종 통합 검증과 운영 배포는 총괄 담당이다.
