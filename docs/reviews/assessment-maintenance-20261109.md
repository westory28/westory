## 변경 근거

세트 문항의 개별 발문 수정은 가능하지만 같은 세트 ID의 공통 지문을 수정하면 서버의 `ASSESSMENT_PAPER_SET_CONFLICT` 검사가 거부했다. 공통 지문을 같은 회차·같은 세트에 원자적으로 반영하고 각 문항의 버전을 증가시킨다. 개별 발문·해설·정답과 이미 제출한 학생의 동결 시험지는 유지한다. 오래된 편집기의 저장, 학생 권한, 보관 학기의 쓰기 차단을 유지한다.

수행평가 일람표는 현재 전출·정원외 상태를 이유로 과거에 응시한 평가까지 제외하고 있었다. 일람표 전용 읽기 투영에서 실제 저장 점수를 보존하고, 평가별로 숫자 점수(0점 포함)가 있는 학생의 인원·합계·평균을 산출한다. 전체 합계에는 모든 실제 점수를 더하되, **전체 평균은 전출·정원외 학생의 점수와 인원을 모두 제외**한 학생별 합계로 계산한다. 이는 사용자가 이번 작업 중 명시한 최종 기준이다. 예를 들어 전출 전 1차만 응시한 학생은 1차의 분자·분모에만 포함하고, 전체 평균에는 포함하지 않는다. 미응시를 0점으로 만들지 않는다. 학기 시작 전 이동자 제외 및 서명 정책은 유지한다.

사용자가 제공한 수정 일람표의 머리글과 하단 출력 IP를 표시 기준으로 삼는다. 만점·반영비율 및 점수·합계·평균의 소수 둘째 자리와 최종 XLSX의 `hair` 테두리를 검증한다. 원본 파일과 운영 점수·서명·학적 문서는 변경하지 않는다. 이 기록에는 실제 학생 명단을 포함하지 않는다.

분석 화면은 본문 최대 폭과 셀 여백으로 불필요한 가로 스크롤이 생겼다. 가용 본문 폭을 사용하고 문항 번호·선지·수치를 압축하며 표본 수는 수치의 도움말에 둔다. S–P 문항은 낮은 정답률부터 배치하고 문항별 응답·주의지수·경계를 같은 문항에 대응시킨다. 회차별 점수·수준에 공통 표 컨테이너·테두리를 적용한다. 기존 계층 목차와 모바일 표 스크롤을 유지한다.

참고: [사용자 제공 성취평가 결과 분석](https://seongchwi-bunseok.pages.dev/). 공개 화면 및 표 스타일을 확인했다. 참고 사이트에 학생 자료를 입력하거나 업로드하지 않았다. 원래의 Westory 디자인 토큰·레이아웃을 우선하고 참고 사이트의 전체 UI를 복제하지 않는다.

- 인증·권한·학기 경로·rules·학생 공개 여부 변경 없음.
- AI 호출·앱 내 에이전트 실행·외부 AI 전송 추가 없음. 출력 IP의 기존 별도 조회는 제거한다.
- 점수 집계는 기존 성적의 읽기·출력 보정이며 공식 원점수·서명·이의 상태를 변경하지 않는다.
