# 정기시험 서논술형 분석과 AI API 선택안

2026-11-14 검토. 기준 HEAD `5043a3ef761f7c2b26357fa12228cf0ebdef76bd`와 현재 작업트리를 읽었습니다. 최초 조사는 읽기 전용으로 진행했으며, 이후 사용자가 확정한 논술형 원점수 분석을 별도 구현했습니다. 실제 학생 자료 조회·외부 전송·AI 호출은 하지 않았습니다.

**현재 필요한 점수 통계에는 AI API가 필요하지 않습니다.** 이미 올린 점수표의 저장본을 재사용하는 것이 우선입니다. 답안 내용을 읽어 오류 원인과 개별 피드백을 제안하려는 단계에서 AI의 효과를 별도로 검증하면 됩니다. 중복 업로드 제거와 기존 통계 연결은 신규 서논술형 통계·AI 도입과 구분합니다.

| 구분 | 가능한 결과와 필요한 자료 |
| --- | --- |
| 기존 자료 재사용 | 현재 점수 관리에 학급 평균·점수 분포·문항 요약이 있습니다. 같은 학기·평가·학급의 저장본을 읽으면 재업로드 없이 제공할 수 있습니다. |
| 이번에 확정해 구현 | 별도 논술형 화면에서 문항·하위 요소 원점수 평균/모집단 표준편차·점수별 인원, 학급 비교, 학생별 점수·저장된 교사 피드백을 제공합니다. 미입력과 실제 0점을 구분하고, 전체 총점은 모든 논술형 항목 입력 완료자만 집계합니다. 일부 입력은 부분합으로 표시합니다. |
| 현재 자료로 판단 불가 | 답안의 근거·논리·오개념, 루브릭 수행 수준, 채점자 간 신뢰도, 학생이 실제로 성찰한 내용입니다. 각각 답안 원문+평가 기준, 수준별 기술문, 복수 채점자의 독립 점수, 학생 본인의 입력이 추가로 필요합니다. AI도 없는 근거를 대신 만들 수 없습니다. |

저장 근거는 [`performanceScores.ts`](../../src/lib/performanceScores.ts)의 `items`(`itemKey/groupKey/name`, `score/maxScore/scoreEntered`, `feedback`, `examSection`), 학생 UID·학기·학급·총점이며, [`writtenExamEssayScoreWorkbook.ts`](../../src/lib/writtenExamEssayScoreWorkbook.ts)가 요소별 점수·교사 피드백을 만듭니다. 논술형 원문 답안이나 수준별 루브릭 전문은 저장하지 않습니다. `studentAnswer` 필드가 있어도 현재 논술형 파서는 이를 채우지 않으며, 엑셀의 ‘AI채점수준’ 열을 읽는 조건은 앱의 AI 채점 기능을 뜻하지 않습니다. 일부 긴 기준은 `1-(1)` 같은 항목 번호로 저장되어 의미를 별도로 연결해야 합니다.

**통계 전 확인할 조건:** 일반 하위 문항 파서는 업로드에서 관측한 최고점을 `maxScore`로 삼는 경로가 있습니다. 특정 논술형 양식의 확인된 1+3+1+5점과 구분하고, 최고점을 실제 배점으로 단정하지 않습니다. 미입력(`scoreEntered:false`)을 0점으로 집계하지 않으며, 총점만 있는 과거 자료로 세부 요소를 복원하지 않습니다. 논술형 `items`는 명부와 학생 점수 문서에 남지만 선택형 세부 답은 학생 점수 문서를 읽어야 하는 경로가 있습니다. 같은 저장본과 최신 수정 버전을 연결하고 이름만으로 학생을 합치지 않습니다.

AI를 검토할 만한 부분은 **답안의 근거 문장을 짚은 오류 유형 후보, 루브릭별 피드백 초안, 재작성 질문**입니다. 기존 교사 피드백을 요약할 수도 있지만, 낮은 점수만으로 오류 원인이나 학생 성향을 단정해서는 안 됩니다. AI 없이도 승인된 문구와 점수로 결과 요약·성찰 질문을 만들 수 있으며, 이것은 학생의 실제 성찰과 다릅니다. Cornell은 평가 요소·수준 기술문·자기평가·수정 제출을 안내합니다. 이 대학의 루브릭 지침은 AI 자동 채점의 효과를 검증한 연구가 아닙니다. [Cornell 공식 루브릭 안내](https://teaching.cornell.edu/teaching-resources/assessing-student-learning/using-rubrics)

AI 도입 시에는 호출량에 따른 비용, 긴 답안·이미지와 재시도로 늘어나는 처리 시간, 모델·설정 변경에 따른 결과 차이와 교사 검토 시간이 추가됩니다. 실제 비용·지연·정확도는 아직 측정하지 않았습니다. 나중에 검토한다면 합성 답안으로 먼저 시험하고, 허용된 자료로 교사 판단과의 일치·근거 없는 지적·수정 시간을 비교하는 소규모 평가부터 권합니다. 모델/프롬프트/루브릭 버전을 남기고 호출 상한·재시도 한도·취소를 두며, 점수 변경과 학생 공개는 교사가 확정합니다.

계약은 실제 제품별로 확인해야 합니다. 현재 Gemini API 약관은 18세 미만 대상 또는 접근 가능성이 있는 서비스에서의 사용을 제한하며, 무료 서비스에는 개인정보·기밀정보를 제출하지 말라고 명시합니다. 유료 서비스의 학습 미사용 조건도 안전 목적 보관과 국외 처리가 없다는 뜻은 아닙니다. [Gemini API 공식 약관](https://aistudio.google.com/docs/terms) GCP 생성형 AI 약관에도 별도 연령 제한이 있습니다. 교사 전용 버튼이나 보호자 동의만으로 제한이 해소된다고 판단하지 않습니다. [Google Cloud 서비스별 약관, AI/ML 18·20](https://cloud.google.com/terms/service-terms)

향후 선택할 공급자의 제품·계약상 허용 범위, 이름·학번 제거 후에도 남는 답안 개인정보, 처리 지역·보관·삭제·학습 사용, 고지·동의 및 기관 검토 조건은 [`responsible-ai.md`](../runbooks/responsible-ai.md)에 따라 확인합니다. 이는 적용 조건의 확인 사항이며 위스토리의 법 위반·승인·면제를 단정한 결론이 아닙니다. **이번 범위는 저장된 점수의 재사용과 원점수 분석이며, AI/API·루브릭 수준 판정·학생 성찰 생성은 구현하지 않았습니다.** 득점률·만점률·문항-나머지 총점 상관도 별도 검토 사항입니다.
