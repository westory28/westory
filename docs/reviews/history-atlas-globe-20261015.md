# 지도 설명·수계·별도 지구본 개편

공유 지도와 별도 지구본에서 같은 지명·단원·시대 자료를 사용한다. 역사교실 지도 연결은 다시 추가하지 않는다. 지도에서 검색·장소 선택은 저장이나 서버 쓰기를 발생시키지 않는다.

## 변경

- 지도 위 설명은 정의 → 핵심 정보 → 축소한 시대 선택 → 역사 맥락 → 다른 이름·연관 장소 → 접힌 출처 순서다. 검색용 키워드는 실제 다른 지명으로 표시하지 않는다. PDF 페이지와 책에 인쇄된 페이지를 모두 보존한다.
- 77개 프로필을 80개 장소에 정확한 ID/명칭으로 적용한다. 원래 55개 장소의 설명과 백두산·주요 강의 정의를 보강했다. 전체 2,639개 장소를 모두 상세 서술한 상태는 아니다. 2,559개는 기본 정보와 교과서 출현 맥락 수준이다.
- 중복 시대를 묶고 처음에 최대 6개 선택지만 표시한다. 버튼 글자 12px, 상하 4px·좌우 8px 간격, 기본 높이 28px, 터치 환경 36px다.
- 선택 카메라는 설명 카드 영역을 제외하고 한반도/지역 맥락을 맞춘다. 긴 강은 실제 전체 선형이 화면 안에 들어오도록 계산한다. 투영·지형 좌표의 비례는 바꾸지 않는다.
- 선택 지점에는 부드러운 2.4초 후광, 선택 강에는 3px 실선과 10px 후광을 표시한다. 숨겨진 화면·화면 밖에서는 애니메이션을 멈추고 reduced-motion에서는 정지 표시한다.
- 공통 정보 버튼의 원·점·선을 SVG 안에 배치했다. 도움말은 제목과 라벨별 행/목록으로 나누며 터치·키보드·Escape·밖 클릭을 지원한다. 링크가 있는 도움말의 키보드 이동과 모바일 설명 출처 링크도 확인한다.
- `지구본`은 별도 지연 로딩 메뉴다. 구면 투영, 앞면 지점만 표시, 드래그 회전, 휠 확대, 두 손가락 확대·비틀기, 북쪽 복원, 키보드 조작을 제공한다. Google Earth의 기본 조작 관례를 참고했으며 위성 영상·지형 고도·건물 모델을 사용하는 제품은 아니다.

## 데이터와 성능

- Natural Earth의 고정 버전과 별도 ODbL OpenStreetMap 하천 데이터베이스를 사용한다. 원본 형상을 AI로 재생성하지 않는다.
- OSM 보완은 21개 강·383개 way, 원본 243,355바이트이며 gzip-9 82,814바이트다. way별로 약 0.0003도 허용 오차로 단순화하고 끝점을 유지한다. 자료에 없는 연결선은 만들지 않는다. 이는 확보한 이름별 구간이며 모든 발원지부터 하구까지 빠짐없이 조사했다는 의미는 아니다.
- 백강·패강 등 위치/동일시가 미확정인 강을 현대 수계에 임의 연결하지 않는다. 출처·수집 시점·query·way ID·원본/결과 해시는 manifest에 남기고 가공 데이터와 함께 도움말에서 내려받을 수 있다.
- 기본 지구본 육지는 gzip 47,956바이트다. 외부 지도 타일/API 요청이 없다. 수계는 강 선택 때 추가로 불러오고 같은 과목 데이터는 캐시한다. 2D 지도를 열어도 지구본 코드·육지는 읽지 않는다.
- Canvas는 DPR 2 이하·200만 픽셀 이하, 조작 중 최대 30fps다. 입력이 없을 때 계속 다시 그리는 루프가 없으며 숨김/화면 밖에서는 렌더링을 멈춘다. 실제 저사양 태블릿의 FPS·배터리를 측정한 결과는 아니다.

## 검증

- 지명 원본 674개 PDF 페이지, 단원·시대 연결, 출처/좌표 계약 검증을 유지한다. 기존 coverage ledger의 판독 불확실한 미세 지도 층은 여전히 완전 판독으로 표시하지 않는다.
- 실제 강 선형과 선택 범위, 동명이인 수계 격리, 백두산 정의, alias의 지명 오인 방지, 트래픽 예산을 검증한다.
- 폭 624/690/900px에서 나일강·창장강·아마존강·한강·백두산과 좁은 한국사 단원의 총 51개 카메라 조합을 검증한다. 카드 가림/화면 잘림이 없고 원래 투영이 변하지 않아야 한다.
- 북극해 등 위도 80도 이상 지명이 기존 범위 상한에 걸려 선택 계산을 반복하던 오류를 수정했다. 실제 극지방 지명 9곳 × 4개 화면 폭의 36개 검사를 더해 총 87개 화면 범위 검사를 통과했다.
- 구면 앞뒤 판정, 드래그·핀치·비틀기 수학, 렌더링 픽셀 한도, 메뉴 마이그레이션·권한 계약을 검증한다.
- Chrome 실제 공통 컴포넌트에서 390/768/1280px, 백두산 정의·시대 버튼, 강 선형/후광, 지구본 드래그·휠·키보드, 목록 복귀 포커스와 도움말/출처 키보드 이동을 확인한다. 모바일 크기 확인은 실제 물리 기기 조작 시험을 대신하지 않는다.
- 빌드의 기존 학습지·PDF·학기 보관·성적 XLSX hair 테두리 검사를 유지한다. 신규 InfoHelp import 때문에 필요한 검증 mock만 추가하고 기존 검증 조건은 바꾸지 않는다.

## 운영 확인

이 변경 검증 중 운영 Google 팝업 로그인이 계정 선택 후 대기하는 현상이 보고되어 로그인 복구 패치 `6af0bfc9`를 먼저 분리·배포했다. 현재 창 Google 인증과 ‘다시 확인’을 거쳐 운영 교사 대시보드 진입을 확인했고, 새 탭의 세션 복원은 약 1.5초였다. 지도 변경은 이후 빌드·푸시·Vercel 승격 및 실제 인증된 운영 지도/지구본 확인을 마친 뒤 완료로 보고한다.
