# 논술형 그래프·학생 결과·백지 집계

## 범위

점수 등록 및 확인에 저장한 논술형 점수·교사 피드백을 평가 분석에서 읽어 표시하는 교사 포털 후속 개선이다. 학생 화면, 성적·서명·이의 처리 원본, 서버 권한, Functions 및 rules는 변경하지 않는다. AI 호출·외부 데이터 전송·새로운 루브릭 진단은 추가하지 않는다.

- 전체 결과에 총점 분포, 문항별 결과에 원점수 평균, 학급별 비교에 총점 평균 그래프를 표시한다. 기존 DOM 막대그래프와 상승 애니메이션을 재사용하며 동작 줄이기·인쇄에서는 애니메이션을 제거한다.
- 학생별 결과는 학생 명단의 숫자 페이지 디자인을 사용해 한 학급씩 표시한다. 평가·학급 범위를 바꾸면 첫 페이지, 같은 범위 새로고침에서는 현재 학급 페이지를 유지한다. 통계는 현재 조회 범위 전체를 사용하며 표시 중인 학생 페이지만으로 계산하지 않는다.
- 교사 피드백은 버튼을 눌러 읽기 전용 팝업으로 연다. 왼쪽 정렬하고 강제 개행은 표시할 때만 공백으로 합친다. 화면 폭에 따른 자연스러운 줄바꿈, Escape·닫기·배경 닫기, 호출 버튼으로 초점 복귀를 제공한다.
- 입력 완료 배지 대신 교사 피드백의 명시적인 ‘백지’ 표지를 학생·문항·학급별로 집계하고 해당 문항 번호를 제공한다. 0점이나 미입력만으로 백지를 추정하지 않는다. 점수·결측값·통계 분모는 그대로 유지한다.

## 데이터와 조회 경계

논술형 문항 점수·개별 피드백·전체 피드백은 업로드와 기존 점수 편집 시 학생 문서 및 학기별 점수 원장에 같은 트랜잭션으로 갱신된다. 논술형 전용 조회는 선택한 학기의 평가 원장 1회만 읽고 학생 개별 점수·문항 자료·모의고사는 조회하지 않는다. 선택형은 기존 개별 답안 조회를 유지한다.

선택형 조회로 이미 확보한 원장은 논술형에서도 재사용한다. 논술형 전용 새로고침 이후 선택형에 돌아갈 때만 선택형 답안과 모의고사를 다시 읽는다. 보고서·학생 페이지·피드백 팝업 이동은 추가 서버 조회·쓰기가 없다. 실패한 요청을 성공 캐시로 취급하지 않으며 계정·학기·평가·학급 경계를 유지한다.

숫자 페이지는 렌더링 범위를 나눈다. 완전한 전체 통계에 필요한 원장 1문서 자체를 서버 커서로 나눈 것은 아니다. 이 패치는 이미 필요한 원장을 재사용해 학생 수만큼 발생하던 중복 문서 읽기를 없앤다. 필드 선택만으로 Firestore 읽기 건수가 줄었다고 설명하지 않는다.

문항별 피드백을 우선한다. 문항별 피드백이 전혀 없는 이전 자료만 기존 문항 번호 파서로 전체 피드백을 연결한다. 여러 문항에 걸친 공통 문장의 ‘백지’를 모든 문항에 전파하지 않는다. 파서는 순수 모듈로 옮기되 기존 엑셀 모듈의 공개 함수와 처리 내용을 보존한다.
