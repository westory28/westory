# 역사 지도 확장·설명 카드 개편 검증

2026-10-15. 한국사·세계사 공통 2D 지도에 적용한다. 역사교실 연결을 다시 추가하지 않으며, 이번 변경에 Functions·rules 수정은 없다.

## 변경

- PC의 장소 목록은 지도 오른쪽, 설명은 지도 위 카드로 배치했다. 가용 폭 900px 미만에서는 오른쪽 패널을 열어 목록·설명을 확인한다.
- 본문은 16px/400, 제목과 소제목은 20px/700·18px/700이다. 44px 조작 영역, 키보드 초점 복귀, Escape, 페이지 스크롤 잠금을 유지한다.
- 단원과 시대를 교차 필터링한다. 통일 신라·발해는 남북국 시대, 후삼국과 고려 초기처럼 겹치는 시대를 함께 지원한다.
- 과거 이름·현재 이름 검색과 시대별 설명 이동을 지원한다. 염포와 울산항은 별도 장소로 구분하면서 서로의 설명과 부산포·제포를 연결한다.
- 해외 장소 선택 시 지역 밖 지형을 불러오며, 요청 실패 시 이전 지형을 잘못 표시하지 않고 가려지지 않은 재시도 버튼을 제공한다.
- 지도 표시가 겹치지 않도록 지명 배치를 제한하고, 나머지 점은 하나의 SVG 경로로 그린다. 장소 목록은 40곳씩 표시한다.

## 자료 범위

- 제공 PDF 4권 총 674쪽을 범위 장부에 포함했다. 지명 2,639개, 시대별 설명 4,648개, 대표 좌표가 있는 장소 1,066개다.
- 한국사 2,820개·세계사 2,826개 출처별 후보 기록의 포함·병합·제외와 등장 쪽수를 검사한다. 포함한 후보의 모든 쪽수가 설명의 출처에 연결되는지 검증한다.
- 좌표를 확인하지 못한 도시·유적과 단일 점으로 표시하지 않는 역사 영역은 구분한다. 미확정 위치를 임의로 지도에 찍지 않는다.
- 미세한 고지도 영인본 원문 글자는 남아 있으므로 두 범위 장부 모두 `complete: false`다. 전수 판독 완료를 주장하지 않는다.
- 원문 PDF·이미지·추출 본문은 배포하지 않는다. 출처와 요약, 지명, 검증 기록만 포함한다.
- 상세 범위는 [한국사 기록](history-atlas-korea-coverage-20261015.md)과 [세계사 기록](history-atlas-world-coverage-20261015.md)을 따른다.

## 검증

- `npm run build` 통과: TypeScript, 학기 보관, 성적표 hair 테두리, 학습지/PDF/판서·역사교실 기존 계약, 지도 데이터·학생 원본 지도 캐시 검사를 포함한다.
- `npm run format:check`, `git diff --check` 통과.
- 실제 브라우저 390·768·1280px 레이아웃 확인. 휴대폰 크기에서 가로 넘침 없음, 본문 16px/400을 확인했다. 이는 실제 휴대폰 하드웨어 성능 인증이 아니다.
- 염포 검색, 울산항 설명으로 이동 및 검색 조건 해제, 연결 설명, 위치 말풍선의 카드 내부 배치를 확인했다.
- 별도 로컬 오류 fixture에서 한국사 화면의 해외 지형 요청을 1회 실패시켰다. 이전 경로 0개, 오류·재시도 버튼 노출 및 버튼 가림 없음, 재시도 후 지형 경로 2개·워싱턴 핀 복구를 확인했다. fixture는 저장소와 배포에서 제외했다.
- 콘텐츠 JSON gzip 330,265바이트. 실제 빌드의 지도 코드·콘텐츠 청크 gzip 344.25KB, 지도 CSS gzip 3.08KB. 지역 지형 gzip 712,445바이트, 세계 지형 737,498바이트. 지도 화면에서 지연 로딩하고 이동·선택마다 타일 요청을 추가하지 않는다.
- 기존 번들 크기 경고는 남아 있다. 원문 PDF를 지도 초기 로드에 포함하지 않고 기존 원본 지도는 별도 지연 로드한다.

## 마지막 패치: 별도 지구본 메뉴

3D는 2D의 대체 보기나 내부 탭으로 넣지 않는다. 별도 메뉴에서만 지연 로드하는 마지막 단계로 유지한다. 이번 릴리스에는 3D 메뉴·운영 코드가 없다.

Natural Earth 110m와 기존 D3의 구형 투영 Canvas 사전 벤치를 390·768·1280px, 12조건, 총 2,160프레임으로 실행했다. 지형 gzip 47,956바이트, 독립 시험 JS+D3 gzip 10,980바이트였다. 30fps 목표·DPR2에서 지형 계산 p95는 16.9/24.6/22.7ms, 986개 점을 포함하면 23.9/26.0/26.1ms였다.

그러나 실제 rAF 간격 중앙값은 약 66.7ms였고, 빈 rAF 대조군도 p95 1,016.7ms로 흔들렸다. 브라우저 가시성·스케줄링 영향을 분리하지 못해 안정적인 30fps를 입증하지 못했다. 실제 휴대폰·태블릿 및 장시간 배경 전환도 검증하지 않았다. 따라서 배포 성능 기준을 통과한 것으로 취급하지 않는다.

다음 단계는 실제 기기에서 기본 정지·상호작용 시 렌더, 30fps 상한, DPR 2 이하와 픽셀 예산, 숨김 시 정지, 저성능 시 2D 이동을 검증하는 것이다. 성능 근거가 확보된 뒤 별도 메뉴 구현·배포를 시작한다.
