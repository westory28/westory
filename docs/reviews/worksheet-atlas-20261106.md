흥인지문·종묘·염포·소쇄원·소수서원은 기존 지도 표시를 확인해 중복 등록하지 않았다. `4군`과 `6진`은 여러 군현의 묶음이므로 단일 지점을 만들어 표시하지 않는다. 기존 지역·개별 지점 정보는 유지한다. 관련 없음이 확인된 세계사 설명이나 기존 지도 지점 좌표는 바꾸지 않는다.

공식 기관 설명을 읽고 새로 작성한 짧은 정의·역사 요약과 좌표 출처를 구분했다. Wikidata는 좌표 수치만 사용하며 CC0 링크를 유지한다. 각 항목의 실제 근거 URL은 `src/data/historyAtlasWorksheetSupplement.ts`에 저장했다. 국가유산청의 공개 XML 좌표는 실제 응답에서 확인했고, 사천·당포는 한국학중앙연구원의 전자지도에 제시된 좌표를 사용했다.

검증: `node scripts/verify-history-atlas-worksheets.mjs`. 13개 표시 지점, 별칭 검색, 시대·지역 구분, 출처와 위치 설명, 규장각·사르후의 장소 구분, 기존 표시 지점 및 세계사 설명 보존을 비교한다. 통합 지도 검증은 `npm run verify:history-atlas`로 수행한다.
