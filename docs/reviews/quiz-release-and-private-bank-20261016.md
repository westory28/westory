# 평가 공개·풀이 연결 및 비공개 문제은행 (2026-10-16)

## 변경 범위

- 새 선택형 문항의 기본 선택지를 5개로 변경한다. 저장된 기존 문항은 보존한다.
- 교사 문항 미리보기·오답 기록과 학생 풀이에서 부정 발문의 핵심어를 밑줄로 강조한다. 문항 원문은 평문으로 유지한다.
- 공개 학급, 제한 시간, 재응시와 힌트 설정을 한 창에서 편집한다. 신규 평가는 비공개·학급 미선택으로 시작하며 진단 10분, 형성 20분, 모의고사 40분을 기본으로 한다. 기존 설정의 시간은 보존한다.
- 미저장 변경, 입력 오류, 로딩 실패와 저장 실패를 구분한다. 저장 실패 시 입력을 유지하며 저장 중 중복 제출을 막는다. canonical 학급 ID 대신 저장한 학년·반 표시 ID를 편집 폼에 복원한다.
- `saveQuizAssessmentSettings`가 설정 문서와 공개 정의를 하나의 revision 검사 트랜잭션으로 저장한다. 공개는 해당 중단원·유형 문항만 한 번 읽고, 비공개는 문항·학급 조회 없이 차단할 수 있다.
- 아직 출제 자료를 확정하지 않은 비공개 QUIZ DRAFT만 학기 준비도 검사에서 빈 source를 허용한다. 공개·중지·종료 평가와 다른 종류의 평가 검사는 유지한다.
- 학생 화면은 전체 정답 포함 문제은행을 읽지 않는다. 본인 응시에 선택된 정답 없는 자료만 서버가 반환한다. 오래된 응시나 큰 이미지의 누락된 스냅숏은 선택 문항의 revision·정답·단원·유형이 일치할 때만 복구한다.
- 학생 응시 조회를 본인 UID와 평가 ID로 제한한다. 동시에 들어온 같은 상태 조회만 합치고 완료된 상태는 캐시하지 않는다. 학기와 무관한 설정 객체 변경은 문제은행 재조회나 응시 초기화를 일으키지 않는다.
- scoped/legacy `quiz_questions` 원본 읽기는 교사 또는 명시적인 문제 읽기 권한으로 제한한다. 학생 본인 풀이·제출·결과 권한은 유지한다.

## 검증

- `npm run build`: TypeScript, 수행평가 XLSX hair 테두리 회귀, 기존 앱 검사와 Vite 빌드를 포함해 통과.
- `npm --prefix functions run check`: 통과.
- `verify-canonical-assessment-client.mjs`, `verify-assessment-release.mjs`, `verify-assessment-attempt-safety.mjs`: 통과. 공개 저장 1명령·브라우저 문제은행 조회 0회, 중복 조회 병합, 응답 유실 복구와 revision 충돌을 확인했다.
- `verify-canonical-assessment-rules.mjs`: 격리된 Firestore emulator에서 47개 권한 검사 통과. 학생의 scoped/legacy 원본 답안 조회를 거부하고 교사·허가된 staff를 허용한다.
- `functions/productionGateway/scripts/verify-quiz-release-integration.cjs`: 실제 callable `.run`, 세션 권한과 Firestore emulator를 연결하여 공개→응시→저장→제출→차단을 검증했다. 정답 없는 문항 전달, 큰 이미지 복구, 제출 replay, 다른 학급 차단, 학기 보호와 동시 수정 충돌을 포함한다. 운영 학생 데이터 쓰기는 없다.
- 실제 브라우저의 격리된 fixture에서 교사 390/768/1280px, 신규 5선지, 비공개 학급 선택 저장·재열기, 공개/차단, 빈 시간 오류, 저장 실패 시 입력 유지, 미저장 닫기와 로딩 실패를 확인했다. 학생은 선택형·OX·단답·순서·연결 문제를 풀고 제출했으며 원본 `quiz_questions` 조회를 금지한 상태에서 완료했다.

## 운영 반영 계약

`executeCommand`, `getCommandStatus`, `getAssessmentState`의 서울 함수만 배포한다. 변경 전 운영 `executeCommand` archive의 관련 파일과 `getAssessmentState`의 query core를 LF 정규화 SHA256으로 대조했다. Firestore 운영 rules도 수정 전 HEAD와 동일함을 확인했다. 다른 함수와 Storage 규칙은 배포 대상이 아니다.

프론트엔드는 최신 main을 반영한 Vercel 배포를 확인하고 `www.westory.kr`에 승격한다. Firebase 함수와 프론트엔드 반영 후 원본 답안 읽기 제한을 배포한다. 배포 ID·운영 확인·등록 결과는 실행 기록에 별도로 보관한다.

## 문항 원본과 등록

첨부 교과서·프린트의 페이지별 구분과 현재 교육과정의 13개 소단원을 연결했다. 사용자 확인 범위는 소단원별 진단 50·형성 50, 합계 1,300문항이다. 이전 정기시험 원안지와 출제 지침의 발문·자료 표기·5선지 길이/가나다순을 기준으로 창작 기출형 문항을 작성한다. 실제 기출 문항을 복제했다고 표시하지 않는다.

교과서·시험 원안·개별 문항·정답·출처 매핑·등록 JSON과 검수 기록은 로컬 제외 경로에 보관하며 공개 Git 저장소에는 넣지 않는다. 등록은 문항 신규 생성만 수행하고 공개 설정을 변경하지 않는다. 문항 ID 충돌은 생성 전제조건으로 거부하고, 재실행은 같은 배치·내용 해시만 인정한다. 등록 후 13개 소단원의 유형별 개수와 내용 해시를 다시 확인한다.
