# 학습지 글자 선택 정밀도 검증 — 2026-10-12

## 변경 범위

운영 기준 `5c7d011`의 교사·학생 정답 피드백을 보존하면서 PDF 글자 선택과 빈칸 경계를 개선했다. AI나 외부 OCR API는 추가하지 않았다. 기존 원본 PDF의 내장 글꼴과 실제 그리기 좌표를 브라우저에서 읽는다.

- 평균 글자 폭 대신 실제 알파 픽셀 경계를 16배로 측정한다. 경계가 겹친 글자만 64배로 다시 측정하고 내부 공백을 제외한 연속 픽셀 구간을 보존한다.
- 쉼표·괄호·조사·좁은 자간은 별도 글자로 선택한다. 짧은 구두점도 줄 전체 높이를 기준으로 손의 작은 상하 움직임을 허용한다.
- 인접 글자의 곡선이 들어오는 가장자리만 잘라낸 빈칸을 저장한다. 두 글자가 실제 픽셀을 공유하면 이웃 획은 남기되 선택 글자의 독립 획은 모두 가리는지 확인한다. `춘추관`처럼 이웃 글자의 내부 빈틈에 들어간 독립 획도 구멍과 분리 영역을 보존하는 even-odd 다각형으로 가린다. 선택 글자를 전혀 가리지 못하거나 글자 중앙까지 침범해야 하는 경우는 거부한다.
- 장식 화살표·회전된 괄호는 주변 획을 보호하는 지역 장애물로 처리한다. 해당 장식 하나 때문에 페이지 전체의 정상 글자가 선택 불가가 되지 않는다.
- `inkClip`은 숫자 좌표만 허용하며 수업자료 저장·재열기·역사교실 가져오기·학생 풀이까지 보존한다. 기존 수동 빈칸과 저장된 사각형은 바꾸지 않는다.

## 자동 검증

- `npm run build`: 타입 검사, 학기 보관 보호, 엑셀 원본 테두리 회귀, PDF 글자·선택·마스크·역사교실 검사, Vite 빌드 통과.
- 실제 PDF에서 추출한 회귀 fixture: 162개 정·역방향 드래그 및 상하 흔들림 검사 통과. `이조 전랑`, `이인좌`, `옷감`, `효종`, 괄호 안 단어, `정국`/`을`, `춘추`/`관`, 짧은 기호로 시작하는 제목 3건 포함.
- 공유 획 합성 사례 14개, 짧은 머리말 검사 4개, 정밀 구간 누락·과도한 겹침·선택 글자 전체 노출의 거부 검사 통과.
- 구멍·분리 영역·꼭짓점 접촉·0.07픽셀 틈·복잡도 제한 등 다각형 생성기 독립 검사 211개 통과. 별도 감사의 고정 seed 무작위 차집합 1,200개도 통과.
- 선택 독립 획의 누락과 이웃 획 가림은 구현과 별도의 행별 다각형 검사기로 검증한다.
- 변경 TypeScript/TSX 포맷과 `git diff --check` 통과.

## 브라우저 검증

실제 학습지의 `이조 전랑`, `이인좌`, `효종`, `기년복`, `옷감`, `정국`을 직접 드래그했다. 정방향·역방향·확대/축소 상태를 포함하며 학생 화면에서 뒤의 조사와 쉼표가 남는 것을 확인했다. 390·768·1280픽셀 프레임에서도 동일한 정규화 경계를 유지했다. 운영 학습지에 검증용 빈칸을 저장하지 않았다.

`춘추관`의 `춘추`도 실제 드래그로 생성됐으며 학생 마스크의 `polygon(evenodd, …)` 적용을 확인했다.

## 등록된 PDF 전체 검사

현재 학기의 PDF 13개에서 7,546개 글자(선택 가능 7,541개, 회전·장식 장애물 5개)를 측정했다. 같은 줄의 연속 범위 49,745개에 대해 방향·끝점·상하 흔들림을 바꾸어 총 1,640,160회 선택했다.

| 항목 | 결과 |
| --- | ---: |
| 선택 성공 | 1,622,488회 |
| 빈 공간·범위 경계 등 안전 거부 | 17,672회 |
| 다른 글자 선택 / 독립 획 누출 / 이웃 획 가림 / 잘못된 마스크 | 각각 0건 |
| 모든 제스처 성공 범위 | 48,231개 |
| 끝점에 따라 일부 성공한 범위 | 1,366개 |
| 모든 제스처가 거부된 범위 | 148개 |

남은 148개는 로고 91개, 겹친 삽화 장식 7개, 서로 다른 표 셀을 넘는 범위 50개다. 원본 렌더로 분류했으며 정상 본문에서 항상 거부되던 범위는 남지 않았다. 추가로 발견한 `춘추`·`추`와 짧은 기호 제목 3개는 각각 30/30회 성공했다. 이는 검사한 13개 자료에 대한 결과이며 모든 미래 PDF나 모든 포인터 위치의 성공을 보장하는 수치는 아니다.

13개 검사에서 선택 소스 `67706cbb…`, 다각형 helper `aee38648…`, 번들 `2383a207…` 지문이 일치했다. 원본 PDF·다운로드 토큰·전체 측정 덤프는 커밋에서 제외했다.

## 적용 한계

원본에 글자 정보가 있는 PDF를 대상으로 한다. 스캔 이미지, 읽을 수 없는 글꼴·투명 그룹, 서로 구별할 수 없을 만큼 중첩된 글자는 추측해 빈칸을 만들지 않는다. 회전 장식과 여러 줄·떨어진 표 셀을 한 번에 가르는 드래그도 자동 선택 대상이 아니다. 전체 PDF와 다운로드 토큰은 검증용 로컬 보관만 하며 저장소에 넣지 않는다.
