# 알림장 안내 글과 모바일 목록 후속 개선

## 변경

- 수행평가·시험범위·재오픈 안내는 각 배너의 버건디/크림, 민트/틸, 파랑/주황을 본문에 적용한다. 그림 프레임 안에 선택 가능한 실제 글자와 표를 배치하고, 핵심 문구를 그림 위에도 표시한다.
- 기존 수행평가 10개 반 일정, 20점·검정색 볼펜, 평가 기준 및 8교과 시험범위를 보존한다. 수행평가 문항·정답은 공개하지 않는다.
- 재오픈 안내는 홈, 역사 지도, 수업 자료, 문제 풀이, 위스 상점, 교사 공개 범위의 위플레이를 설명한다. 기존 재오픈 알림장의 순서·기간·대상은 유지하며 상세 글 링크만 추가한다.
- 1024px 미만 개발자 일지 목록은 제목 한 줄만 표시한다. 검색과 정렬은 한 행, 데스크톱은 기존 5열이다.
- 알림장 이미지 프레임을 테두리 없는 16:9로 맞춘다. 학생 알림장의 기존 820ms 전환은 사용자의 명시적 요청에 따라 reduced-motion에서도 유지하며 일시정지 기능을 보존한다.
- 개발자 일지 푸터는 자연스러운 본문 뒤 배치를 유지하고 해당 화면에서만 기존 muted 색과 경계선을 사용한다.

## 검증

- 실제 NoticeBoard/TeacherNoticeBoard·CSS fixture: 390/768/1280px에서 프레임 비율 오차 0px, 테두리 0px, 현재 1200×675 원본의 내용 크롭 0.
- 실제 reduced-motion=true에서 학생 전환 좌표가 492→364.91→259.676→178.761→79.8822→0.001px로 변하고 다음 이미지로 정착. 자동 넘김, 수동 좌우 이동, 일시정지 6.2초 동안 이미지 불변 확인.
- 모바일 목록390/768px: 제목 높이24px 한 행, 목록 행48~49px, 표시되는 열은 제목1개. 1280px에서5열 유지.
- 실제 MainLayout·PortalWorkspace·DeveloperLog renderPostDetail를 사용해 StrictMode에서 작업공간→긴 상세 글 이동 시 workspace footer1→0, fallback0→1 정리 확인. 학생390/768, 교사1280에서 본문 끝과 푸터 시작이 일치.
- 운영 수행평가 글의 교사 화면도 본문 끝787.203px와 푸터 시작787.203px, 끝855.203px(화면855px)로 정상 확인. 누락/겹침을 재현하지 못했으므로 공통 스크롤 구조는 수정하지 않았다.
- 새 본문 그림6개는 built-in imagegen으로 생성한 후 실제 compressDeveloperLogImage 경로로 처리. 원본비율5:2, 출력1280×512, 각각109~175KB, 파랑We/주황story 워터마크 적용.
- 기존 본문과 새 HTML의 학급 일정·쪽수·문항 수를 대조했다. 제목·표·이미지 구조는 실제 편집기에서 보존한다.
- 안내 글3개를320/390/768/1280px에서 확인했다. 문서 가로 넘침0, 모든 표의 scrollWidth=clientWidth. 모바일 전 교과 표는 과목/문항 수 한 행과 전체 너비 범위 행으로 배치하며 강제 줄바꿈을 제거했다. 표의 native 역할도 보존했다.
