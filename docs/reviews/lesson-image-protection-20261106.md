# 학생 수업 자료 이미지 저장 메뉴 차단

## 범위

- 기준: `58586d0290c5edfd78716aefea514bd6f9afd61e` (`origin/main`, 운영 도메인 연결 커밋).
- 학생 `LessonContent` 내부 이미지와 이미지 링크의 `contextmenu`·`dragstart` 기본 동작을 취소한다. iOS의 이미지 길게 누르기 메뉴는 범위를 한정한 `-webkit-touch-callout: none`으로 억제한다.
- 학습지, 본문 HTML, 각주(사료 이미지 포함), 전체 화면에 같은 처리를 적용한다. 교사 편집·제시와 `disablePersistence`를 사용하는 교사 학생 미리보기는 기존 동작을 유지한다.
- 입력란과 일반 텍스트·링크의 메뉴, 텍스트 선택, 터치 이동·확대는 유지한다. 화면 배치·디자인 토큰·단원 목차에는 변경이 없다.
- 학기 경로, 기존 자료 정규화·legacy 처리, 빈칸 정답·마스크·저장, 인증·권한·Functions·rules는 변경하지 않는다. 폐기된 판서 기능은 다시 연결하지 않는다.
- AI 호출·에이전트 실행·외부 데이터 전송·공개 대상·개인정보·처리 위치에 변화가 없는 기존 화면 유지보수다. 보안성 검토 승인이나 면제를 새로 주장하지 않는다.

## 검증

`node scripts/verify-lesson-image-protection-browser.mjs`는 실제 `LessonContent`, `LessonWorksheetStage`, `LessonFootnoteDialog`와 합성 자료를 사용한다. Firebase 접근은 차단하고 운영 데이터에 쓰지 않는다.

- 390/768/1280px의 학생 일반·전체 화면·교사 미리보기.
- 학습지·본문·이미지 링크·일반/사료 각주·각주 HTML 이미지의 메뉴와 드래그.
- 빈칸 메뉴 허용, 한글 조합과 포커스 이탈 뒤 입력 유지.
- 스크롤, 휠 확대, 합성 두 손가락 확대, 단일 터치 취소 여부, 가로 넘침·런타임 오류·외부 요청 없음.
- 기본 `npm run build`(타입 및 기존 필수 회귀 검사 포함), `npm run format:check`.

## 한계

브라우저의 일반적인 이미지 저장 동작을 억제하는 UI 처리다. 이미지 원본 접근 권한을 새로 제한하거나 화면 캡처·개발자 도구 추출을 막는 보안 경계는 아니다. Edge 터치 에뮬레이션과 합성 이벤트 검사를 실제 iOS Safari의 길게 누르기 메뉴 검증으로 취급하지 않는다.
