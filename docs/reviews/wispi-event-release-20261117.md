# 위스피 이벤트·졸업 정산·개발자 일지 통합 (2026-11-17)

## 요청과 경계

- 학생 투자 현황은 현재 보유 수익률 상위 5명의 실제 시기별 꺾은선 그래프 하나로 표시하고 이름을 모두 표시한다. 기존 막대와 개인 선택형 차트는 제거한다.
- 종목 졸업 시 마지막 가격으로 보유 주식을 수수료 없이 전량 정산하여 학생 주식 지갑에 입금한다. 교사가 졸업을 명시적으로 선택하고 확인하며, 이번 배포에서 실제 운영 종목을 임의로 졸업시키지 않는다.
- 이벤트는 기존 이체를 포함한 전체 학기 누적 입금 500위스 이상인 학생에게 인당 한 번 500위스를 주식 지갑으로 지급한다. 이벤트 보상은 거래 수익으로 계산하지 않는다. 일반 지갑의 기존 입금 한도와 대기 시간은 유지한다.
- 생성한 홍보물은 참고 이미지의 그림체만 사용하고, 차트를 보는 새 구도로 제작했다. 원본에는 학생 정보나 사용자 화면을 넣지 않았다. 안내 글 하단에는 역할별 위스피 목적지로 연결되는 실제 버튼을 둔다.
- 개발자 일지의 낙관적 좋아요, 실패 복구, 메타데이터 한 행 및 본문 좌우 여백은 기존 권한과 Firestore rules를 유지한다.
- 런타임 AI 호출·학생 정보 외부 전송·인증/권한·개인정보 수집 항목·새 게임 공개에는 변경이 없다. 기존 서비스 범위의 유지보수와 사용자가 승인한 가상 위스 이벤트다.

## 검증 근거

- `npm run build`: 타입 검사, 기존 필수 회귀 및 Vite 빌드 통과. 기존 큰 청크 경고는 남아 있다.
- `npm --prefix functions run check`: Node 22에서 통과. 금융 후속 보완의 전용 통합 검사는 별도 회계 검증 문서에 기록한다.
- 투자·졸업·이벤트 화면: [투자 현황 검증](wispi-top-five-20261117.md).
- 좋아요 158개 규칙 검사와 46개 브라우저 시나리오: [개발자 일지 검증](developer-log-speed-layout-20261117.md).
- 운영 인덱스는 `scripts/ensure-wispi-campaign-index.mjs`로 필요한 `wis_stock_history / COLLECTION_GROUP / studentUid + kind` 하나만 추가했으며 READY를 확인했다. 다른 운영 인덱스와 rules는 변경하지 않는다.
- 각 Firebase 함수의 운영 원본 ZIP·설정·전체 파일 SHA를 보존하고, `scripts/prepare-wispi-graduation-event-release.mjs`로 패치한다. 기존 함수별 가격 모델 차이는 유지한다.
