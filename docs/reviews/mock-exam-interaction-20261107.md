## 범위

기준 커밋은 `e5986a1f`다. 선지 번호 공백, 보기 사이 방향키 이동, 교사 미리보기의 문항별 풀이, 시험지 선택 표시·머리말·저작권, 지문 빈칸 상자의 크기와 줄바꿈을 수정했다. 첨부 문항의 정답·해설은 개인 작업 경로에 별도로 제공하며 저장소와 운영 문항에 추가하지 않는다.

공통 시험지와 답안 입력부는 교사 미리보기와 학생 풀이 양쪽에 사용된다. 교사 답안은 컴포넌트 상태에만 보관하고 창을 닫으면 지운다. 학생의 기존 20자 제한·순서형·연결형·제출 상태는 공용 입력부 추출 뒤에도 유지한다. 서버·권한·학기 경로·평가 점수 계산은 변경하지 않는다.

## 동작과 화면

- 문항을 클릭하거나 Enter/Space로 열면 파란 테두리와 옅은 파란 배경이 남는다. 풀이에서 시험지로 돌아오면 선택 문항과 포커스를 복원하며, 숨긴 시험지의 0px 측정으로 쪽 배치가 바뀌지 않게 한다.
- 시험지 첫머리 제목은 종이와 함께 스크롤한다. 큰 굵은 제목 아래 부제를 두고 상단에 노비·상민·양반·왕 공란을 배치한다. 전체 쪽수와 현재 쪽수, 위스토리 저작권을 매 쪽 아래에 표시한다.
- 선지 번호와 본문 사이를 0.33em 띄운다. 좁은 미리보기에서도 무공백 어절이 잘리지 않도록 열 수를 보수적으로 계산한다.
- 빈칸은 1px 직각 테두리, 세로 여백 0, 줄높이 1.2를 사용한다. 저장한 em 너비를 유지하며 상자 전체가 다음 줄로 이동한다. 본문보다 큰 상자는 해당 영역 안에서 가로로 스크롤한다. 기존 문장 강조 상자는 유지한다.
- 보기 방향키는 한글 조합과 편집 조합키를 가로채지 않는다. 첫·끝 보기, 추가·삭제, 읽기 전용 상태를 확인했다.
