# 가입 기준과 이순신·윷놀이 안정성 검증

2026-11-02, 변경 전 기준 커밋 `518b91063dcd50ff18270bac7e136ffd8bfb5b9d`. 원격 main과 운영 Vercel `dpl_CtqY1FMxxfxVxexcsG3Pz6qQv6Vf`가 이 기준과 일치함을 확인했다. 기존 미추적 `output/`은 커밋에서 제외한다.

## 수정과 경계

학생 명단의 신규 가입 기준에서 계정 발급 연도·학년을 서버에 저장한다. 2026/3은 `263NNNN`, 2027/2는 `272NNNN`이며 학교 도메인과 숫자 네 자리를 엄격하게 검사한다. 로그인·Firestore 자기 프로필 생성·교사 승인에서 같은 원본을 검사한다. 기존 승인 학생·legacy 계정과 교사 권한은 보존한다. [정책 검토](student-registration-policy-20261102.md)에 상세 계약을 기록했다.

이순신 게임은 답안 요청마다 입력창 disabled/장면 inert/로딩 창 포커스로 키보드가 닫히고 응답 후 강제 focus로 다시 열렸다. viewport scroll 이벤트와 중복 RAF·layout effect가 브라우저 자동 스크롤과 서로 간섭했다. 답안 전송 중 포커스·IME·다음 초안을 유지하면서 중복 명령만 차단하고, 안정된 크기 변경에 한 번만 보정한다. 정산은 기존 전체 차단을 유지한다. 숨김 탭의 50ms 화면 갱신을 중지하며 복귀 때 서버 기준 경과 시간을 다시 계산한다.

윷놀이는 공개 여부 재확인 통신 실패 시 진행 중 컴포넌트가 제거되어 싱글 상태와 미확정 명령 영수증이 사라졌다. 같은 계정·학기의 상태는 메모리에 보존하고 공개 재확인 전까지 숨김·중단한다. 공개 철회·권한 거부는 즉시 차단하며 실시간 구독도 해제한다. 계정·학기 전환은 상태를 폐기한다. 숨김·중단 상태의 250ms 갱신을 멈추고 변하지 않은 판의 합법 이동을 재계산하지 않는다.

게임 규칙·위스 보상·게임 공개 설정·게임 Functions는 변경하지 않는다. 신규 AI 호출·에이전트 실행·외부 AI 데이터 전송이나 개인정보 항목 추가는 없다. 기존 이용 범위의 가입 제한과 오류 복구 유지보수이며 기관 보안성 검토의 미확인 상태를 승인·면제로 바꾸지 않는다.

## 운영 원본 대조

세션 함수 4개의 운영 ZIP에서 `sessionAuthority.js`, `studentRegistrationAccess.js`가 변경 전 소스와 일치했다. 운영 세션의 `studentMaintenance.js` 차이는 이후 도입된 설정 저장용 revision/학기 CAS이며 세션이 사용하는 접근 검사와 wrapper는 동일하다. 설정 저장 함수는 이번 배포 대상이 아니다. 운영 `executeCommand`의 세션·maintenance·등록 접근·승인 adapter와 Firestore rules도 변경 전 소스와 일치했다.

## 검증 결과

- 기본 `npm run build` 통과: 타입 검사, 최종 XLSX hair 테두리, 인증/학기/자료/아바타 검증 포함. 기존 대용량 chunk·정적/동적 import 혼용 경고는 남는다.
- 전체 `npm run format:check` 통과.
- Node 22 환경의 전체 `npm --prefix functions run check`와 가입 정책 Firestore·세션 통합 검증을 통과했다. 손상된 revision `9007199254740992`는 서버와 rules가 모두 차단한다.
- 가입 기준 화면은 320/390/768/1280px에서 설정·동시 수정·조회 오류·초안 보존·응답 유실 후 동일 revision 재시도를 통과했다. 실제 StudentList·모달·adapter·공통 재인증 controller/provider를 사용하며 Google 팝업과 서버 경계만 합성 자료다. 재인증 취소·실패는 저장 0회, 재시도 성공은 저장 1회, 최상단 클릭과 닫은 후 초점 복귀를 확인했다. 읽기 전용 사용자는 설정 버튼·정책 조회가 없다.
- 이순신은 실제 게임·프레임에서 답안 지연, 중복 제출, 다음 초안, 15초 타임아웃과 늦은 응답·같은 eventId 재시도, 모바일 layout/visual viewport, offset·확대·회전·IME·숨김 탭 복귀를 검사했다. 390px 모바일과 768/1280/1366px에서 확인했으며 별도 전체 해전 검사는 23묶음·51캡처, 서버/클라이언트 전투 재현 일치는 8건이다.
