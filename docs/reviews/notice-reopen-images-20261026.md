# 재오픈 이미지 안내와 시험범위 맺음말

## 요청과 적용 범위

재오픈 게시글을 기존 알림장 배너의 파랑·주황, 학생 탐험가와 펼친 책 그림체를 이어받은 이미지 4장으로 구성했다. 역사 지도 탐색, 장소 이야기, 충무공 타자 게임, 마우저구 윷놀이를 각각 소개한다. 시험범위 마지막 이미지의 학교장 표기는 `자세한 사항은 e알리미를 통해 확인하세요`로 바꾼다. 시험 단원·쪽수·문항수·학습지 범위는 그대로다.

공통 이미지 안내 렌더러에는 재오픈 테마만 추가한다. 학생·교사 알림장 모두 같은 본문 렌더러를 사용하며 포털 탐색과 권한에는 변화가 없다. 재오픈도 대표 배너와 더보기만 먼저 표시하고 명시적으로 펼친 뒤 상세 이미지 요소를 만든다. 기존 일반 글·카드뉴스는 기존 렌더링을 유지한다. 본문은 최대 720px 한 열이며 390px 화면에서도 가로 넘침이 없다.

## 콘텐츠 근거

- 지도 종류·필터·지명 검색: `HistoryMaps.tsx`, `HistoryAtlas.tsx`의 한국사/세계사/지구본, 단원/시대/지역, 현재 이름/옛 이름 검색.
- 장소 이야기: `AtlasPlaceDetails.tsx`의 설명, 관련 이야기, 기억할 점, 시대별 보기와 출처. 데이터가 있는 장소라는 조건을 함께 적는다.
- 충무공 게임: `weplayTitle.ts`, 게임 카탈로그와 안내, `LaunchPanel.tsx`의 1인 역사 단어 타자 게임·화포·연습/도전·우리 반 랭킹/내 기록.
- 윷놀이: `YutGame.tsx`의 컴퓨터와 혼자 즐기기, 친구들과 방 생성/참여. 윷가락 삽화는 `YutThrowScene.ts`의 네 개와 맞췄다.
- 두 게임 이미지 모두 교사가 열어 둔 게임과 방식으로 참여한다는 조건을 표시한다. 게임 공개 설정에는 쓰기가 없다.

## 이미지와 검증

`public/notice-guides/20261026/reopen-01.webp`부터 `reopen-04.webp`, `exam-05-v2.webp`를 추가한다. 1024×1536 원본을 무손실 WebP로 저장하고 디코딩 픽셀이 생성 원본과 같은지 확인했다. 기존 immutable 시험범위 URL을 덮어쓰지 않고 새 파일명을 사용한다. 생성 문안은 이미지 alt에도 저장한다.

- `node scripts/verify-notice-image-article-browser.mjs`: 390·768·1280px에서 재오픈 테마, 더보기 전 상세 요청 0건, 펼침/접기, 게시글·본문·미리보기 변경 초기화, 키보드, 검색과 일반 글 회귀 검증 통과.
- 실제 신규 이미지와 본문으로 동일한 세 화면 폭 검증: 가로 넘침 0, 더보기 전 상세 요청 0, 브라우저 오류 0. 글자·표·문장 줄바꿈을 스크린샷으로 확인했다.
- 독립 시각 검수: 최종 4개 윷가락, 게임명과 전체 문안 일치. 시험범위 마지막 장의 5개 단원·번호·쪽수·문항수·학습지 범위 일치.
- `npm run build`, 변경 TSX/검증 스크립트 Prettier 확인, `git diff --check` 통과. 전체 빌드의 수행평가 엑셀 원본 hair 구분선 회귀 검사도 통과했다.

로컬 이미지·문안·검증 증거는 `output/notice-followup-20261026/`에 보관한다. 운영 반영은 Vercel의 해당 커밋을 운영 도메인으로 승격하고 새 이미지의 해시와 캐시 헤더를 확인한 뒤, 기존 재오픈·시험범위 두 게시글만 수정한다. 수정 직전 원문과 updateTime을 확인하고 원자적 쓰기를 사용한다. 생성일·게시일·대표 배너·작성자·고정 여부는 보존한다.
