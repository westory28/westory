# 위스피 기획안·종료 일정·전광판 점검

기준: 2026-11-23, `139ad72f4f67cc826a6579922c91b80ac9a2ac65`.
회사 PC의 깨끗한 main을 원격보다 7커밋 앞선 위 기준으로 fast-forward했고,
Vercel 운영 도메인 `www.westory.kr`도 같은 Source/Ready임을 확인했다.

## 원인과 변경

- 6주 기획안은 고정 날짜·100위스·별도 시드·1시간 합성 시세였고 하루 제한만 반영했다.
  등록 종목은 운영 객체와 실제 이력을 그대로 표시한다. 미상장 종목만 저장된 전체 가격 규칙,
  시작일, 30분 주기로 브라우저에서 계산한다. 실제 이력에 가상 미래 시세를 붙이지 않는다.
  같은 화면에서 규칙을 저장하면 즉시 반영하고 다른 PC의 변경은 새로고침으로 받는다.
  계산은 화면 수명 안에서 규칙·학기·일정 값에 의존하며 새 서버 폴링이나 구독을 추가하지 않는다.
- 종료는 고장이 아니라 상장만 연결한 기존 설계의 미구현 영역이었다.
  운영 읽기에서 26종목이 ACTIVE이고 정각·30분 가격 작업과 주문 복구 작업이 ENABLED임을 확인했다.
  비파메탈은 431위스, 11월 23일 17:30:08 KST까지 갱신됐으며 기획상 종료는 11월 20일 11시였다.
- 사용자는 지난 종료일을 오늘 이후로 옮기고 향후 기획안과 맞추도록 지시했다.
  돌끝테크·비파메탈은 11월 24일 11시, 거석리프트는 12시, 빗살키친은 13시,
  위만브릿지는 14시로 연장하는 적용 화면을 제공한다. 나머지 미래 일정은 유지한다.
- `activateWisStockCatalogExits`는 권한·활성 학기·revision·영수증을 검사한다.
  원본 `catalogPlan` v1은 유지하고 최상위 `catalogExits`에 활성화·연장 정보를 보관한다.
  관리 응답에서만 두 자료를 합쳐 같은 날짜 함수로 기획안과 운영을 표시한다.
  활성화 자체는 학생 계좌를 바꾸지 않는다. 배포만으로 자동 종료를 활성화하지 않는다.
- 도래한 canonical 기획 종목은 다음 가격 계산 전에 마지막 실제 가격을 고정하고,
  기존 GRADUATED 작업으로 예약 취소·보유 주식 무수수료 정산·주식 계좌 입금을 처리한다.
  이름만 같은 개별 등록 종목은 자동 종료하지 않는다. 중지·비공개·휴장에는 보류하고
  다음 거래 회차/재개에서 처리한다. 기존 실패 롤백·영수증·중복 차단을 유지한다.
- 정렬 옆 공통 InfoHelp에 총자산(주식 계좌 현금+보유 평가액), 평가손익(평가액−매수 원가),
  제외 항목과 동액 정렬을 개조식으로 제공한다. 학생 화면은 바꾸지 않는다.
- 속보는 개별 상장/시세 사건의 정각·30분 구간 안에서 10분 간격으로 표시한다.
  30분 경계에서 표시·음성을 종료하며 전일 대비나 문서 갱신만으로 오래된 사건을 재생하지 않는다.
  닫기 왼쪽에 알림음·음성 독립 토글을 두고 기본 꺼짐으로 시작한다.
  한국어 고품질/Google 음성을 우선하며 같은 품질이면 로컬 음성을 선택한다.
  기기·브라우저 제공 음성의 품질/가용성은 달라질 수 있다.

  변경 없는 회차/재처리는 2읽기/0쓰기. 새 스케줄러·감시 작업은 없다.

## 배포 범위와 운영 확인

`scripts/prepare-wispi-lifecycle-release.mjs`의 snapshot/prepare/before/after 절차를 사용한다.
함수별 운영 ZIP·IAM·자원·환경과 스케줄러를 보존하고 두 관리 모듈과 공통 날짜 모듈만 교체한다.
getWisStockManagement/saveWisStockMarketRules는 확인된 `1854e214` 소스였으며,
이미 운영 중인 `139ad72f`의 상장가 변경을 포함한 현재 관리 모듈로 맞춘다.
나머지 4개는 `139ad72f`와 일치했다. 관련 없는 운영 파일은 해시로 보존한다.

대상은 getWisStockManagement, saveWisStock, saveWisStockMarketRules,
setWisStockMarketHalted, activateWisStockCatalogPlan, advanceWisStockPrices와
신규 activateWisStockCatalogExits다. rules·학생 거래·정산 worker·랭킹은 재배포하지 않는다.
서버 확인 후 같은 main 프론트엔드를 Vercel 운영으로 승격하고 지정 Chrome 프로필에서
종료 일정의 5개 연장값을 확인해 명령을 실행한다. 운영에서 테스트 정산을 만들지 않는다.
실제 학생 자산을 소급 변경하거나 11월 24일 미래 종료를 이미 완료된 정산으로 보고하지 않는다.

음성은 종목명·상장가·가격 변동 문장만 브라우저 음성 합성기에 전달한다.
선택 음성에 따라 브라우저/운영체제 제공자의 음성 서비스를 쓸 수 있으며 학생 정보는 전달하지 않는다.
새 외부 AI API·API 키·학생 개인정보 전송·공개 범위 확대는 없다.
증거는 Git 제외 `output/wispi-lifecycle-20261123`, `output/wispi-plan-sync-20261123`,
`output/wispi-catalog-exits-20261123` 및 각 브라우저 검사 출력에 보관한다.
