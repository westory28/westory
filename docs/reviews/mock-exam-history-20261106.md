# 모의고사 회차·응시 기록 연결 검증

기준 커밋: `a290b0f9cae67eb30b2841a752bbe775ae1f3b81`. 이 문서는 시험지 패치 중 출제 원본 검증과 학생 마이페이지 연결 범위를 기록한다. 운영 반영 여부는 전체 패치의 배포 기록에서 별도로 확인한다.

## 출제 원본과 서버 계약

- 학기별 `quiz_questions` 조회와 기존 세션·권한 경로를 유지한다. 회차가 지정된 모의고사 문항이 한 개라도 있으면 해당 `examRound`와 정확하게 일치하는 문항만 출제 원본으로 취급한다. 비어 있는 회차에 다른 회차나 옛 공통 문제은행 문항을 대신 넣지 않는다.
- 회차를 지정한 문항이 전혀 없는 기존 문제은행은 이전 원본 해시 형식과 호환된다. 신규 회차의 원본 해시는 기존 `id`, `answer`, `sourceRevision`에 `examRound`, `paperOrder`, `points`를 더한 뒤 ID순 정렬과 canonical JSON을 사용한다. 줄바꿈·페이지 나눔 등 본문 변경은 기존 `contentRevision`으로 함께 검출한다.
- 브라우저 공개 준비 목록과 서버 채점·출제 경로가 같은 문항 수와 해시를 사용한다. 고정 시험지의 실제 문항 수로 준비 목록을 계산하며 이전 무작위 출제 설정의 문항 수가 새 시험지를 잘라내지 않는다.

## 학생 마이페이지

- `getMyQuizHistory`가 반환한 저장 당시 문항·정답·학생 답안·채점 결과만 사용한다. 마이페이지에서 현재 문제은행을 다시 읽지 않는다.
- 저장된 배점·문항 순서·페이지 나눔을 공통 시험지에 전달한다. 문제를 누르면 기존 큰 문항 상세로 이동하고 키보드 포커스를 옮긴다. 정답·내 답·해설·연결 자료와 오답 복습은 기존 흐름을 유지한다.
- 문제 원문이 일부 보관되지 않은 과거 기록은 완전한 시험지로 재구성하지 않는다. 기존 문항별 조회와 `문제 원문이 보관되어 있지 않습니다.`, `답안 미보관` 처리를 유지한다. 미보관 값과 실제 미응답·0점을 구별한다.
- 루트·학기별 legacy 읽기나 canonical 소유자·학기 검사를 넓히지 않았다. AI 호출이나 외부 데이터 전송을 추가하지 않았다.

## 로컬 검증

- `node scripts/verify-assessment-release.mjs`: 실제 서버 adapter와 브라우저 공개 준비 로직을 합성 저장소에서 실행. 회차별 격리, 빈 회차 차단, 문항 수 보정, 서버/브라우저 해시 일치, 다른 회차 편집 시 기존 회차 해시 보존 통과. 기존 공개·일시중지·경합·학기 전환·응답 유실 복구 회귀도 통과.
- `node scripts/verify-mypage-assessment.mjs`: 기록 정규화·소유자·학기·중복·누락 점수 회귀 25개 통과.
- `node scripts/verify-quiz-history-identity.mjs`: 출제→복원→답안→제출→저장 원문 연결 시나리오 18개 통과.
- `node scripts/verify-quiz-relearning.mjs`: 기존 문항 유형·오답 복습과 저장 시험지 메타데이터, 새 회차 이름 검증 통과.
- `node scripts/verify-mock-exam-history-browser.mjs`: 실제 `MyQuizHistory`와 공통 시험지를 Edge의 390/768/1280px에서 확인. 문서 가로 넘침 없음, 점수·페이지 나눔·내 답 표시, 문항 클릭과 포커스 이동, 원문 미보관 fallback 통과. 외부 네트워크와 Firebase 런타임을 제외한 합성 응답만 사용했다. 실물 태블릿 검증은 포함하지 않는다.
- `node scripts/verify-mock-exam-runner-browser.mjs`: 실제 `QuizRunner`·제출 확인창·시험지 확대 UI를 합성 서버 경계로 실행한다. 390/768/1280px에서 임의 문항 열기, 키보드 확대·Escape 복귀, 선택형·단답형 답안, 자동저장 후 새로고침·이어하기, 미응답 포함 제출 확인과 취소, 제출 실패 후 동일 답안 재시도, 저장 원문·해설 표시를 검증한다. 3문항 중 1문항 정답이지만 가중 점수가 30점인 결과로 서버 점수가 33점으로 재계산되지 않는지 확인한다. 터치 가로 화면 CSS 회전과 세로 복귀 후 답안 보존, 키보드 높이 변화 모사도 포함한다. 이는 브라우저 모사이며 실물 키보드·태블릿 확인을 대체하지 않는다. 16문항 시험지와 긴 자료 확대의 두 단 배치·스크롤을 별도로 확인한다.

브라우저 산출물은 기본적으로 운영 데이터가 없는 임시 폴더 `westory-mock-history-*`에 저장한다. `MOCK_EXAM_HISTORY_EVIDENCE_DIR`로 별도 검증 경로를 지정할 수 있다.
러너 산출물은 `westory-mock-runner-*` 또는 `MOCK_EXAM_RUNNER_EVIDENCE_DIR`에 저장한다. 러너 검증은 기존 공식 Tailwind 런타임 캐시 `westory-qa-tailwind.js`를 사용하며 `PORTAL_DESIGN_TAILWIND_PATH`나 `ASSESSMENT_QA_TAILWIND`로 지정할 수 있다.
