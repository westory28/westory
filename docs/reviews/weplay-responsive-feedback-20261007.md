# 위플레이 입력 반응·효과음·로딩 개선

## 변경

- 화면에 보이는 정답을 입력하면 표시용 이벤트를 즉시 반영한다. 서버는 정답 인정과 위스 정산을 계속 결정한다. 누적 응답의 도착 순서가 바뀌어도 발사를 반복하지 않고, 거절·오류 시 예측 피해와 예약 효과를 취소한다.
- 일반 화포는 필살기 연출 중에도 즉시 발사하며 420ms 뒤 독립 명중한다. 거북선 이미지의 실제 표시 영역과 움직임을 기준으로 입 위치를 구한다.
- 제목의 붓글씨 하단과 지휘관 그림의 표시 범위를 복원하고, 잘린 화포 장식을 실제 HTML 장전 게이지로 정리했다.
- 직접 합성한 장전·포격·연속 포격 효과음을 추가했다. 기존 소리 버튼과 음소거 상태를 공유하며 탭 숨김·최종 화면 종료 시 정지한다.
- 학생 메뉴의 마우스·키보드·터치 접근 시 게임 코드만 선로딩한다. 대기 화면 요청 중 공개 이미지도 미리 읽는다. 사용자 데이터나 게임 시작 요청을 선실행하지 않는다.
- 서버는 빈칸 추출과 공개·삭제·최신 자료 판별에 필요한 학습지 필드만 읽는다. 독립 조회를 병렬화하되, 만료 게임 정산 뒤 잔액·기록·랭킹을 읽는 순서는 유지한다.

## 검증

- `npm run build`: 타입 검사, 학기 자료 보호, NEIS·채점 엑셀 hair 경계선 회귀 포함 통과.
- Functions 문법 검사와 위플레이 단위 테스트 32개 통과.
- 입력 지연 브라우저 7그룹: 500–2000ms 응답 지연, 역순 응답, 거절/오류 복구, 동일 요청키 재시도, 연속 네 단어 두 발, 필살기 중 일반 발사, 서버 결과 정산 통과.
- 320/390/768/1280px에서 포구 중심 오차 0.54px 이하. 로고·장전칸·게이지 글자 잘림과 가로 넘침 없음.
- 안내 브라우저 15그룹, 대기/종료 브라우저 12그룹, 음악 7그룹, 효과음 7그룹, 선로딩 6그룹 통과. 학생·도전·교사 미리보기와 키보드·터치·효과 줄이기 경로 포함.
- 격리 Firestore 검증: HTML/PDF 빈칸, 학기/레거시 우선순위, 공개 변경 즉시 반영, 반복 시작의 1회 차감, 만료 게임 복구 직후 잔액·기록·랭킹 일관성 통과.
- 기존 광범위 통합 에뮬레이터는 위플레이 관련 6그룹 통과 후 별도 학생 정리 관리자 fixture의 `auth_time` 누락으로 중단됐다. 전체 통합 통과로 간주하지 않는다.

동일 로컬 에뮬레이터 fixture를 3회 측정한 중앙값은 대기 75→46ms, 연습 시작 188→96ms, 도전 시작 279→140ms였다. 학습지 응답은 432,914→854바이트였다. 이 수치는 운영 네트워크 속도나 실제 학습지 크기를 보장하지 않는다. 콜드 스타트와 네트워크 지연은 남는다.

운영 소스 대조에서 대상 5개 함수의 기존 `index.js`, `weplay.js`, `weplayCore.js`, `weplayBattle.js`, `package.json`이 작업 전 HEAD와 일치했다. 배포 범위는 `getWeplayLobby`, `getWeplayManagement`, `saveWeplayGameSettings`, `previewWeplayGame`, `startWeplayGame`으로 한정한다. 로그인 함수와 rules는 이 패치에서 배포하지 않는다.
