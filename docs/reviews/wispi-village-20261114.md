# 위스 마을·위스피 후속 검증 (2026-11-14)

기준은 `ce126312`까지의 main이며, 별도 checkout에서 원래 작업 폴더의 미커밋 변경을 보존했다. 동시에 진행된 아바타 외형·중복 안내 제거 변경도 통합했다. 이번 패치는 런타임 AI나 외부 자료 전송을 추가하지 않는다.

## 화면과 접근 경계

- 교사 위스 마을: 위스 상점 / 아바타 상점 / 위스피(WsPI). 기존 URL·권한 키를 유지하고 구매 요청은 상점 내부 탭으로 이동했다. 학생은 기존 공개된 상점·아바타만 보며 위스피와 실제 매매는 닫혀 있다.
- 아바타는 종류 버튼·유형 배지와 관리/학생 상점 미리보기 두 탭이다. 초안과 필터를 보존하고 미리보기 구매·저장을 차단한다. 저장된 자료 1회 조회 뒤 필터·유형·미리보기 전환은 추가 조회 0회다.
- 위스피의 규칙 구분선과 회색 탭 밑선을 제거했다. 새 종목 추가는 관리 하단 오른쪽의 파란 버튼이다. 모든 탭에 빨간 비상 정지가 있고 PC에서는 탭 행 오른쪽에 놓는다. 767px 이하에서는 탭을 가리지 않도록 버튼을 다음 행 오른쪽에 배치한다.
- 차트는 흰 모눈 격자, 위스 가격축·한국 날짜/시간축, 실제 관측값 툴팁을 제공한다. hover·터치·방향키/Home/End/Escape를 지원하고 모션 감소 설정을 존중한다. 조회된 이력만 사용하며 상호작용으로 추가 RPC를 만들지 않는다.

## 거래 정지 서버 계약

일반 규칙 저장은 `halted` 값을 바꾸지 않는다. 별도 정지 명령은 현재 권한·세션·학기를 트랜잭션 안에서 확인하고 flag·revision·수정 시각과 영수증을 함께 기록한다. 새 정지 요청은 이미 정지 중이어도 revision을 올려 이전에 시작된 재개 요청을 무효화한다. 재개만 현재 revision 일치를 요구한다. 동일 영수증 재시도는 0쓰기, 새로운 정지는 6읽기/2쓰기다. 일반 저장·조회 응답의 낮은 revision은 UI 상태를 되돌리지 못한다.
