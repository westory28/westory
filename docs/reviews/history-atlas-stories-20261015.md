# 역사 지도 설명·관계·강조 보완

## 변경 범위

- 한국사·세계사 평면 지도는 선택한 과목 안에서만 시대 이야기·관련 장소·교과서 출처를 탐색한다. 지구본 상세는 두 과목을 함께 고려한다.
- 교과서 지도 제목·자료 등장 기록을 역사 사건으로 취급하지 않는다. 원래 자료 색인은 출처 영역에 보존한다.
- 출처가 있는 역사 이야기 283개를 321개 지명에 연결했다. 한국사 98개, 세계사 99개를 보강하고 기존 출처 설명에서 시대가 명시된 이야기 86개를 분리했다. 각 이야기에는 시기·시대·출처와 실제 관계를 저장한다.
- 관련 장소는 같은 자료·단원에 등장했다는 이유로 연결하지 않는다. 다중 장소 이야기의 관계에는 출발 지명을 명시하여 도시의 관계가 유적이나 다른 나라로 전파되지 않도록 했다. 역방향 탐색도 같은 출발 제한을 적용한다.
- 철원의 905년 천도, 911년 태봉 개칭, 918년 고려 건국과 개경의 919년 천도를 구분했다. 930년 고창 전투는 전북 고창에서 안동으로 바로잡고 당시 지명을 함께 표시한다. 세계사 나라 시대 도다이지 및 로마의 시대 분류를 교정했다.
- 도시·건축물이 하나의 이야기를 공유할 때 각각의 역할을 명시했다. 근현대 서울, 스탈린그라드 등 시대에 맞는 이름을 보존한다.
- 해당 시대에 확인된 설명이 없으면 장소 개요를 표시한다. 다른 시대의 사건을 개요로 다시 주입하던 fallback도 차단했다.
- 점·배지의 2.4초 물결 강조를 복구했다. 요청에 따라 위치 강조는 운영체제의 움직임 줄이기 설정과 별도로 기본 켜짐이며, 44px 켜기·끄기 버튼을 제공한다. 카메라의 움직임 줄이기는 유지한다. 화면 밖·비활성 탭의 강조는 일시 정지한다.

## 검증

- `npm run build`: 타입 검사, 학기 보관·평가 XLSX·학습지·역사 지도 회귀 검증과 Vite 빌드.
- `npm run format:check`, `git diff --check`.
- `node scripts/verify-history-atlas-stories.mjs --report`: 2,639개 지명의 과목 경계·시대 정렬·출처 구조·관계 출발점·대체 항목·실제 상세 컴포넌트 SSR 검사. 철원, 고창 전투, 도다이지, 현대 서울, 발해 지도 원산의 다른 시대 fallback, 공유 장소의 한국사/세계사/지구본 범위와 도시-유적 역방향 관계 회귀를 포함한다.
- 실제 Chrome에서 390px, 768px, 1440px 화면 확인. 한국사 철원→태봉 연결, 세계사 로마의 시대와 관계, 지구본 팝업 및 지도 선택 강조를 확인했다. 좁은 화면 상세 패널 가로 넘침이 없고 Escape로 닫힌다.
- 움직임 줄이기가 켜진 환경에서도 평면 지도 점의 scale·opacity와 배지 shadow가 시간에 따라 변함을 확인했다. 지구본 점·배지의 변환 행렬도 변화하며, 끄면 모두 `animation-name: none`으로 바뀐다.
- 공통 지도 컴포넌트와 정적 자료만 수정했다. 학생·교사 지도 진입부와 권한·저장 경로는 수정하지 않았다.

## 범위와 남은 자료 한계

[전체 지명 점검표](history-atlas-story-audit-20261015.json)는 구조 검사 결과이며 모든 지명의 역사 서술을 개별 완성했다는 뜻은 아니다. 2,125개 지명/과목 조합은 확인된 사건 없이 장소 개요로 남는다. 일반 지리 지명과 근거가 부족한 항목에 임의의 역사 사건·관계를 생성하지 않았다. 관계 검사 수는 선택 이야기별 탐색 결과의 합계이며 고유 관계 개수가 아니다.

기존 교과서 원본 coverage ledger의 미해결 source layer 5개는 유지된다. 이번 작업은 원본 PDF 전 페이지를 새로 읽었다는 증명이 아니다. Vite의 큰 청크 경고도 남지만 자료 gzip 예산 검증은 통과한다.

운영 배포와 실제 도메인 확인 결과는 완료 보고에 기록한다.
