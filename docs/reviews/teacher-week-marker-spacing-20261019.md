# 교사 주간 일정 점 간격 (2026-10-19)

- 기준: `9fd52417`. 일정별 점을 추가한 `b0b25e36`과 날짜 숫자를 흰색으로 유지한 `d14f7611`을 확인했다.
- 운영 교사 대시보드에서 오늘 날짜 원의 외곽선과 일정 점이 2px 겹치는 것을 측정했다. 점의 기존 `translateY(-2px)`가 원인이었다.
- 교사 전용 점 행만 `translateY(4px)`로 조정했다. 기존 4px 간격 토큰을 재사용하며, 원의 외곽선 아래 실제 간격은 4px다. 날짜 원과 주간 스트립의 크기는 유지한다.
- 기존 주간 일정 브라우저 fixture를 `--serve`로 실행하고 Chrome에서 390/768/1280/1366px를 확인했다. 모든 폭에서 외곽선과 점 사이 4px, 가로 넘침 없음, 일정 7개와 12개 날짜의 한 줄 점 표시를 확인했다.
- 학생 전용 스타일과 데이터·권한·저장 로직은 수정하지 않았다.
- `npm run build` 통과. 최종 XLSX의 `hair` 테두리 검사를 포함한 사전 검증도 통과했다. 기존 청크 크기 및 정적/동적 import 경고는 남아 있다.
