# 평가 공개 학급 선택과 저장 복구

## 원인과 변경 범위

학교 설정·이전 사용자 프로필로 만든 학급 목록과 현재 학기 canonical 학급 목록이 달랐다. 2026-2 운영 학급은 3-1~3-10이며, 설정창에 함께 표시된 미등록 테스트 학급을 선택하면 `ASSESSMENT_CLASS_NOT_FOUND`로 저장 전체가 거절됐다.

교사 평가 설정창은 현재 학기의 ACTIVE·쓰기 가능한 학급만 조회한다. 별도 공개/비공개 라디오는 제거하고, 선택 학급이 있으면 공개, 없으면 비공개로 저장한다. 새 평가는 빈 선택으로 시작한다. 기존 PAUSED 평가에 남은 과거 학급 선택은 폼에 적용하지 않아 문항 수·시간 변경만으로 재공개하지 않는다. 기존 공개 평가의 유효하지 않은 학급은 경고와 해제 동작을 유지하고, 해제 전에는 저장을 막는다. 모두 선택은 현재 유효한 학급만 선택한다.

서버는 미등록 학급을 무시하거나 legacy 학급으로 우회하지 않는다. 기존 학급·학기·세션 검사를 유지하며 실패한 학급을 한글 오류에 표시한다. 학급을 모두 비워 저장하면 canonical 배정도 함께 비운다. 학생 화면과 rules는 수정하지 않는다.

## 디자인 확인

루트 AGENTS.md → UI_RULES.md → 교사 AGENTS.md, DESIGN.md의 지도 기준 화면 계약 및 평가 설정 계약을 확인했다. 교사 설정 모달의 기존 폼·구분선·간격·색상 토큰을 재사용하며 새 토큰을 추가하지 않는다. 공개 방식과 응시 초기화 도움말은 제목 뒤 하나의 i 버튼에 모으고 중복 상시 안내를 제거한다. 단원 트리는 기존 계층 탐색에 필요하므로 유지한다.

브라우저 증거는 `.superloopy/sessions/assessment-publication-20261019/evidence/`에 저장한다. 320/390/768/1280/1366px에서 모달·본문의 가로 넘침, 저장 버튼, 옵션 구분선, 모바일 한 열 배치를 확인한다. 새 카드·테마·글꼴·색상·간격 체계를 도입하지 않는다.

## 검증과 운영 계약

- `npm run verify:quiz-settings`: 실제 설정창과 토스트를 합성 서버 경계에서 검증한다. 기본 비공개, 선택 저장으로 공개, 전체 해제로 비공개, 재열기, PAUSED 과거 대상, 실패·재시도, 중복 저장 방지, 읽기 전용, 모의고사 규칙, 유효하지 않은 기존 학급 복구를 포함한다.
- `node scripts/verify-assessment-release.mjs`: 실제 브라우저 adapter와 서버 명령을 연결해 원자적 공개·비공개, source/revision 충돌과 기존 학생 평가 계약을 확인한다.
- `npm --prefix functions run check`: 새 학급 조회의 관리 권한·세션·현재 학기·readOnly·타학기 제외와 기존 평가·학습·보상 계약을 확인한다.
- 루트 기본 검증은 `npm run build`이며 최종 XLSX hair 테두리 회귀를 포함한다.

운영 원본은 executeCommand generation `1792320234111814`와 getAssessmentState generation `1792121951455773`을 대조했다. 변경한 assessmentLifecycle 의존 소스는 두 운영 원본과 LF 정규화 기준 일치했다. 대상 Functions는 서울 `executeCommand`, `getAssessmentState` 두 개다. 새 프론트보다 먼저 이 두 함수를 배포한다. 프론트는 검증한 main 커밋의 Vercel 배포를 운영으로 승격하고 `www.westory.kr`의 교사 설정창에서 실제 반영을 확인한다. 검증 목적으로 평가를 새로 만들거나 학생에게 공개하지 않는다.
