# 학생 위스피 봉차트 연결

기준은 `main`의 `4af6f4f7da0e7cf1cddb9da2fff5efee0febfdf2`이며 원격과 운영 도메인이 일치했다. 학생 `WisStocks.tsx`가 공통 차트를 기본 선차트로 호출하던 부분에 `variant="candlestick"`를 명시한다. 기존 공통 기능으로 기본 일봉·시간봉·주봉, 실제 관측의 시가·고가·저가·종가와 상승 빨강·하락 파랑 채움을 제공한다. 교사 화면과 공통 계산 로직은 변경하지 않는다.

실제 학생 화면 컴포넌트를 합성 자료로 열어 390/768/1280px에서 화면과 계산 스타일을 확인했다. 하락 몸통·테두리는 `rgb(37, 99, 235)`이며 선택 버튼은 투명 배경과 44px 이상의 높이를 유지한다. 기간 전환·키보드·터치와 실제 OHLC 값이 일치하고 추가 서버 요청은 0건이다. 기존 학생 위스피 회귀를 포함한 28항목이 통과했다. 기존 브라우저 검사의 선차트 애니메이션 대기는 봉차트 표시·완료 대기로 바꿨다.

포맷·diff 검사와 `npm run build`가 통과했다. 같은 main 커밋을 Vercel에서 운영 도메인으로 승격하고 학생 시장 번들과 공통 봉차트 스타일을 운영 도메인에서 확인한다. 서버 조회·쓰기·권한·학기·거래 동작과 AI 호출·외부 전송은 변경하지 않으며 Firebase 배포는 필요하지 않다. 운영 학생 거래는 검증에 사용하지 않는다. 증거는 로컬 `output/wispi-student-candles-20261118/`에 보관한다.
