# 학생 역사교실 학습지 가독성 (2026-10-21)

- 학생 runner만 `studentSolve` 변형을 사용한다. 하단의 단원 경로·통과 기준을 숨기고, MainLayout의 포털 푸터는 학생 역사교실 실행 경로에서만 제외한다. 제목·타이머·페이지·힌트·단어 목록·제출과 기존 내비게이션은 유지한다.
- 학습지를 화면 높이에 맞춰 축소하던 기본 배율을 학생 화면에서는 너비 맞춤으로 바꾼다. 원본 빈칸 좌표·크기·마스크는 유지한다. 긴 페이지는 기본 배율에서도 한 손가락·마우스로 이동하고 일반 휠은 세로 스크롤한다.
- 학습지 실제 상단부터 visual viewport 하단까지의 남은 공간을 사용한다. 키보드가 열려도 입력 배율과 답안을 유지하고 아래쪽의 활성 입력칸을 가시 영역으로 옮긴다. window scroll마다 문서 높이를 늘리지 않으며 측정 상단은 sticky 도구막대 아래로 제한한다. 단어 목록을 펼칠 때도 학습지의 현재 세로 위치를 유지한다.
- 학생 화면 외곽·도구막대 아래 간격은 4px, 맞춤 여백·하단 여유는 8px다. 교사 미리보기의 높이·전체 페이지 맞춤·하단 정보·휠 조작은 기존 분기를 유지한다. 화면 계약의 학생 풀이 예외는 DESIGN.md에 기록했다.
- 실제 학생 컴포넌트 38개 브라우저 시나리오를 통과했다. 추가 검증은 390/768/1280px에서 계정 영역 48px, visual viewport 높이 절반 축소·24px 이동·키보드 닫힘, 페이지 아래쪽 입력칸, 답안 크기·내용 유지와 기본 배율의 긴 문서 터치 이동이다. 기존 시작·이탈·통신 장애·복구·제출도 함께 검사했다.
- 교사 실제 컴포넌트 390/768/1024/1280/1366px 검증을 통과했다. 공통 포털 반응형 검사와 루트 빌드·포맷 검사 후 검증한 커밋을 운영 Vercel 도메인으로 승격한다. 운영 학생 응시나 답안에는 쓰지 않는다.
- 합성 검증 증거는 Git에서 제외한 `.superloopy/sessions/history-classroom-stabilization/evidence/runner-worksheet-keyboard-*`와 `runner-active-*`에 둔다.
