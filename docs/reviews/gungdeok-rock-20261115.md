- 독자적인 신문고 SVG, 중앙 원형 터치, 가운데 쿵/가장자리 덕, 두 줄 세로 악보. 기존 상용 게임의 캐릭터·로고·그림·화면 배치·음원을 사용하지 않았다. 유사성에 대한 법률적 확정을 의미하지 않는다.
- 터치와 F/J·D/K, 버튼의 Enter/Space, 세 가지 난이도, 3초 준비 박자, 판정·콤보·결과·재도전.
- AudioContext 한 시계로 음원·노트·판정을 맞춘다. 사용자 시작 전 소리 없음, 음소거 선호 재사용, 시차 ±250ms, 탭 숨김/창 이탈/오디오 중단 시 일시정지. 공개 해제 시 플레이·음원을 종료한다.

## 곡과 권리 확인

## 공개·권한·비용 경계

공개 문서는 `years/{year}/semesters/{semester}/rhythm_publication/gungdeok-rock` 한 건이다. 기본 문서 미존재는 비공개이며 제작·배포·미리보기로 공개 문서를 만들지 않는다. 현재 학기, 활성 세션, 승인·재적·삭제 상태, 메뉴 공개 여부를 Firestore rules에서 검사한다. 교사 미리보기는 관리 읽기 권한으로 분리한다.

실시간 문서 구독만 사용하며 캐시·미확인·오류 상태에서는 새 연주/계속하기를 막는다. 비공개 전환은 즉시 게임을 해제한다. 숨은 탭과 오프라인에서는 구독을 정리하고 복귀 시 서버 상태를 재확인한다. 계정·인증 세대·학기·역할 경계를 넘어 이전 결과를 재사용하지 않는다. 목록 전체 조회·폴링·음원 네트워크 요청은 없다.

학생의 매 곡 시작·재개에는 정확한 공개 문서를 서버에서 1번 더 읽어 시간 경과로 만료된 세션도 재검사한다. 확인 전에는 AudioContext만 준비하고 소리를 예약하지 않는다. 교사 미리보기는 추가 시작 조회가 없다. 비공개 게임 이름이 사이드바에 나타나지 않도록 기본 학생 하위 메뉴는 추가하지 않으며 공개 확인된 게임 목록으로만 진입한다.

설정 변경은 transaction에서 공개 1문서와 교사 전용 마지막 변경 감사 1문서를 함께 쓴다. 교사 UID는 학생에게 읽히는 공개 문서에 넣지 않는다. 실제 변경은 1읽기·2쓰기, 무변경·응답 유실 재시도·revision 충돌은 1읽기·0쓰기다(권한 규칙의 종속 문서 조회는 별도). 개인정보 항목·외부 서비스·처리 위치·기존 학생 범위는 확장하지 않는다. 기존 승인 범위 안의 유지보수/비공개 기능 추가로 다루며 기관 승인·면제 상태를 새로 단정하지 않는다.
