# 평가 설정과 교사 알림장 검증

## 변경 범위

- 평가 설정 저장 성공 후 창을 닫고 공통 우하단 토스트를 표시한다. 실패하면 창과 입력값을 유지한다.
- 공개/비공개를 고정 라벨의 라디오 버튼으로 선택하며 적용할 학급 범위를 표시한다. 성공 알림의 공개 여부는 저장 응답의 `status`로 판정한다.
- 새 진단·형성평가만 20문항·15분·단원 순서·힌트 3회·재응시 허용·5분 대기를 적용한다. 기존 canonical/legacy 저장값과 모의고사 규칙을 보존한다.
- 문항 수·제한 시간·출제 순서·힌트·재응시 사이에 구분선을 추가한다. 교사 알림장은 기존 `ws-surface`를 사용한다.

## 원인 확인

기존 체크박스는 체크 해제 시 ‘모든 학생에게 비공개’라는 라벨을 표시했다. 이 상태에서도 학급 선택은 보존되므로 학급 체크만 보고 공개로 해석할 여지가 있었다. 서버의 저장 상태가 뒤집히는 결함은 확인되지 않았다.

`saveQuizAssessmentSettings`는 설정과 공개 상태를 원자적으로 저장한다. 응답에는 `status`와 `revision` 등이 있고 `assignedClassIds`는 없다. 공개 여부는 응답으로 확인하고 학급 수는 성공한 요청의 선택 목록으로 표시한다. Firebase Functions·rules·학생 화면 코드는 변경하지 않았다.

## 검증 결과

- `npm run build`: 통과. 타입 검사와 필수 사전 검증 포함. 기존 청크 크기 경고는 유지된다.
- `npm run verify:assessment-release`: 통과. 실제 서버 어댑터를 합성 저장소로 실행해 공개/비공개 원자 반영과 실패 시 기존 상태 보존을 확인했다.
- `npm run verify:quiz-settings`: 통과. 실제 모달·정규화·포커스 관리·토스트를 사용하고 서버 경계만 합성했다.
- 변경 TSX Prettier 검사와 `git diff --check`: 통과.
- 읽기 전용 독립 코드 검토: 신규 기본값 적용 분기, 기존 설정과 모의고사 보존, 서버 응답 처리, 성공 닫기·실패 재시도에서 발견된 결함 없음.

브라우저 검증은 신규 기본 설정 저장, 기존 값 보존, 공개 대상 0개 검증, 중복 저장 차단, 서버 응답 전 성공 알림 차단, 공개 저장 후 닫기·재개방, 실패 후 입력 보존·재시도, 비공개 저장, 미저장 변경 취소, 읽기 전용을 포함한다. 오류 토스트를 닫고 재시도할 수 있다. 공개 대상 등 실제 학교 데이터는 변경하지 않았다.

320·390·768·1280px 및 1366×768px에서 모달의 가로 넘침 없음, 본문 스크롤, 하단 저장 버튼, 옵션 구분선을 확인했다. 교사 알림장은 320·390·768·1280px에서 흰 배경·1px 테두리·16px 모서리와 패딩, 제목/조작부 포함, 16:9 이미지와 `contain`, 넘김·일시정지·빈 상태를 확인했다.

합성 브라우저의 외부 요청과 예기치 않은 콘솔 오류는 없었다. 증거 이미지는 임시 `westory-quiz-settings-*` 폴더와 제외된 `.superloopy/notice-surface`에 보관한다. 이 기록은 배포 전 기능 검증이며, 운영 반영은 Vercel 배포 커밋·도메인 연결 및 실제 교사 화면을 별도로 확인한다.
