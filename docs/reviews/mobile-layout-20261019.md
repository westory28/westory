# 모바일 조작과 윷놀이 화면 검증 (2026-10-19)

## 변경 범위

- 교사 패치 메모와 학생 역사 사전의 보조 플로팅 버튼은 열린 모달, 모바일 메뉴, 전체화면, 페이지 스크롤 잠금에 양보한다. 일반 화면에서도 실제로 누를 수 있는 버튼·입력란과 겹치면 숨기고, 겹침이 사라지면 복원한다. 사전을 닫으면 표시가 복원된 뒤 런처로 키보드 포커스를 돌려준다.
- 교사 역사교실 날짜 점을 타임라인 선 중심에 맞춘다. 좁은 화면에서 상태 4칸·수정·접기 버튼을 같은 행에 배치하며 두 버튼은 44px 조작 영역을 유지한다.
- 윷놀이 전체화면은 별도 전체화면 버튼으로만 시작한다. 휴대전화 방향·회전 잠금 여부와 관계없이 긴 변을 가로로 쓰며, 물리 화면이 세로이면 안쪽 게임 전체를 시계 방향 90도로 돌린다. Fullscreen API를 지원하지 않거나 요청을 거부하는 브라우저도 같은 가로 화면을 사용한다. 나가기·Escape·포커스 복원과 공용 스크롤 잠금을 제공한다.
- 일반 페이지 스크롤과 모바일 주소창에 의한 높이 변화로 윷판 크기를 다시 계산하지 않는다. 전체화면 진입과 실제 화면 폭·방향 변경에서만 갱신한다. 가로 좌표계에서 HUD·윷판·조작부·대화상자·3D 캔버스와 터치를 함께 검증한다.
- 안내 아이콘의 폰과 바깥쪽 화살표를 분리한다. 화살표가 먼저 회전한 뒤 폰이 가로로 돌아가며, 사용자 요청에 따라 동작 줄이기 설정에서도 이 연출을 유지한다. 숨김 탭과 화면 밖에서는 멈춘다.

기존 DESIGN/UI_RULES의 색상·글꼴·간격·44px 조작 토큰을 재사용한다. 페이지 제목·필터·탭 구조를 새 컨테이너로 감싸지 않는다. 전체화면 안쪽은 물리 방향과 독립된 가로 좌표계를 사용한다. 데이터 경로·학기·권한·게임 공개·서버 판정은 변경하지 않는다.

## 검증

- `node scripts/verify-floating-launchers-browser.mjs`: 실제 교사/학생 런처, 합성 서비스, 390/768/1280px. 모달·실제 버튼 충돌·스크롤 잠금·메뉴·자체 패널·복원·포커스를 검사한다. 운영 데이터는 읽거나 쓰지 않는다.
- `node scripts/verify-history-classroom-teacher-browser.mjs`: 실제 교사 컴포넌트와 메모리 데이터. 390/768/1024/1280px의 날짜 점 정렬, 같은 행과 44px 버튼, 펼침/접힘, 기존 설정·제출 회귀를 확인한다.
- `$env:YUT_MOVEMENT_QA_SECTION='mobile-viewport'; node scripts/verify-yut-movement-browser.mjs`: 기존 브라우저 하네스에서 모바일 세로/가로, 명시적 전체화면 진입, API 미지원 대체 화면, 가로 경기장 강제와 회전된 터치·규칙창·3D 화면 비율, 높이 변화·스크롤 시 크기 유지, 퇴장 복원을 검사한다. 회전 안내는 동작 줄이기 설정에서도 화살표가 먼저 돌고 폰이 뒤따르는지 확인한다.
- `node scripts/verify-teacher-patch-memo-controller.mjs`, `npm run verify:page-scroll-lock`, `npm run verify:portal-design`를 실행한다. 스크롤 잠금 검사는 현재 인라인 상품 미리보기를 잠금 소유자로 간주하던 오래된 참조를 제거하고 실제 상품 상세 모달을 검사하도록 갱신했다.
- 초기 모바일 패치는 별도 worktree에서 빌드했다. 가로 화면 고정 후속 패치는 최신 main의 평가 설정 변경까지 포함해 `npm run build`와 모바일 회귀 검사를 다시 수행한다. 최종 반영 시 검증한 파일만 명시적으로 스테이징한다.

브라우저 화면과 스크린샷 검증은 Chromium/Edge에서 수행했다. 실제 iPhone Safari의 주소창·safe area·소프트키보드 동작은 실기기 확인이 남아 있다. API를 제거한 합성 브라우저 검사는 대체 전체화면 경로를 검증하며 실기기를 완전히 대체하지 않는다.
