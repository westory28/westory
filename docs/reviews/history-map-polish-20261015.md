# 역사 지도 완성도 보완

## 범위

- 학생·교사의 공용 한국사, 세계사, 지구본 화면을 개선한다. 로그인·학기·권한·서버 저장 계약은 변경하지 않는다.
- 기존 지도 자료로 이동하는 버튼과 양쪽 포털의 전환 UI를 제거한다. 저장된 PDF와 역사교실의 기존 과제 자료는 삭제하지 않는다.
- 지명 목록은 한국어 표시 이름을 기준으로 가나다순 정렬한다. 단원·시대·지역 조건과 같은 장소의 시대별 이름은 유지한다.
- 한국사 점 선택은 약 3도 × 3도 주변으로 확대하며, 강 선택은 전체 물줄기를 포함한다. 지도 위 중복 과목 헤더는 제거하고 확대 제어와 배율을 지도 내부에 배치한다.
- 지도 휠은 Ctrl 없이 확대·축소한다. 설명·목록 스크롤은 지도 배율을 바꾸지 않는다. 작은 점은 가장 가까운 실제 지점을 우선 선택해 주변의 44px 버튼이 클릭을 가로채지 않도록 한다. 키보드로는 큰 지점 버튼과 동일한 장소 목록을 사용할 수 있다.
- 위치는 두 개의 확산 링과 지명 배지로 강조한다. 현재 검증 PC의 동작 감소 설정에서는 크기가 다른 정지 링과 불투명 배지를 유지한다.
- 지구본은 국가 경계·분쟁선·187개 주요 하천·사하라와 고비의 범위·233개 한국어 지형 라벨을 버전 고정 Natural Earth 자료로 제공한다. 역사적 국경으로 해석하지 않도록 출처 도움말을 유지한다. 런타임 외부 지도 API는 추가하지 않는다.
- 지구본 설명은 지도 내부 팝업으로 표시하고 닫기는 본문 스크롤과 분리한다. 좁은 화면의 장소 목록만 기존 dialog로 연다.

## 장소 설명과 확인 한계

- 전체 2,639개 중 2,310개에 장소의 정의·의미를 제공한다. 실제 조회 우선순위 기준으로 교과서·개별 검토 381개, 백과사전 1,929개다. 기존 단원·자료에 등장한다는 문장은 본문에서 제외하고 접힌 출처에 둔다.
- 한국어·영어 위키백과의 실제 판번호, 한국민족문화대백과사전, 국사편찬위원회와 지자체 등 확인한 출처를 연결한다. 번역·요약 및 CC BY-SA 4.0 표시를 보존하고 실행 중 외부 백과 API를 호출하지 않는다.
- 한국민족문화대백과의 최초 후보 189개를 단원·좌표와 전수 대조했다. 잘못 연결되거나 확정되지 않은 18개를 제외하고, 확인된 항목은 별도 수동 설명으로 보강했다. 위키백과는 동명 지명·옛 왕조·좌표 없는 항목을 중심으로 독립 대조했으며 전체 문장의 전수 사실 검증을 뜻하지 않는다.
- 정의가 확정되지 않은 329개는 기본 명칭·유형을 유지한다. 328개는 좌표 없는 지명이며, 좌표가 있는 항목은 우스터 1개다. 우스터는 현재 스위스 Uster의 좌표지만 원문 지도의 대상과 일치하는지 재확인이 필요하여 영국 Worcester 등의 설명을 임의로 연결하지 않았다. 해당 인용 원전은 `atlas-2022` PDF 42쪽이며 이번 checkout에는 원본 `atlas-evidence`가 없다.
- 실제 좌표가 있는 1,066개 중 1,065개에 정의가 있다. 미보강 항목은 한국사 297개·세계사 32개이며, 이유는 표제어·본문 미확보 183개, 동명이의 68개, 미검증된 다른 표기 연결 34개, 유형 대조 미확정 26개, 원문 식별 필요 11개, 비지리 동명 5개, 신원 불일치 2개다.
- 따라서 요청 1의 모든 지명 보강은 아직 완료로 표시하지 않는다. 나머지 조작·배치·지구본 지형 기능은 구현과 화면 검증을 완료했다. `verify-history-atlas-profiles.mjs`가 출처·문장 손상·알려진 오매칭·최소 설명 수·좌표가 있는 장소의 설명 누락을 빌드에서 검사한다.

## 검증

- `npm run build`, `npm run format:check`, `git diff --check` 통과. 빌드는 타입, 학기 보관, 학습지·PDF, 성적 XLSX hair 테두리, 기존 역사 지도 검증을 포함한다. 기존 대형 청크 경고는 유지된다.
- `scripts/verify-history-atlas-navigation.mjs`: 기존 51개 일반·36개 극지 카메라 검사에 실제 좌표 3,261개 모바일 검사를 추가했다. 지도 높이 400px, 카드 위 가용 높이 180px, 폭 286·356·720px에서 제주도·상하이·케이프타운·포토시·북극해를 포함한 선택점이 카드 위에 남는지 검사한다.
- `scripts/verify-history-globe.mjs`: 기존 회전·앞뒤 판정·클릭·배율·픽셀 예산·권한 검증과 국가 경계/하천/지명/출처 해시 검사를 수행한다.
- 실제 Chrome에서 공통 컴포넌트와 실제 데이터로 320·390·768·1280px를 확인했다. 백두산·제주도·케이프타운 확대, 파리의 지도/지구본 선택, 가나다순, 지구본 점 클릭, Escape 닫기, 가로 넘침 및 위치·카드·제어의 겹침을 확인했다.
- 2D 지도에서 Ctrl 없는 휠로 317% → 651% 확대를 확인했고 설명·목록 위 휠에서는 651%가 유지됐다. 지구본도 설명 위에서는 180% 유지, 지구본 위에서는 229% 확대를 확인했다.
- 작은 점은 기존 단일 SVG 경로로 그려 DOM 수를 유지하고, 상위 클릭 처리에서 실제 위치와의 거리를 판정한다. 최종 코드에서 작은 점을 눌러 광주목 설명·목록 선택·339% 확대가 함께 적용되는 것을 확인했다.
- 모바일 320px의 세 탭 넘침과 도구모음 3행 가능성을 수정했다. 도구모음은 두 행으로 배치되고 선택 카드와 10px 이상 분리된다. 320px 제주도 선택점 하단 558px, 선택 카드 상단 625px를 확인했다.

## 배포

작업 시작 시 `main`과 `origin/main`은 `2e8d1cbc25748c98bef28893e61ccb2eee56cc83`으로 일치했고, 운영 `www.westory.kr`의 Vercel 배포도 같은 커밋의 Ready 상태였다. 기존 `output/` 자료와 연구 캐시는 이번 커밋에서 제외한다.

최종 통합 중 원격에 추가된 역사교실 수정 `89bbea5`를 확인했다. 지도 수정 파일과 겹치지 않아 fast-forward로 반영했으며, 해당 변경을 포함한 상태에서 최종 검증을 통과했다. 배포 직전 운영 도메인도 `89bbea5`의 Ready 배포임을 확인했다. 이번 지도 패치에는 Functions나 rules 변경이 없다.
