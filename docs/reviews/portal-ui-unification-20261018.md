# 포털 UI 통일 검증 (2026-10-18)

## 적용 기준

역사 지도처럼 제목·보기 전환·필터를 페이지 배경 위에 배치하고, 실제 지도·표·문서·편집 폼에만 경계를 둔다. 이후 패치는 `DESIGN.md`의 **전 포털 공통 화면 계약: 지도 기준**과 `UI_RULES.md`를 먼저 확인한다. 공통 구현은 `portalPage.css`, `PortalSubNavigation`이다.

- 지도: 계정 행을 확보하고 데스크톱 가용 높이에 맞춘다. 좁거나 짧은 화면에서는 최소 지도 높이와 자연 스크롤을 유지한다.
- 탐색: 설정, 위스 정책·등급, 학생 마이페이지·생각모아의 단순 내부 메뉴를 상단 탭으로 배치한다. 주 메뉴의 경로·쿼리가 바뀌면 열린 아코디언을 접는다.
- 페이지: 학생의 위스·사전·학습 자료·역사교실·평가 목록·점수·캘린더, 교사의 자료·평가·명단·점수·위스·일정·위플레이 화면에 공통 제목·탭·필터 구조를 적용한다.
- 유지한 예외: 수업·평가 단원 트리, 긴 대상 목록, 실제 자료와 편집 폼, 게임·문제 풀이·PDF·판서 작업 영역. 권한, 학기 경로, 서버 저장, 채점과 보상은 변경하지 않는다.

브라우저 자동 검증은 실제 React 컴포넌트·CSS·지도 데이터를 사용하되 계정과 조회 응답은 합성 데이터다. 외부 요청과 애플리케이션 쓰기는 차단한다. 운영 학생 계정의 저장 검증을 대신하지 않는다. 운영 배포는 `docs/runbooks/production-release.md`에 따라 해당 커밋의 Vercel Ready와 운영 도메인 연결, 로그인한 교사 화면을 별도로 확인한다.
