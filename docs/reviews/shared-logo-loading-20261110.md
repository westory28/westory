# 공통 로고 로딩 검증 (2026-11-10)

## 변경 범위

PageLoading·LoadingOverlay·InlineLoading의 지구본을 사용자가 제공한 원본의 기존 `westory-wordmark.webp`로 교체했다. 같은 이미지 한 개를 일곱 SVG 클립으로 나누며, 원본 알파 경계의 투명한 틈을 따라 W/e·r/y 등 기울어진 글자도 분리한다. 원본 이미지·게임 전용 로딩·실제 업로드 진행률은 변경하지 않는다.

흐린 밑그림 위로 왼쪽부터 색이 채워지고 글자가 순서대로 튄다. 대기 중 색은 30초에 94%까지 감속하며, 기존 로딩 컴포넌트가 제거될 때 180ms 색 채우기와 최대 240ms 사라짐만 이어진다. 새 콘텐츠·오류·버튼은 즉시 사용 가능하다. 성공/실패 판단이나 데이터 완료율을 표시하는 효과가 아니며 서버 진행 조회는 없다. 100ms 미만의 짧은 대기·StrictMode probe·같은 위치의 연속 로딩에는 완료 잔상이 없다.

사용자 추가 요청에 따라 하단 `처리 중...` 문구와 말줄임 점을 제거했다. 화면에는 로고만 표시하고, 화면 낭독기용 `role=status`, `aria-label=처리 중`, `aria-busy`는 유지한다. 동작 줄이기 설정에서도 애니메이션을 유지한다는 사용자 명시 요청을 적용했다. 숨긴 탭·화면 밖·pagehide에서는 모션을 중지한다.

## 후속 통일 패치

사용자 선택인 화면 전체의 약한 블러를 PageLoading·InlineLoading·LoadingOverlay에 동일하게 적용했다. `LoadingProvider`가 보이는 화면의 실제 대기만 모아 로고 한 개를 유지한다. 흰색 60% 덮개와 4px 블러를 body의 native modal dialog에 렌더링하므로 작은 컨테이너의 transform·overflow나 사전 팝업에 잘리지 않는다. 숨긴 탭과 닫힌 팝업의 대기는 제외하며 동시에 실행한 작업 중 하나만 끝났을 때 로딩을 먼저 닫지 않는다.

사용자의 마지막 겹침 지적에 따라 완료 효과에도 원래 로딩 영역의 배경과 블러를 그대로 복사하고 로고와 함께 240ms 안에 제거한다. 완료 효과는 클릭·키보드를 막지 않는다. 대기 중에는 다른 native dialog를 포함한 배경을 inert로 잠그고, 완료·오류·이동 시 기존 inert·스크롤·초점을 복원한다. 모바일 메뉴가 닫힌 뒤 초점을 반환할 수 있도록 잠금은 passive effect에서 시작한다.

학생의 달력·홈·내 정보·위스·검색·역사교실·학습지 저장·점수/이의 화면, 교사의 일정·명단·점수·평가·역사교실·사전·생각모아·사료창고·설정·위플레이 관리, 공통 지도·PDF·편집기·개발일지의 초기 조회와 명시적 작업에서 누락된 대기 표시를 연결했다. 기존 pending을 우선 재사용하고, 빈 목록을 대기로 오인하던 사료 선택기와 이미지 오류는 실제 완료·오류 상태로 분리했다. 기존 입력 DOM과 초안을 보존한다. 자동 저장·검색 입력·게임 명령·실시간 갱신·주기적 새로고침은 기존 비차단 동작을 유지한다.

조회 조건·서버 호출·응답·쓰기 권한·성적/답안/서명·학기 경로를 바꾸지 않았다. 추가 진행률 조회·폴링·외부 AI 전송은 없다. Calendar 재시도는 정상 기존 출석 구독을 재연결하지 않으며 실패/설정 누락 때만 이전 설정을 지운다.
