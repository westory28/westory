# 학급별 풀이 분류 검증 — 2026-10-25

기준: `ace5a8fde50f3c771d60b387646a5ca2116dcc3b` / `main`. 사용자가 요청한 짧은 분류명과 같은 보기 반복을 교사 학급 분석에 추가한다. 기존 `output/`은 작업 산출물에서 제외한다.

## 조회와 표시

- 학급·학년 요약은 개인 자료 대신 분류별 인원만 반환한다. `찍기 추정`, `반복 선택`, `미해당`, `기록 부족`을 비교하며 기존 제출/미제출 인원도 유지한다.
- 학급 인원을 누를 때만 기존 단일 학급 상세 요청을 사용하고, 학생 탭의 해당 분류를 연다. 학년 전체 학생을 요청하지 않는다. 선택 학생에서 시간 중앙값, 관측 범위, 수정/재방문, 빠른 응답 정답률, 반복 보기 비율을 확인한다.
- 기존 저장된 `analytics`와 원본 결과의 `answers`를 기존 조회의 필드 선택에 추가했다. 새 학생 제출 요청, 리스너, 추가 원본 문서 조회는 없다. 캐시 버전은 3으로 바꾸고 기존 무효화·범위·용량 제한을 유지한다. 최초 캐시 생성 시 필드 크기는 늘지만 요약 응답에는 답안·시간·학생 식별자를 넣지 않는다.
- 인증, 답안 제출, 채점, 보상, rules는 변경하지 않는다. 학생이 기록 수집 실패로 제출을 거부당하는 경로도 추가하지 않는다.

## 분류 계약

- 현재 조회 범위에서 가장 최근 **실제 한 번의 제출**만 사용한다. 문항별로 여러 재응시를 합치지 않는다. 제출 순서 불명은 기록 부족, 응시 없음은 미응시다.
- 현재 명시 버전과 출제 당시 버전이 일치하는 객관식/OX와 정확히 대응되는 답안만 근거다. `legacy`는 버전 증거가 아니다. 보기 순서가 고정인 현재 객관식의 보기 번호와 O/X를 서로 다른 그룹으로 집계한다. 순서형·연결형 등은 제외한다.
- 반복 선택: 같은 유형의 대상 문항 중 같은 보기가 **5회 이상이면서 80% 이상**. 연속 클릭 순서나 학생 의도를 측정했다는 의미가 아니다. 시간이 없어도 원본 답안으로 확인할 수 있다.
- 온전한 시간은 analytics v1 / 전체·문항 complete, 음수·비정수·상한 초과 없음, 최초≤최종≤active, 수정·재방문 수 유효일 때만 인정한다. 재접속 등 partial 기록은 속도 분류에 쓰지 않는다.
- 빠른 응답: 활성 시간 **3초 이하**, 숨겨진 시간 0, 수정 0, 재방문 0, 힌트 사용 없음. 대상 문항 중 온전한 시간 관측 **5개 이상·80% 이상**이고 빠른 응답 **5개 이상·60% 이상**일 때 반복 신호로 본다.
- 찍기 추정: 위 빠른 응답 반복과 함께 **빠른 응답 오답 3개 이상·정오답 확인 응답 중 오답 50% 이상**, 또는 반복 선택 조건이 있어야 한다. 빠른 정답이나 낮은 점수만으로 찍기 추정이 되지 않는다.
- 우선순위는 찍기 추정 → 반복 선택 → 미해당 → 기록 부족이다. 미해당도 충분한 시간·답안 관측이 있어야 한다. 모든 분류 인원 합계에는 미응시를 포함하여 학급 인원과 일치한다.
- 요약에서 원본 답안이 없는 결과는 `behaviorAnswersAvailable:false`를 보존한다. 상세에서 과거 immutable submission의 답안을 보충하더라도 요약과 분류가 달라지지 않는다.
- 위 수치는 Westory의 교사 확인 조건이며, 검증된 추측 확률·능력·태도 평가가 아니다. 응답 시간의 기준은 평가에 따라 검증해야 한다는 연구를 참고했으며, 이 값으로 점수나 불이익을 자동 결정하지 않는다: [Kong·Wise·Bhola(2007)](https://journals.sagepub.com/doi/10.1177/0013164406294779), [NWEA의 응답 시간 기준 연구](https://www.nwea.org/research/publication/an-information-based-approach-to-identifying-rapid-guessing-thresholds/).
