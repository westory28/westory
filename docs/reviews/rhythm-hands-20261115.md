## 변경

- 4곡 × 3장단의 시간순 노트를 왼손부터 교대로 배정한다. 노트 안에 왼/오를 표시하며 손과 가운데/가장자리 종류가 일치해야 소비한다. ←/Z는 왼손, →/X는 오른손이다.
- 북 위에 좌우 가운데·가장자리 네 지점을 반투명 원과 3px 테두리로 표시한다. 최소 44px이며 원 가장자리도 전체 입력된다. 원 외 북면은 기존 원형 거리 판정과 좌우 좌표를 사용한다. 90도 회전 터치 좌표를 역변환한다.
- 독립 투명 왼손/오른손 북채를 하단의 연주자 시점으로 배치한다. 220ms 타격·복원은 해당 손만 다시 실행한다. 상대 손의 진행 중 동작을 취소하지 않는다.
- 65ms 이내 지화자 좋다! 1,000점 / 130ms 이내 얼씨구 650점 / 160ms 이내 좋다 300점이다. 기존 점수 산정은 보존하며 금색 이중 파동·초록 파동·남색 작은 파동과 불꽃 개수 12/6/3으로 구별한다. 연속 성공은 콤보를 쌓고 놓치면 끊긴다.
- 맞힌 노트는 화면상의 노트 좌표부터 점수 좌표까지 600ms 이동한다. 회전된 전체 화면에서도 논리 좌표로 변환하며 도착 시 점수를 강조한다. effect 배열은 상한이 있고 완료·초기화·unmount 때 정리된다. 동작 감소에서도 요청된 연주 효과를 유지한다.
- 공개 확인 뒤 기존 WeplayStudioIntro를 한 번 실행하고 완료 후 본 게임을 mount한다. 학생 카드/교사 미리보기 클릭에서 AudioContext를 준비하며, 공통 음소거·건너뛰기·숨김·초점 복귀를 유지한다. 자체 합성 BGM이며 다른 게임 배경음은 시작하지 않는다.
- 대문의 짙은 직사각형은 투명 PNG/WebP 자체가 아니라 `.weplay-game-card img`의 배경·4:3 비율 상속이었다. 리듬 커버 안의 이미지에만 배경 transparent와 aspect-ratio auto를 적용했다. 다른 게임 카드는 바꾸지 않는다.
