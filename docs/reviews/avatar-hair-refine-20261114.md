# 로열 헤어와 이미지 워터마크 보완

사용자 참고 이벤트 그림에 맞춰 로열 애쉬의 양옆 머리끝을 바깥으로 휘도록 조정하고, 로열 초코 단발의 앞머리와 옆머리 사이 검은 경계를 이어진 실루엣으로 정리한다. 기존 80×112 픽셀 격자와 얼굴·목·포즈 기준을 유지한다. 공통 렌더러를 사용하는 학생 상점·옷장과 교사 미리보기·관리 썸네일에 함께 반영한다.

아이템 ID·소유권·이름·가격과 구매·저장 동작은 변경하지 않는다. UI 레이아웃과 디자인 토큰을 추가하지 않으며, 권한·학기·서버 읽기/쓰기·런타임 AI 호출·외부 전송 경로도 변경하지 않는다.

알림장 가로 배너와 개발자 일지 콘테스트 세로 안내 이미지에 직접 들어 있던 우측 하단 로고를 기본 이미지 생성 도구의 국소 편집으로 제거한다. 기존 글과 배너의 이미지만 교체하며, 제목·본문·이벤트 분류·대상·기간·연동 게시물은 보존한다. 업로드 후 앱의 자동 워터마크가 한 번만 표시되는지 운영 화면에서 확인한다. 앞으로 업로드할 원본에 별도 로고를 넣지 않는 사용자 지시를 루트 AGENTS.md에 기록한다.

검증 산출물은 커밋하지 않는 output/avatar-royal-refine-20261114(렌더러)와 output/avatar-hair-refine-20261114(이미지·운영 확인)에 보관한다. 기본 앱 빌드, 기존 포즈·염색·피부·모자 렌더 검증, 정적 썸네일 일치 검사와 전후 비교 이미지를 사용한다. 운영 확인에서는 학생의 구매·선택 저장·접수·위스 지급을 실행하지 않는다.

## 검증 결과

- `npm run build`, 변경 TS 두 파일의 Prettier, `git diff --check` 통과.
- 실제 렌더러 착용 57,960조합, 모자·장식 7,728조합, 정수리 576건, 헤어 두피 192건 및 정적 프리뷰 237개 무결성 검사 통과. 제품 프리뷰 변경은 두 헤어의 남녀용 4장뿐이다.
- 실제 AvatarStudio를 사용하는 합성 데이터 브라우저 검사 179건 통과. 학생·교사·상점의 320/390/768/1280px 해당 화면에서 오류가 없었다. 기록된 구매와 저장은 로컬 대역이며 운영 거래가 아니다.
- 운영의 기존 알림장과 콘테스트 글에서 이미지 교체 후 자동 워터마크가 하나만 표시되는 것을 확인했다. 사용자가 바꾼 글 제목 `[이벤트] 나만의 아바타 콘테스트`를 보존했다.
