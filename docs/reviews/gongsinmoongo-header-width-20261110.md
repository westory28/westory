# 공부의 神문고 제목·탭과 본문 폭

2026-11-10 사용자 정정에 따라 교사 제목 옆 운영 상태를 배지로 표시하고 질문함·운영 설정 탭을 제목 아래로 분리했다. 탭 오른쪽에 새로고침을 두며, 기존 투명 헤더와 답변 입력부를 유지한다. 기존 파랑·중성 색상, 둥근 배지, 공통 밑줄 탭과 44px 이상 조작 높이를 재사용한다.

PC 본문 오른쪽은 기존 상단 계정 도구 모음의 1536px 최대 폭과 24px 여백을 따라 계산하며, 로그아웃 버튼 오른쪽에서 12px 안쪽으로 제한한다. 주 메뉴가 접히면 실제 접힌 메뉴 폭으로 계산한다. 새로고침·대화·답변 작성·운영 설정에 같은 기준선을 적용한다. 두 줄 제목 영역을 확보하면서도 기존 설정 전체가 1280×720에 들어오도록 설정 행의 상하 여백은 8px로 맞췄다.

변경은 교사 스타일과 제목 묶음에 한정한다. 학생 제목 묶음은 `display: contents`로 기존 배치를 유지한다. 조회·저장·알림·권한·학기·AI 호출과 외부 전송에는 변경이 없다. 검증 중 운영 질문·답변·설정은 변경하지 않는다.

검증:

- 합성 브라우저에서 320/390/768/1280/1440/1920px 학생·교사 화면, 제목과 배지의 같은 줄 정렬, 제목 아래 탭, 투명 헤더와 입력부, PC 페이지 넘침 없음, 설정 다섯 항목과 저장 버튼 노출을 확인했다.
- 1280/1440/1920px의 새로고침·작성 영역 오른쪽과 로그아웃 경계를 비교했다. 1920px 주 메뉴 접힘 상태에서도 같은 관계를 확인했다.
- 기존 비공개 질문·답변·설정·실패 복구·계정 경계·자료 연결 검증을 유지한다. 이미지 검증은 `decode()` 완료 뒤, 화면 캡처는 로딩 종료 효과가 사라진 뒤 수행해 준비 중인 화면을 결과로 판정하지 않는다.
