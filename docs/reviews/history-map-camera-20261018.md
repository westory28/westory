# 역사 지도 선택과 지형 표시 검증

## 변경 범위

- 학생·교사가 공유하는 `HistoryAtlas`와 `HistoryGlobe`만 수정했습니다. 인증·학기·저장·권한 로직은 변경하지 않았습니다.
- 평면 지도의 기준 경선을 고정하고, 투영 배율이 재계산되면 현재 화면의 중심 좌표와 실제 배율을 보존한 뒤 카메라를 이동합니다. 바탕 지도는 선택 때문에 비우지 않습니다.
- 선택 이동은 기존 300ms 동안 같은 카메라 값을 지형·점·이름에 적용합니다. 첫 프레임부터 실제 이동 시간을 계산하며, 직접 조작과 동작 감소 설정을 존중합니다.
- 제주도뿐 아니라 섬·강·지역·국가 배지의 지리 좌표를 고정했습니다. 화면 가장자리로 배지를 다시 붙이지 않고, 화면 밖 또는 지구 뒤편이면 숨깁니다.
- 한국 지형 7개(개마고원, 강남·함경·낭림·아호비령·소백·태백산맥)를 전통 권역명보다 먼저 배치합니다. 가까운 빈 위치로 옮기는 지형명에는 실제 지형까지 연결선을 표시합니다. 기존 지형 자료·출처는 유지합니다.
- 국가의 면은 클릭을 받지 않습니다. 국가명을 통해서만 국가 설명과 범위를 선택하며, 지형·장소와 겹친 국가명은 가까운 빈 위치에 배치합니다.
- 지구본 SVG 라벨 풀은 지명별 노드를 재사용하여 이동 중 키보드 포커스가 다른 국가로 바뀌지 않도록 했습니다.

## 검증

- `npm run build`: 타입 검사와 기존 지도·학기·학습지·엑셀 테두리 검사를 통과했습니다.
- `npm run verify:portal-design`: 학생·교사 320/390/768/1280/1366/1440px, 지도 높이·메뉴·탭·반응형 검증을 통과했습니다.
- `npm run verify:history-map-ui`: 320/390/768/1280/1366/1440px의 한국사·세계사·지구본과 실패 후 재시도·지형 설정 유지 등 20개 항목을 통과했습니다. 필터 초기화, 해외 지명, 지역·국가 설명, 키보드, 지형 표시를 확인했습니다.
- `node scripts/verify-history-map-camera.mjs`: 390/768/1280/1366px에서 20개 항목을 통과했습니다. 한국 지형 7개, 실제 RAF 화면 좌표의 연속성, 바탕 지도·선택 범위의 같은 변환, 제주·강화도·한강의 이동 및 화면 밖 배지 숨김, 나일강과 이집트 중첩 클릭, 국가명 선택, 지역 선택 후 Home, 지구본 선택과 배지 고정을 확인했습니다.
- 브라우저 검증에는 운영 계정 쓰기 없이 합성 화면과 공개 지도 자료를 사용했습니다. 실제 운영 배포 후에는 로그인된 교사 지도에서 같은 변경을 추가 확인합니다.

증거는 작업 공간의 `output/history-map-camera/`와 `output/atlas-revision-20261018/ui/`에 저장합니다. 카메라 검증의 최종 통합 판정은 `summary.json`이며, 앞선 Home 실패는 `final-1280/report.json`에서 재검증했습니다. RAF 측정은 브라우저의 렌더링이 끝난 뒤 DOM을 읽으며, 측정 중 스크린샷으로 프레임을 강제 갱신하지 않습니다. 헤드리스 측정의 최대 프레임 간격은 제주 224ms, 러시아 416ms였습니다. 이 검증은 이동 경로의 연속성과 레이어 정합성 확인이며, 60fps 성능 보장 결과는 아닙니다.
