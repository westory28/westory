# 역사 지도 지역 탐색과 선택 지명 강조

## 범위

- 학생·교사의 공용 2D 지도와 별도 지구본에 같은 지역 분류를 적용한다. 단원·시대·검색과 지역 조건은 함께 적용한다.
- 세계사는 큰 지역을 고른 뒤 해당 세부 지역 드롭다운을 표시한다. 유럽·아시아·아프리카·아메리카·오세아니아와 중동·극지방·그린란드, 바다·대양을 포함한다. 중동과 서아시아처럼 중복되는 탐색 분류를 허용한다.
- 한국사는 조선 후기 8도 기준이다. 과거 모든 시대의 도 경계를 재현하는 기능은 아니다. 해외 장소는 ‘8도 밖’, 근거가 부족한 지명은 ‘지역 미분류’와 전체 지역에서 계속 찾을 수 있다.
- 선택한 지명에는 파란 계열 배경·테두리와 굵은 글자를 표시한다. HTML 지도와 Canvas 지구본의 장소·강 이름에 같은 표현을 적용하고 기존 후광을 유지한다.
- 역사교실·로그인·권한·학기·백엔드·저장 기능은 변경하지 않는다.

## 자료와 성능

- 지명 ID별 정적 분류를 사용한다. 검색 별칭이나 본문 키워드로 다른 장소의 지역을 추측하지 않는다. 좌표가 없는 지명도 기존 목록과 교과서 출처를 보존한다.
- 한국사 1,277곳 중 1,078곳, 세계사 1,383곳 중 1,381곳을 분류했다. 한국사의 광역 역사국가·불명 지명 199곳과 세계사의 ‘쿠람·말라야’, ‘두르가 사원’ 2곳은 강제로 배정하지 않는다.
- 근거와 미분류 목록은 `history-atlas-korea-regions.sources.json`, `history-atlas-world-regions.sources.json`에 기록한다. 빌드용 원자료와 생성 규칙은 `scripts/`에 있으며, 국가 경계 원자료는 브라우저에 전송하지 않는다.
- 필터를 조작할 때 외부 지도 API·Firestore 조회·서버 쓰기는 없다. 분류 데이터 gzip 예산은 35KB 이하다. 지구본 지연 로딩과 기존 수계 캐시는 유지한다.
- 최종 두 분류표의 JSON gzip 크기는 24,680바이트다. 교과서 본문·좌표·기존 지형 자료는 변경하지 않았다.

## 검증 기준

- 실제 데이터의 과목별 지명 ID, 허용된 지역 ID, 중복 여부와 전체/미분류에서의 발견 가능성을 검사한다.
- 파리·아테네·베이징·바그다드·보스턴·지중해·그린란드 및 한양·개성·제주·평양·백두산·상하이 등 별도로 정한 지리 사례를 확인한다. 교과서 원문·좌표·출처가 필터 처리로 변경되지 않아야 한다.
- 큰 지역 변경 시 세부 지역과 목록 첫 페이지를 초기화한다. 과목 변경과 전체 초기화 시 지역 조건도 해제한다. 연관 이야기 이동은 대상과 충돌하는 조건만 해제하고 결과를 알린다.
- 390·768·1280px에서 계층 드롭다운, 복합 필터, 빈 결과 복구, 선택 지명 배경, 강 이름 강조와 가로 넘침을 확인한다. 브라우저 화면 크기 시험은 실제 물리 기기의 성능 측정과 구분한다.
- `npm run build`, `npm run format:check`, 기존 지도·지구본·학습지·PDF·성적 XLSX 테두리 검증을 유지한다.

## 브라우저 확인

- 공통 컴포넌트를 실제 데이터로 열어 390·768·1280px에서 가로 넘침 없이 큰 지역→세부 지역과 8도 선택이 표시되는 것을 확인했다. 세계사 유럽→서유럽→파리, 바다·대양→지중해, 한국사 전라도→금산·제주도, 지구본 서아시아/중동→바그다드 및 동아프리카→나일강을 확인했다.
- 제주도에서 강화도 연관 이야기를 선택하면 지역·검색 조건만 풀리고 해당 장소로 이동한다. 빈 검색 결과의 필터 초기화는 세부 지역도 해제한다. 과목 전환은 다른 과목의 지역 조건을 남기지 않는다.
- Canvas의 바그다드·나일강과 HTML의 파리·제주도·한강 이름 배경을 확인했다. 모바일 화면에서 한강의 선형과 이름 강조가 함께 표시된다.
- 1280→768px 전환 때 제주도 이름과 지점이 하단 카드에 가려지는 문제를 발견했다. 카드의 실제 높이를 측정해 카메라·라벨의 가용 높이에 반영하고 compact 전환 때도 다시 맞췄다. 수정 후 제주도 지점 하단 719px, 설명 카드 상단 756px로 분리됨을 확인했다. 기존 87개 카메라 사례와 별도 모바일 안전영역 8사례도 통과했다.
- 실제 학생 계정으로 운영 세션을 새로 생성하는 시험은 하지 않았다. 학생/교사 공용 UI를 직접 검증하고 기존 메뉴·접근 권한 검사를 유지한다.

운영 완료 판단은 검증한 커밋의 Vercel Ready 및 운영 도메인 승격 후 실제 로그인된 지도·지구본 확인까지 포함한다.
