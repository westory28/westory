# 모의고사 출제 화면 간소화

기준 커밋은 `70299b3c09e5dd7b7097e389283d3ad394ed1fa9`다. 사용자의 후속 요청에 따라 JSON 가져오기·내보내기·양식과 수동 쪽 나누기를 제거했다. 기존 기능 기록보다 이 변경과 [현재 출제 절차](../runbooks/mock-exam-papers.md)를 우선한다.

- 교사 화면은 문제 등록과 읽기 전용 미리보기를 사용한다. 파일 파서·내보내기·일괄 저장 코드도 제거했다. 직접 등록의 기존 학기·권한·revision·서버 저장 경로는 유지한다.
- 미리보기는 검색·단원 필터와 독립적으로 선택 회차의 전체 문항을 읽는다. 회차가 있는 시험지에 과거 공통 문제은행 문항을 섞지 않는다.
- 공통 시험지 렌더러는 글꼴과 이미지의 실제 높이에 따라 단·쪽을 자동 배치한다. 교사 미리보기·학생 풀이·마이페이지 모두 같은 배치이며 과거 수동 쪽 나누기 값도 적용하지 않는다. 저장된 문항 원문·답안·점수는 변경하지 않는다.
- 직접 등록 검사에서 발견한 비동기 이미지 첨부의 React `currentTarget` 해제 오류를 입력 요소 참조 보존으로 수정했다. 본문·선지·같은 편집기의 연결형 이미지 입력에 적용했다.
- 기존 공통 UI와 시험지 디자인 계약을 유지하며 새 토큰·카드·안내 문장은 추가하지 않았다. Functions·rules·인증·개인정보·AI 호출·외부 전송 계약은 변경하지 않는다. 운영 문항·점수·공개 상태를 검증용으로 수정하지 않는다.

## 검증 근거

- 직접 등록: 5선지·배점 검증, 정답/선지 이미지 동시 정렬, 학습 메타데이터, 실패 입력 보존과 동일 ID 재시도 통과.
- 실제 교사 컴포넌트: 검색 결과 1문항이어도 회차 전체 24문항을 미리보기. 긴 본문과 이미지 6개가 있는 시험지는 390/768/1280px에서 동일한 9쪽으로 자동 배치되고 모든 문항·이미지가 페이지 안에 표시됨. 과거 강제 쪽 나누기 값이 있는 짧은 4문항은 1쪽으로 배치됨. 읽기 전용 미리보기의 쓰기·외부 요청·브라우저 오류는 0건.
- 실제 학생 러너: 390/768/1280px, 터치 회전, 키보드 높이 변화, 확대/포커스, 저장/재개, 미응답 확인, 제출 실패 재시도, 배점과 불변 제출 기록 통과.
- 실제 마이페이지: 390/768/1280px에서 자동 배치와 저장 원문·순서·점수·답안 보존, 확대 포커스, 과거 원문 누락 안내 통과.
- `npm run build`의 타입·권한·학기·엑셀 테두리·지도·자산 검증과 Vite 빌드, `npm run format:check`, `git diff --check` 통과. 기존 번들 크기 경고만 남았다.

합성 검사 산출물은 로컬 임시 디렉터리와 `output/`에 두며 커밋하지 않는다. 프론트엔드만 Vercel main으로 배포하고 운영 도메인 연결·방재석 Chrome 프로필의 화면 확인까지 수행한다.
