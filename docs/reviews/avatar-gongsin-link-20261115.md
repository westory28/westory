## 변경

- 공개 상태 구독에 오류가 나면 옷장의 보내기 진입점과 오류 표시가 함께 사라지던 문제를 수정했다. 오류가 난 경우에만 `다시 확인하기`를 보여 주며, 열린 접수창에서는 작성한 소개를 보존한다. 이벤트가 정상 종료된 경우에는 기존처럼 진입점을 숨긴다.
- 재시도는 기존 계정·학기별 공유 구독을 명시적으로 다시 연결한다. 정상 경로에 추가 조회·자동 폴링·쓰기를 추가하지 않는다. 오류 복구 검사에서 명시적 재시도 2회, 구독 3회, 추가 접수 조회 0회, 쓰기 0회였다.
- 학생 질문, 교사 답변, 학생 미리보기의 양쪽 전송, 아바타 최종 접수 버튼에 공통 SVG 북면을 적용했다. 기본 64px·아바타 88px, 삼태극·크림 가죽·세 색 테·금속못을 표현한다. 포커스·로딩·비활성·기존 전송 조건을 유지한다.
- 일반 버튼과 SVG에 적용되던 상위 스타일을 북 버튼에서 제외해 사각형 테두리, 20px 축소, 비활성 투명도의 이중 적용을 막았다. 교사 1280×720 화면의 대화 높이를 확보하도록 입력줄 내부 세로 여백만 6px에서 4px로 조정했다.
