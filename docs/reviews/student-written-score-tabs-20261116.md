## 변경 범위

- 학생 정기시험의 좌측 목차를 수행평가와 같은 상단 탭으로 바꾼다. 선택형과 논술형 문항을 평면으로 배치하고 기존 18px/800, 56px 높이, 투명 배경과 파란 밑줄을 재사용한다. 번호 없는 기존 논술형 자료도 제목 중복 없이 표시한다.
- 학생 점수 화면에서만 OMR을 두 열로 배치한다. 모바일 안쪽 여백과 답안 타원 폭을 조정하며 교사 OMR과 공용 컴포넌트는 변경하지 않는다.
- 등록된 선택형과 논술형 문항 탭을 모두 직접 선택해야 점수 확인·서명 버튼이 활성화된다. 미등록 점수는 제외하며 실제 0점은 포함한다. 계정·학기·점수 종류 변경 시 열람 상태를 초기화한다.
- 점수·만점·문항별 피드백·전체 근거를 열람 버전에 포함한다. 수정 시 다시 열람해야 하며 제출 직전 서버 재조회에서 같은 시각의 내용 변경도 확인한다. 기존 이의/답안지 처리 대기 차단, 유효 서명 보존, 실패 재시도 경계를 유지한다.
- 기존 학기·본인 범위 조회와 legacy 읽기 경로를 유지한다. 탭 선택에는 서버 통신이 없다. 추가 조회·쓰기, AI 호출·외부 데이터 전송, 권한·공개 범위 변경은 없다. Firebase Functions/rules/storage는 수정하거나 재배포하지 않는다.

## 검증 및 배포

- `npm run build` 통과. 타입 검사와 필수 수행평가 XLSX 테두리 회귀를 포함한 prebuild 검사 및 Vite 운영 빌드를 완료했다.
- 합성 학생 자료와 메모리 저장소를 사용해 실제 학생 컴포넌트를 검증한다. 운영 점수·서명·이의 처리 상태는 변경하지 않는다.
- `npm run format:check`, `npm run test:score-request-rules` 통과. 에뮬레이터에서 교사 조회·학생 본인 조회·타인 차단·서명 및 이의 처리 경계를 확인했다.
- `node scripts/verify-student-score-objection-browser.mjs` 전체 학생 점수 회귀 통과. 모바일 OMR 여백 보정 뒤 관련 정기시험 검증도 다시 통과했다. 320/390/768/1280px에서 상단 탭 18px/800, 투명 헤더·탭, 두 열 OMR, 답안 버블 비겹침, 가로 넘침 없음을 계산 스타일과 캡처로 확인했다.
- 각 폭에서 최초 합성 읽기 5건, 탭 열람 추가 읽기·쓰기 0건. 동일 timestamp 피드백 변경 시 서명 쓰기 0건, 저장 실패 뒤 재시도 시 등록된 3개 점수의 서명만 3건 기록했다. 브라우저 오류 0건.
