# 충무공 인게임 대기 화면

## 변경 범위

- 기준 커밋 `d14f76116dc681730f2fcaba78a1e1b6c2f6402c`. 기존 `C:\westory`의 미커밋 작업과 뒤처진 main은 보존하고 별도 worktree에서 작업했다.
- 배포 직전 원격에 추가된 학사 일정 변경 `494b5e0`을 fast-forward로 반영했다. 대기 화면 변경과 겹치는 파일은 없었으며 통합 빌드를 다시 수행했다.
- 학생·교사 공통 대기 장면을 판옥선의 이순신 뒷모습과 밀집한 일본 함대 생성 이미지로 변경했다. 윷놀이의 따뜻한 게임 화풍, 가까운 투구·어깨 구도, 《노량》 스틸을 참고한 흑철·은색 투구를 적용했다. 영화적 재현이며 실제 착용 갑주의 정확한 복원으로 표시하지 않는다.
- 교사의 `대기 화면 미리보기` 제목과 해당 행을 제거했다. 연습·도전, 난이도, 시작 및 학생 기록 버튼을 장면 안으로 배치했다. 카탈로그와 교사 체험 카드에는 같은 생성 이미지의 썸네일을 사용한다.
- 약 3.8초 주기로 붉은 모자 깃 영역만 변형한다. 투구·함대·메뉴는 고정하고 동작 감소·숨김 탭·화면 밖에서는 멈춘다. 네트워크 호출·시작 타이머·위스 조건·교사 무보상 체험·공개 설정은 바꾸지 않았다.
- 포털 외곽은 기존 공통 프레임을 사용한다. 게임 내부의 해전 테마는 사용자 요청에 따른 예외이며 별도 포털 디자인 체계를 추가하지 않았다.

## 검증

- `npm run build`: 타입 검사와 전체 prebuild 검사, 최종 XLSX hair 테두리 회귀를 포함해 통과했다. 태블릿 CSS와 교사 썸네일 후속 변경 뒤 `npx vite build`도 통과했다.
- 변경 TSX 다섯 파일의 Prettier 검사와 `git diff --check`를 통과했다.
- `node scripts/verify-weplay-opening-layout.mjs --frame-only`: 학생·교사, 충무공·윷놀이, 390/768/1280/1366/1920px에서 인트로·대기·경기 공통 프레임 크기와 여백 검증을 통과했다.
- `WEPLAY_QA_LOBBY_ONLY=1 node scripts/verify-weplay-lobby-exit-browser.mjs`: 320/390/768/1280px의 그림·메뉴·44px 버튼·키보드·미리보기 행 제거·모드/난이도 유지·시작 실패 동일 키 재시도·읽기 전용 교사·미저장 초안 보존·기록 모달을 확인한다. 실제 컴포넌트를 사용하고 인증/Firebase만 합성 응답으로 대체한다. 운영 데이터에는 쓰지 않는다.
- 대기 화면의 7개 검증 그룹을 모두 통과했으며 브라우저 오류와 외부 요청은 0건이었다.
- 같은 검사에 `--motion-only`를 지정하면 24개 실제 렌더 프레임을 저장한다. 최종 전체 검사에서 프레임당 최대 89,684개 픽셀이 바뀌었고 깃 주변 이외의 변화는 0픽셀이었다. 생성 GIF는 실행 화면 캡처이며 이미지 생성으로 만든 동영상이 아니다.
- 초기 및 실행 중 동작 감소 설정에서 SVG 변형이 멈추는 것을 확인했다. 768px 경계에서 발견된 투구·함대와 메뉴 겹침은 900px 이하 하단 배치로 수정했다.

로컬 최종 검증 증거: `.superloopy/yi-sunsin-lobby/`의 `frame`, `lobby` 디렉터리. 실제 모션 프레임·GIF·픽셀 비교는 `lobby/motion`에 있다. 생성 프롬프트와 참고 자료는 `public/assets/weplay/naval/ASSETS.md`에 보존했다.
