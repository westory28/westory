# 윷놀이 모바일 판독성 개선

- 학생 게임과 교사 체험이 공유하는 윷놀이 표시만 변경한다. 공개 설정·서버 판정·보상·투척 궤적은 유지한다.
- 조작 영역의 고정 높이와 축소를 제거하여 힘 안내·버튼·사건 문구가 각자의 공간을 갖도록 한다. 화면 읽기 설명에는 회전된 화면에서도 적용되는 clip-path를 사용한다.
- 시간 게이지를 하단 상태 행으로 옮긴다. 이동 가능 발판이 표시되면 윷과 큰 결과 연출은 중앙 선택을 가리지 않는다.
- 경로·목적지 강조는 원본 발판과 같은 SVG 좌표와 도형을 사용한다. 터치 영역의 최소 44px 크기와 그림의 크기를 분리하고 최종 목적지의 밝기와 윤곽을 강화한다.
- 둥근 갈색 등에만 X를 새기고 평평한 배는 밝은 나무색으로 표시한다. WebGL과 대체 CSS 표시 모두 같은 규칙을 사용한다.
- 전체화면 조작 버튼은 물리 회전에 맞춰 매핑한 safe area에 16px 여백을 더한다.

검증: `npm run build`, `YUT_MOVEMENT_QA_SECTION=mobile-viewport node scripts/verify-yut-movement-browser.mjs`, `node scripts/verify-yut-throw-browser.mjs`. 모바일 회귀에는 390×844·844×390·768×1024·1280×800의 설명 겹침, 중앙 발판 클릭, 강조 도형과 조작 여백 검사를 포함한다. 운영 데이터 쓰기 없이 합성 서비스 및 교사 체험으로 검증한다. 실제 iPhone의 베젤과 브라우저 UI는 실기기 확인이 추가로 필요하다.
