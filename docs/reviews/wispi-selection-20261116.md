# 위스피 종목 선택과 고정 차트

사용자는 종목별 작은 그래프를 나열하는 대신 좌측 종목·현재가·등락 목록과 우측 고정 그래프를 요청했다. 기준 checkout은 `9744c626b7465bf88bc29f02c8078985dc446867`, main 동기화 상태이며 작업 중인 위플레이·신문고 변경은 포함하지 않는다.

- 전체 위스피를 목록 첫 항목으로 두고 종목 클릭 시 같은 우측 패널의 제목·가격·등락·차트·설명만 바꾼다. 종목별 작은 그래프와 두 열 카드 나열을 제거했다.
- 좌측 목록은 제한된 높이 안에서 스크롤하고 우측은 PC에서 sticky를 사용한다. 본문 가용 폭 760px 이하에서는 차트 위/목록 아래로 전환하며 목록 높이는 320px이다. 제목·탭·필터의 투명 배경과 기존 차트의 흰 모눈 배경을 유지한다.
- 등락은 한국 시각 기준 전 거래일 마지막 실제 관측과 비교한다. 첫날은 첫 관측, 기록이 없으면 `—`다. 가격 데이터·지수·시장 규칙·계좌·주문·권한·학생 화면은 변경하지 않는다.
- 유형/시대 필터를 유지하고 선택 종목이 필터에서 사라지면 첫 표시 종목, 빈 목록이면 전체 지수로 전환한다. 보기 선택·필터·목록 스크롤에는 추가 서버 조회/쓰기 0이다.
- 기존 편집 폼은 별도 `종목 편집`/읽기 전용 `종목 설정 보기` 버튼으로 연다. 보기 선택과 미저장 초안을 분리하고 다른 종목 편집으로 초안을 덮어쓰지 않는다. 계정·학기 변경에는 선택을 초기화한다. 기존 등록·규칙·상장·실시간 갱신은 유지한다.
- 런타임 AI·에이전트 실행·외부 전송·개인정보·권한·운영 공개 범위를 바꾸지 않는 교사 UI 유지보수다. Firebase 배포는 필요하지 않으며 프론트엔드만 운영 반영한다.

브라우저 29그룹과 독립 필터 2그룹을 통과했다. 320·390·768·1280·1440px에서 선택 즉시 차트 교체, 좌측 스크롤 중 우측 위치, 전체 지수 복귀, KST 자정·주말·첫날 등락 기준·색상·빈 기록, 필터/초안/계정 경계, 투명 헤더·44px 조작 영역·오버플로를 검증했다. 기존 60% 규칙·주문 예시·시장 제어·예약 상장·권한 회귀도 유지한다. 변경 TSX/TS의 Prettier 검사와 루트 `npm run build`를 통과했다. 증거는 `output/wispi-master-detail-20261116`, `output/wispi-selection-20261116`, `output/wispi-filters-20261116`에 기록한다.
