# 지도 지형·전통 지역·국가 설명 검증 (2026-10-18)

기준은 운영 `5410783`이며, 별도 작업 폴더에서 지도 변경만 합쳤다. 공통 `HistoryAtlas`와 `HistoryGlobe`를 사용하는 학생·교사 포털에 적용한다. 로그인·권한·학기·Firebase 저장 동작은 수정하지 않았다.

## 변경과 자료의 범위

- 산맥·고원·사막·평야·분지 394개를 지도와 지구본에 표시한다. 기존 흰 육지·파란 바다에 녹색 산지와 능선 질감, 황토색 사막과 점질감, 중성색 고원을 더했다. 공개 지형 자료는 개략 범위이며 정밀 측량 경계가 아니다.
- 한국의 태백·소백·함경·낭림·강남·아호비령 산맥은 GMBA v2, 개마고원은 USGS/Mapzen 고도 자료로 추출한 참고 범위다. 개마고원의 고도 기준은 지명 경계의 확정값이 아니며 도움말에 제한을 표시한다.
- 관북·관서·해서·경기·관동·호서·호남·영남·제주 9개 전통 권역과 별도 선택 가능한 기호를 제공한다. 현대 도 경계를 조합한 참고 범위다. 관동은 강원 남북, 관서는 평안 남북, 영남은 경상 남북, 호남은 전라 남북을 포함한다. 선택 시 지도 범위·설명·장소 목록을 함께 갱신한다.
- 육지 영역을 공통 육지 형상 안으로 자르고 해안선을 마지막에 그린다. 해역 자체를 선택하는 기존 동작은 유지한다.
- 국가명은 마우스·터치·키보드로 설명을 연다. 243개 국가·지역에 개요와 역사, 198개에 출처가 확인된 대한민국 관계를 제공한다. 44개는 관계 설명 미확인으로 표시하고 대한민국 자체는 외교 관계 절을 만들지 않는다.
- 국가 설명은 위키백과 판 고정 자료와 저자 이력, CC BY-SA 4.0, 발췌·번역 여부를 함께 배포한다. 열 때 외부 API를 호출하지 않는다. 출처 메타데이터와 발췌 대조 검사는 빌드에 포함한다.
- 한국사·세계사 장소 목록은 흰 배경과 행 구분선으로 정리했다. 기존 페이지 이동·선택 동작과 모바일 목록 대화상자를 유지한다.

자료의 URL·판·해시·가공 방법은 `src/data/atlas/terrain.sources.json`과 `country-profiles.json`에 기록했다. 재생성 스크립트는 `scripts/build-history-atlas-terrain.py`, `scripts/build-history-atlas-country-profiles.mjs`다.

브라우저 증거는 작업 폴더 `output/atlas-revision-20261018/ui`, `portal`에 있으며, 각 검증 명령으로 다시 생성할 수 있다.

첫 Vercel 빌드에서는 Python의 Windows 줄바꿈과 Git의 LF 정규화 차이로 지형 해시 검사가 실패했다. 생성기의 UTF-8/LF 출력을 명시하고 세 지형 파일의 Git 줄바꿈 속성을 고정했으며, 실제 Git blob과 manifest 해시를 대조했다. 좌표·내용 변경은 없고 엄격한 파일 해시 검사는 유지한다.

운영 설명을 검토하며 발견한 위키 원문 날짜 모순은 외교부 기록과 대조했다. 인도네시아의 1973년 11월 수교, 스페인의 2019년 70주년, 예멘의 1992년 수교 문장을 제외했다. 인도네시아의 정확한 수교 일자가 신뢰 자료 사이에서 엇갈리는 문장도 제외했다. 신규 날짜를 만들지 않았으며 나머지 240개 프로필은 그대로다. 공식 확인 URL과 재유입 방지는 국가 설명 빌더·검증기에 기록했다.

## 지구본 회전

30fps 타이머와 RAF가 중복 적용되던 대기를 제거하고 한 RAF에 최신 입력을 합쳤다. 색상 조회를 캐시하고, 회전 중 선·지형의 화면 오차를 0.35 CSS px 이내로 제한해 단순화한다. 국가 면과 히트 판정은 원형상을 유지하며 회전 종료 후 정밀 형상으로 복원한다. 정지·숨김 상태에서 반복 렌더링하지 않는다.

동일한 Edge headless 1280×900 환경의 120프레임 포인터 입력을 두 번 비교했다. 프레임 간격 중앙값은 기존 83.3ms에서 34.9/40.3ms, p95는 83.6/83.5ms에서 42.6/48.4ms로 줄었다. 변경 버전의 선·지형 좌표 수는 회전 중 33,373개에서 종료 후 75,521개로 복원됐고 유휴 그리기가 없었다. 새 지형을 포함한 값이며 기기 성능에 따라 달라질 수 있다. 60fps를 보장하는 수치는 아니다.

성능 원자료는 작업 폴더 `output/atlas-revision-20261018/globe-performance.json`에 보관했다. 운영 반영과 로그인한 운영 화면 확인은 배포 후 별도 결과로 보고한다.

## 후속: 지역 설명·자유 이동·목록 고정·질감·해외 지명

지역 설명과 범위 표시 기준을 제목 아래 본문으로 옮기고 출처 링크만 접는다. 한국사·세계사 지도에서 화면 크기로 드래그를 제한하던 처리를 제거했다. 한국사 배경 자료가 잘린 동아시아 범위를 벗어나면 세계 배경을 사용하며, 돌아오면 상세 한국 해안선을 복원한다. 기존 배율 제한, 전체 보기, 장소·지역 선택에 따른 이동은 유지한다.

지구본 목록은 제목과 이전·다음 버튼이 고정되고 가운데 장소 행만 스크롤된다. 페이지 전환 시 행의 스크롤 위치를 처음으로 되돌린다. 산맥의 반복 꺾쇠는 평면 지도와 지구본이 공유하는 64px 미세 입자 질감으로 교체했다. 질감은 한 번 생성해 재사용하며 기존 산지 색과 지형 켜기·끄기를 유지한다.

한국사에 교토(1590년 통신사), 에도(1607~1764년 통신사), 심양·북경(병자호란 이후 소현세자), 도쿄(1919년 2·8독립선언)를 실제 사건과 연결했다. 네 도시의 기존 대표 좌표를 사용하고 시대별 명칭을 구분한다. 설명은 우리역사넷·한국민족문화대백과사전 근거를 요약했으며 세계사 항목은 유지한다. 남한산성↔심양↔북경, 서울↔도쿄는 정확한 사건을 연결한다.

- 지도 UI 20개 조합: 320·390·768·1280·1366·1440px의 3개 보기, 지형 재시도와 보기 전환 상태 유지 통과. 모든 너비에서 다섯 한국사 명칭의 검색·설명·선택 지점 화면 이동, 지역 본문 즉시 표시와 출처 접힘을 확인했다.
- 1280px 한국사·세계사에서 네 방향으로 각각 5회 연속 드래그해 실제 이동량이 제한되지 않음을 확인했다. Home 복귀 후 카메라와 배경 해안선이 복원된다. 단위 검증에는 멀리 이동한 상태의 확대 중심 유지, 비정상 좌표 복구, 델리로 이동할 때 세계 배경 선택을 추가했다.
- 학생·교사 포털 6개 너비, 12개 조합 통과. 공통 지도와 각 포털 레이아웃을 사용하고 인증·조회는 로컬 검증 자료로 대체했다.
- 지구본 목록 390·768·1280px: 600px 휠 스크롤 전후 제목·페이지 버튼 좌표 불변, 부모 스크롤 없음, 다음 페이지 스크롤 초기화, 마지막 항목에서 페이지 버튼으로 Tab 이동, 브라우저 오류 없음.

화면·원자료는 `output/atlas-context-20261018/ui`, `portal`, `globe`에 보관한다. 빌드의 기존 시대 분류 검증에 따라 추가 해외 사건의 역사사전 분류 자료도 동기화한다.
