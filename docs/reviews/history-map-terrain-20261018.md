# 지도 지형·전통 지역·국가 설명 검증 (2026-10-18)

기준은 운영 `5410783`이며, 별도 작업 폴더에서 지도 변경만 합쳤다. 공통 `HistoryAtlas`와 `HistoryGlobe`를 사용하는 학생·교사 포털에 적용한다. 로그인·권한·학기·Firebase 저장 동작은 수정하지 않았다.

## 변경과 자료의 범위

- 산맥·고원·사막·평야·분지 394개를 지도와 지구본에 표시한다. 기존 흰 육지·파란 바다에 녹색 산지와 능선 질감, 황토색 사막과 점질감, 중성색 고원을 더했다. 공개 지형 자료는 개략 범위이며 정밀 측량 경계가 아니다.
- 한국의 태백·소백·함경·낭림·강남·아호비령 산맥은 GMBA v2, 개마고원은 USGS/Mapzen 고도 자료로 추출한 참고 범위다. 개마고원의 고도 기준은 지명 경계의 확정값이 아니며 도움말에 제한을 표시한다.
- 관북·관서·해서·경기·관동·호서·호남·영남·제주 9개 전통 권역과 별도 선택 가능한 기호를 제공한다. 현대 도 경계를 조합한 참고 범위다. 관동은 강원 남북, 관서는 평안 남북, 영남은 경상 남북, 호남은 전라 남북을 포함한다. 선택 시 지도 범위·설명·장소 목록을 함께 갱신한다.
- 육지 영역을 공통 육지 형상 안으로 자르고 해안선을 마지막에 그린다. 해역 자체를 선택하는 기존 동작은 유지한다.
- 국가명은 마우스·터치·키보드로 설명을 연다. 243개 국가·지역에 개요와 역사, 198개에 출처가 확인된 대한민국 관계를 제공한다. 44개는 관계 설명 미확인으로 표시하고 대한민국 자체는 외교 관계 절을 만들지 않는다.
- 국가 설명은 위키백과 판 고정 자료와 저자 이력, CC BY-SA 4.0, 발췌·번역 여부를 함께 배포한다. 열 때 외부 API를 호출하지 않는다. 출처 메타데이터와 발췌 대조 검사는 빌드에 포함한다.
- 한국사·세계사 장소 목록은 흰 배경과 행 구분선으로 정리했다. 기존 페이지 이동·선택 동작과 모바일 목록 대화상자를 유지한다.

자료의 URL·판·해시·가공 방법은 `src/data/atlas/terrain.sources.json`과 `country-profiles.json`에 기록했다. 재생성 스크립트는 `scripts/build-history-atlas-terrain.py`, `scripts/build-history-atlas-country-profiles.mjs`다.

## 지구본 회전

30fps 타이머와 RAF가 중복 적용되던 대기를 제거하고 한 RAF에 최신 입력을 합쳤다. 색상 조회를 캐시하고, 회전 중 선·지형의 화면 오차를 0.35 CSS px 이내로 제한해 단순화한다. 국가 면과 히트 판정은 원형상을 유지하며 회전 종료 후 정밀 형상으로 복원한다. 정지·숨김 상태에서 반복 렌더링하지 않는다.

동일한 Edge headless 1280×900 환경의 120프레임 포인터 입력을 두 번 비교했다. 프레임 간격 중앙값은 기존 83.3ms에서 34.9/40.3ms, p95는 83.6/83.5ms에서 42.6/48.4ms로 줄었다. 변경 버전의 선·지형 좌표 수는 회전 중 33,373개에서 종료 후 75,521개로 복원됐고 유휴 그리기가 없었다. 새 지형을 포함한 값이며 기기 성능에 따라 달라질 수 있다. 60fps를 보장하는 수치는 아니다.

성능 원자료는 작업 폴더 `output/atlas-revision-20261018/globe-performance.json`에 보관했다. 운영 반영과 로그인한 운영 화면 확인은 배포 후 별도 결과로 보고한다.
