# 덩기덕 쿵더Rock 도전·피버 개선

기준: `c30f889740350cb683f6530a185c16b388c1a782`, 별도 작업 폴더 `C:\westory-weplay-update`. 기존 작업 폴더의 다른 미커밋 변경은 포함하지 않는다.

## 동작

- 첫 진입은 연습이며 시작·타격·중지·완주·재시도에 랭킹 시작/완료 요청을 보내지 않는다. 사용자가 도전을 고를 때만 이번 주 곡·종료 횟수·남은 무료 횟수를 조회한다.
- 도전은 서버에서 받은 한 곡의 자진모리·휘모리만 제공한다. 하루 무료 3회 이후에는 `50위스로 도전` 버튼으로 금액을 명시한다. 교사 체험에는 시작/완료 요청 및 위스 차감을 하지 않는다. 실제 차감과 횟수·학기·공개 검사는 서버가 수행한다.
- 10/20/50/100콤보의 해당 타격부터 각각 5/10/25/50%를 더하고 정수 반올림한다. 실수 시 콤보와 피버가 즉시 해제된다. 100회 연속 정확 판정은 116,500점이다. 기본 30회 실수 종료는 놓친 노트와 잘못 누른 입력 모두에 적용된다.
- 클라이언트·서버는 같은 `rhythmCore.ts` 생성본의 점수·시간 순서·종료 계산을 사용한다. 타격 직전에도 기한이 지난 노트를 먼저 처리해 RAF 간격에 따라 콤보나 종료 결과가 달라지지 않게 했다. 종료 이후 입력은 처리하지 않는다. 실패한 완료 저장은 같은 세션·입력·종료 시각으로 재시도한다.
- 북과 리듬 벨트에 단계별 노랑·주황·빨강·무지개 아우라를 표시한다. 지화자/얼씨구는 붓글씨를 유지하면서 큰 크기·윤곽·그림자·별 장식으로 강조한다. 리듬 내부 왼/오는 산세리프 굵은 글씨를 사용한다. 노트 크기를 키운 만큼 빠른 악보의 화면 내 이동 시간을 조정해 이웃 노트가 겹치지 않게 했다.
- 점수는 노트가 도착할 때 240ms 동안 확대·복귀한다. 기존 inline 숫자 요소를 inline-block으로 바꿔 transform이 실제 적용되도록 했다. 기존 국소 게임 효과의 동작 줄이기 계약은 유지한다.
- 연습·도전 선택은 기존 경기장 상단의 44px 조작 행에 둔다. 곡 선택 영역에 별도 행을 넣었을 때 시작 버튼이 잘리는 현상을 실제 1280px 화면에서 찾아 고쳤다. 보상 설정의 펼침 표시는 기본 삼각형 대신 16px SVG chevron과 펼침 상태를 사용한다.

## 범위와 검증

기존 Firebase 게임의 유지보수이며 AI 호출·런타임 에이전트·외부 서비스·학생 자료 외부 전송을 추가하지 않는다. 공개 설정 변경은 교사의 기존 조작으로만 수행한다. 이름·점수·개인정보를 검증 보고서에 넣지 않고 합성 자료만 사용한다.

- `node scripts/verify-rhythm-core.mjs`: 피버 경계/해제, 100콤보, 틀린 입력·놓친 노트의 정확한 종료, 종료 뒤 입력 제외, 클라이언트 종료 시각의 서버 재판정, 기존 악보/판정/오디오 회귀 통과.
- `node scripts/generate-rhythm-ranking-core.mjs --check`: 클라이언트와 생성된 서버 판정 일치 확인.
- `node scripts/verify-rhythm-network.mjs`: 기존 공개 조회·권한·계정·학기·오류·재시도·무변경 저장 9개 시나리오 통과. 운영 데이터 접근 없음.
