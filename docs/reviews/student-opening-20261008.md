  완주 보상, 지도 태그 보상도 기존 신뢰 명령을 사용한다. 수업 학습·생각모아 보상은
  서버가 저장한 증거를 확인하는 별도 명령으로 canonical 원장에 기록한다.

## 후속 구조 정리 참고
