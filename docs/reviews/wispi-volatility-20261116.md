# 위스피 시장 설정과 종목 등락폭 연동

기준은 `e6ef7576d785598ade627dd00deb55b1a6c4195d`이며 변경 전 운영 도메인 커밋과 일치했다. `C:\westory`의 진행 중인 작업을 보존하고 별도 작업 공간에서 수정했다.

시장 `dailyPriceLimitBps`가 기존에는 최종 가격 제한에만 쓰였다. 이제 기본 10%에 대한 설정 비율을 반올림 전 종목 이동에 적용한다. 20%는 2배, 60%는 6배이며 정수 가격·종목 가격 범위·일일 한도·서킷에 도달하면 실제 이동은 제한된다. 모델의 시점별 상한은 `min(6000, 3000 × 배율)`이다. 기본 10%의 계산, 종목별 차이, 비공개 seed, VALUE 기준 성장 가격을 유지한다. 명시적인 무작위 변동폭 0의 고정 추세는 그대로다.

서버의 다음 정상 시세 갱신과 6주 합성 미리보기에 같은 모델을 사용한다. 과거 시세·지갑·주문·공개 설정을 소급 수정하지 않는다. 시장 설정값 자체도 변경하지 않는다. 교사 도움말만 현재 계산과 맞췄으며 레이아웃·학생 화면은 바꾸지 않았다. 외부 AI 호출·에이전트·외부 전송·개인정보·권한 변경이 없는 기존 기능 유지보수다.

## 배포 범위

`prepare-wispi-volatility-release.mjs`가 미국 `advanceWisStockPrices` 운영 원본 256파일을 보존한다. `wisStocks.js`, `wisStockPriceModel.mjs`만 교체하며 다른 254파일과 독립 진입점·권한·거래 exports는 동일하다. 256MiB·CPU1·최소0·최대1·동시80·60초, 매시 정각/Asia-Seoul 스케줄을 유지한다. 선택 배포 후 `verify-wispi-volatility-release.mjs --after`로 전체 파일 해시·런타임·스케줄을 대조한다. 다른 Functions·rules는 배포하지 않는다.

프런트엔드는 검증한 main 배포를 운영 도메인에 승격한다. 운영 검증은 소스/배포본 대조와 읽기 전용 화면 확인이며 종목·시장 규칙·학생 거래를 시험 목적으로 쓰거나 가격 갱신을 강제로 실행하지 않는다. 상세 실행 결과는 `output/wispi-volatility-20261116`에 보관한다.
