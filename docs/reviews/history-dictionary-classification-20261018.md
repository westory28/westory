# 사전 테마 분류 검증 — 2026-10-18

## 범위와 결과

사전 2,373개 항목(역사 용어 133개, 지명 2,240개)에 분야·관련 시대·지역·주제를 연결했다. 118개 분류를 710개 조합으로 압축해 저장하며, 생성 metadata의 gzip 크기는 29,222바이트다. 사전 실행 코드에서 지도 데이터, 경계 파일, Firebase를 불러오지 않는다.

| 분류 | 근거가 있는 항목 | 미지정·미확인 처리 |
| --- | ---: | --- |
| 역사 용어 관련 시대 | 133 / 133 | 범시대 개념은 `시대 공통`으로 별도 분류 |
| 지명 관련 시대 | 718 / 2,240 | 1,522개는 시대 배지를 생략하고 사유를 JSON에 기록 |

지도에 실제 표시되는 344개 지명을 포함한 기존 사전 콘텐츠와 저작권·출처 표시는 보존했다. 원문과 라이선스 범위는 [콘텐츠 출처 기록](history-dictionary-content-provenance-20261018.md)을 따른다. 이번 분류 작업은 새 원문 수집이 아니라 기존 정의와 지도 근거의 분류 검토다.

## 시대를 붙이는 기준

`관련 시대`는 사전 뜻풀이와 확인된 역사 설명에서 다루는 시대다. 장소의 설립 연대나 존속 기간 전체를 보장하지 않는다. 단원명이 포함된 원래 `tags`와 지도 `entry.eraIds` 전체 합집합은 근거로 쓰지 않는다. 지명에는 지도 `getAtlasHistoryEntries()`가 캡션·현재 지리 개요·자료 소장처 맥락을 걸러 낸 실제 설명을 사용한다.

- 674개 지명은 해당 지명의 역사 설명에 직접 시대 근거가 있다.
- 신라 두 항목과 세계사 북위는 개별 검토한 뜻풀이에 따라 시대를 보정했다. 이 중 직접 근거 분류에 없던 2개가 추가됐다.
- 42개는 동일 지명·동일 출처 문서·동일 개정 번호인 다른 지도 항목의 역사 설명으로 연결했다.
- 나머지 1,522개의 시대는 지정하지 않았다. 근거를 모르는 상태를 `시대 공통`으로 치환하지 않는다.

133개 역사 용어는 `build-history-dictionary-classification.mjs`에 용어별 수동 분류를 명시했다. 고조선·고려는 조선 건국 프린트에서 추출됐어도 해당 왕조의 시대로 분류한다. 정몽주와 위화도 회군은 고려, 고려사는 편찬된 조선 전기로 구분한다. 집현전·사헌부·춘추관·성균관은 정의에 나온 고려·조선의 맥락을 반영한다. 유교·불교·왕조·군역·유격전 등 일반 개념은 특정 프린트 시대에 가두지 않는다.

현대 기관인 독립기념관·도호쿠대학·국립현대미술관·경북대학교·리움·이화여대박물관에는 소장품의 역사 시대를 옮겨 붙이지 않는다. 이들 기관에 시대가 없다는 것은 현대 기관인지 모른다는 뜻이 아니라, 현재 사전에서 검증된 역사 설명의 시대 연결을 제공하지 않는다는 뜻이다.

## 지역과 실체 식별

세계 지역은 기존 검증된 지도 지역표를 재사용한다. 한반도 지역은 `아시아 → 동아시아 → 한반도·주변 섬 → 조선 8도 → 각 도`로 연결한다. 조선 8도는 조선 후기의 역사 탐색 기준이며 현대 행정구역이 아니다. 따라서 제주도의 전라도 연결이나 서울·개성의 경기도 연결은 이 분류 범위에서 해석해야 한다. 화면 도움말에도 이 점을 명시했다.

지역 근거는 기존 [한국사 지역 출처](history-atlas-korea-regions.sources.json), [세계사 지역 출처](history-atlas-world-regions.sources.json)를 따른다. 좌표 범위나 이름만 보고 미확인 지역을 추정하지 않는다. 직접 지역 근거는 1,898개이며, 동일 실체 출처 연결로 98개의 미확인을 해소했다. 이미 일부 지역이 있던 항목의 보강을 포함하면 출처 연결 기록은 116건이다.

출처 문서가 같다는 사실만으로 장소가 같다고 판단하지 않는다. 자동 연결은 **정규화한 지명과 출처 문서·개정 번호가 모두 같을 때**만 허용한다. 예를 들어 4군과 6진, 구산선문의 여러 사찰은 같은 글에 나와도 서로 다른 실체다. 중국 안양과 한국 안양, 미국과 한국의 독립기념관은 동명이므로 합치지 않는다. 한국사·세계사 양쪽에 등장하는 동일 지명의 분야는 유지한다.

## 주제

지도 표현용 `kind`에 역사국가가 일반 지역으로 들어 있는 경우가 있어, 정의로 확인되는 로마 제국·오스만 제국·무굴 제국·프랑크 왕국·신라·북위 등은 `국가·정치 영역`으로 보정했다. 거란·숙신·여진·읍루의 정의는 민족을 가리키므로 국가 분류를 제거했다. 지명 끝의 사막·섬·산맥과 뜻풀이가 모두 해당 지형을 명시하면 자연 지형의 하위 분류를 추가한다. 직책과 기관을 함께 다루는 주제는 `관직·통치 기구`, 일본의 통치자를 포함하는 인물 주제는 `군주·통치자`로 표시한다.

## 검증

다음 검증을 수행했다.

```sh
node scripts/build-history-dictionary-classification.mjs --check
node scripts/verify-history-dictionary-classification.mjs
node scripts/verify-history-dictionary-catalog.mjs
npx tsc --noEmit
git diff --check
```

생성물 최신성, 2,373개 ID의 완전성, 중복·잘못된 분류 참조·상위 분류 누락, 분야 보존, 미지정 항목과 감사 기록의 일치, 출처를 공유하는 항목의 실체 조건, 지도 근거와 생성 결과의 일치를 전수 확인했다. 서로 다른 분류 축의 AND 및 같은 축의 OR, 잘못된 필터 ID, 기존 검색·출처 표시·지도 344개 coverage도 확인했다.

대표 회귀 사례는 고조선·고려·정몽주·위화도 회군·고려사, 신라·북위, 현대 기관 7종, 4군과 6진의 평안도/함경도 분리, 광조사와 다른 구산선문 사찰의 지역 분리, 안양의 서로 다른 실체, 제주도의 조선 8도 상위 분류, 민족/국가의 구별, 사막·섬 주제다. 독립 감사 담당자도 구조 전수 및 이 사례들을 별도로 확인했다.

오분류 점검에 사용한 공식 보조 근거:

- [우리역사넷 교과서 용어해설](https://contents.history.go.kr/front/tg/list.do?treeId=0210): 4군은 평안도, 6진은 함경도의 북방 개척이다.
- [우리역사넷 한국사 연대기 — 정몽주](https://contents.history.go.kr/mobile/kc/view.do?code=kc_age_20&levelId=kc_n204300): 고려 인물로 1337~1392년의 생애를 확인했다.
- [도호쿠대학교 공식 소개](https://www.tohoku.ac.jp/en/about/): 1907년 설립 기관으로, 조선 후기 소장품 맥락을 해당 기관의 시대 배지로 사용하지 않는다.

분류 근거가 없는 1,522개 지명의 시대를 채우는 일은 후속 원문 검토가 필요하다. 현재 coverage를 높이기 위해 추정한 시대를 노출하지 않는다. 원문·지도 데이터가 바뀌면 생성기를 다시 실행하고 동일 검증을 통과해야 한다. 개별 미지정 사유, 원문 연결과 검토 override는 [감사 JSON](history-dictionary-classification-20261018.json)에 보관한다.
