## 서버·권한·운영 범위

최신 사용자의 불필요한 실시간 통신 제거 지시에 따라 공개 문서는 계정·학기·권한 범위의 진입마다 서버 get 1회만 수행한다. React StrictMode의 effect 재실행은 같은 진행 중 Promise를 사용한다. 실시간 구독, 폴링, 숨김/복귀·네트워크 이벤트 재조회, 시작·타격·정지·재개·재도전 요청은 없다. 교사의 공개 해제는 다음 진입부터 적용한다. 기존 실시간 차단 지침과 다른 이 동작은 사용자에게 작업 중 설명했다.

새 게임 기본 비공개, 교사 미리보기/공개 저장 분리, 서버의 현재 학기·세션·역할·메뉴 권한 검사는 유지한다. 계정·학기·권한 범위 변경은 이전 게임을 종료하고 다시 확인한다. 교사 저장은 기존 1읽기·2쓰기와 revision 충돌 검사를 유지하며 성공 후 재조회하지 않는다. 관련 근거는 `rhythm-network-20261115.md`에 있다.

게임은 로컬 합성 오디오·현재 화면 점수만 사용한다. 기존 전통 아리랑과 별도 창작 세 곡은 변경하지 않았다. 위스 지급·학생 기록·온라인 방·순위·신규 개인정보·외부 AI 호출·음원 스트리밍을 추가하지 않는다. 기존 공개 범위 안의 게임 UI 유지보수이며 학생 공개나 학교 도입 범위를 확대하지 않는다. Functions·Firestore/Storage rules 변경이 없어 이번 변경에서는 Firebase 재배포가 필요하지 않다.

## 독립 리뷰에서 수정한 사항

1. 공통 도움말 body portal이 native/page 전체 화면 밖에 남는 문제: 공통 도움말 아이콘·내용 렌더러를 재사용하고 게임 안에 위치하는 `RhythmHelp`로 해결했다. 공통 포털 코드는 변경하지 않았다.
2. 숨긴 북 하단 때문에 Tab 초점이 스크롤되는 문제: crop/zone을 `overflow:clip`으로 바꾸고 높이를 너비의 절반으로 명시했다. 초점 전후 스크롤 0과 2:1 crop을 확인했다.
3. 전체 화면 종료 후 세로 안내 버튼으로 초점이 돌아오지 않는 문제: 진입 전 초점을 보관하고 교체된 안내 버튼에 복원하는 fallback을 추가했다.
4. 현판의 양옆 장식에 곡 번호/BPM이 겹치는 문제: 글자 영역을 그림 안쪽으로 제한했다.
