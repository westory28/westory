# 역사 지도 위치·관계 선별 및 조작부 보정

## 변경 범위

지도 학습에서 지명, 역사적 사건, 실제 위치가 함께 선택되도록 보정했다. 한국사·세계사 공통 지도와 지구본에 적용하며 로그인·권한·수업자료 저장·Firebase는 변경하지 않았다. 원격의 별도 역사교실 수정 `ab8cc2a`, `5225df5`와 평가 분석 수정 `4554b4e`를 보존하여 통합했다.

- 원본 장부 2,639곳은 `historyAtlasSourceDataset`에 보존하고 지도용 `historyAtlasDataset`을 따로 선별한다. 지도에는 한국사 60곳·세계사 79곳, 총 139곳과 역사 항목 283개가 남는다.
- 좌표가 없거나 위치 근거가 없는 항목, 국가·왕조·광역 범위, 박물관·연구소·고속도로 등 비핵심 시설, 개별 역사 내용 없이 교과서 수록 사실만 설명하는 항목은 지도·목록·검색에서 제외한다. 캡션이 필터를 통과한 의림지 등은 별도로 제외했다.
- 태봉은 철원의 도시 별칭이나 독립 위치로 취급하지 않는다. 철원의 905년 이야기에서 태봉 키워드를 선택하면 같은 철원의 911년 국호 변경 이야기와 위치를 함께 선택한다.
- 귀주는 국사편찬위원회의 현대 지명 비정과 GeoNames 1875107을 연결하여 구성시 일대 대표점으로 표시한다. 정확한 전투 지점·성곽 경계라는 의미는 아니다. 위치 도움말에 이 한계를 명시하고 출처를 함께 제공한다.
- 관련 장소의 정확한 사건을 `targetEntryId`로 지정할 수 있게 했다. 잘못된 지정은 다른 시대 이야기로 대체하지 않는다. 같은 장소의 다른 시대·국호는 관련 키워드로, 다른 장소는 함께 볼 장소로 구분한다.
- 팔도·세계 지역을 바꾸면 이전 검색과 선택을 해제하고 해당 조건의 실제 장소들이 보이도록 지도를 이동한다. 이 카메라 범위를 역사 경계 폴리곤으로 그리지 않는다. 황해도는 현재 선별 기준을 만족하는 장소가 없어 빈 결과로 표시하며 이전 위치 강조를 남기지 않는다.
- 확대·배율·축소·전체 보기를 우측 상단 32px 높이 한 줄에 둔다. N 버튼은 제거하고 우측 하단 48px 나침반을 배치했다. 지구본의 나침반 방향은 실제 투영과 회전에 맞춰 갱신한다.
- 지도 폭 344px 미만에서는 설명창을 올려 나침반과 겹치지 않게 했다. 강조점도 조작부와 설명창 사이에 둔다. 태그 높이·한 줄 필터·지도 내부 설명창·물결 강조는 이전 패치를 유지한다.
- 지도 본문과 도움말을 평서형으로 고쳤다. 날짜·ID·좌표·제목·인용·출처 URL은 문체 교정에서 보존했다.

## 관계 전수 감사

선별 후 반환 관계 150개를 대상·이유 기준 45개 조합으로 묶어 실제 대상 본문과 비교했다. 철원 918년의 송악 연결은 정확한 919년 천도 항목으로 고쳤다. 추가로 확인된 불일치 7조합은 다음과 같이 처리했다.

| 원래 관계 | 잘못 열리던 이야기 | 처리 |
| --- | --- | --- |
| 후백제의 전주→광주 | 1929년 학생항일운동 | 일치 대상이 없어 지도용 연결 제외 |
| 강화도 조약→부산 개항 | 1979년 부마항쟁 | 일치 대상이 없어 지도용 연결 제외 |
| 인천 상륙→서울 수복 | 1960년 4·19 혁명 | 기존 6·25 전쟁 서울 항목으로 지정 |
| 부산 임시수도→서울 | 1960년 4·19 혁명 | 기존 6·25 전쟁 서울 항목으로 지정 |
| 927년 공산 전투→경주 | 7세기 지방 제도 | 일치 대상이 없어 지도용 연결 제외 |
| 묘청의 서경 천도 운동→개경 | 919년 왕건 천도 | 일치 대상이 없어 지도용 연결 제외 |
| 강화 천도·개경 환도→개경 | 919년 왕건 천도 | 일치 대상이 없어 지도용 연결 제외 |

원본 이야기와 출처는 보존한다. 연결을 다시 노출하려면 해당 사건의 설명과 위치 근거를 갖춘 대상 항목을 먼저 준비해야 한다. 세계사 조합에서는 추가로 명백한 사건 불일치를 발견하지 않았다. 정·역방향과 다른 시대에 반복되던 관계를 함께 정리한 최종 반환 관계는 83개이다.

## 검증

- `npm run build`: 타입 검사, 원본 지명·교과서 장부, 지도/지구본 투영·조작, 지역, 장소 설명, 역사 이야기, 새 지도 선별 검사와 Vite 빌드를 수행한다.
- `npm run build`, `npm run format:check`, `git diff --check` 모두 최종 통합 상태에서 통과했다.
- `verify-history-atlas-curation.mjs`: 모든 원본 장소의 포함/제외 판정, 과목 경계, 연결 대상과 좌표 존재, 원본 불변, 국호 별칭 오인 방지, 시설 재도입 방지, 태봉·919년 천도·관계 오류 회귀를 검사한다. 결과 명단과 판정 기록은 `output/atlas-map-curation-summary.md`, `output/atlas-map-curation-audit.json`에 생성한다.
- 지도 투영 검사는 10개 설명창 배치에서 실제 장소 1,390회, 지역 범위 956회, 전체 강줄기 170회, 극지방 90회를 검사했다. 지구본은 64개 지역 카메라 범위, 방위, 필터와 태그의 실제 핸들러를 검사했다.
- Chrome 실제 컴포넌트 하네스에서 320×844, 390×844, 768×1024, 1440×1000 화면을 확인했다. 크기 조정 후 새로 불러와 해당 크기의 레이아웃을 검사했다. 가로 넘침과 설명창·나침반 겹침이 없다.
- 320px에서 태봉→철원 911년, 390px 지구본에서 귀주→구성시 대표점, 768px에서 철원 918년→송악 919년을 직접 조작했다. 1440px 세계사에서 지도 위 로마를 클릭하여 목록과 같은 설명·선택 강조를 확인했다.
- 평면 지도와 지구본에서 귀주 검색 뒤 전라도를 선택하면 검색과 기존 선택이 지워지고 9곳의 지역 보기로 이동한다. 지도 위 휠은 Ctrl 없이 배율을 변경하며 설명과 목록 위 휠은 배율을 변경하지 않는다.
- 황해도 빈 결과에서 이전 귀주 선택·팝업이 남지 않음을 확인했다. 태봉 버튼은 Enter 키로도 철원 911년 이야기를 선택한다. 선택 배지의 실제 CSS animation 상태가 running임을 확인했다.
- 로컬 화면 증거: `output/map-curation-320.jpg`, `output/map-curation-globe-320.jpg`, `output/map-curation-globe-390.jpg`, `output/map-curation-768.jpg`, `output/map-curation-world-1440.jpg`.

## 운영 화면 후속 보정

`48fd01a`를 Vercel Production으로 승격하고 `www.westory.kr`의 해당 커밋 연결을 확인했다. 운영에서 한국사 60곳, 태봉→철원 911년, 귀주 대표점을 확인했다. 320px 운영 화면에서는 공통 교사 패치 메모 버튼이 우하단 나침반과 겹치는 문제를 발견했다. 지도 화면의 모바일 메뉴 구간(1023px 이하)에서만 이 버튼을 32px로 줄여 상단 메뉴 왼쪽에 배치한다. 헤더와 함께 스크롤되어 지도 위에 다시 겹치지 않는다. 패치 메모의 권한·데이터·열기 동작은 바꾸지 않는다. 학생 화면에는 이 교사 전용 선택자가 적용되지 않는다.

## 범위와 남은 조건

선별 검사는 기존 좌표와 근거 필드의 일관성을 확인한 것이며 139곳 전부를 별도 지리 자료로 다시 측량·검증했다는 뜻은 아니다. 새 좌표를 추가한 귀주는 별도 근거를 대조했다. 국내성·하얼빈 등 역사적 의미가 있어도 좌표가 없는 장소는 현재 지도에서 제외한다. 추후 근거 좌표를 확보하면 다시 심사한다.

역사 영역은 새로 추가하지 않았다. [시대 변화 기능과 자료 조사](history-atlas-temporal-research-20261015.md)에 사건·천도 연표를 우선하는 구현안, 행정구역 자료의 기준 시점·좌표계·재배포 조건을 기록했다. 연표 재생이나 왕조 영토 변화를 이번에 구현한 것은 아니다.

모바일 실기기의 터치·회전은 확인하지 않았으며 브라우저 크기별 검증과 기존 조작 회귀 검사로 확인했다. 빌드의 대형 번들 경고는 남아 있으며 이번 수정에서 번들 구조를 전면 개편하지 않았다.
