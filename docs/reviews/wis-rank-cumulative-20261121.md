## 원인과 변경

요청한 현재 학기의 한 학생 계좌만 이름·학년·반·학기로 서버 필터하여 확인했다. 계좌의 누적은 10,010, 과거 등급 적립 필드는 9,510으로 초기 지급 500만큼 달랐다. 해당 계좌 원장 99건을 누락 없이 재합산한 누적·지출·조정 합계와 잔액, 두 조회용 문서가 모두 원본과 일치했다. 원장 계산 오류나 보정 대상은 없었다. 식별자와 학생 원장은 이 문서에 저장하지 않는다.

사용자 지시에 따라 등급은 화면에 표시하는 현재 학기 canonical `earnedTotal`로 판정한다. 초기 지급과 정상 누적 적립을 포함하고 지출은 등급을 낮추지 않는다. 주식 이체는 기존 원장 계산을 그대로 따른다. 반환 원금은 누적을 늘리지 않으며 일반 지갑에 확정된 출금 수익만 이미 누적에 포함되어 같은 등급 기준에 반영된다. 양수 수동 조정은 누적에 이미 들어 있으므로 다시 더하지 않는다.

지갑·마이페이지·대시보드 배지·승급 알림·이모지 검증과 서버의 이모지 선택·아바타 구매·프로필 재검증을 같은 기준에 연결했다. 순위 공개 응답에는 별도 `earnedTotal`을 추가했다. 이전 명예의 전당의 `cumulativeEarned` 순위·커서 의미를 바꾸거나 과거 순위를 다시 쓰지 않는다. 서버가 먼저 새 필드를 제공한 뒤 프런트엔드를 배포한다.

`rankEarnedTotal`과 잔액·원장·정책 문서를 마이그레이션하지 않는다. 누적이 없거나 안전한 비음수 정수가 아니면 문자열 변환, 예전 등급 필드, 프로필, 거래내역, 잔액으로 해금을 추정하지 않는다. 기존 계정·학기·학적·세션·공개 범위와 계좌 유효성 검사는 유지한다. 공개 범위·개인정보 항목·런타임 AI 호출·에이전트 실행·외부 데이터 전송 변경은 없다.
