# 충무공 수자기·모션·로딩·전투 음악 정정

## 원인과 변경

- 기준은 `f2b1a28fa6504a610e62891b8c5601f9d6982d79`이다. 기존 `C:\westory`의 사용자 미커밋 작업을 보존하고 연결된 별도 worktree에서 수정했다.
- 운영 브라우저에서 깃의 `data-motion=reduced`, 변형 `scale=0`을 확인했다. 이전 코드는 OS 동작 감소에서 RAF를 막고 SVG까지 숨겼다. 사용자 요청에 따라 이 차단을 제거하고, 같은 3.8초 주기의 작은 영역 변형을 유지한다. 일반은 scale 80±8, 동작 감소는 50±5이다. 44px 멈춤/켜기 버튼과 숨김 탭·화면 밖 일시정지·정리 동작을 제공한다.
- 아군 판옥선에 잘못 들어간 일본식 꽃 문양을 누런 천·검은 `帥`자 수자기로 교체하고 썸네일도 같이 수정했다. 멀리 있는 적 함대는 유지했다. 생성 원본·프롬프트·국립국어원 및 강화전쟁박물관 근거는 `public/assets/weplay/naval/ASSETS.md`에 기록했다. 조선 후기 유물을 이순신의 실물로 설명하지 않는다.
- 해전 로딩의 W 인장을 판옥선 선화·파도·노 젓기로 바꿨다. 동작 감소에서는 이동 없이 금색 점 밝기가 순환한다. 외부 이미지 없이 표시되며, 교사 체험 초기 로딩에도 연결했다. 실제 요청이 끝나면 닫히며 가짜 진행률이나 추가 지연을 만들지 않는다.
- 기존 합성 음악을 45초·128BPM·4/4박자 전투곡으로 교체했다. 북·장구·징·태평소를 떠올리게 하는 합성 음색에 현 반복구, 절제와 돌격의 강약을 넣었다. 전통 악기 실연·역사적 연주법의 복원으로 주장하지 않는다. 음소거·사용자 제스처·탭 숨김·화면 이동 정책과 윷놀이·인트로 음악을 유지했다.
- 그림과 음악의 URL에 각각 `sujagi-2`, `naval-war-2` 버전을 붙여 기존 자산 캐시와 구분했다. 권한·학기·위스·게임 판정·서버 코드는 변경하지 않았다.

## 검증

- `npm run build`: 타입 검사·전체 prebuild·Vite 빌드 통과. 기존 수행평가 XLSX hair 테두리 회귀도 포함한다.
- 변경 TSX/TS 여섯 파일의 Prettier 검사와 `git diff --check`.
- `node scripts/verify-weplay-loading-motion.mjs`: 320/390/768/1280px, 정상/동작 감소의 실제 로딩 모션 영상, 화면 밖·숨김·복귀, busy/inert·포커스·정리, 윷놀이 로딩 보존. 8개 항목 통과.
- `node scripts/verify-weplay-network-loading.mjs`, `node scripts/verify-weplay-start-timeout.mjs`: 키보드가 열린 작은 화면, 답변·정산 대기, 타임아웃·재시도·포커스 복귀 통과.
- `node scripts/verify-weplay-lobby-exit-browser.mjs --motion-only`: 최종 수자기 그림으로 일반 1280px·동작 감소 390px의 실제 프레임 캡처. 연속 프레임에서 두 설정 모두 깃 움직임을 확인했다. 동작 감소에서 깃 바깥 변화와 두 설정의 수동 정지 중 변화는 0픽셀이었다. 일반 설정의 한 프레임은 배경 래스터 오차가 있었고, 채널 1/255를 넘는 차이는 4픽셀의 2/255뿐이었다. OS 설정을 실행 중 바꿔도 움직임을 유지하며 명시적 멈춤·키보드 재개를 통과했다.
- 같은 스크립트 `--loading-only`: 교사 초기 로딩과 학생·교사 시작 보류, 중복 클릭 차단, 실패 후 재시도와 정상 경기 전환 통과. 브라우저 오류·외부 요청 0건.
- `node scripts/verify-weplay-opening-layout.mjs --frame-only`: 학생·교사와 충무공·윷놀이 공통 프레임 및 작은 화면의 조작 배치 회귀 통과. 새 멈춤 버튼은 320/390px에서 투구와 기록 버튼을 가리지 않는다. 320px 학생 화면의 기존 랭킹 버튼이 투구 최상단 일부를 가리는 상태는 유지되며 390px에서는 겹치지 않는다.
- `node scripts/verify-weplay-music-browser.mjs`: 네이티브 WAV 디코딩·제스처 재생·45초 반복·음소거 저장·탭 숨김/복귀·해제·자동재생 거부 후 재시도 통과. 클리핑 0, 피크 0.750, 루프 경계 차이 0.014, 네 마디 구간 RMS 0.150~0.273. 고정 시드 재생성의 SHA-256이 동일하다. 자동 수치 검사와 실제 재생을 확인했으며 주관적 청취 평가를 수행했다고 주장하지 않는다.

모션 3파일의 독립 코드 검토에서 출시를 막을 결함은 발견하지 못했다. 정지 후 재개 시 변형 위상이 처음부터 시작하는 작은 차이는 게임·정지 기능에 영향을 주지 않는다.
