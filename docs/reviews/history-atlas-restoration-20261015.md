# 역사 지도 지명·자연지형 복원 검토

기준 커밋은 `26e17b5b86e204b7c756c52b9073430a0bb027b0`이다. 기존 지도는 140곳이었다. 원본 2,639곳의 포함·제외 판정을 다시 계산하고, 개별 역사와 위치 근거를 확인한 장소를 344곳으로 늘렸다. 한국사는 179곳, 세계사는 165곳이다. 지구본의 기본 과목은 전체이며 두 과목을 함께 표시한다. 교과 구분은 원본 ID의 접두어가 아닌 최종 역사 항목의 단원을 기준으로 한다.

## 복원 내용

- 안동은 기존 고창 전투 항목의 시대별 이름이 목록 이름을 대신하면서 찾기 어려웠다. 목록과 지도 배지는 안동을 유지하고, 설명에서는 고창 전투와 서원 이야기를 시대별로 선택한다. 전북 고창과 구분한다.
- 발해 5경은 상경 용천부·중경 현덕부·동경 용원부·남경 남해부·서경 압록부 모두 표시한다. 수도 이동 관계는 정확한 대상 사건으로 연결한다. 중경은 서고성, 동경은 팔련성 유적을 기준으로 삼는다. 남경의 청해토성 비정에 대한 다른 견해와 서경의 린장 일대 근사 위치는 위치 정보에 명시한다.
- 한국사에서는 국가유산청 등록 유적 78곳, 발해 수도 4곳, 명량·노량·옥포 해역 3곳의 좌표를 보완했다. 57개 이야기와 44개 명시적 사건 관계를 추가했다. 기존 진주·행주·한산도 등의 사건도 연결한다. 국가유산 등록 주소로 팔도 분류를 대조했다.
- 세계사에서는 도시 25곳과 추가 도시·유적 39곳의 역사 내용을 보완했다. 추가 유적 21곳은 UNESCO 공개 좌표를 사용한다. 바빌론·카르타고·산치·보로부두르 등의 기존 이야기는 좌표 보완으로 다시 표시된다. 윈강·룽먼·보로부두르·아크로폴리스의 중복 개요는 출처 장부에 보존하고 지도 필터에서는 정확한 시대 이야기로 정리했다.
- 자연지형은 38개 이야기로 41곳을 복원했다. 강줄기와 사막 면을 직접 누르거나 목록·배지를 선택해 같은 설명을 열 수 있다. 금강과 웅진·사비, 태평양과 마닐라·아카풀코 등 검증된 관계를 연결했다.
- 황허강은 `Huang` 상·중류가 별칭에서 빠져 하류만 선택되던 문제를 수정했다. 실제 자료의 세 구간을 모두 표시한다. 창장·티그리스·유프라테스의 상류 별칭도 보완했다. 고비와 사하라는 기존 Natural Earth 면 자료로 표시한다.
- 한국사·세계사는 자기 교과의 역사 항목과 관계를 사용한다. 지구본 전체 모드의 지역 선택은 한국사 팔도와 세계사 권역을 구분하며, 장소나 이야기 선택 후에도 전체 모드를 유지한다.
- 독도의 대한민국 표시, 실제 해안선, 필터와 독립된 기본 배지와 선택 동작을 보존했다. 강·사막 강조와 기존 지점 물결 애니메이션을 함께 사용한다.

## 근거와 제외 기준

원본 지명·교과서 인용·쪽수 장부는 수정하지 않았다. 이번 작업에서는 보존된 전 페이지 대조 장부와 국사편찬위원회, 한국학중앙연구원, 국가유산청, UNESCO, 의회·국립공원청 등 개별 자료를 대조했다. 전체 원본 교과서·역사부도 PDF가 현재 작업 환경에 없으므로 이번에 전권을 새로 읽었다는 의미는 아니다.

박물관의 현재 소장 위치를 과거 유적 위치로 대신하거나, 동명 유적을 혼동하거나, 국가·왕조 영역을 임의의 점으로 복원하지 않았다. 역사 사건의 정확한 현장이 알려지지 않은 경우 도시·해역의 대표점이라는 차이를 위치 근거에 명시했다. 출처 이름과 좌표 출처를 구분하고 필요한 라이선스를 함께 제공한다.

타클라마칸·카라쿰은 대응하는 사막 면 자료가 없어 임의의 원이나 도시 점으로 추가하지 않았다. 검증이 남은 항목은 삭제된 원본이 아니라 보존된 자료 장부에 남아 있다. 자연지형 196항목의 전체 판정과 자료의 축척·현대 수계 한계는 [자연지형 검토](history-atlas-landform-restoration-20261015.md)에 기록했다.

## 검증

- `npm run build` 통과: 타입 검사, 기존 앱 회귀 검사, 전체 역사 지도 검사와 Vite 빌드가 완료됐다. 최종 지도는 344곳·507개 역사 항목·201개 유효 관계이다. 기존 큰 번들 경고는 남아 있으나 빌드 오류는 없다.
- `npm run format:check`, 수정 후 대상 파일 Prettier와 `git diff --check`가 통과했다.
- 기본 빌드의 역사 지도 검사에 한국사 복원 검사와 선·면·세계사 복원 검사를 추가했다. 실제 앱 데이터에 포함되는지, 원본을 보존하는지, 출처·좌표·과목·시대·팔도·정확한 관련 사건이 일치하는지 검사한다.
- 지구본의 실제 전체 과목 필터, 강·사막 선택 처리와 반대편 지형 배제, 독도 그리기를 실행하는 회귀 검사를 확장했다.
- 실제 브라우저에서 안동 검색과 경상도 필터, 발해 필터의 5경 목록, 중경→상경 사건 이동, 황허 상류 직접 클릭, 고비 사막 내부 클릭을 확인했다.
- 320px·390px·768px 및 데스크톱 화면에서 배치를 확인했다. 320px에서 문서 너비와 화면 너비는 모두 320px이다. 필터와 확대 조작은 한 줄을 유지하고 설명은 지도 내부에 표시된다.
- 설명에서 휠 스크롤할 때 배율은 635%로 유지됐고, 지도 위에서 Ctrl 없이 스크롤하면 1200%로 확대됐다.
