- 새 파일 TypeScript 변환 진단 0건.
- 16개 고유 ID와 16개 PDF 검색어를 모두 확인했다. 장안·시안, 항저우·임안은 각각 한 항목으로 연결된다.

- 평성/성락, 베이징/중경, 장안/함양, 하얼빈/상경회령부, 업/안양, 장링/하오쉐를 잘못된 동일 장소 별칭으로 추가하지 않았음을 검사했다.

- 이번 파일은 정적 데이터다. 요청, 구독, 네트워크 라이브러리와 렌더링 루프를 추가하지 않는다. 전체 배열 통합 후에는 과목별 지리 개요가 16개씩 추가되고, 기존 미표시 도시 8개가 지도 표시 대상이 된다. 실제 표시·성능 영향은 부모 작업의 전체 데이터 검증 및 순차 브라우저 검증에서 확인한다.
