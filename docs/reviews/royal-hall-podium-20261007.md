# 명예의 전당 어좌·학생 배지 검증

## 변경 범위

- 사용자 제공 태조 어진·영조 곤룡포를 참고한 왕실 배경과 1위 어좌 이미지. 생성 프롬프트는 `src/assets/wis-hall-of-fame-royal-podium.md`에 보관.
- 기본 그림은 royal_podium_v2 배치로 전환. 별도 사용자 업로드 이미지의 기존 배치 유지.
- 2·1·3위 이모지와 순위는 그림 위, 학년·반·번호·이름·위스 배지는 그림 아래 같은 순서의 3열.
- 동점자 배지는 모두 표시하며 클릭·키보드 포커스로 대표 이모지 선택.
- 공개 데이터에 제공된 번호만 유지하고, 없으면 ‘번호 비공개’. 다른 학생 프로필 조회 추가 없음. 이름 마스킹 유지.

## 검증

- `npm run build`: TypeScript, 학기 보관 경계, NEIS/평가 Excel hair 테두리 회귀 검사, Vite 빌드 통과.
- 변경 TS/TSX/CSS에 Prettier 확인, `git diff --check` 통과.
- 오프라인 실제 컴포넌트 fixture: 1280·768·390·320px 화면에서 가로 넘침 없음. 긴 이름 및 123,456,789 위스 표시 확인.
- 6명 동점자, 번호 누락, 빈 랭킹, 전교·학급 전환, 좁은 모바일 미리보기 확인. Tab으로 두 번째 동점자에 포커스하면 대표 이모지 변경 확인.
- 데스크톱 강제 모드의 372px 시상대에서도 데스크톱 좌표 유지. 넓이 24→36 변경 시 이모지 40→60px 반영.
- 순수 설정 검증: 이전 기본 프리셋 이관, 기본 좌표 독립 복사, 저장 좌표 유지, 사용자 업로드 보존, 번호 유무 및 마스킹된 이름 보존 통과. 네트워크 호출 없음.
- 독립 코드 리뷰에서 확인한 좁은 데스크톱 좌표 오적용과 넓이 조절 무반영을 수정하고 재검증.

## 운영 검증의 한계

현재 운영의 공개 랭킹은 이름 마스킹·기본 이모지를 사용하고 번호를 제외한다. 기존 랭킹 불러오기/반영 오류도 남아 있어 실제 학생이 채워진 운영 시상대는 검증할 수 없다. 배지 배치 검증에는 가상 학생만 사용했다. 이번 패치는 프런트엔드 표시 변경이며 운영 Functions·개인정보 공개 범위는 변경하지 않는다.
