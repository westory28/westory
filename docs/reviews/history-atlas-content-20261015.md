## 구현·운영 검증

- 교사·학생 지도를 공통 2D 지도 컴포넌트로 통합하고 기존 지도 자료는 별도 버튼에서 지연 로드한다. 한국사·세계사와 단원별 범위, 옛 지명 검색, 관련 장소 이동, 시대별 설명, 출처 쪽수를 제공한다.
- Natural Earth의 고정 버전 지형을 사용한다. 지형·강·장소 좌표에 같은 투영식을 적용하며 AI가 생성한 지도 그림은 사용하지 않는다. 한국사는 Mercator, 세계사는 Natural Earth 투영이므로 평면 지도의 투영 왜곡은 존재한다. 현대 지형과 대표 장소를 표시하며 역사 국경을 복원한 지도는 아니다.
- 주제별 지형 파일을 처음 열 때만 내려받고 메모리에서 재사용한다. 지형·강 파일의 gzip 합계는 한국사 712,445바이트, 세계사 737,498바이트다. 이는 지도 데이터 크기이며 전체 앱 최초 전송량은 아니다. 장소 클릭은 Firebase 읽기나 외부 지도 타일 요청을 만들지 않는다.
- 교사 PC 화면과 390·768·1280px 브라우저 뷰포트를 검증했다. 실제 학생 태블릿·휴대폰의 GPU, 배터리, 터치 성능을 측정한 결과는 아니다. 3D 라이브러리와 지구본은 이번 배포에 포함하지 않는다. 후속 도입은 실기기에서 로딩·드래그 프레임·메모리·배터리를 측정하고 2D 복귀를 검증한 뒤 판단한다.
- 역사교실 안정화 작업이 완료된 `00738715`를 병합한 뒤 지도 연동을 제거했다. 새 과제는 학습지만 사용하며 기존 지도 과제는 저장된 이미지·빈칸·선택지를 유지한다. 과거 mapResourceId는 출처 메타데이터로만 남고 더 이상 조회·갱신하지 않는다. 운영 문서나 이미지를 삭제하는 마이그레이션은 없다.
- 운영 읽기 전용 조사에서 지도 기반 과제 75개 모두 자체 이미지·빈칸을 보유했다. 3개의 선택적 OCR 영역 누락과 3개의 빈칸 기본 필드 차이는 보존·설정 변경 검증에 반영했다. 기존 이미지 URL을 공유하므로 지도 자료 삭제도 저장소 이미지를 삭제하지 않는다.
- 검증 범위: 전체 빌드·타입 검사·포맷 검사, 지형 해시·좌표·육지/바다·인용 무결성, 기존 지도 캐시 9개 시나리오, 지도 저장 명령 23개 검사, 역사교실 학생·교사 화면 및 Firestore 에뮬레이터 회귀 검사. Functions 배포 대상은 `executeCommand` 하나다.
