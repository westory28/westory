# 윷놀이 교사 관전

`플레이 모니터링` 버튼을 교사 체험의 행동 영역으로 이동한다. 방의 `관전`을 누르면 기존 팝업 안에서 보드와 참가자 현황으로 전환하고, `목록으로`를 누르면 방 목록으로 돌아온다. 방 목록은 기존 PC 두 열·작은 화면 한 열을 유지한다. 관전은 최대 1536px, 목록은 1152px이며 제목·목록으로·닫기는 고정하고 본문 하나만 스크롤한다. 관전 내부 폭 800px 이상은 보드와 256px 현황을 나란히 배치하고 작은 화면에서는 세로로 쌓는다.

`YutSpectator`는 경기 조작 컴포넌트를 실행하지 않는다. 기존 보드·말·프로필 표시만 재사용하며 모든 말 선택과 이동을 비활성화한다. 참가·준비·던지기·자동 넘김·이동·감정표현·접속 표시·보상 명령이 없다. 현재 차례·윷 결과·완주·선두와 종료 결과는 서버에서 확인한 방 자료로 표시한다. 남은 시간과 만료는 관리 조회 때 받은 서버 시각 차이를 사용하며 표시용 타이머로 경기 상태를 변경하지 않는다.

한 관전 화면은 선택한 방 문서 구독 하나만 유지한다. 관전 중에는 전체 목록의 15초 조회를 중단한다. 목록 복귀·닫기·방/계정/권한/학기 전환·숨김·오류·만료 시 구독과 보관 중인 표시 자료를 해제한다. 캐시 자료를 서버 확인 자료로 사용하지 않으며 늦게 온 이전 구독의 응답을 무시한다. 숨김 후 복귀는 서버 확인부터 다시 시작한다. 오류·만료 후에는 명시적인 다시 연결만 제공한다. 대기방의 만료는 `expiresAtMs`와 생성 후 10분 중 빠른 시각이며, 시작 갱신이 만료 직후 도착하는 경우에도 수동으로 다시 확인할 수 있다.

## 권한과 운영 영향

Firestore `yut_rooms`의 단일 문서 `get`에만 교사·관리자·교사 포털이 활성화된 `lesson_read` 직원 관전을 허용한다. 학교 계정·유효한 세션·계정 승인/삭제·점검 설정·활성 학기와 방 만료 조건을 유지한다. 학생 공개 설정과 교사 관전 권한은 구분한다. 비참가 관전자는 대기·진행·종료 방만 읽으며 닫힌 방은 거부한다. 기존 교사/학생 참가자의 닫힌 방 읽기 호환성은 유지한다.

학생의 참가자·재적·공개 조건을 바꾸지 않으며 방 목록 직접 조회와 모든 클라이언트 생성/수정/삭제는 계속 거부한다. 읽기 권한 판정에서 같은 세션 검사를 중복 호출하지 않아 기존 학생 읽기의 문서·표현식 예산을 유지한다. 관전으로 방·차례·revision·타이머·참가자 목록·플레이어 포인터를 저장하지 않는다.

운영 rules의 LF 정규화 해시 `0870a510b173e9e90ae878186d1be7da0770323be099f83d5136cc53c28f074a`가 작업 기준 `c11a7374`와 일치함을 배포 전에 확인했다. 백엔드 배포 대상은 `firestore:rules`뿐이다. 경기/설정 Functions와 Storage rules는 변경하거나 다시 배포하지 않는다. 학생 클라이언트의 강제 새로고침이나 현재 방 데이터 변경은 없다.

## 검증 경로

- `npm run build`, 변경 TS/TSX Prettier, `git diff --check`.
- `npm --prefix functions run check`.
- 전용 demo Firestore 에뮬레이터의 `npm --prefix functions run test:yut-integration`: 비참가 교사·관리자·직원 읽기, 권한 회수, 승인/삭제, 세션·학기·점검·공개·방 상태, 학생 비참가 거부, 목록과 모든 직접 쓰기 거부, 관전 전후 경기와 포인터 전체 불변.
- `YUT_MANAGEMENT_ONLY=1 node scripts/verify-yut-management-browser.mjs`: 버튼 위치·목록/관전 전환·단일 관전·목록 조회 중단·닫기/복귀·계정/학기 정리·서버 시각 차이 전달.
- `node scripts/verify-yut-spectator-browser.mjs`: 실제 관전 컴포넌트의 서버 확인·실시간 갱신·읽기 전용 조작·숨김/복귀·방 전환·오류/재시도·만료·늦은 응답 격리와 반응형 배치.

운영에서는 새 커밋을 Vercel에 승격한 뒤 실제 교사 화면에서 기존 방의 읽기 전용 관전을 확인한다. 운영 검증을 위해 방·학생·보상을 생성하거나 경기/설정 명령을 보내지 않는다.
