# 세부 채점결과 수행평가 가져오기

2026-10-07 사용자가 제공한 `채점결과_20261007.xlsx`를 기준으로 수행평가 가져오기를 수정한다. 원본은 읽기만 하며, 학생 이름·개별 점수·피드백을 저장소나 검증 스크린샷에 복제하지 않는다.

## 입력 계약

- A1은 학급별 채점 결과 설명, A2는 `평가: 하여가와 단심가 다시 쓰기(논술형)`, 4행은 학생 정보·총점·세부 기준·피드백 헤더다.
- A:D는 학년/반/번호/이름, E는 총점, F:K는 6개 채점 기준, L은 AI 채점 수준, M은 선생님 작성 피드백이다. 채점 수준은 점수 항목이 아니다.
- 평가명은 헤더 앞의 평가명 메타데이터에서 읽는다. 파일명을 바꾸어도 평가명은 바뀌지 않는다. 평가명이 없으면 미리보기에서 입력해야 저장할 수 있다.
- 수행평가 과목은 항상 역사다. 세부 항목명에 역사 단어가 있는지로 과목을 추측하지 않는다.
- 세부 항목 이름은 원문을 보존한다. `역사적 맥락`을 지난 학기의 `평점 근거`로 치환하는 등 특정 평가에 묶인 축약 규칙은 제거한다.
- 이 양식은 하나의 평가 안에 여러 채점 기준이 있는 구조다. 6개 평가로 나누지 않고 하나의 명단과 학생별 6개 항목으로 저장한다. 기존 NEIS 양식의 평가별 열 분리는 해당 양식에서만 유지한다.
- 원본에는 별도 배점 행이 없다. 명시된 배점이 있으면 그것을 우선하고, 없으면 관측된 항목별 최고점을 사용한다. 이번 원본은 6/6/6/4/4/4, 총 30점으로 사용자 참고 화면과 일치한다. 미리보기의 `배점 수정`에서 실제 배점으로 조정하거나 항목 헤더에 `기준명(6점)`처럼 명시할 수 있다. 같은 평가·같은 기준을 다시 업로드할 때 추론 배점보다 큰 기존 저장 배점을 유지한다.
- 교사 피드백의 Markdown 번호 이스케이프와 문자 형태의 줄바꿈을 정리한다. 번호 목록은 줄바꿈하되 소수·날짜·경로의 의미를 바꾸지 않는다. 정리된 피드백과 평가 근거를 그대로 저장해 학생 화면에서도 줄바꿈이 유지된다.

## 미리보기와 저장

평가명을 상단에 명확히 표시하고, 세부 기준은 `기준명(배점)`의 작은 인라인 목록으로 표시한다. 큰 항목 카드는 사용하지 않는다. 엑셀에서 읽은 학년/반/번호 필터와 범위를 제공하고, 한 학급 파일은 그 학년·반을 기본 선택한다. 필터는 조회용이며 저장은 파일의 전체 학생을 대상으로 기존 명단 일치 검증을 수행한다.

배점 편집은 필요할 때만 펼친다. 배점의 빈칸·0 이하·비정상 숫자와 이미 입력된 학생 점수보다 작은 배점은 저장하지 못한다. 배점 수정 시 각 항목·학생별 항목의 배점과 총배점이 함께 갱신되며 학생이 받은 점수는 바뀌지 않는다. 추론 배점 도움말은 세부 기준 옆의 `i` 버튼에서만 표시한다.

기존 배점 보존은 미리보기 상태와 저장 트랜잭션에서 읽은 최신 평가 양쪽에 적용한다. 다른 교사가 배점을 먼저 수정했더라도 추론 배점으로 되돌아가지 않게 한다. 교사가 `배점 적용`으로 확정한 값이나 파일에 명시된 배점은 추론값과 구분한다.

새 평가의 일람표 순서는 1차/2차 중 선택한다. 기존 동일 평가의 순서는 유지하고, 신규 평가에는 비어 있는 순서를 기본 제안한다. 평가명이나 파일명의 특정 단어로 신규 순서를 정하지 않는다. 일람표에 실제 평가명과 총점이 들어가도록 연결하며 기존 XLSX 레이아웃과 `hair` 점선 계약은 변경하지 않는다.

## 검증

- `verify-grading-performance-import.mjs`: 합성 채점표의 평가명·과목·세부 기준·총점·피드백·0점/빈칸 및 잘못된 입력 검사. 선택적으로 원본 파일을 읽어 개인별 값 출력 없이 구조를 검증한다. 기본 build에도 연결한다.
- `verify-score-workflow-browser.mjs`: 합성 32명으로 390/768/1280px 미리보기, 필터, 단일 평가 저장, 재업로드, 서명 유지와 일람표 내보내기를 검사한다. 실제 첨부 파일의 브라우저 인식 검증은 저장·스크린샷 없이 수행한다.
- 기존 NEIS 가져오기, 명단 연결, 이의제기 통합, 서명 버전, 엑셀 점선 회귀도 유지한다. 실제 운영 학생의 점수나 서명은 검증용으로 변경하지 않는다.

검증 결과: `npm run build`, `npm run format:check`, 원본 파일을 포함한 파서 검사, 점수·명단 계약 및 이의제기 클라이언트 검사가 통과했다. 실제 브라우저 390/768/1280px 검증에서 페이지 오류는 0건이었다. 원본 인식은 32명·6개 기준·30점이며, 합성 데이터로 단일 평가 저장, 동일 점수 재업로드의 서명 유지, 배점 수정 후 31점 일람표 출력, 미리보기 이후 서버 배점 변경 보존을 확인했다. 30점·31점 XLSX 모두 평가명·학생 원점수·서명 이미지와 직렬화된 `hair` 테두리 검사를 통과했다.
