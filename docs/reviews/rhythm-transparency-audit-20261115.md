- 결론: 독립 자산 자체에 사각 색판이나 체커 패턴이 구워져 있지 않았다. 이번 조사에서는 이미지 파일을 변경하거나 재생성하지 않았다.

## 사각 배경 원인

조사 시점 `src/components/common/weplay/weplay-catalog.css`의 77행부터 있는 다음 공통 규칙이 카드 안의 모든 후손 이미지에 적용됐다.

```css
.weplay-game-card img {
  display: block;
  width: 100%;
  height: auto;
  aspect-ratio: 4 / 3;
  object-fit: contain;
  background: #163c4e;
}
```

사용자 첨부 화면에서 정확히 `#163c4e`인 픽셀은 **14,671개**였다. 독립 WebP 9종에서는 같은 RGB이면서 알파가 128 이상인 픽셀이 모두 **0개**였다. 마스코트와 두 노트의 각 모서리는 알파 0이다. 이는 투명 자산 뒤에 카드 공통 CSS의 배경이 칠해진 현상과 일치한다.

공통 선택자 범위를 대표 이미지로 좁히거나 리듬 카드의 독립 레이어 이미지에 투명 배경을 명시하는 코드 수정이 필요하다고 통합 작업자에게 전달했다. 코드·CSS는 이 아트 조사 작업에서 수정하지 않았다.

## 수행 방법과 변경 범위

Pillow로 이미지 속성·알파 히스토그램·특정 색 픽셀 수만 읽었다. 픽셀 편집이나 재인코딩은 하지 않았다. 자산에 제거할 배경이 없으므로 내장 이미지 도구를 다시 호출하지 않고 기존 완성본을 보존했다. 이번 조사에서 추가한 파일은 이 제작·검증 문서뿐이다. 실제 카드 수정 및 화면 회귀 검증은 통합 작업에서 별도로 수행한다.
