## 기존 이번 주 기록 이관

`functions/scripts/migrate-weplay-weekly-rankings.cjs`는 기본 dry-run이며 `--apply --writers-deployed`를 모두 지정해야 쓴다. 원본 게임·점수·지갑·보상·프로필은 읽기만 하고 새 주간 projection만 갱신한다. 삭제/탈퇴 예정·미승인 계정은 제외하며 학기·학급·원본 필드를 트랜잭션에서 재확인한다. 오류나 시간 증거 부족은 전체 적용 전에 차단한다.

- 해전: 주 안에 완전히 들어간 기간을 확인하고 해당 기간의 완료 도전 세션을 서버에서 필터·커서 조회한다. 학생·반·난이도별 최고점을 복원하며 새 writer의 `rankingWeekId`가 있는 세션은 제외한다. 월간 최고점으로 주간 점수를 추정하지 않는다.
- 리듬: 집계가 이번 주에 시작됐고 각 점수 시각이 이번 주인 기존 최고점만 가져온다. 과거 누적 최고점을 임의로 주간 점수로 바꾸지 않는다.
- 윷: 실제 완주 이벤트와 기존 누계가 일치해야 한다. 나가기·닫기로 이벤트가 덮였으면 `주 시작 ≤ 방 생성 ≤ 완주 기록 ≤ 현재 시각 < 다음 주`와 완주 상태·승자·학급·누계를 확인한다. 이 경우 동점 순서에는 기존 기록 시각을 사용하며 정확한 완료 순간이라고 주장하지 않는다. 이전 주 생성이나 모순된 완료 이벤트는 이 대체 경로로 통과시키지 않는다.

배포 전 실제 dry-run은 33문서 읽기, 8페이지, 기존 요약 3개·해전 기간 1개·완료 해전 세션 3개, 적용 후보 7개와 윷 2승을 확인했고 오류·쓰기 0이었다. 두 윷 기록은 나가기로 마지막 이벤트가 덮여 생성/기록 시각 증거를 사용했다. 학생 이름·UID는 보고서에 남기지 않는다. 윷 이관 영수증은 누적 baseline의 증가분만 적용하므로 새 writer와 병행하거나 다시 실행해도 중복 가산하지 않는다.
