# 현재 지역 범위와 접힌 출처

## 범위

- 한국사 8도 필터 이름은 유지한다. 2026-10-16 OpenStreetMap의 현재 남북한 29개 도·광역시 경계를 8개 탐색 범위로 묶는다. 과거 도 경계나 행정적 소속을 재현하는 자료가 아니다.
- 세계사와 지구본은 같은 43개 대륙·세부 권역·해역 범위를 사용한다. Natural Earth의 현대 국가·별도 영토와 물리 지리, 저장소의 UN M49 분류를 결합했다. 러시아·튀르키예 등은 자연지리 대륙 경계로 나누고 해외 영토는 실제 위치로 분류한다.
- 위치가 있는 지명은 현재 범위로 분류한다. 간소화된 해안선 밖 항구·해협·작은 섬 및 위치 미확인 지명은 검토된 기존 분류를 보완 자료로 사용한다. 바다·대양은 기존 해역 분류를 먼저 확인하여 항구 도시·강·호수가 섞이지 않게 한다.
- 범위 출처는 기존 출처 아코디언 양식을 사용하며 기본 접힘이다. 다른 범위로 바꾸면 다시 접힌 상태로 시작한다.
- 범위 필터만 선택해도 실제 경계와 배지를 표시한다. 해당 지역의 장소가 0개여도 범위는 유지한다. 좁은 화면에서 출처를 펼쳐도 지역 전체가 팝업 아래에 들어오도록 지역 전용 기본 투영을 조정하고 기존 최소 배율 50%를 유지한다.

## 출처와 재생성

한국사 및 세계사 원본 URL·버전·체크섬·처리 규칙은 `src/data/atlas/areas-korea.sources.json`, `src/data/atlas/areas-world.sources.json`에 기록했다. 생성기는 `scripts/build-history-atlas-areas.py`, `scripts/build-history-atlas-world-areas.py`다. 서비스 실행 중 외부 경계 API를 조회하지 않고 과목별 번들 자료를 한 번씩 읽어 지구본과 공유한다.

## 검증

- `npm run build`: TypeScript 및 기존 학기·학습지·수행평가 XLSX 테두리·지도 회귀 검사 포함.
- `npm run format:check`, `git diff --check`.
- 현재 51개 지역 × 10개 팝업 배치에서 전체 경계 510회 화면 맞춤 검사. 기존 실제 장소 3,440회, 지역 카메라 2,220회, 극지 90회 검사 유지.
- 지구본 실제 그리기 122상태, 세계 범위 43개·실제 위치 73개·평면/지구본 투영 129회 검사. 날짜변경선 양쪽 표기, 해외 영토, 대륙 횡단, 해역/내륙 분리, 캐시와 부분 실패 재시도 포함.
- 실제 브라우저 1280/768/390px: 한국사 현재 강원도, 세계사 유럽·서유럽·대서양, 지구본 유럽·서유럽의 범위·배지·출처 기본 접힘과 펼침·지역 전환 확인.
- 검증 로그와 화면은 `.superloopy/sessions/map-current-regions-20261016/evidence/`에 보관한다. 기존 지도 지명·독도·상단 설명·선/면 선택 회귀도 빌드에서 검증한다.

학생·교사는 같은 지도 컴포넌트를 사용한다. 인증·학기·저장 경로·Firebase Functions·rules는 변경하지 않는다. 운영 배포는 이 변경의 main 커밋과 Vercel Source commit을 대조한 뒤 www.westory.kr 승격 및 실제 화면으로 확인한다.
