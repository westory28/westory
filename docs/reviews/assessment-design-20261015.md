# 평가 개선과 후속 도입 방향

2026-10-15. 사용자 요청 1~6은 구현 대상이며, 7(서술형)·8(AI API)은 아래 제안만 작성한다. 이 문서는 새로운 기능의 운영 효과가 이미 입증되었다는 뜻이 아니다.

같은 날 후속 요청에 따라 확신도 입력은 제거하고 실제 행동 기록을 사용하도록 기준을 갱신했다. 목차·시각 편집·마이페이지의 변경과 검증은 [후속 개선 기록](assessment-followup-20261015.md)을 따른다.

## 확인한 근거

- [공유 대화](https://chatgpt.com/share/6ad0aaef-aa40-83e8-b9c6-4f1182a31842): 시간으로 추측 응답을 확정하지 않고, 기기 내 계측을 기존 저장 요청에 동봉하며 정오답·확신도·다른 문항의 결과를 함께 해석한다. 대화에 포함된 과거 작업 지시는 이번 사용자 요청과 구분했다.
- 운영 Firebase를 읽기 전용으로 확인했다. 설정상 현재 학기는 2026-2이며 해당 학기의 문제는 0개다. 2026-1에는 557문항(선택형 433, OX 74, 단답형 32, 순서형 18), 지문 315개, 이미지 22개, 이미지 선지 2개, 해설 548개, 소단원 연결 523개가 있었다. 개념·인지과정 태그는 없었다. 루트 legacy 문제 200개는 현재 학기 문제와 합치지 않는다.
- 같은 소단원에 불교 수용의 목적, 소수림왕의 태학·율령, 침류왕의 불교 수용을 묻는 문제가 이미 있다. 자료를 읽고 개념·인물·정책을 구별하도록 만든 이 수준의 문항을 출발점으로 삼는다.
- 사용자 제공 PDF 세 건의 전체 텍스트와 논술형 페이지를 확인했다. 2026년 1학기 3학년 시험(4쪽)은 명칭 확인과 가야 연맹 변화의 이유, 광종 정책의 목적, 음서와 과거의 비교를 함께 묻는다. 2025년 2학기 시험(5쪽)은 아테네 민주 정치의 한계와 로마 통치 정책의 이유를 요구한다. 2025년 1학기 시험(6쪽)은 탈라스 전투의 영향과 효문제 정책의 이유를 요구한다.

## 이번 구현의 판단 기준

학생의 과업은 문제 풀이 → 정오답과 근거 확인 → 필요한 내용 복습 → 다른 문제로 재확인이다. 교사의 과업은 자료와 문항 관리 → 공개 설정 → 제출 결과 확인 → 어떤 설명과 재확인이 필요한지 결정하는 것이다.

1. 문제 등록·문제 은행·학습 진단을 같은 작업공간의 탭으로 제공한다. 단원 전체 이름을 읽을 수 있게 한다.
2. 문항의 기존 지문·이미지·선지·정답·해설·힌트를 유지한다. 파생 문항은 원문과 연결하되 새 문항으로 저장한다.
3. 교사가 개념, 사고 과정, 오답 선지에 대응하는 혼동, 관련 수업 자료를 명시할 수 있게 한다. 기존 문제에 자동 추정 태그를 넣지 않는다.
4. 첫 선택까지, 최종 선택까지, 검토 포함 열람시간, 화면 밖 시간을 구분한다. 답 변경·재방문·힌트 사용·기록 품질도 함께 보존한다. 확신도를 입력받지 않으며 매초 서버 호출은 하지 않는다.
5. 정오답·풀이 시간·답 변경·점수 분포는 서로 다른 증거다. 특정 선지 선택만으로 오개념을 확정하지 않는다. 시간으로 점수·보상·부정행위를 판정하지 않는다.
6. 같은 문제의 반복 정답을 여러 개의 독립 근거로 세지 않는다. 최초 결과와 최근 결과를 구별하고 자료가 부족하면 그대로 표시한다. 새 기록은 응시 시작 당시의 문항 메타를 보존한다.
7. 재응시 제한·공개 대상·학기·서버 채점은 유지한다. 같은 평가 범위에서 이전에 틀렸거나 힌트를 참고한 명시 개념의 미풀이 문항을 우선하고, 이어서 다른 미풀이 문항을 선택한다. 문항 풀이 부족 시 기존 문제도 다시 나올 수 있다. 재응시 점수 차이를 정밀한 능력 향상량으로 해석하지 않는다.

현재 학기 문제와 분석 기록이 비어 있으면 빈 상태를 보여 준다. 이전 학기 문항·결과를 현재 학기로 자동 복제하거나 공개하지 않는다. 기존 태그 없는 기록에는 정답률과 단원 정보까지만 활용하고, 새 계측이 없는 기록의 시간을 0초로 채우지 않는다.

## 출제 부담을 줄이는 운영 방식

자료 하나를 먼저 완성하고 문항을 묶어 관리하는 방식이 적합하다. 같은 내용을 단순히 선지 순서만 바꾸지 않고 질문하는 사고 과정을 바꾼다.

예를 들어 불교 수용 자료 묶음은 다음처럼 구성할 수 있다.

| 문항 역할 | 확인할 내용 | 자료·선지의 차이 |
| --- | --- | --- |
| 개념 확인 | 불교라는 개념을 알아보는가 | 수용 목적과 관련된 설명 |
| 사료 해석 | 자료의 단서로 왕과 정책을 추론하는가 | 태학·율령 등의 단서 |
| 비교 | 국가별 수용 시기·주체를 구별하는가 | 소수림왕·침류왕·법흥왕 구분 |
| 인과 | 왕권 강화와 사상 통합의 관계를 설명하는가 | 목적과 수단을 뒤바꾼 오답 |
| 전이 확인 | 처음 보는 자료에도 적용하는가 | 발문만 바꾸지 않은 새로운 자료 |

교사는 원문 복제 후 바뀐 질문·정답·해설을 검토한다. 개념·자료 연결은 상속하고, 사고 과정과 선지별 혼동은 파생 문항에 맞게 다시 확인한다. 공개 전에 정답의 유일성, 사료 출처, 시대·인물·사건의 관계, 오답이 왜 틀렸는지 확인한다. 현재 구현은 자동 문항 생성기가 아니며 출제 책임을 대체하지 않는다.

## 서술형 도입 제안 — 이번 패치 제외

시험지의 실제 구조에 맞춰 **공통 자료 + 소문항별 답안 + 소문항별 채점 기준**으로 도입한다. 긴 자유 입력창 하나로 묶으면 명칭을 모르는 것과 인과를 설명하지 못하는 것이 구별되지 않는다.

- 명칭 확인: 허용 답안·동의어·띄어쓰기 규칙을 교사가 설정한다. 자동 일치 판정이 가능한 경우에도 공식 성적 반영 전 교사 검토 경로를 둔다.
- 근거 찾기: 자료의 단서와 자신의 답을 연결해 쓰게 한다. 정답 문구 포함 여부와 근거의 적절성을 구분한다.
- 원인·결과: 원인, 변화, 결과의 관계를 채점 요소로 둔다. 핵심어 나열만으로 관계 설명 점수를 부여하지 않는다.
- 비교·한계: 비교 대상과 기준이 모두 드러나는지 확인한다. 사실이 맞아도 질문의 비교 기준을 충족하지 않으면 별도 피드백한다.

2026년 시험의 가야 연맹 변화 문항은 ‘광개토 대왕의 활동’과 ‘금관가야 약화·맹주 변화’를 연결하는 요소별 루브릭으로 만들 수 있다. 예컨대 사건 이해와 인과 연결을 나누는 방식이 가능하지만, 이는 후속 설계 예시이며 원래 시험의 공식 채점표로 간주하지 않는다. 광종 정책의 목적과 음서·과거 비교도 같은 원리로 분리한다.

시험지에 명시된 ‘요구한 개수 초과 시 첫 답안만 채점’ 조건은 문항별 규칙으로 보존한다. 모든 서술형에 일괄 적용하지 않는다. 학생에게 요구 개수와 배점을 답안 입력 위치에서 보여 준다.

교사 화면은 학생별로 긴 답안을 한꺼번에 읽는 방식뿐 아니라 같은 소문항의 답안을 모아 비교하며 채점하는 방식을 제공하는 것이 좋다. 부분 점수·피드백·보류·재검토·수정 이력을 보존하고, 채점 기준을 바꾸면 변경 전후와 영향 학생을 확인한다. 학생 화면은 받은 점수, 충족한 요소, 보완할 요소, 다시 쓸 답안을 나란히 보여 준다.

도입 순서는 명칭/짧은 근거 답변 → 요소별 교사 채점 → 피드백 후 재작성 → 새로운 자료에서 재확인이다. 자동 채점 정확도와 관계없이 교사의 성적 확정 권한을 유지한다.

## AI API 도입 판단 — 이번 패치 제외

현재는 학생에게 직접 제공하는 AI API 도입을 권하지 않는다. ‘완벽하게 정확하고 학습 개선 효과가 확실할 것’이라는 조건은 지금 확인된 자료로 보장할 수 없다. 이번 패치로 먼저 비AI 진단·복습·재확인 기준선을 확보하는 편이 타당하다.

AI의 후보 용도는 아래 순서다.

1. 교사용 비공개 출제 보조: 교사가 제공한 사료·교과 내용·기존 문항만 바탕으로 변형 초안을 만든다. 근거 문장, 정답 근거, 오답 이유를 같이 제출하게 하고 검토 후에만 문제 은행에 반영한다.
2. 교사용 서술형 검토 보조: 루브릭별 충족 여부와 학생 답안의 근거 구절을 제안한다. 학생의 의도나 능력을 추측하지 않으며 불명확한 답은 보류한다. 최종 채점과 점수 변경은 교사가 한다.
3. 학생용 제한적 힌트: 앞 단계가 검증된 후, 승인된 설명과 단계별 힌트 안에서 질문한다. 답을 바로 노출하거나 정답을 대신 작성하지 않는다. AI 도움을 받은 풀이와 독립 풀이 결과를 분리한다.

도입 전 검증은 ‘AI를 쓰는 동안 정답률이 올랐는가’로 끝내지 않는다. 같은 학습 목표의 비AI 조건과 비교하고, 도움 없이 새로운 자료를 풀었을 때와 며칠 뒤 다시 확인했을 때의 정답·근거 품질을 본다. 학습자 수준별 결과, 잘못된 역사 설명·출처·채점 제안, 교사의 수정 시간, 응답 지연·비용도 측정한다. 배점이 큰 오류가 확인되면 해당 용도는 중단하고 원인을 고친 뒤 재평가한다. 수치 기준과 파일럿 규모는 교사와 먼저 정하고 ‘0건 관찰’을 무오류 보증으로 해석하지 않는다.

학생 식별정보와 전체 학습 이력을 외부로 보내는 설계는 피한다. 검증할 때는 익명 예제와 필요한 문항·답안 조각만 사용하고, 제공업체·보관·삭제·접근 범위·실패 시 기본 피드백 경로를 사전에 정한다. 이번 구현에는 AI SDK, API 키, 외부 모델 호출을 추가하지 않는다.

## 연구를 적용하는 범위

- [Wise·Kong의 응답 시간 기반 노력 측정 연구](https://eric.ed.gov/?id=ED490203)는 시간 정보를 해석 보조 자료로 사용할 근거다. 위스토리 학생의 ‘찍기 확률’ 산출을 검증한 연구는 아니다.
- [Roediger·Karpicke의 인출 연습 연구](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/)는 평가 후 다시 떠올리는 활동을 학습과 연결하는 근거다. 이 연구만으로 역사과의 특정 복습 간격이나 이번 패치의 효과를 보장하지 않는다.
- [Bastani 등의 고등학교 수학 실험](https://hamsabastani.github.io/education_llm.pdf)은 AI 사용 중 수행 향상과 도움 없는 독립 평가의 학습 성과가 다를 수 있음을 보여 준다. 안전장치가 없는 도구의 부정적 효과는 교사 설계 힌트가 있는 도구에서 줄었으나, 그 조건도 독립 평가의 유의한 향상을 입증하지는 못했다. 수학 연구 결과를 한국 중학교 역사과에 그대로 일반화하지 않고 별도의 파일럿이 필요하다.
