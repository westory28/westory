# 위스피 지수·종목 화면·투자 그래프 개선

사용자 요청: 전체 위스피 지수와 종목별 차트, 종목 설명과 가로 공간 개선, 수익률 상위 5명 차트, 하루 가격 제한폭 60% 및 예측 반영. 추가 요청으로 유형 드롭다운과 시대·주제 버튼 필터를 제공한다.

## 계산과 저장

- 전체 지수는 기준 1,000의 시가총액 가중 연쇄지수다. 기존 종목의 가격 변화에 이전 발행량을 적용하고 신규 상장·발행량 변경은 이후 가중치에만 반영한다. 시총 합산은 BigInt로 처리한다.
- 기존 시장은 보관된 실제 가격 이력부터 재구성하며, 과거 발행량 기록은 없으므로 현재 발행량을 사용한다. 최초 기준 시각 이후 지수를 canonical market 안에 저장하고 최근 120관측을 보관한다. 조회는 저장하지 않는다. 종목/가격 변경 트랜잭션에 포함하여 별도 문서·스케줄러·조회·쓰기를 추가하지 않는다.
- 학생 public projection의 필드·시드 비공개·거래 권한·학기 경로는 유지한다. 지수는 교사 관리 응답에만 포함한다. 학생 화면 디자인은 변경하지 않으며 공통 차트의 기본 가격 동작은 유지한다.
- 보유 수익률은 `평가손익 / 매수 수수료 포함 보유 원가`다. 전체 매매 성과의 투자 원금 자료가 없으므로 실현손익과 현금 입출금은 섞지 않는다. 원가 0 또는 미보유자는 제외하고 동률은 학년/반/번호/학생 키 순으로 정한다. 같은 학급 projection에서 추가 조회 없이 상위 5명을 계산한다.
- dailyPriceLimitBps와 circuitBreakerBps의 허용 최대값은 6000이다. 기본값·운영 저장값은 유지한다. 하루 누적 상하한만 확장하고 기존 1회 가격모델 안전 상한은 유지한다. 기획안 cache는 제한폭을 키에 포함하며 실제 시세와 가상 예측을 구별한다.

## 화면과 비용

- 전체 지수는 pt·소수 두 자리로 표시하며 원본 소수 관측값을 보존한다. 종목은 두 열/한 열의 설명·가격·작은 차트로 표시하고 선택 시 전체 설명·상세 차트를 보여 준다.
- 유형/시대 필터는 이미 받은 현재 학기 종목에서 계산한다. 필터 변경은 조회/쓰기를 발생시키지 않는다. 계정/학기 변경에 초기화하고 편집 초안은 필터·가격 갱신으로 덮어쓰지 않는다.
- 표시 중인 종목 관리에만 기존 안전 공개 문서를 구독한다. 새로운 revision은 관리 자료 1회(기존 5문서 읽기) 갱신, 동일 revision은 0회다. 숨김·다른 탭·세션/계정/권한 변경·오류에서 구독을 종료하며 폴링은 추가하지 않는다.
- 예약 상장 일정과 기존 시장 공개 상태는 보존한다. 필수 영수증·감사·동시성 검사는 유지한다. AI 호출·외부 AI 전송·개인정보 항목·공개 범위를 추가하지 않는 통상 유지보수다.
