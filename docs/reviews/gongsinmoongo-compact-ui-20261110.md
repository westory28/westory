# 공부의 神문고 설정 밀도와 투명 헤더

2026-11-10 사용자 정정에 따라 교사 공신문고의 기본 운영 선택 3개와 기본 제한 기간을 PC 한 행에 배치했다. 알림·학습 연결·첫 사용 안내도 같은 배지형 체크 항목을 사용한다. 기존 파랑·중성 토큰, 44px 조작 높이, 8px 간격과 네이티브 체크박스·select를 유지한다. 좁은 화면에서는 필요한 만큼 줄바꿈한다.

페이지 제목은 공통 `ws-page-header`를 사용하며 교사 페이지·대화 헤더의 흰 배경, 그림자, 전역 sticky와 최소 높이를 명시적으로 초기화했다. 학생 화면 재디자인, 저장 동작·조회·권한·알림·AI 호출 변경은 없다.

`AGENTS.md`, `UI_RULES.md`, `DESIGN.md`에 새 화면·새 패치에서 페이지 제목·탭·필터·본문 소제목을 흰색 사각형 헤더로 감싸지 않는 기준을 기록했다. 과거 UI 기본값의 흰 카드·sticky header 표현도 수정했다. 전역 header 스타일의 유입 여부는 실제 계산 스타일로 확인한다.
