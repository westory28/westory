## 변경

- 사용자 추가 지시에 따라 대문 모션은 매 방문 기본 ON. 하단 버튼으로 OFF/ON을 제어하며 OS 설정은 변경하지 않는다.
- '생각을 연결하다'는 첫 96px의 스크롤에 따라 나타난다. ㅏ에서 시작하는 선도 96px 이후에만 출발한다.
- 섹션 경계 연결선을 제거하고 각 구역의 주요 타이포/미리보기로 흡수되는 곡선으로 변경. 180ms 지연, 1600ms 이동/꼬리 흡수, 900ms 밝기 강조.
- SVG 이동 경로는 실제 cubic Bézier 명령만 사용하며 접점의 접선 방향을 맞췄다. 이동 완료 후 선은 남지 않는다. 대상이 움직이거나 글꼴/화면 크기가 바뀌면 위치를 다시 측정한다.
- 마이페이지 소개는 실제 메뉴 3개와 가상 데이터로 간소화했다. 큰 이모지 선택과 반복 점수 입력을 제거하고 기존 공개 문항의 해설을 재사용한다.
- 상단 소개 문구 삭제, 헤더 로고 -0.0625em 광학 정렬, 모바일 푸터 버튼과 맨 위로 버튼 간 여백 확보.

## 검증

- `npm run build`: 타입 검사와 학기 아카이브 검증 포함 통과. 기존 번들 크기 경고만 발생.
- `npm run format:check`, `git diff --check`: 통과.
- 실제 Chrome, OS 동작 감소 설정 ON 상태에서도 새 대문 `data-motion=on` 확인.
- 1280×900, 768×1024, 390×844, 320×568에서 레이아웃과 가로 넘침 확인. 페이지 가로 넘침 없음.
- 맨 위에서 강조 제목 opacity 0, 40px 스크롤에서 0.4167, 120px에서 1 확인.
- 첫 선의 ready → running → absorbed 전환, 이동 후 마스크 길이 0, cubic 경로, 노트북 열림 진행도 확인.
- 마이페이지 기본 정보/성적표/오답 노트, 방향키 메뉴 전환, 정답·해설 열기 확인. 모바일 메뉴 영역은 60px 높이로 줄바꿈되어 접근 가능.
- 모션 OFF: 선 모두 숨김, sticky stage 0개, 본문 opacity 1, body 고정 해제 확인. ON으로 다시 전환 확인.
- 브라우저 콘솔 오류 없음.
- 독립 코드 검토에서 발견된 SVG 길이 캐시 초기화 문제를 수정했다. 위치 변경 시 머리가 경로 시작점으로 튀지 않도록 실제 d 변경 때만 길이를 갱신한다.

변경은 공개 대문과 해당 디자인 계약에 한정한다. 로그인된 학생/교사 포털, 인증, Firebase Functions/rules의 동작은 수정하지 않았다.
