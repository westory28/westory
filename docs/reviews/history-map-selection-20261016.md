# 지도 지명 선택과 범위 표시

## 적용 범위

학생·교사의 공용 한국사·세계사·지구본을 수정했다. 로그인·권한·학기·서버 저장은 변경하지 않았다. 두 포털은 같은 `HistoryMaps`와 동일 데이터셋을 사용한다.

- 독도는 일반 지명으로 표시하고 선택할 때만 공통 선택 배지를 쓴다. 실제 해안선, 공식 좌표, 필터 독립 표시와 역사 설명은 유지한다.
- 지명 글자와 점은 동일한 선택 함수를 사용한다. 지구본 SVG 지명은 클릭·터치·Enter·Space로 선택한다. 설명이 연결된 장소 지명은 배경 지형 이름에도 같은 동작을 적용한다.
- 강·면적 선택은 대표점과 원형 후광을 없애고 실제 선·면을 강조한다. 배지는 실제 도형 위의 앵커와 가장자리 8px가 겹친다. 곡선 강의 중심이 물줄기 밖으로 벗어나거나 폴리곤 내부 구멍에 배지가 놓이지 않도록 실제 도형을 검사한다.
- 설명은 좌측 상단에 표시한다. 작은 지도 또는 장소 목록 버튼이 보이는 레이아웃은 상단 56px를 확보한다. 좁으면 설명 아래, 넓으면 오른쪽에 선택 위치를 맞춘다.
- 8도는 기존 지역 선택으로 범위를 강조하며 배지를 누르면 범위 기준·출처를 확인한다. 인천·강화도·제주도·한산도는 기존 역사 설명과 범위 표시를 연결한다.

## 범위 자료와 한계

- [국사편찬위원회 역사지리정보DB](https://hgis.history.go.kr/pro_g1/dataset.do)의 1910-05-10 경계를 남·북도별로 합친 8도 탐색 범위다. 한성부는 경기도 탐색 범위에 함께 표시한다. 조선 전 시기의 정확한 경계나 당시 한성부의 경기도 소속을 주장하지 않는다. 원자료의 추정·신뢰도 코드, 시점, 해시와 가공 절차를 `areas-korea.sources.json`에 기록했다.
- 인천은 [OpenStreetMap 행정 경계](https://www.openstreetmap.org/relation/2297419)와 기존 Natural Earth 육지의 교집합이다. 강화도·제주도·한산도는 기존 1:10,000,000 육지 자료의 본섬 폴리곤이다. 현대 참조 범위이며 과거 행정·해안·작전 범위와 구분하는 위치 도움말을 제공한다.
- 총 12개 범위 자산은 982,587바이트, gzip 306,943바이트이며 필요 시 한 번 불러와 공유한다. 런타임 외부 지리 API 요청은 없다. Windows/Linux 해시 일치를 위해 자산 줄바꿈을 LF로 고정했다.

## 검증

- 타입 검사, 전체 앱 빌드, `npm run format:check`, `git diff --check`를 통과했다. 빌드는 기존 학기 보호·학습지·성적 XLSX hair 테두리 검사도 포함한다.
- 실제 지도 코드의 독도/지명 UI 28개 지구본 상태, 혼잡 배치 10회, 3,440개 장소 카메라, 170개 도형, 극지 90회, 2,220개 지역 카메라 및 지구본 지역 64회를 검사한다. 기존 필터 독립성과 앞·뒷면 판정은 유지한다.
- 새 범위 검사로 8도 대표 도시 포함, 폴리곤 방향·폐쇄·내부 앵커, 인천/강화도 범위 구분, 출처 해시와 공유 로더를 확인한다.
- 실제 Chrome의 공통 컴포넌트에서 390·768·1280px, 지도/지구본의 지명 클릭·키보드·상단 설명·무점 범위·가로 넘침을 확인했다. 증거는 `.superloopy/sessions/map-selection-20261016/evidence/`에 보관한다.
