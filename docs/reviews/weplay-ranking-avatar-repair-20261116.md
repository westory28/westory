## 아바타 원인과 복구

기준 커밋의 실제 CSS에서 저장 버튼 배경과 글자가 모두 `rgb(255,255,255)`임을 재현했다. 기본 버튼 선택자가 primary 배경을 덮는 충돌을 해당 스튜디오 범위에서 고쳤다. 비활성 상태도 글자가 남고 활성 버튼은 파랑/흰색 대비를 유지한다.

기존 썸네일 변환은 WebP 인코딩 요청에 PNG를 반환하는 브라우저를 실패 처리했다. 2,630자 PNG도 기존 코드에서 용량 오류가 발생했다. 새 클라이언트는 Image로 디코딩하며 PNG/WebP를 받아 서버로 보낸다. 서버는 MIME·시그니처·입력 128KiB·512px 한도·단일 프레임을 검사하고 APNG를 차단한 뒤, 기존과 같이 64KiB 이하 WebP로 재인코딩한다. 원본 저장 경로·소유권·revision·영수증·신문고 참여/보상은 유지한다.

저장 Storage 실패는 10읽기/0쓰기, 성공은 17읽기/3쓰기, 동일 요청 재시도는 8읽기/0쓰기였으며 지갑 변화는 없다. 초안과 요청 키를 보존하고, 응답 유실의 중복 영수증에만 복구 조회한다.
