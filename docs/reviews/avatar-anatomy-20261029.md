# 아바타 팔·짧은 머리 재검토

## 문제와 판정 기준

사용자가 제시한 관복 정면 화면은 팔꿈치가 바깥으로 꺾이고 어깨가 별도 구체처럼 보인다. 토벤 헤어는 짧은 옆머리 대신 한쪽으로 긴 덩어리가 내려오며 두상과 분리되어 보인다. 기존의 메시 유효성·연결·리소스·미리보기 지문 검사는 이런 해부학적 방향과 실루엣의 완성도를 판정하지 못했다.

팔은 기본 자세의 짧은 손 도달 거리와 바깥쪽 팔꿈치 방향, 의상의 구형 어깨 연결부를 함께 검토한다. 헤어는 기존 풍성한 가르마 모델의 바운딩 박스에 외부 GLB를 맞추는 방식 대신 실제 두상·헤어라인·귀 주변·후두부의 연결을 검토한다. 얼굴형 선택은 턱 부분을 바꾸므로 전체 헤어 크기를 얼굴형마다 임의 확대하는 것으로 해결하지 않는다.

정면·양측면·후면, 기본·표현 포즈, 맨팔·긴 소매, 양쪽 캐릭터, 피부색·염색·모자를 실제 렌더로 확인한다. 수치 검증 통과와 시각 검토 결과를 구분한다.

## 2D 전환 판단

현재 결함은 3D 라이브러리 자체의 한계보다 모델 맞춤·리깅·시각 검토의 문제다. 팔의 굽힘을 교정해 실제 렌더로 개선을 확인했지만, 두 차례 짧은 헤어 재구성은 모자 같은 실루엣과 피부 경계 때문에 기각했다. 원본 얼굴과 머리가 결합된 메시를 계속 보정하는 대신, 2D 원화 시안을 제시했고 사용자가 **원화 기반 2D 전환**을 선택했다. 최종 패치에는 중간 3D 실험을 포함하지 않는다.

새 두상·표정·헤어·의상·장식 원화를 투명 레이어로 합성한다. 84개 카탈로그 ID·가격·소유권·서버 저장 계약을 유지하고, 피부색·염색은 원화 명암을 보존해 적용한다. 팔의 상·하부와 손·소매를 연결해 여섯 포즈를 구성한다. 3D 회전은 제거하고 전체·얼굴 보기를 유지한다. 3D 캡처를 평면으로 붙이는 방식이 아니다.

순위·명예의 전당은 이미 정지 썸네일을 사용한다. 기존 사용자 썸네일은 사용자가 다시 저장할 때 갱신되며 자동으로 사용자 기록을 수정하지 않는다.

## 영향 범위

학생·교사 꾸미기가 공유하는 클라이언트 렌더러와 배포용 품목 미리보기만 변경한다. 카탈로그 ID, 보유 품목, 가격, 구매, 저장 권한, 학기 경로 및 legacy 조회 경로는 변경하지 않는다. 런타임 AI 호출·에이전트 실행·외부 데이터 전송을 추가하지 않으며 검증은 합성 자료와 로컬 자산을 사용한다. 개인정보 처리·공개 범위 확대가 없는 기존 화면의 유지보수다.

원화·manifest·미리보기는 `avatar/v2/`의 새 URL로 발행하여 기존 v1 immutable 캐시에 남은 이미지를 재사용하지 않게 한다. v2는 재검증 가능한 캐시를 사용하며 이전 버전은 열린 구 클라이언트와 기존 썸네일을 위해 보존한다.

## 원화 출처와 재현

내장 `image_gen`으로 자체 제작한 시안과 여섯 원화 시트, 하트 손 부품, 착용 정면 헤드폰을 사용한다. 실제 학생·교사 사진·개인정보를 입력하지 않았고, 공급자의 기존 게임 이미지나 3D 메시를 복사한 자산을 배포하지 않는다. 입력은 새 시안과 그림 형태의 제작 지시이며 추가 부품은 자체 신체 시트와 합성한 위스토리 캐릭터만 참조로 사용한다. 원본은 `assets/avatar-source/v2/`, 명시적 셀 범위·배치·팔레트·원본 SHA256은 `scripts/avatar-2d-art-registry.json`, 생성기는 `scripts/build-avatar-2d-assets.mjs`다. 상세 프롬프트 요약은 원화 폴더의 README에 남긴다.

명령: `node scripts/build-avatar-2d-assets.mjs --spec scripts/avatar-2d-art-registry.json`, `node scripts/render-avatar-item-previews.mjs`. 사용자 썸네일은 서버의 기존 검증·revision 경로를 통해 명시적으로 저장하며 자동 변환 쓰기를 하지 않는다.

## 실제 합성 검토와 검증

첫 합성에서 관복 상체가 치마의 전체 바운딩 박스에 종속되어 소매와 떨어지는 문제를 확인했다. 몸판과 치마를 허리에서 나눠 등록하고 상체의 어깨·허리 폭을 맞췄다. 팔·소매는 실제 관절의 겹침을 기준으로 배치하며 손바닥 원화의 위·아래 방향을 교정했다. 하트는 두 주먹을 모은 모양을 기각하고 손가락 사이 하트 구멍이 있는 전용 원화로 교체했다. 전체 품목 검토에서는 하복 맨팔의 절단면과 한복 몸판·하의 사이 틈도 따로 확인했다.

`verify-avatar-2d-renderer.mjs`는 실제 브라우저에서 투명 캡처·화면 확대·축 반전·비동기 선택 취소·로딩 실패·리소스 해제와 WebGL 미사용을 검증한다. 실제 React fixture의 카탈로그 검사는 학생 320/390/768/1280px, 교사 390/768/1280px, 151개 캐릭터별 꾸미기 선택, 양쪽 여섯 포즈, 합성 구매와 투명 저장·동일 모습 재저장을 포함한다. 실제 설정·가격표 fixture는 반응형, 로컬 필터, 가격 검증, 저장 중 잠금, 재조회 오류와 동시 수정 초안 보존을 검사한다. 운영 사용자 정보나 지갑은 테스트에 사용하지 않는다.

원화 체크는 원본 8장·등록표·생성기·manifest·레이어 해시를 확인하고, 미리보기 체크는 153개 캡처의 원화·렌더러 지문과 이미지 예산을 확인한다. 미리보기 생성 시에는 얼굴 확대 구도와 별개로 실제 저장 캡처의 네 가장자리를 검사하여 모자 꼭대기 등의 잘림을 차단한다. 줄바꿈은 Windows/Linux에서 같은 해시가 되도록 정규화하며 CI 체크에는 이미지 생성용 의존성이 필요하지 않다. 시각 증거는 `output/avatar-2d-20261029/`, 실제 화면 검증 증거는 `output/avatar-2d-ui-20261029/`에 로컬 보관한다.
