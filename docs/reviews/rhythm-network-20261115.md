## 조회와 저장 범위

공개 상태는 `years/{year}/semesters/{semester}/rhythm_publication/gungdeok-rock` 한 문서를 `getDocFromServer`로 확인한다. 미존재는 비공개이고 잘못된 데이터·서버 미확인 캐시·8초 초과·연결 오류는 게임을 열지 않는다. 권한 거부는 닫힘으로 처리한다. 전체 목록 조회, legacy fallback, Firestore 실시간 구독, 주기적 조회는 없다.

조회 결과는 현재 마운트된 화면의 메모리에만 둔다. 계정 UID·인증 세대/상태·포털·학기·메뉴 접근·교사 권한 경계가 바뀌면 기존 승인을 즉시 버린다. 새 범위에 권한이 있으면 한 번 새로 확인하며, 과거 요청이 늦게 도착해도 새 범위를 열지 않는다. 화면을 떠난 뒤 재진입하면 다시 읽는다. React StrictMode의 effect 재실행은 같은 요청 promise를 공유하여 중복 읽기를 만들지 않는다. 로컬 저장소·서비스 워커·계정 간 공유 캐시는 추가하지 않는다.

게임 목록의 공개 확인과 개별 게임 진입은 각각 독립된 화면 진입이므로 각 한 번씩 읽는다. 연주 시작, 가운데/가장자리 타격, 일시정지, 재개, 다시하기, 소리 변경, 탭 숨김/복귀, online/offline/focus/blur 이벤트는 이 기능의 서버 조회나 쓰기를 추가하지 않는다. 앱 공통 인증·메뉴 기능의 통신과는 구분한다. 게임은 점수·학생 기록·위스를 서버에 저장하지 않는다.

교사 공개 변경은 기존 transaction과 권한 규칙을 유지한다. 공개 문서 1건과 교사 전용 마지막 변경 감사 문서 1건을 함께 저장한다. 성공 응답의 상태·revision을 현재 관리 화면에 적용하며 별도 재조회하지 않는다. 변경 없는 저장과 같은 상태의 응답 유실 재시도는 쓰지 않는다. 충돌이나 저장 실패는 자동 재조회하지 않고, 사용자가 `다시 확인`을 누를 때 한 번 읽는다. 교사 미리보기의 연주 동작에는 조회가 없다.
