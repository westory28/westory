# 학년 전체 모의고사 분석 복구와 그래프 진입 효과

## 원인과 변경

- 2026-11-10 운영 3학년 초시 분석의 읽기 전용 확인에서 대상 학생 317명, 선택 회차 결과 288건의 응답이 8,509,607바이트였다. 기존 8MiB 전송 제한을 넘어서 전체 결과를 표시하지 못했다.
- 문항 원문은 이미 내용 해시 사전으로 중복을 제거하고 있었다. 학생별 학습 메타데이터와 분석 기록의 반복이 남아 있었다. gzip 결과는 668,300바이트였다. 압축 자체는 Firestore 문서 읽기 수를 줄이지 않는다.
- 새 클라이언트는 초기 성취 분석에만 `responseEncoding: gzip-base64`를 요청한다. 서버는 학생·응시·답안·당시 원문·회차 점수·실시간 변경 커서를 모두 무손실 압축한다. 최종 전송 JSON의 8MiB 제한과 압축 전 32MiB 제한을 함께 검사한다.
- 클라이언트는 스트림을 읽는 동안 복원 크기를 제한하고 gzip 무결성, 선언한 UTF-8 바이트 수, UTF-8 디코딩 및 기존 문항 사전 복원을 검증한다. 실패하면 부분 통계를 표시하지 않으며 수동 재시도로 새로 조회한다. 기존 inline 응답도 지원한다.
- 동시 요청 공유와 계정·학기 경계, 서버 세션·권한·갱신 검사는 유지한다. 추가 조회·캐시 저장·폴링·원본 쓰기는 없다.
- 교사 평가 분석 그래프의 표시 요소만 기존 300ms 토큰으로 아래에서 위로 한 번 올라온다. 축·라벨·배치는 고정한다. 진입·새로고침·명시적 재조회 시 재생한다. 사용자의 명시적 요청에 따라 동작 줄이기 설정에서도 재생하며 인쇄에는 적용하지 않는다.

## 검증

- 서버 회귀 69개 및 클라이언트 회귀 통과. 300명 합성 자료 14,197,458바이트를 839,900바이트 전송 JSON으로 복원하고 선택 결과 본문 300회 조회·쓰기 0건을 확인했다. 기존 inline과 압축 요청의 조회 경로·필터·projection·횟수는 동일하다.
- 과거 문항 버전·실제 0점·한국어·legacy 자료·실시간 커서와 전체 응시 보존을 검사했다. 손상·잘린 gzip, 잘못된 UTF-8, 선언 크기 불일치, 복원/전송 상한, 계정 분리, 오류 후 재시도를 검사했다.
- Functions 기본 검사, 프론트엔드 빌드·타입·변경 TSX 포맷 검사를 통과했다.
- `verify-achievement-analysis-browser.mjs`에서 실제 브라우저의 gzip 복원 및 390/768/1280px × 일반/동작 줄이기 조합을 확인했다. 진입·새로고침·명시 재조회마다 300ms 상승, 기준선 고정, 보기 전환 뒤 이전 그래프 제거, 추가 조회 없음·쓰기 0건, 인쇄 시 정지를 검사했다. `verify-quiz-class-browser.mjs`의 일반 평가 회귀도 통과했다.

## 운영 범위와 배포 확인

- 기존 서비스의 조회 오류를 고치는 통상 유지보수다. 인증·권한·공개 범위·개인정보 항목·외부 서비스·AI 호출·에이전트 실행·외부 전송 범위는 확대하지 않는다. 학생 점수·답안·공개 상태를 검증용으로 변경하지 않는다.
- 운영 `getQuizClassAnalysis` 리비전 `getquizclassanalysis-00016-peb`의 배포 원본과 수정 전 관련 의존 파일 39개의 LF 정규화 내용이 모두 일치했다.
- 배포 대상은 서울 `getQuizClassAnalysis` 하나와 Vercel main 프론트엔드다. 다른 Functions·Firestore/Storage rules는 배포하지 않는다.
- 서버 선택 배포 성공 후 `firebase functions:list` 및 `gcloud functions describe`로 `getquizclassanalysis-00017-com`, `ACTIVE` 상태를 확인했다.
