## 원인과 변경

- 관복의 정사각 원본 셀이 593×870px로 그려져 소매·팔까지 세로 1.47배 늘어났다. 가로/세로 배율을 일치시켜 이 왜곡을 제거한다. 짧아진 관복 아래에는 전용 속바지를 합성하고 선택 하의를 가리는 기존 계약은 유지한다.
- 일반 상의는 어깨 폭을 넓히고 목 아래 몸통·팔을 짧게 배치한다. 하의·다리·신발도 같은 허리·발목 기준으로 옮겨 의상만 줄였을 때 생기는 틈을 방지한다. 포즈 원화 전체와 피부 마스크를 유지하며 관절에서 소매를 잘라 회전시키지 않는다.
- 눈과 입을 별도 레이어로 등록한다. 눈의 크기와 간격을 기존 등록 기준의 70%로 줄이고 표정마다 다른 원화 중심을 정렬한다. 입은 독립된 아래쪽 위치를 유지한다.
- 자연·둥근·갸름한 얼굴의 폭을 실제로 구별한다. 헤어·눈·장식은 선택한 얼굴 폭에 맞춰 함께 조절하고 고개 기울이기를 결합한다. 헤어별 높이·폭과 안경·핀·헤드폰의 착용 위치도 조정한다.
- `scripts/avatar-2d-proportions.mjs`가 명시적인 배치 기준을 관리한다. `register-avatar-outfits.mjs` 재실행 시 이 기준을 다시 적용하므로 등록표를 갱신해도 보정이 사라지지 않는다.
- 원본 PNG는 변경하지 않는다. 기존 원화의 레이어 등록과 합성 좌표를 수정하며, 픽셀 필터나 다른 서비스의 캐릭터 복제는 적용하지 않는다.
