# 평가 분석의 단원·검색·학년 비교 개선

기준은 main 및 운영 도메인의 `657e4c5cd2e3fb213890aa19847c0f2e26fc2cb6`이다. 기존 학생 이력·재학습 패치 위에서 교사 조회 화면과 분석용 읽기 함수만 확장한다. 로그인, 응시 시작·저장·제출, 공개 제어, 보상, Firestore rules는 수정하지 않는다.

## 화면과 조회 계약

- 대단원 → 중단원 → 평가 → 학급을 선택한 뒤 조회한다. 비교는 같은 행의 슬라이더 버튼에서 최대 4학급과 학년 전체 평균을 고른다.
- 돋보기 입력은 왼쪽으로 펼친다. 입력 중 서버 요청은 없으며 Enter 또는 검색 버튼으로 실행한다. 검색은 현재 학기의 모든 단원·평가 종류를 대상으로 하고, 검색을 해제하면 보존한 단원 선택으로 돌아간다.
- 검색 대상은 문항·제시문·선지·해설·핵심 개념·연결형 보기의 텍스트다. NFC/공백을 정규화하고 여러 검색어는 모두 포함하는 문항을 찾는다. 검색 최대 80자, 일치 문항 최대 500개이며 한도를 넘으면 일부 결과를 정상 통계로 표시하지 않는다.
- 일반 평가 평균은 마지막 공식 제출 점수다. 검색 평균은 검색 문항의 현재 버전별 최신 정오답으로 계산한 학생별 정답률의 평균이다. 수정 전 문항, 정오 미확인, 시간 순서 미확인은 분모에서 제외한다. 이를 공식 점수로 저장하지 않는다.
- 학년 전체는 활성 학급 전체의 학생 수를 합치고, 점수가 확인된 학생 수로 평균을 가중한다. 응답 없는 학생은 평균과 분포에 0점으로 넣지 않는다. 개념별 응답 학생에는 해당 개념을 모두 맞힌 학급도 포함한다.
- 문항 표는 질문과 핵심 개념을 분리하고 제목·데이터 정렬을 맞춘다. 상세는 학급 하나만 추가 조회하는 native dialog이며 Escape·포커스 복귀·한 개의 본문 스크롤을 유지한다.

## 서버 부하와 호환성

`getQuizClassAnalysis`에 선택적 `keyword`/`comparisonGrade` 입력만 추가했다. 기존 입력과 응답을 유지한다. 검색용 문항 텍스트는 서버 전용 압축 캐시에 보관하고 contentGeneration으로 무효화한다. 같은 문항 집합 검색과 학년 평균은 학급 요약 캐시를 재사용한다. 캐시 schema 2는 개념 분모가 없는 이전 요약을 한 번 재작성한다.

학년 최초 집계는 최대 3학급씩 병렬 처리한다. 최대 30학급·cold 조회 30,000문서·64MiB 및 기존 학급별 제한을 적용하고 초과 시 명시적으로 실패한다. 응답 직전 revision을 재확인해 변경 중의 학년 합계나 검색 문항을 섞지 않는다. 요약 응답에는 학생 이름·UID·개별 답안을 포함하지 않는다. 수동 새로고침 외 폴링이나 전체 학생 실시간 구독은 없다.

## 검증

- `npm run verify:quiz-analysis`: 기존 40개와 전 범위 검색·빈 검색·버전/시간 불명·canonical 중복 우선의 4개 시나리오.
- `npm --prefix functions run check`: 새 학급 분석 20개 및 기존 인증·평가·학생 이력 검사.
- `scripts/verify-quiz-class-analysis-client.mjs`: 세션 기반 호출, 동시 요청 중복 제거, 권한 오류, 명시적 갱신, 단일 학급 상세.
- `functions/scripts/verify-quiz-analysis-integration.cjs`: 실제 exported callable과 Firestore demo emulator로 20분 경과 세션, 전 범위 검색·검색 문항 재계산, 학년 전체, 빈 검색, 학생 조회 거부, 취소 세션 거부, 기존 학생 본인 이력 검증.
- `scripts/verify-quiz-class-browser.mjs`: catalog-only 진입, 대/중단원 순서, 선택만 할 때 요청 없음, 비교/학년 전체, 검색 입력 중 요청 없음, 명시적 검색, 상세 한 학급만 조회, 모달 포커스와 Escape, 오류/재시도, 늦은 응답 폐기. 320/390/768/1280/1366px 가로 넘침 확인 및 화면 캡처.
- 기본 빌드에는 인증·학기·학습지·수행평가 XLSX hair 테두리 회귀 검사가 포함된다.
- 상세 전송에서 요약 전용 `comparisonGrade`는 속성을 제거한다. Firebase의 undefined→null 직렬화를 재현한 브라우저 fixture 및 클라이언트 회귀 검사로 서버 거부 재발을 막는다.
- 작은 화면에서는 단원 2열·평가/학급 2열·조작 행으로 배치하고, 검색창·닫기·돋보기가 같은 행에 보이도록 입력 폭을 줄인다. 문항 상세 독립 브라우저 검증 4개는 헤더/본문 열 위치, 1행 표, 상세 편집/파생, 공식99점 유지와 검색50% 구분을 확인했다.

## 배포

백엔드 대상은 `getQuizClassAnalysis` 하나다. 기존 인증·제출 함수나 rules를 일괄 배포하지 않는다. 프런트엔드는 검증한 main 커밋의 Vercel 배포를 운영으로 승격하고 `www.westory.kr`에 연결된 커밋 및 로그인된 교사 화면에서 확인한다. 운영 학생의 응시·점수는 생성하거나 변경하지 않는다.

`getQuizClassAnalysis` 선택 배포 성공과 `functions:list`의 ACTIVE / asia-northeast3 / nodejs22 상태를 확인했다. 새 인덱스는 필요하지 않다.
