작업 시작은 `ef28593d8fcc43b4e3097b6cfa3efd70535a7854`, 검증 기준은 병행 변경이 합쳐진 `b250c53b4917b558a49bd6e01846b8b4c7cc0af0`이다. 배포 전 운영 도메인의 Vercel 소스도 후자와 일치했다.

단발·웨이브의 안쪽 머리끝이 입꼬리에 지나치게 가까웠다. 원본 PNG를 보존하고 정적 원화 생성 단계에서 아래쪽 양 갈래만 바깥으로 완만하게 이동한다. 단발·웨이브·긴 머리·반묶음·트윈테일마다 시작 높이와 강도를 등록하며, 앞머리와 원래 가닥의 뾰족한 끝을 유지한다. 알파를 고려한 보간으로 투명 경계의 검은 테두리를 방지하고 트윈테일 염색 마스크도 같은 결과에서 재생성한다.

볼 전체를 도려내는 컷아웃 시안은 귀 아래가 잘린 듯 보여 채택하지 않았다. 최종 패치는 기존 renderer와 앞/뒷머리 레이어 계약을 유지한다. 신체·눈·의상·화면 구조·카탈로그·가격·구매·저장·학기·권한은 변경하지 않는다. 추가 서버 읽기/쓰기, 런타임 AI 호출, 외부 전송, Functions/rules 변경은 없다. 기존 저장 프로필 이미지는 사용자가 꾸미기에서 저장할 때 갱신된다.
