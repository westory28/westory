- 작업 기준: `e5986a1f461e6d21f06c13b2b040d5fe2ec29937`, 2026-11-07.
- 기존 시험지 관련 미커밋 변경을 보존하기 위해 별도 worktree에서 수정·검증했다.

- 학생 정기시험과 공유하는 서명 컴포넌트에 동일한 준비 조건을 적용한다. 차수 메뉴 스타일은 수행평가에만 적용되며 교사 화면은 변경하지 않는다.
- 기존 학기·소유자·점수 버전 검사, 미등록 평가 제외, 기존 유효 서명 보존, 저장 직전 서버 재조회, 저장 후 완료 검증은 유지한다. Functions·rules·권한·저장 경로·AI 호출·에이전트 실행·외부 데이터 전송에는 변경이 없다. 기존 서비스의 표시 및 입력 준비 조건 유지보수이며 이용자·공개 범위 확대가 없다.
