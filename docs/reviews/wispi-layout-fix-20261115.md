# 위스 마을 목차 레이아웃·아바타 가로 스크롤 수정

기준 커밋은 `78f2beeec0d2fb5facf946ae9bd5f737b331c94d`다. 사용자 정정에 따라 사이드탭을 유지하고 평가 관리의 공통 전높이 목차 구조를 재사용한다. 앞선 128px/64px 본문 안 메뉴 방식은 이 변경으로 대체한다.

- `TeacherWisVillage`가 `PortalWorkspace`와 `PortalSubNavigation`을 사용한다. 주 메뉴 바로 옆에서 시작하며 데스크톱은 계정 헤더 높이까지 올라가 화면 상단에 붙는다. 본문과 푸터도 같은 격자에 놓인다. 목차 180px, 접힘 56px, 모바일 펼침/접기를 지원한다.
- 상점·위스피·아바타 진입부의 중첩 `ws-page` 여백을 제거한다. 일반 위스 관리와 학생 상점은 유지한다. 읽기 전용 안내는 본문에 놓아 목차 시작점을 밀지 않도록 한다.
- 교사 아바타 종류와 교사 화면 안의 학생 상점 미리보기 종류는 `flex-wrap`으로 배치한다. 가로 스크롤바를 숨기거나 항목을 잘라내지 않는다. 검색·판매 유형·성별 필터와 실제 저장·구매 동작은 바꾸지 않는다.
- 데이터 조회·쓰기·권한·학기·위스 지갑·학생 공개·AI/외부 전송은 변경하지 않는다. Firebase 배포 대상은 없으며 Vercel 프런트엔드만 배포한다.

실제 교사 주 메뉴·계정 헤더·공통 푸터와 페이지 본문을 결합한 `verify-wis-village-navigation.mjs` 검증을 통과했다. 320/390/768/1024/1280/1440px의 36개 배치와 아바타 9개 조합에서 주 메뉴 펼침·접힘, 목차 top/left/height/width, 제목 배경, 목차 이동·키보드·모바일 접힘·아바타 종류 12개의 내부 scrollWidth와 항목 경계·기존 조회 횟수를 확인했다. 평가·설정 CSS를 함께 로드해도 폭 충돌이 없고 브라우저 오류와 쓰기는 0회다. 1920×900 및 390×844 viewport 캡처를 별도로 확인했다.

`npm run build`, 관련 아바타/월렛 브라우저 회귀, 변경 TSX의 Prettier 검사도 통과했다. 배포 전 운영 커밋은 작업 기준과 동일하다. 검증한 변경을 운영 도메인에 승격한 뒤 방재석 Chrome에서 화면을 확인한다. 로컬 근거는 `output/wispi-layout-fix-20261115/`에 보관한다.
