# 역사 지도 자연지형 복원 조사 · 2026-10-15

현재 통합 데이터와 기준 커밋 `26e17b5b86e204b7c756c52b9073430a0bb027b0` 사이의 자연지형 복원을 검토했다. 원본의 자연지형 196항목(한국사 원본 68, 세계사 원본 128)을 분리했으며, 38개 출처 기반 이야기로 41곳을 복원했다. 고비는 원본의 한국사 접두어 ID를 보존하면서 세계사 이야기에 연결했다. ID 접두어로 교과를 추론하지 않았다.

이 문서는 초기 `output/atlas-landform-restoration-audit-20261015.md`의 조사를 저장소에 옮기고 최종 통합 상태로 갱신한 기록이다. 명량은 한국사 병행 복원으로 최종 지도에 포함되었다. 이전 보고서의 위치 미확정 49항목은 48항목으로 줄었다.

## 구현과 자료 근거

- 황허강의 상·중류 이름 `Huang`이 별칭에서 빠져 `Yellow` 하류만 선택되었다. 기존 Natural Earth 10m·50m 자료 양쪽에서 3개 feature 전체를 선택하도록 수정했다. 세계사 자료 범위는 동경 96.164187~119.035660도, 북위 33.355794~40.874663도이다. 상류와 오르도스 굴곡이 포함되며, 자산에 없는 구간을 직선으로 연결하지 않았다. 10m 자료에서는 rivernum 66과 95를 함께 선택한다.
- 같은 명칭 분리 문제인 창장 상류 `Tongtian`·`Jinsha`, 티그리스 상류 `Dicle`, 유프라테스 상류 `Firat`도 보완했다. [FAO AQUASTAT의 튀르키예 수계 설명](https://www.fao.org/4/W4356E/w4356e0w.HTM), [중국 인터넷정보센터의 창장 구간별 명칭](https://www.china.org.cn/english/travel/40876.htm)을 대조했다.
- 고비는 기존 자산의 사막 1면, 사하라는 2면을 그대로 사용한다. Polygon을 선택·강조·확대하는 공통 API를 제공했다. [Natural Earth 원본](https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_110m_geography_regions_polys.geojson)은 퍼블릭 도메인이다. 1:110m로 일반화한 현대 지형이며, 특정 역사 시대의 사막 경계가 아니다.
- 금강과 가르강의 새 대표점은 기존 OpenStreetMap 선에 실제로 있는 꼭짓점에서 골랐다. 각각 [금강 way 34834591](https://www.openstreetmap.org/way/34834591), [가르강 way 65981268](https://www.openstreetmap.org/way/65981268)에 존재한다. 발원지·하구 또는 역사 사건 지점으로 표시하지 않는다. 선 자료와 메타데이터는 ODbL 1.0 조건에 따라 함께 제공한다.
- 자연지형 41곳의 지역 필터를 전수 검사했다. 고비만 세계사 정적 분류가 없어 `asia-east`를 보완했다. 나머지는 기존 정적 다중 지역 분류를 유지한다.
- 지형 이야기의 관련 링크 20개는 정확한 사건 entry를 지정한다. 복수 장소 이야기에는 `fromPlaceIds`를 명시했다. 금강은 웅진·사비, 토함산은 불국사·석굴암, 태평양은 마닐라·아카풀코, 북해·발트해는 뤼베크의 같은 역사 맥락으로 연결된다.
- 역사 서술의 개별 근거는 `src/data/historyAtlasLandformRestoration.ts` 각 이야기의 `sources`에 기록했다. 한국사는 국사편찬위원회·한국학중앙연구원·국가유산청·박물관·지방자치단체와 학술 논문을, 세계사는 UNESCO·미국 국립공원청·해양대기청·TVA 등 직접 출처를 사용했다. 고비의 암각화 근거는 세계유산 **잠정목록 신청 자료**이며 등재 유산이라고 서술하지 않았다.

## 재현 가능한 회귀 검사

```powershell
node scripts/verify-history-atlas-restoration.mjs
node scripts/verify-history-atlas-restoration.mjs --report
```

검사는 실행 위치에 관계없이 저장소의 실제 앱 모듈과 지형 자산을 읽는다. `.codex-tmp`, `output` 파일이나 네트워크 응답을 입력으로 사용하지 않고 파일도 생성하지 않는다. `--report`는 현재의 전체 판정과 범위를 표준 출력으로 내보낸다.

검사 범위는 다음과 같다.

- 지형 41곳, 세계사 25곳과 추가 39곳이 모두 실제 `historyAtlasDataset`에 포함되는지 확인한다. 단순 원본 목록이나 override의 존재만으로 통과하지 않는다.
- 각 이야기의 교과·시대·요약·출처, 좌표 override와 위치 근거가 최종 지도에 보존되는지 확인한다. 지구본의 전체 자료와 교과별 조회를 구성하는 실제 도우미를 호출한다.
- 관련 관계가 정확한 대상 사건, 교과, 설명과 출처를 유지하며 `getAtlasHistoricalRelations`에서 실제로 반환되는지 검사한다. 다중 출발 장소를 펼친 결과는 현재 32개이다.
- 추가 세계사 장소 21곳의 공개 DMS 좌표를 독립 변환하여 `[경도, 위도]`와 비교한다. 남위의 음수와 원문에 있는 60초 올림도 확인하고 UNESCO 식별 번호에 해당하는 근거 링크를 점검한다.
- 윈강 석굴·룽먼 석굴·보로부두르·아크로폴리스의 중복 시대 항목 4개는 원본 자료에 보존하면서 최종 지도·시대별 조회에서 제외되는지 검사한다. 네 장소와 근거가 있는 상세 이야기는 계속 포함되어야 한다.
- 황허의 상·중·하류, 창장·티그리스·유프라테스의 상류 별칭과 복원한 강의 선 선택을 검사한다. 반환 선이 기존 원본 feature인지 확인하여 임의로 생성한 연결선이 섞이지 않게 한다.
- 사막 면의 원본 좌표, 사하라의 작은 두 번째 면, 면 내부·외부 판정, 평면·지구본 자료 형식 호환, 면 전체를 포함하는 확대 범위를 검사한다.
- 사막 자산 로더의 동시 요청과 완료 후 캐시, HTTP 실패와 잘못된 형식 이후의 재시도를 확인한다.
- 지구본 지형과 OSM 보충 선의 실제 SHA-256 및 라이선스 메타데이터를 확인한다.

통합 상태에서 회귀 검사가 통과했다. 앱의 `tsc --noEmit`, 기존 역사 이야기·지역 회귀 검사 및 수정 파일 포맷도 앞선 검증에서 통과했다. 브라우저의 클릭·강조·팝업·반구 가시성 검증은 UI 담당 작업에서 별도로 수행한다. 이 검사는 인용한 역사 서술의 학술적 타당성을 자동 판정하지 않으며, 출처 확인과 문맥 검토를 대신하지 않는다.

## 현재 범위와 한계

현재 지도에는 전체 344곳이 포함된다. 자연지형 196항목 가운데 이번 지형 복원 41곳과 기존·병행 작업으로 포함된 10곳, 총 51곳이 지도에 있다. 남은 상태는 개별 역사 설명 재검토 94곳, 위치 근거 보완 48곳, 실제 사막 면 필요 3곳이다. 이는 역사나 위치가 원천적으로 없다는 판정이 아니라 현재 검증 범위와 최종 선별 결과이다.

- 타클라마칸의 한국사·세계사 각 ID와 카라쿰은 역사적 역할을 설명할 근거가 있지만 기존 사막 자산에 대응 면이 없다. 임의 도시 좌표나 원으로 사막 범위를 대체하지 않았다. [NASA의 타클라마칸 니야 유적 설명](https://www.jpl.nasa.gov/images/pia01725-space-radar-image-of-niya-ruins-taklamakan-desert/), [UNESCO의 카라쿰 회랑 설명](https://whc.unesco.org/en/list/1675/)을 확인했다.
- 백강·패강 등 역사 수계명은 문헌마다 비정이 다를 수 있어 현대 강으로 자동 대체하지 않았다. 백마강은 금강의 일부 구간이므로 금강 전체 선을 백마강으로 표시하지 않았다. [한국민족문화대백과사전의 백마강 설명](https://encykorea.aks.ac.kr/Article/E0022106)을 참고했다.
- 살수의 설명은 확인된 청천강 지형에 연결했다. 좌표가 없는 별도 원본 `살수` ID를 추가 점으로 만들지 않았다. 울돌목과 명량처럼 같은 공간과 관련된 이름도 개별 원본 ID의 상태를 구분한다. **명량은 최종 지도에 포함되어 있다.**
- 강선은 일반화된 현대 수계이다. 원본의 분리 구간과 작은 간극을 보존하며, 모든 강의 미세한 발원지부터 모든 하구 갈래까지 완전한 측량선을 보장하지 않는다. 고대의 유로를 복원한 선으로 해석해서는 안 된다.
