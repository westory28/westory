연습은 시작·완료 기록 요청이나 위스 차감을 하지 않는다. 도전은 한국 시간 하루 세 번 무료이며 그 이후에는 사용자가 50위스 도전을 선택했을 때만 현재 학기의 정식 위스 계좌에서 차감한다. 각 시작 요청의 불변 세션 문서가 영수증이며 계좌·원장·projection·일일 횟수와 함께 transaction으로 기록된다. 응답 유실 뒤 같은 요청, 동시 요청, 잔액 부족에서 중복 차감이나 무료 횟수 손실을 막는다. 기존 legacy 지갑은 읽거나 쓰지 않는다.

주차는 한국 시간 월요일 기준이다. 기본은 기존 네 곡의 매주 순환이며 교사는 이번 주 한 곡을 지정하거나 자동으로 돌릴 수 있다. 자진모리·휘모리만 도전할 수 있다. 아이쿠 종료 횟수는 기본 30회이고 교사는 1~300회로 설정한다. 곡·장단·설정 revision·종료 횟수는 시작 때 서버가 확인하고 고정한다. 변경 없는 저장은 0쓰기이며 revision 충돌과 저장 영수증을 검사한다. 공개 여부는 기존 설정을 그대로 사용하고 교사 체험은 미기록·무차감이다.

서버는 공유 생성 코드로 입력 순서·판정·피버 가산·놓친 노트·종료 시점을 재계산한다. 10/20/50/100콤보를 달성한 타격부터 5/10/25/50%를 가산하며 실수하면 단계가 초기화된다. 종료 뒤 추가 입력과 불가능한 종료 시각은 거부한다. 이전 연습 기록은 보존하고 도전 순위는 내부 `challenge:곡:장단` 분류로 분리한다. 도중에 주가 바뀌면 결과만 반환하고 다음 주의 다른 곡 순위에 넣지 않는다.

서버 조회는 본인·현재 학기·주차의 설정·세션·횟수 문서로 제한한다. 무료 시작과 상태 조회는 지갑을 읽지 않는다. 플레이 중 요청·폴링은 추가하지 않는다. 직접 Firestore 접근은 기존 기본 거부를 유지하며 rules를 변경하지 않는다. 새 AI 호출·런타임 에이전트·외부 서비스·개인정보 항목은 추가하지 않는다.
