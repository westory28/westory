# 사전 캡슐 색인·복수 태그 개선 검증

기준: 2026-10-18, `origin/main`의 `946128a`를 포함한 사전 작업 트리. 기본 checkout의 다른 작업 파일은 수정하지 않았다.

## 변경

- 오른쪽의 불투명 흰색 세로 캡슐에 초성 색인을 배치했다. 가용 높이만큼의 글자와 `…` 버튼을 렌더링하며 내부 스크롤은 사용하지 않는다.
- 마우스 휠, 누른 채 위아래 이동, 터치 포인터, 키보드 방향키·Home·End로 이어 탐색한다. 작은 높이에서도 전체·그룹 버튼에서 드래그를 시작할 수 있다.
- 단어 행의 세로 여백을 줄이고 종류 중복 표기를 제거했다. 태그와 출처를 하단에 배치하고 출처는 오른쪽으로 정렬했다.
- 태그를 누적 선택해 모두 일치하는 단어를 찾는다. 검색어·초성·드롭다운 조건을 보존하며 선택 배지나 본문 태그로 개별 해제한다.
- 공통 색인 사용 화면의 DOM 순서도 결과 다음에 색인이 오도록 맞췄다. 저장·권한·학기·서버 계약은 변경하지 않았다.

## 자동 검증

- `npm run build` 통과: 타입 검사, 수행평가 XLSX 선 보존, 학습지·지도·사전 및 기존 필수 회귀 검사와 Vite 빌드 포함.
- 변경한 TypeScript/TSX·검증 스크립트·CSS의 Prettier 검사 및 `git diff --check` 통과.
- 색인 검사는 모든 펼침 조합·선택 글자·표시 용량, 휠 누적/throttle, 포인터 캡처·취소·정리, 키보드, 가용 높이 변화, 1~3행에서의 터치 시작을 검증한다.
- 생략 버튼을 누른 뒤 높이 재측정으로 표시 범위가 바뀌어도 포인터·키보드로 누른 당시의 대상 글자를 선택하도록 보완하고 회귀 검사를 추가했다.
- 독립 검토에서 100ms 간격 휠 10회가 120ms 제한에 맞춰 5글자를 이동함을 재현했다. 태그 조건 7개 상태의 819개 분류 전환에서 표시 수와 실제 결과 수가 일치했다.

## 실제 브라우저 확인

로컬의 메모리 전용 fixture에서 운영 데이터를 쓰지 않고 확인했다.

- 교사 사전 1280/1366px: 결과 컨테이너 오른쪽에 64px 캡슐 배치. 1366px에서 결과 오른쪽 1255px, 색인 왼쪽 1263px. 짧은 뜻풀이 행 높이 약 133.8px.
- 학생 사전 390/320px: 검색·분류 두 줄, 가로 넘침 없음. 320px에서 출처를 펼쳐도 태그·등록 버튼·출처가 각각 줄바꿈하며 겹치지 않았다. 출처 글자는 12px.
- 학생 단어장 390px: 같은 오른쪽 캡슐 적용과 기존 단어 목록 표시 확인.
- 팝업 768px: ㄱ에서 아래로 88px 드래그해 ㄷ 선택, 휠로 ㄹ 선택. 바깥 내용을 스크롤해도 색인은 팝업 상단 아래에 유지된다.
- 숫자 그룹 펼침, 생략 버튼 직접 클릭, 영문 펼침 후 End로 z 선택을 확인했다. 모든 측정에서 색인의 `scrollHeight === clientHeight`, `scrollTop === 0`이었다.
- 한국사 → 조선 전기 → 평안도를 차례로 선택해 세 배지가 유지되고 결과가 4군·의주 2개로 좁혀짐을 확인했다.

로컬 화면 자료: `output/dictionary-capsule-desktop.png`, `output/dictionary-capsule-mobile.png`. 모바일은 데스크톱 브라우저의 화면 폭 조정 및 터치 이벤트 회귀 검사이며 실제 휴대전화 검증을 의미하지 않는다.
