# 윷판 고정과 경기 도구 배치

사용자 요청은 윷 던지기 버튼 때문에 윷판이 위아래로 움직이지 않게 하고, 감정표현·설명·뒤로가기 도구를 우측 상단으로 옮기는 것이다. 학생 온라인·싱글과 교사 체험은 같은 `YutGame`을 사용하므로 함께 검증한다. 교사 관전은 별도 읽기 전용 화면의 배치를 유지한다.

기존 원인은 행동 영역과 사건 문구의 실제 높이를 보드 가용 높이에서 빼고, 그 영역의 ResizeObserver가 매 상태 전환마다 보드 크기를 다시 계산하는 구조였다. 던지기 버튼을 보드 위에 띄우고, 보드 계산에서 가변 행동 높이를 제거한다. 기존 게임 팔레트·버튼·그림자·44px 조작 영역과 키보드 입력을 재사용한다. 독립된 경기장 안의 배치만 바꾸며 포털의 제목·탭·내비게이션 구조는 변경하지 않는다.

던지기 오버레이는 출발 지점 살짝 아래에 두고 보드 위의 말과 겹쳐도 위치를 유지한다(2026-10-22 사용자 수정 지시). 보드의 출발 좌표 `(360, 455)`를 기준으로 일반·짧은 가로·세로 회전 전체 화면에 같은 배치를 적용한다. 요청·투척·이동 대기 동안 숨겨 연출과 이동 입력을 가리지 않는다. 행동·사건 영역에는 상태와 무관한 높이를 예약하며 보드 크기는 프레임 변화에만 반응한다. 경기 도구는 우측 상단, 전체 화면 버튼은 좌측 상단에 둔다. 감정표현 메뉴는 프로필 사이 중앙에서 열리고 실제 캔버스 높이를 넘으면 내부 스크롤한다. 메뉴의 Escape는 메뉴만 닫고 전체 화면을 유지한다.

낮은 경기장에서는 하단 프로필을 중앙 행동 영역 양옆에 배치한다. 가장 짧은 화면에서도 실제 보드를 최소 260px로 표시하면서 배치용 높이는 고정하고, 선택·결정 버튼은 44px 높이를 유지한다. 기존 가로 화면·세로 회전 전체 화면 및 안전 영역을 사용하며 공통 관전 보드의 스타일과 게임 명령·권한·공개 설정은 수정하지 않는다.

검증: `npm run build`, 변경 UI 파일의 Prettier, `git diff --check`를 통과했다. 빌드 시작 전후 UI 소스 해시가 같다. `node scripts/verify-yut-board-layout-browser.mjs`는 390×844·768×1024·568×320·740×360·844×390·1024×600·1280×800·1440×900에서 학생 온라인 2/3/4인 24개와 교사 미리보기 8개, 총 32개 검사를 통과했고 브라우저 오류는 없었다. 모든 진행 단계와 requestAnimationFrame 구간의 보드 좌표·크기, 느린 투척 응답 중 오버레이 숨김, 실제 말·갈림길·결정 클릭, 44px 조작 영역, 프로필 상호·메뉴 겹침, 한글 이름·학급·사건 표시, 짧은 메뉴의 내부 스크롤·오류·재사용 대기, 교사 체험의 온라인 쓰기 0건을 확인했다.

기존 entry-controls와 mobile-readability 검사도 통과했다. `node scripts/verify-yut-spectator-browser.mjs`로 390/768/1280px 관전의 읽기 전용·구독 해제·오류 복구와 쓰기 0건을 확인했다. 독립 코드 검토의 지적을 반영한 뒤 재검토에서 남은 차단 사유가 없었다. 위 자동 검사는 합성 데이터만 사용했고, 운영 확인에는 Chrome `방재석`의 교사 체험을 사용한다.

2026-10-22 위치 수정 검증: `npm run build`와 `git diff --check`를 통과했다. 기존 board-layout 검사를 568×320·390×844·768×1024·1280×800에서 실행해 학생 2인 경기와 교사 4인 체험, 총 8개 검사를 통과했다. 출발 지점 아래 정렬·44px 조작·보드 좌표 고정·세로 회전 전체 화면·키보드 던지기·말 이동·교사 체험의 온라인 쓰기 0건을 확인했다. 대기 응답 검사는 800ms 경과에 의존하지 않고 합성 응답을 명시적으로 해제해 확인한다. 포털 구조와 읽기 전용 관전 화면에는 변경이 없다.
