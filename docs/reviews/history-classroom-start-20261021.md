# 학생 역사교실 시작 화면 (2026-10-21)

- 시작 전에는 학습지 영역 중앙에 `응시 시작` 버튼 하나를 표시한다. 학습지에는 2px 흐림과 반투명 흰 표면을 적용하고 `inert`로 빈칸의 클릭·키보드 접근을 차단한다.
- 클릭은 기존 canonical 시작 명령으로 바로 연결한다. 요청 중·실패 상태를 구분하며, 서버가 확정한 응시 마감 시각으로 입력과 타이머가 함께 활성화된다. 진행 중 응시의 복구·답안·마감 시각은 유지한다.
- 단어 목록의 문자 화살표를 SVG chevron으로 교체했다. 펼침 상태는 `aria-expanded`를 유지한다. 이후 펼침 버튼도 SVG를 사용하도록 `UI_RULES.md`에 사용자 지시를 기록했다.
- 공통 view의 시작 덮개는 학생 runner가 명시적으로 `onStart`를 전달할 때만 사용한다. 교사 미리보기와 완료 결과 화면에는 적용되지 않는다. 페이지 외곽 제목·탭·필터 구조는 변경하지 않는다.
- 실제 학생 컴포넌트 브라우저 검증: 390×844, 768×1024, 1280×800, 1366×768에서 버튼 중앙 배치·가시성·입력 차단·시작 전 대기·단일 클릭 후 입력과 타이머·SVG 펼침 상태를 확인한다. 지연·실패·재시도와 기존 복구·이탈·제출 회귀도 함께 검사한다.
- 공유 view의 교사 사용처는 기존 교사 브라우저 검증의 390/768/1024/1280/1366px와 미리보기로 확인한다. 검증용 응시·결과는 로컬 합성 자료만 사용하며 운영 학생의 응시를 시작하거나 수정하지 않는다.
- 증거는 Git에서 제외한 `.superloopy/sessions/history-classroom-stabilization/evidence/runner-start-overlay-*`에 둔다. 루트 빌드 및 포맷 검사 후 검증한 커밋의 Vercel 배포를 운영 도메인으로 승격하고 변경 번들과 교사 미리보기를 확인한다.
