# 동아시아 지리 표기와 설명 닫기 검증

## 변경 범위

- 한국사·세계사·지구본 공통 자료에 지방·지형·하천 25곳과 도시 16곳을 연결한다. 기존 ID와 역사 서술은 보존하며 지리 배경은 날짜가 있는 사건과 분리한다.
- 요동·요서·만주·간도·연해주·오르도스·화북·중원·강남·화중·화남·서남은 대표점과 범위 설명을 사용한다. 검토용 `evidenceBounds`를 지도 경계로 그리지 않는다.
- 요하·송화강·황하·회수·장강·압록강·두만강은 실제 저장된 하천 선을 사용한다. 타클라마칸사막과 티베트고원은 기존 지형 자료의 정확한 ID에 연결한다.
- 요하는 기존 Natural Earth의 잉커우 방향 선과 현대 판진 하구 본류를 구별하여 OSM relation 405843의 본류 14개 way·1,846개 정점을 보존했다. 기존 보충 하천 파일을 사용하므로 별도 요청을 추가하지 않는다.
- 설명 닫기와 Escape는 선택·강조·진행 중 이동을 해제한다. 현재 카메라를 보존하며 지역 필터가 남아 있어도 강조가 다시 나타나지 않는다.
- 두 포털에서 공통 지도 컴포넌트를 사용한다. 포털별 권한·라우트·학생 공개 설정은 바꾸지 않는다. 기존 공통 설명창과 내부 본문 스크롤을 그대로 사용한다.
- 역사 사전은 해당 41개 지명에 한해 기존 31개를 보완하고 누락 10개를 추가한다. 기존 3,367개 ID와 출처를 보존하며 최종 3,377개·출처 4,980건이다. 분류의 의미 변경도 이 범위에 한정하고 기존 분류 번호는 유지한다. 원본과 읽기 스냅샷은 기존 버전 조건부 동기화 도구로 함께 갱신한다.

## 고증

[지방·지형 출처 검토](history-atlas-east-asia-sources-20261020.md)와 [도시 검토](history-atlas-east-asia-cities-20261020.md)에 기관·학술 출처, 위치 정확도, PDF 캡션의 혼동과 자료 한계를 기록했다. 공급된 PDF를 지명 수록 범위로 사용하되 성락/평성, 요 중경/베이징, 함양/장안 등의 동일시를 복사하지 않았다. 제주도는 기존 항목을 유지하며 탐라라는 정치체를 현대 도시의 단순 별칭으로 추가하지 않는다.

## 검증

- `npm run build` 전체 통과: TypeScript·공통 사전·지도 회귀 검사와 Vite 배포 빌드. 기존 대용량 청크 경고는 남아 있으며 이를 실물 기기의 성능 측정으로 대체하지 않는다.
- `verify-history-map-east-asia.mjs`: 390·768·1280·1366px, 세 지도에서 72회 검색·설명 읽기·닫기 통과. 본문 16px/1.65, 내부 스크롤, 가로 넘침 없음, 닫은 후 배율 유지·강조 해제·지도 자산 재요청 없음.
- 모바일·태블릿·PC 캡처를 직접 확인했다. 좁은 화면에서도 기존 필터 배치와 지도 내부 팝업을 유지한다.
- `verify-history-atlas-east-asia.mjs`: 41개 지리 참조의 양 과목 검색, 시대·단원 중 탐색, 출처·대표점, 7개 실제 하천, 지형 폴리곤, 요하 판진 하구와 대요하 구별을 검사한다.
- 실제 컴포넌트 핸들러 검사는 설명 닫기 후 장소·국가·지역 선택 해제와 현재 카메라 보존을 포함한다.
- 사전 전체 검사에서 지도 연결·41개 정의/출처/별칭·평성/성락 등 혼동 방지·기존 출처/ID 보존·동기화 버전 조건·스냅샷 일치를 검증했다. 지역 및 외국 역사 맥락 검사는 날짜 없는 지리 배경과 역사 사건을 구분하도록 갱신했다.
- 증거 이미지와 실행 로그는 로컬 `output/atlas-east-asia-20261020/`에 보관하며 배포 파일에 포함하지 않는다.

저사양 실물 기기의 프레임률을 측정한 결과는 아니다. 이번 닫기 검사는 자산 재요청이 없음을 확인하며 서버 트래픽 절감량을 추정하지 않는다.
