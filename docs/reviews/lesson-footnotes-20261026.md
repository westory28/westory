# 학습지 각주 이동 및 배율 검증 (2026-10-26)

- 교사 PDF 편집에서 기존 각주를 마우스·터치로 끌어 옮기고 방향키로 미세 조정한다. Shift+방향키는 더 크게 이동한다. 클릭은 기존 각주 편집을 열고, 드래그 종료는 편집창을 열지 않는다. Escape·pointercancel은 이동을 취소한다.
- 기존 각주의 ID, 연결된 각주, 페이지, 크기, 내용을 유지하고 좌상단 비율 좌표만 기존 PDF 저장 경로로 전달한다. 학생 풀이와 교사 제시에서는 각주를 이동할 수 없다. 학기 경로·legacy 읽기·권한·서버 저장 계약은 변경하지 않는다.
- 각주와 선택 표시의 중심을 페이지 비율 좌표에 배치하고 자기 크기의 절반만큼 보정한다. hover 이동 효과를 없애 배율·화면 크기·마우스 위치에 따라 중심이 흔들리지 않게 한다. 기존 색·40px 아이콘·48px 선택 표시를 재사용하며 새 디자인 토큰이나 페이지 레이아웃 예외는 없다.
- 학생 및 교사 제시 각주 제목 앞의 자동 `PDF` 표시를 제거한다. 본문 각주 번호는 유지한다.

## 검증

- `npm run build`: 타입 검사, 필수 회귀 검사, 최종 XLSX hair 테두리 검사를 포함해 통과.
- `npm run verify:lesson-management`: 기존 학기·충돌·오류 복구 검사 통과. `verify-lesson-loading.mjs`에 실제 편집기의 이동 콜백 → 저장 명령 payload → 재조회 검사를 추가해 좌표·각주 ID·내용 보존을 확인했다. 외부 저장은 모의 전송이다.
- `node scripts/verify-lesson-annotations-retired.mjs`: 세 모드의 판서 폐기 및 페이지 이동 계약 통과.
- `node scripts/verify-lesson-footnotes-browser.mjs`: 실제 React Stage, 합성 자료, Edge 브라우저에서 390·768·1280px와 세 모드를 검증했다. 앱 배율 70/100/150/200%, CSS zoom 50%, hover 중심, 드래그/클릭 구분, 방향키, 취소, 페이지 경계 제한, 확대 중 이동, 교사 페이지 이동 도구와 오른쪽 버튼 이동 설정을 확인했다. CDP 터치 입력도 통과했다. 물리적 모바일 Safari 검증은 아니다.
- 브라우저 fixture의 저장·재마운트·새로고침은 sessionStorage를 사용한다. 운영 Firebase 데이터는 검증을 위해 쓰지 않는다.
- 화면·좌표 증거: 로컬 `output/lesson-footnotes-browser/`. 기존 미추적 `output/` 자료는 커밋에 포함하지 않는다.

배포 전 운영 도메인의 Vercel 소스 커밋은 작업 기준과 같은 `7a252d66d0e71b51a72d3dc1292edfec87f90fd8`임을 확인했다. 배포 및 운영 화면 확인 결과는 작업 최종 보고에서 구분한다.
