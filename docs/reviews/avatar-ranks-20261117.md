# 아바타 구매 등급과 조선 복식 (2026-11-17)

## 상품·구매 계약

기존 120품목은 모두 `tier_1`(노비 이상)로 보존하고 19품목을 추가한다. 카탈로그 세대 2, 기존 ID·소유권·가격 설정·저장 모습은 유지한다. 최소 구매 등급이므로 정상 5단계에서 양반은 노비·상민·중인·양반 상품을, 왕실은 전체 상품을 살 수 있다. 이미 보유한 상품은 등급 하락 이후에도 착용한다. 무료 상품의 기존 자동 보유 정책도 유지한다.

관리자 `위스 상점 → 아바타 아이템 관리`의 상품 수정창에 구매 등급을 추가한다. 기존 설정 주소의 이동은 유지한다. 카드별 저장·무변경 저장 차단·다른 카드 초안 보존·revision 충돌·응답 유실 재시도를 기존 가격/성별 설정과 같은 트랜잭션으로 처리한다. 운영 설정 문서의 일괄 migration은 필요하지 않으며 값이 없는 옛 상품은 카탈로그 기본값을 사용한다.

학생에게는 최소 구매 등급과 구매 가능 여부를 보여 준다. 실제 구매는 현재 학기 본인 계좌의 `rankEarnedTotal` 및 학기별 `point_policies/current`의 등급 기준으로 서버에서 다시 검사한다. 정책 문서에서 `rankPolicy.tiers`만 선택하여 전달량을 줄이며 문서 읽기 횟수 감소로 계산하지 않는다. 기존 세션·학기·학생 공개·지갑·소유권·영수증·감사 기록은 유지한다. 검색·종류 전환·페이지 이동·미리보기는 추가 서버 조회를 만들지 않는다.

등급 코드는 표시 이름의 고정 식별자다. 기존 등급 관리의 단계 추가·삭제·기준 재정렬을 지원하기 위해 서버는 실제 정책에서 도달한 구매 등급 집합 `allowedPurchaseTiers`를 반환한다. `tier_6` 등을 노비로 떨어뜨리거나 코드 숫자만으로 정책 순서를 추정하지 않는다. 삭제된 상위 요구등급은 차단하고 `tier_1`은 기존 상품의 공통 기준으로 유지한다. 클라이언트는 허용 집합이 없거나 손상되면 제한 상품을 잠근다. 무료 상품은 노비 이상으로 표시·정규화하며 구매 등급 입력을 비활성화한다. 유료에서 무료로 바꾸면 등급도 초기화한다.

## 고증과 그림의 한계

조선 후기·말기 복식의 특징을 기존 80×112 픽셀 아바타에 맞춰 새로 그렸다. 첨부 도판과 유물 사진을 그대로 복제하지 않았다. 이 카탈로그의 구매 등급은 게임 규칙이며 역사적 착용 신분을 단독으로 규정하지 않는다. 특히 와룡관·당의·가체·갓·두루마기·생활복은 상품 설명에서 전용 복식이 아님을 구분한다. 노비의 획일적 제복·누더기·맨발 같은 표현은 만들지 않는다.

- **곤룡포·익선관:** 붉은 둥근 깃의 포, 원형 용보, 옥대와 위로 선 두 익선을 표현한다. 관리의 사모와 가슴의 사각 흉배로 대체하지 않는다. 미세한 용 발톱 수는 픽셀에서 판독하기 어려우므로 원형 용보의 단순화임을 명시한다. [국립고궁박물관 영친왕 곤룡포·익선관·화](https://www.gogung.go.kr/gogung/pgm/psgudMng/view.do?menuNo=800065&psgudSn=367882), [영친왕 익선관](https://www.gogung.go.kr/gogung/pgm/psgudMng/view.do?menuNo=800065&psgudSn=363625).
- **와룡관·학창의:** 골이 있는 벌어진 관과 말린 양옆, 학창의의 흰 바탕·검은 선·넓은 소매를 사용한다. 왕실 등급의 와룡관도 왕만의 관모로 설명하지 않는다. [국립고궁박물관 와룡관 해설](https://www.gogung.go.kr/gogung/bbs/BMSR00129/view.do?boardId=6374&pageIndex=1), [국가유산 지식이음 이하응 초상](https://portal.nrich.go.kr/kor/portraitNdUsrView.do?menuIdx=1258&portrait_idx=86), [전통문화포털 학창의](https://www.kculture.or.kr/clothes/code/943/menu/923/idx/175/currentPage/6).
- **당의·가채:** 녹색 계열 당의, 자주 고름, 흰 거들지와 길고 굽은 자락을 반영한다. 가채는 머리를 땋아 얹은 표현이며 왕실 전용이나 조선 전 시기에 동일한 예법으로 단정하지 않는다. [서울공예박물관 당의](https://craftmuseum.seoul.go.kr/search/collection_materials_view/5187), [국립중앙박물관 당의](https://www.museum.go.kr/MUSEUM/contents/M0501000000.do?pageSize=10&relicRecommendId=411790&schM=view), [국립민속박물관 가체](https://folkency.nfm.go.kr/topic/detail/6830).
- **갓·두루마기:** 갓 크기는 신분뿐 아니라 시대·유행·규제에 영향을 받았다. 좁은 갓=중인 전용으로 가르치지 않는다. 두루마기는 옆이 막힌 형태와 재료 차이를 사용한다. [서울공예박물관 갓](https://craftmuseum.seoul.go.kr/search/collection_materials_view/1118), [한국민족문화대백과사전 갓](https://encykorea.aks.ac.kr/Article/E0000945), [한국학중앙연구원 주의](https://dh.aks.ac.kr/sillokwiki/index.php/%EC%A3%BC%EC%9D%98%28%E5%91%A8%E8%A1%A3%29).
- **생활복:** 무명=면포, 삼베 적삼은 여름용 홑옷의 용례로 구분한다. 천 수건은 작업 차림의 표현이지 신분 표지가 아니다. [한국민족문화대백과사전 무명](https://encykorea.aks.ac.kr/Article/E0019032), [한국연구재단 한국복식사전 적삼](https://dh.aks.ac.kr/~katd/wiki/index.php/%EB%B3%B5%EC%8B%9D%EC%82%AC%EC%A0%84%3A%EC%A0%81%EC%82%BC).

사용자 시각 검토 후 새 관모 전체의 폭과 착용 높이를 수정했다. 머리 크기를 줄이지 않고 모자를 머리 위로 올렸으며 갓끈은 볼 바깥에서 턱 아래로 내렸다. 가채 착용 중에만 머리를 모아 긴 머리 끝이 아래에 남지 않게 한다. 기존 헤어 선택 값 자체는 바꾸지 않는다. 새 7개 관모에 얼굴 영역 비가림·최소 폭·착용 높이 회귀 검사를 추가했다.

## 검증·배포

합성 계정·로컬 에뮬레이터로 구매/설정/충돌/재시도/권한을 검증하며 실제 학생 계좌를 시험용으로 변경하지 않는다. 화면은 390/768/1280px와 실제 계산 스타일로 확인한다. `render-joseon-avatar-review.mjs`로 의도한 조합을, `verify-minimi-renderer.mjs`로 체형·머리·옷·포즈 조합을, `render-avatar-item-previews.mjs`로 정적 상품 이미지와 런타임 일치를 확인한다.

서버는 원본을 비교해 13개 함수를 5개 소스 그룹으로 격리 배포한다. 가격 관리 2개, 아바타 조회·구매 4개, 아바타 저장 2개, 위스 순위 투영 4개, 새 복식을 접수해야 하는 `manageGongsinmoongo` 1개다. 양 리전 위스 조회와 최신 저장 썸네일 복구를 보존한다. index·package·lockfile·권한·리소스 설정을 통째 교체하지 않으며 rules 변경은 없다. 관련 스크립트는 `prepare-avatar-ranks-release.mjs`, `verify-avatar-ranks-release.mjs`다.

운영 기준은 작업 중 반영된 별도 위스피 패치를 fast-forward로 받은 `4266df73`이다. AI 호출·에이전트 제품 기능·외부 AI 전송·개인정보 항목·학교/학생 공개 범위 확대는 없다. 기존 상품 관리·구매 검증의 유지보수이며 외부 자료에는 학생 데이터를 전송하지 않았다. 증거는 Git에서 제외한 `output/avatar-ranks-20261117`, `output/avatar-purchase-tiers-20261117`에 보관한다.

2026-11-17 로컬 검증 결과: `npm run build`, `npm run format:check`, Functions 전체 `check`, 서버 단위 검사 74건과 Firestore 에뮬레이터 19건을 통과했다. 학생·관리자 화면은 390/768/1280px에서 구매 차단·설정 저장·충돌·재시도와 가로 넘침을 확인했다. 아바타 전체 조합 93,357건 및 별도 새 관모 7종의 얼굴 비가림·폭·높이 검사를 통과했다. 상품 정적 이미지 275개를 다시 생성하고 런타임 렌더러와 대조했다.

조회 비용은 학생 스튜디오 15읽기/0쓰기, 구매 18읽기이며 정상 구매는 기존 감사·영수증을 포함해 8쓰기다. 등급 부족은 0쓰기이고 이미 처리한 구매 영수증 재조회는 등급 정책을 다시 읽거나 쓰지 않는다. 화면 필터·미리보기에는 추가 서버 호출이 없다. 각 배포 소스 그룹의 별도 합성 검사에서는 추가 등급·삭제된 등급·기준 순서 변경·무료 상품 전환도 확인했다.
