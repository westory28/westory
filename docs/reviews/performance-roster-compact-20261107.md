# 수행평가 일람표 모바일·태블릿 배치

기준 커밋은 `c7eaecb34fb6827a8397d73ea7c83205d35ecb8f`이며 변경 전 운영 도메인의 Vercel 배포도 같은 커밋이었다. 다른 시험지 작업의 미커밋 변경과 기존 `output/`, `tmp/`를 보존하기 위해 별도 worktree에서 수행평가 일람표만 수정했다.

## 변경 범위

- 제목·닫기, 평가/학급 선택·조회, 인원/서명 현황을 각각 한 줄로 표시한다. 큰 현황 카드와 상시 설명, 하단 중복 닫기 버튼을 제거한다.
- 모바일 선택 필드는 행 내부에서 가로 스크롤하고 조회 버튼은 같은 행 오른쪽에 고정한다. 기존 접근성 이름과 로딩·비활성 조건을 유지한다.
- 학생 표가 창의 남은 높이를 사용하며 표 안에서만 세로 스크롤한다. 표 최소 폭 960px로 학생 식별 열을 보존하고 상태·번호·이름·점수·서명·반려·일시의 줄바꿈을 막는다.
- 수행평가 전용 클래스에만 압축 스타일을 적용한다. 정기시험 서명 현황, 학생 포털, 학기 경로와 legacy 조회, 점수·서명 처리 및 XLSX 생성은 수정하지 않는다.
- AI 호출·에이전트 실행·외부 데이터 전송·개인정보 항목·권한·공개 범위 변경이 없는 기존 UI 유지보수다. Firebase 배포 대상은 없다.

## 화면 검증

Chrome 방재석 프로필에서 변경 전 운영 화면을 읽기 전용으로 측정했다. 390×844px에서는 현황 영역 높이 394.5px, 표 시작 위치 967.5px, 첫 학생 행 높이 116.5px로 명단이 화면 아래에 있었다. 768×1024px에서도 현황 영역 233.5px, 표 시작 위치 786.5px였다. 운영 점수·서명·이의 상태는 변경하지 않았다.

기존 점수 보관 학기 검증의 합성 32명 fixture에 실제 컴포넌트와 CSS, 로컬 Tailwind를 적용해 Microsoft Edge에서 검사했다. 모든 외부 요청을 차단하며 운영 SDK와 데이터는 사용하지 않았다. 임시 검증 스크립트와 캡처는 커밋에서 제외한다.

| 화면 크기 | 수정 후 첫 학생 행 시작 | 완전히 보이는 학생 수 |
| --- | ---: | ---: |
| 390×844 | 260px | 8명 |
| 768×1024 | 214px | 12명 |
| 768×1024 터치 | 230px | 12명 |
| 1280×800 | 214px | 8명 |
| 1366×768 | 214px | 8명 |

모든 학생 행이 57px 이하이며 서명 이미지·반려·일시도 같은 행에 있다. 필터·현황은 한 줄, 문서 전체 가로 넘침은 없고 조회 버튼의 Tab/포커스 접근, 표의 PageDown과 내부 가로 스크롤을 확인했다. 모바일·태블릿 터치 조건에서는 44px 조작 영역을 확인했다. 정기시험은 네 화면 크기에서 변경 전후 제목·필터·요약·표·행·푸터의 실제 좌표와 높이가 동일하다. 브라우저 오류, 외부 요청, 데이터 쓰기는 모두 0건이다. 이는 브라우저 크기·터치 조건 검증이며 실물 iOS/Android 장치 검증은 아니다.

`npm run build`의 타입·점수 계약·최종 XLSX hair 점선 테두리 검사를 통과했다. `npm run format:check`와 최종 필터 배치 보완 후의 `npx tsc --noEmit`, `npx vite build`도 통과했다. 운영 반영은 최종 커밋의 Vercel Ready·승격 및 실제 도메인의 수행평가 일람표 확인으로 마무리한다.
