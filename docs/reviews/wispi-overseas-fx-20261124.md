# 위스피 해외 모의시장과 환율 운영 검토

2026년 11월 24일 검토. 첫 도입안은 USD 한 통화, 한국 수업 시간에 열리는 해외 모의종목, 영업일별 공시환율이다. 학생은 위스를 외화로 환전하고 그 통화 잔액으로 주문한다. 해외 시세와 역사는 수업용 시나리오로 운영하고, 환전에는 현재 공시일과 적용 환율을 보여준다.

## 수업에서 보이는 흐름

- 교사가 한국사·세계사 사건을 같은 연도에 배치하고 관련 모의종목을 정한다. 예를 들어 1789년은 조선 정조 13년이자 프랑스 혁명이 시작된 해다. 각 사건의 근거를 해당 종목에 연결하고, 산업에 미칠 가상 효과는 수업 시나리오로 표시한다. [국사편찬위원회 정조대 자료](https://contents.history.go.kr/data/pdf/km/km_040.pdf) · [프랑스 혁명](https://contents.history.go.kr/front/ta/print.do?levelId=ta_h32_0060_0020_0040_0040&whereStr=)
- 학생은 환전 전 받을 USD와 차감될 위스를 확인한다. 현재 위스와 원화의 수업용 환산비는 교사가 정한다. 지갑에는 매수 당시 환율, 현재 평가 환율, 종목 자체 손익과 환율 변동 영향을 표시한다. 오늘의 USD는 모의 결제 통화이며 역사 자료에 나오는 당시 화폐는 별도로 표기한다.

## 환율 데이터

한국수출입은행 API를 1순위 후보로 둔다. 공공데이터포털에는 무료 API와 새 요청 도메인 `oapi.koreaexim.go.kr`이 안내되어 있다. 신청 키로 공시 시각, 실제 승인 한도, 휴일·빈 응답, 통화별 기준 단위와 응답 필드를 확인한 뒤 도입한다. 환율 출처로 보내는 데이터는 조회일과 API 인증 정보로 한정한다. [한국수출입은행 환율 정보](https://www.data.go.kr/data/3068846/openapi.do)

ECB도 한국 원화와 미국 달러의 유로당 기준환율을 영업일 유럽 중부 시각 약 16시에 공시한다. 원/달러 환율은 같은 날짜의 유로당 원화 값을 유로당 달러 값으로 나누어 구한다. 국내 수업 시각과 공시 시각이 달라 대체 공급자로 검토할 때 가격 기준일을 화면에 표시해야 한다. 공급자를 바꿀 때에는 기존 거래 영수증의 출처와 환율을 보존한다. [ECB 기준환율](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)

## 비용과 장애 대응

공시 후 서버 작업 하나가 모든 학급이 사용할 통화 묶음을 한 번 받아 기준일·통화·기준 단위와 함께 저장한다. 같은 공시를 다시 받으면 환율 문서 쓰기는 0회다. 주가가 10분마다 바뀌어도 일별 환율은 그대로 사용할 수 있다. 실패 시 짧은 시간 제한과 횟수 제한을 두고 재시도한다. 휴장일에는 직전 공시일을 표시한다. 새 공시가 있어야 할 시점이 지나도 확인하지 못하면 새 환전만 보류한다.

| 가정한 사용량 | 하루 | 수업일 20일 |
| --- | ---: | ---: |
| 공시환율을 한 번에 수집하는 외부 요청, 재시도 제외 | 1회 | 20회 |
| 학생 300명이 환전 화면을 한 번 열어 공용 문서 1개씩 읽음 | 300읽기 | 6,000읽기 |
| 같은 학생들이 10시간 내내 10분마다 환율 문서를 직접 조회하는 경우 | 18,000읽기 | 360,000읽기 |
| 하루 300건 환전, 거래당 환율·계좌·기존 영수증 조회 3건과 계좌·영수증 쓰기 2건을 가정 | 900읽기·600쓰기 | 18,000읽기·12,000쓰기 |

위 표는 설계 비교용으로, 실제 청구액은 리전·공유 무료 할당량·인증 및 권한 조회·동시 거래의 재시도·저장공간·함수 실행량에 따라 달라진다. 특히 Firestore 실시간 구독은 결과 문서의 변경 때 연결된 사용자별 읽기가 생긴다. 일별 환율을 10분마다 갱신하는 공개 시장 문서와 분리하면 해외장을 쓰지 않는 학생에게 환율 변경을 전송할 필요가 없다. [Firestore 과금 기준](https://cloud.google.com/firestore/pricing)

운영 기본 데이터베이스의 위치는 `nam5`다. Google의 해당 위치 과금 예시 단가(10만 건당 읽기 $0.06, 쓰기 $0.18)를 적용하면, 화면 읽기와 환전을 합한 월 24,000읽기·12,000쓰기는 무료분 차감 전 약 **$0.036**이다. 이 금액은 위 표의 환율 문서·계좌·영수증 작업만 계산한 값이다. 외환 수집 전용 Scheduler 작업을 하나 추가할 때에는 결제 계정의 무료 작업 3개를 이미 사용했다면 31일당 $0.10이 추가된다. 오늘 변경한 국내 주가 스케줄은 같은 작업의 빈도를 바꾸므로 Scheduler 자체의 작업 수 과금은 같다. [Google의 nam5 과금 예시](https://docs.cloud.google.com/firestore/native/docs/billing-example) · [Cloud Scheduler 요금](https://cloud.google.com/scheduler/pricing)

서버는 학생·학기·통화·환율 버전과 잔액을 검증하고, 환전 양쪽 금액과 영수증을 한 트랜잭션에서 확정한다. 재전송은 같은 요청 ID의 영수증을 반환하고, 견적이 만료되거나 적용 버전이 바뀌면 새 견적을 보여준다. 금액은 통화의 최소 단위 정수로 보관하고 원 미만 처리와 왕복 환전 반올림을 정한다. 외화 매수·매도에도 동일한 중복 방지와 잔액 검사를 사용한다.

도입 판단에는 한 학급 규모의 합성 거래로 외부 API 중단, 휴일, 중복 요청, 동시 매수·환전, 잔액 일치와 트랜잭션 재시도 비용을 측정하는 것이 필요하다. 이번 변경에서 해외 주식장이나 환전 기능을 운영에 추가하지 않았다.
