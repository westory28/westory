# 평가 분석 진입과 조회 범위 개선

## 원인과 변경

- 모의고사 문제 등록에서 분석 탭으로 이동할 때 선택 정보가 전달되지 않았다. 단원과 모의고사 분류를 경로에 보존하고, 성취기준 분석을 학급 상세 창 밖의 본문에서도 연다.
- 조회 전·로딩·오류에도 분석 보기와 표 구조를 표시한다. 조회 전 값은 `—`이며 실제 서버 응답에서 확인한 응시 0명과 구분한다. 회차·학급·계정·학기 변경 시 이전 분석 선택과 늦은 응답을 폐기한다.
- 초기 분석 진입은 `catalog` 요청 한 건만 실행하며 관리 화면의 별도 curriculum 조회를 시작하지 않는다. 성취기준 결과 조회는 해당 학급·회차의 `achievement` 요청 한 건이며 중간 summary/detail 조회를 생략한다.
- 카탈로그는 학급·평가 정의의 필요한 필드만 읽고 `catalogGeneration`으로 무효화한다. 명단·프로필 변경으로 목록 전체를 재집계하지 않으며 문항 분류·회차·등록·삭제, 평가 정의, 학급 구성, 교육과정 변경은 계속 반영한다. 기존 6시간 TTL·서버 세션/권한/학기 검사·legacy tree fallback은 유지한다.
- 비교·검색·초기화·결과 조회를 8px 간격으로 묶고 결과 조회를 맨 오른쪽에 둔다. 초기화 동작은 기존과 같다.

## 범위

기존 교사 평가 분석의 유지보수다. 학생 화면·데이터 저장 계약·공개 범위·성적·서명·이의 처리·AI 호출·외부 전송은 변경하지 않는다. 운영 확인에는 학생 점수와 분석용 수준을 저장하지 않는다.

## 검증과 운영

- `npm run build`, `npm --prefix functions run check`, 분석 클라이언트 및 상세 브라우저 회귀 검사 통과.
- 카탈로그 캐시 및 실제 무효화 trigger를 포함한 학급 분석·학생 이력 합성 검사 36개 통과.
- 실제 ManageQuiz → QuizBankTab → QuizClassAnalysis를 연결한 합성 브라우저에서 선택 유지, 초기 목록 1건, 추가 tree 조회 0건, 결과 조회 achievement 1건, 응시 0명, 오류 재시도 및 늦은 응답 폐기를 확인한다.
- 320/390/768/1280/1440px에서 조회 전·응시 0명 화면과 버튼 순서를 확인한다. 페이지 가로 넘침 없이 기존 필터 재배치와 표 내부 스크롤을 유지한다.
- 배포 전 운영 원본의 실행 JS/CJS/JSON 124개와 기준 `e5986a1f`를 LF 정규화 비교해 모두 일치함을 확인했다.
- `getQuizClassAnalysis`만 선택 배포했다. 2026-11-07 20:32 KST에 `getquizclassanalysis-00007-tul`, ACTIVE 상태를 확인했다. 권한 규칙과 다른 함수·trigger는 배포하지 않았다.
- 프런트엔드 운영 배포와 실제 도메인 검증 결과는 반영 확인 후 추가한다.
