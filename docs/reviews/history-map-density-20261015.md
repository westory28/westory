# 역사 지도 화면 밀도 개선 검증

## 변경 범위

- 공통 `HistoryAtlas`, `HistoryGlobe`, `AtlasPlaceDetails`와 지도 필터 스타일을 수정했다. 학생·교사 포털이 같은 지도 컴포넌트를 사용하며 권한·라우팅·학기·백엔드 계약은 변경하지 않았다.
- 시대 태그는 연도·시대, 관련 장소 태그는 지명만 표시한다. 14px 글자/20px 행간/상하 3px 여백으로 실제 높이는 28px이다. 긴 설명은 hover·focus 말풍선과 선택 후 본문으로 제공한다.
- 위치 강조 끄기 버튼을 제거했다. 위치·배지 물결은 기본 재생하며 화면 밖·숨겨진 탭에서는 일시 정지한다.
- 드롭다운은 한 줄, 작은 화면의 검색은 다음 한 줄이다. 아주 좁은 화면이나 하위 지역 필터가 추가되면 필터 행 안에서 가로 스크롤한다.
- 확대·축소·배율은 우측 상단, 설명은 지도 안 좌측 하단으로 통일했다. 모바일 전체 화면 설명 패널과 큰 하단 선택 카드를 제거했다. 지구본의 미선택 목록 행은 테두리가 보이지 않는다.

## 확인 결과

- 최신 `origin/main`의 `49c8a01`을 합친 상태에서 `npm run build`, `npm run format:check`, `git diff --check` 통과.
- 지도 이동 검증: 실제 장소 8,696개 배치, 전체 도형 136개, 극지방 72개 사례 통과. 실제 팝업 위치·크기를 사용하여 선택점과 설명창의 겹침을 검사했다.
- 기존 역사 사건 283개, 사건 연결 장소 321개, 과목 범위 관계 392개 검증 통과. 이 패치는 역사 데이터와 과목 경계를 변경하지 않는다.
- Chrome viewport 320px, 390px, 768px에서 필터 한 줄과 페이지 가로 넘침 없음을 확인했다. 390px 지구본 필터 높이는 36px, 미선택 행 border 색은 transparent였다.
- 768px 평면 지도의 설명창은 280×201.6px이며 지도 안에 유지됐다. 태그 실제 높이 28px를 확인했다.
- 철원 → 911년 → 태봉, 로마 → 콜로세움 선택과 관련 설명 노출을 확인했다. 장소 목록 선택 후 대화상자가 닫히고 설명 제목으로 초점이 이동했다.
- 키보드 Tab으로 태그 말풍선 표시, Escape로 말풍선만 닫기, 선택 후 설명 본문으로 스크롤 복귀를 확인했다.
- 독립 코드 검토와 지도/지구본/역사 이야기 재검증에서 추가 결함이 발견되지 않았다.

브라우저 검증은 데스크톱 Chrome의 viewport 변경으로 진행했으며 실제 iOS/Android 기기 검증은 아니다. 로컬 화면 기록은 `output/map-polish-globe-mobile.jpg`, `output/map-polish-tablet.jpg`에 보관한다. `output/`은 커밋에 포함하지 않는다.
