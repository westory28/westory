# 충무공 깃 5프레임 교체

사용자는 이전 SVG 변위 연출에서 배경까지 흔들려 보이고 깃 움직임이 어색하다고 지적했다. 사각형 안의 변화만 확인했던 이전 검증은 실제 깃 바깥의 정지와 자연스러운 연출을 보장하지 못했다.

## 변경

- 변위·난류 필터를 제거하고 투명 깃 다섯 장을 같은 위치·크기로 교체한다. 정상은 자세당 180ms, 동작 감소는 240ms이다. 한 번에 한 자세만 보여 중첩으로 하늘이 비치는 현상을 막는다.
- 원본 배경 이미지는 유지한다. 깃이 있던 부분만 생성한 깃 없는 정적 이미지로 가리고, 투구에 붙는 뿌리는 첫 프레임으로 고정한다. 뿌리 끝의 연결부는 불투명 고정 깃 위에 덮는다. 이미지 이동·늘이기·배경 필터는 없다.
- 모든 새 자산을 디코딩한 뒤 표시한다. 느리거나 실패한 요청에는 기존 완성 장면을 유지한다. 명시적 정지·숨김 탭·화면 밖 정지는 현재 프레임을 보존한다.
- 연습/도전·기록·시작 버튼, 수자기, 썸네일, 로딩, BGM, 서버·권한·위스 처리는 변경하지 않는다. 공통 장면을 쓰는 학생·교사 양쪽을 확인한다.
- 내장 image_gen의 생성 원본과 정확한 프롬프트는 `public/assets/weplay/naval/ASSETS.md`에 기록했다. 기존 장면의 인물·함대·수자기 픽셀은 배경으로 유지하며 정적 패치는 이전 깃 위치에만 표시한다.

## 검증

- `npm run build`와 변경 TSX Prettier, `git diff --check`를 통과했다. 마지막 이미지 연결부 수정 후 Vite 빌드도 통과했다.
- `scripts/verify-weplay-lobby-exit-browser.mjs --motion-only`에서 다섯 생성 프레임 순환, 배경과 뿌리 정지, 명시 정지·숨김 탭·화면 밖 정지와 위치 보존 재개, 동작 감소, 학생·교사 390/768/1280px을 통과했다.
- 독립 코드 검토에서 두 이미지 투명도 중첩의 alpha 감소를 발견해 단일 프레임 표시와 불투명 뿌리로 수정했다. 최종 수명·정리·실패 복구 검토에서 추가 결함은 발견하지 못했다.

브라우저 캡처·픽셀 비교·빌드 로그·운영 반영 기록은 `.superloopy/yi-sunsin-plume-frames/`에 보관한다.

최종 1280/390px 각각 24프레임에서 실제 깃 알파 영역 밖 배경, 고정부착점, 투구, 함대, 좌측 수자기와 정지·동일 자세 반복의 픽셀 변화는 모두 0이다. 관측 프레임 간격 평균은 일반 175ms·동작 감소 237.5ms이다. 최초 캡처의 초기 합성 오차 증거는 initial-compositing 아래 별도 보존했으며 렌더 정착 후 촬영한 최종 시퀀스와 구분했다.
