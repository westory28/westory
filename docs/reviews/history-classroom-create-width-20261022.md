# 새 역사교실 등록 팝업 너비

등록 팝업의 최대 폭만 96rem에서 74rem으로 줄였다. 기존 내부 컨테이너 72rem과 본문 좌우 16px 여백을 합친 폭으로, 1920px 화면에서 양옆 빈 공간이 각각 192px에서 16px로 줄고 내부 폼의 1152px 너비는 유지된다. 자료 수정에서 재사용하는 같은 팝업에도 적용된다. 교사 전용 표시 변경이며 저장·배정·공개·학기 경로와 학생 화면은 변경하지 않았다.

기존 실제 교사 컴포넌트의 합성 fixture를 브라우저에서 390×844·768×1024·1280×900·1366×768·1920×855로 확인했다. 문서와 본문의 가로 넘침이 없고, 작은 화면은 기존 단일 세로 스크롤과 반응형 배치를 유지한다. 작은 화면 오른쪽의 추가 15px은 기존 스크롤바 공간이다. 새로운 디자인 토큰이나 포털 탐색 예외는 없다.

검증: `npm run build`(타입 검사와 최종 XLSX hair 테두리 검사 포함), 변경 TSX의 Prettier 검사, `git diff --check` 통과. 합성 화면에서 등록 명령이나 운영 데이터 쓰기는 실행하지 않았다.
