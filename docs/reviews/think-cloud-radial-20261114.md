# 생각모아 중심 방사형 배치 보완

사용자 정정에 따라 행을 채우던 보드를 중앙에서 확장하는 불규칙한 방사형으로 바꿨다. 첫 단어는 중앙에 유지하며 새 단어는 중앙에서 자기 위치로 등장한다. 모든 글자는 가로 방향이고, 빈도에 따른 글자 크기 증가·동작 줄이기에서도 작동하는 효과·수동 효과 끄기를 유지한다.

- 실제 글자·버튼 영역을 측정하고 공간 인덱스로 충돌을 검사한다. 바뀌지 않은 단어의 위치를 먼저 예약하므로 중복 성장으로 주변 단어가 연쇄 이동하지 않는다. 이동이 필요한 기존 단어는 위치를 확정한 뒤 투명도 전환을 적용해 다른 글자를 가로지르지 않는다.
- 한 번 나온 단어도 파랑·보라·로즈·코랄·주황의 9색을 사용한다. 단어의 색은 빈도와 순서가 달라져도 유지한다. 보드 배경에서 대비는 4.52~6.29:1이며, 선택·호버 배경은 더 밝은 흰색이다. 회색 글자 덮어쓰기는 제거했다.
- 화면 너비, 제시 화면 높이, 글꼴 준비 시 브라우저에서만 다시 배치한다. 새 서버 호출·폴링·의존성·AI 호출·외부 전송은 없다. 기존 실시간 delta·권한·저장·영수증·보상 로직과 Firebase 배포는 변경 대상이 아니다.

검증:

- `node scripts/verify-think-cloud-layout.mjs`: 21개 배치, 최대 200개, 성장·긴 문장·모든 응답 유지·겹침 방지·기존 위치 보존.
- `node scripts/verify-think-cloud-browser.mjs`: 실제 학생/교사 컴포넌트의 합성 transport 검사 22개. 320/390/768/1280px, 390→768→1440px 변경, 첫 단어 중앙 유지, 순차 추가, 색상 유지, 166개·100자 문장, OS 동작 줄이기·효과 끄기, 실시간 조회 횟수와 기존 제출/운영 흐름.
- 768px에서 60개 단어 중 한 단어만 70회로 증가시키는 독립 검사: 나머지 59개 좌표 유지, 애니메이션 150ms의 텍스트 겹침 0건. 최초 검토에서 발견한 연쇄 이동·중간 겹침을 이 검사로 보완했다.
- 독립 검사에서 긴 문장 200개와 너비 고정·높이 700→1400px 제시 화면의 중앙 정렬·가로 넘침 없음도 확인했다.
- 기존 전체 앱 빌드와 포맷 검사를 통과했다. 화면과 상세 결과는 로컬 `output/think-cloud-radial-20261114/`에 보관하며 운영 학생 데이터는 검증용으로 변경하지 않는다.

## 후속 요청: 계속 떠다니는 효과

사용자가 동작 줄이기 상태에서도 계속 떠다니도록 요청해 내부 단어 버튼에 가로 ±2px·세로 ±3px, 4.8~6.8초 CSS 반복 효과를 추가했다. 실제 배치 좌표와 분리하고 단어별 주기·시작점을 고정한다. 최소 배치 간격 9px보다 두 단어의 최대 접근량 6px이 작으며, 성장 효과의 크기 초과도 제거했다. 호버·키보드 포커스·선택·숨김 탭·화면 밖에서는 정지하고 수동 움직임 끄기와 인쇄에서는 제거한다. 프레임별 JS, 추가 서버 요청, 새 의존성은 없다.

`npm run build`, 포맷 검사와 브라우저 23개 시나리오를 통과했다. 새 시나리오는 OS 동작 줄이기에서 실제 시간에 따른 이동, 16개 위상의 겹침 없음, 단어별 서로 다른 주기, 입력 방식별 정지·복귀, 화면 이탈·탭 숨김·수동 끄기·인쇄, 추가 전체/delta 조회 0회를 검증한다. 결과는 `output/think-cloud-float-20261114/`에 보관한다. 이 후속 변경도 프론트엔드만 배포하며 기존 Firebase 구현은 유지한다.
