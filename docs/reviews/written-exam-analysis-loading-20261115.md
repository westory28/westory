# 정기시험 분석 조건·로딩·조회 개선

- 기준: `18d69c88bb4851df8eb8fa56e19f2358d7ffc0fc`, 운영 `www.westory.kr`.
- 평가명 선택창의 intrinsic minimum을 제거하고 반응형 그리드로 학급·분석 항목·분석 버튼을 분리했다. 조건 선택은 조회하지 않으며 분석 시에만 선택형/논술형을 조회한다. 보고서 보기 전환은 추가 조회하지 않는다.
- 초기 결과와 재조회에 공통 로딩 로고를 표시한다. 같은 tick 중복 제출을 차단하고 오류 후 조건을 보존한다.
- 학생 284명 답안은 개별 284개 요청/20명씩 15개 순차 묶음에서 100·100·84명 REST batchGet 3개 병렬 요청으로 변경했다. 원안지 메타데이터도 병렬로 읽는다. 명시된 학생·평가 경로만 요청하며 ID token, 설정된 AppCheck, Firestore rules를 유지한다. 일부 실패/누락/중복/다른 경로/계정 변경은 전체 실패 처리한다. 문서 읽기 수는 점수표·원안지 포함 286개로 동일하다. 필드 projection은 전송량 절감이다.
- 조회 성공 결과는 같은 탭의 sessionStorage 및 메모리에 최대 6개, 항목당 3MiB 문자열 이내, 10분간 저장한다. 계정·인증 세대·학기·역할·승인·권한·평가·학급·유형·점수표 갱신 시각으로 격리한다. 화면 진입 시 서버에서 평가 목록을 확인한 뒤 재사용한다. 만료 타이머와 포커스 복귀 시 청소하며 탭 종료/로그아웃/계정 교체 시 삭제한다. 브라우저가 백그라운드 타이머를 지연하면 재개 시 삭제한다. 저장 공간 제한 시 메모리로 대체한다.
- 새로고침은 해당 시험의 모든 유형 캐시를 무효화하고 서버 재조회한다. 점수 저장·자료 등록 성공도 무효화한다. 다른 장치의 변경은 최대 10분 또는 명시적 새로고침 뒤 반영된다. 실패한 모의고사 연결 결과는 캐시하지 않는다. 인증 토큰·세션 증명·PDF·이미지를 캐시하지 않으며 불필요한 학생 이메일과 선택형의 논술형 행은 제외한다.
- 정기시험·모의고사 공통 A–E 막대 안에 수준 문자를 넣고 좁은 구간의 실제 비율과 표를 유지한다.
- 새 AI 호출·외부 서비스·학생 공개·점수/서명/이의 상태 변경은 없다. Firebase rules/Functions 변경 및 배포도 없다.
