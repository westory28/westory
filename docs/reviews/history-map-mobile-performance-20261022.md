## 적용 원칙

- 지형은 기본적으로 끈다. 켜거나 지형의 실제 선택 범위가 필요한 경우에만 지형 자료를 요청한다. 같은 화면에서 탭을 바꾸거나 필터를 초기화할 때 사용자의 지형 선택을 유지한다.
- 평면 지형은 256 CSSpx 그리드 타일로 캐시한다. 같은 배율의 이동은 겹치는 타일의 경로와 이미지를 재사용하며 새로 드러난 타일만 만든다. 경계/Path2D 캐시, 화면 밖 지형 제외, 320px 이동 여유, 타일 세대당 100만 픽셀(교체 중 이전 세대와 합계 최대 200만 픽셀)·DPR 1.5 상한을 적용한다. 확대·축소 때 이전 지형을 유지하며 새 타일로 교체하고, 1 physical px 여유와 육지색 사전 합성으로 경계 틈·중복 알파를 방지한다. 짧은 작업 단위와 조작 우선 처리, 화면 밖 타일 퇴출, 전환·언마운트 시 늦은 결과 무시를 적용한다.
- 평면 지도는 정지 화면의 SVG를 제한된 크기의 canvas로 미리 준비한다. 이동·확대 중에는 준비된 bitmap과 별도 지명 레이어만 이동한다. SVG의 non-scaling stroke·pattern이 확대마다 다시 그려지는 비용을 피한다. 정지하면 원본 SVG의 정확한 선택 범위를 복원한다.
- 라벨은 매 입력마다 `left/top`을 바꾸지 않고 개별 `translate`로 이동한다. 글자 크기·접근성·기존 CSS 중심 정렬을 유지한다. 긴 이동/축소가 여유 범위를 소진하면 표면을 갱신한다.
- 지구본은 이동용 2048×1024 지표 텍스처를 준비해 GPU에서 구면 투영한다. 정지하면 원본 지리와 정밀 질감을 복원한다. 선택 범위는 정확한 자료로 별도 표시하고 국가 강조의 육지 clip을 유지한다. WebGL 미지원·생성 실패·컨텍스트 손실 시 화면 오차 기준의 단순화, 화면 밖 도형 제외와 DPR 1 canvas 경로로 전환하고 복구 시 GPU 경로를 다시 준비한다.
- 평면 캐시는 원본 SVG와 분리된 복사본에서 카메라를 읽는다. 선택/투영 변경 시 캐시를 무효화하고, 일반 카메라 변경 중에는 이미지가 만들어진 카메라를 함께 저장해 안전하게 재사용한다. 지형 채우기는 다음 이동 여유 범위까지 검사해 긴 연속 드래그에서도 소량씩 보충한다.
- 화면 복사본에서는 보이지 않는 국가·강·지형 hit 경로를 제외한다. 육지 채움·육지 clip·해안선이 공유하는 긴 경로는 복사본 내부의 `defs/use`로 한 번만 직렬화한다. 원본 SVG의 정확한 hit 경로, 선택 강조, 실제 표시되는 면적 경계는 유지한다. 표시 스타일 복사를 4ms 단위로 나누고 새 입력·카메라·선택 변경 시 오래된 작업과 이미지 디코딩을 취소한다.
- 기존 지형 의미 색, 산지 입자와 사막 점질감, 한국 전통 지역선, 국경·강·독도·지명과 출처는 유지한다. 기능 개선과 무관한 UI 개편은 하지 않는다.

## 측정 방법

별도 번들로 고정한 수정 전 fixture와 수정 후 fixture를 동일 Edge·CPU 4배 제한·390×844 DPR3 / 1024×768 DPR2 조건에서 비교한다. 지형 on/off, drag/zoom을 분리하며 동일한 45개 입력을 requestAnimationFrame마다 전달한다. 개별 프레임 간격, long task, TaskDuration, ScriptDuration을 JSON에 기록한다. 정지 후 상세 복원 비용도 별도로 포함한다.

준비된 렌더러를 기준으로 측정한다. 평면 bitmap과 지구본 텍스처가 준비된 뒤 입력을 시작하며, 최초 로딩·첫 캐시 생성 시간은 이 수치에 포함하지 않는다. 준비 전에는 기존 벡터 렌더링을 사용한다. 지구본 각 조건에서 실제 GPU 사용은 46회 관측 중 44~45회였다.

이는 데스크톱 브라우저의 화면·CPU 제한 시험이다. 물리적인 휴대폰/태블릿 GPU, 발열, 메모리 압박, 실제 touch-to-photon 지연을 재현하거나 모든 기기의 FPS를 보장하지 않는다. 일부 초기 측정은 호스트의 다른 검증과 겹쳤으므로 정확한 개선률보다 반복되는 큰 병목이 제거됐는지를 확인한다. 최종 비교는 다른 브라우저 검증·빌드와 분리한다.

측정·브라우저 증거: worktree의 `output/atlas-performance-20261022/` (Git 미포함).

## 후속: 지구본 한 손가락 배율 고정 (2026-10-22)

- 기준은 운영과 main의 `a02d1efc`다. 공용 지구본 입력 처리와 라벨 touch-action만 수정하며 학생·교사 화면 구조, 평면 지도, 자료·권한·Firebase는 그대로 유지한다.
- 원본의 390px CDP 터치에서 중국 라벨을 8px 이동하면 장소 선택으로 처리되어 배율이 100→116%로 변했다. 라벨+바탕의 두 손가락은 같은 제스처로 등록되지 않아 핀치도 작동하지 않았다. 긴 라벨 드래그는 브라우저 pointercancel로 끝났다.
- 지명에서 시작한 포인터도 canvas capture와 기존 회전·핀치 처리를 공유한다. 원래 누른 지명 ID는 값으로 보존하고, 이동·멀티터치·취소가 없는 실제 탭만 선택한다. 마지막 pointerup 위치도 검사해 중간 이동 이벤트가 누락된 빠른 드래그를 탭으로 처리하지 않는다. 키보드·보조 기술 클릭은 유지하며, SVG 라벨에도 touch-action:none을 적용한다.
- 활성 포인터가 있는 동안 늦게 도착한 지리 자료가 선택 카메라를 다시 움직이지 않게 한다. 한 손가락 드래그와 두 손가락에서 한 손가락으로 전환한 뒤의 이동은 배율을 보존한다.
- 실제 production handler를 발췌한 VM 회귀에서 라벨 드래그, 라벨+바탕 핀치, 2→1 전환, 이동 이벤트 없는 빠른 종료, 취소, 라벨 노드 재사용 뒤 정상 탭, 비동기 선택 카메라 차단을 확인했다. 별도 코드 읽기 리뷰에서 추가 P1/P2 문제는 없었다.
- `node scripts/verify-history-globe-touch.mjs`의 실제 브라우저 CDP 터치로 390/768/1280px의 24조건을 검증했다. canvas·라벨·8px 짧은 드래그는 회전하면서 지구본 배율과 visualViewport.scale을 유지하고, 라벨+canvas 핀치는 100→124%, 이어 한 손가락만 남긴 이동은 124%를 유지한다. 정상 탭·키보드 선택·취소 후 복구·연속 드래그도 통과했다. 물리 기기 실측은 아니다.
- 터치 증거는 작업 공간 `output/globe-touch-20261022/validated.json`에 원시 파일 출처와 함께 기록했다. 최초 하네스가 CDP touchEnd에 남을 손가락을 전달한 3조건은 제외하고, 뗄 손가락만 전달하도록 고친 `after-pinch-transition.json`의 3조건을 `after.json`의 유효 21조건과 합쳤다.
- `npm run verify:portal-design -- --kind=map`은 학생·교사 × 320/390/768/1280/1366/1440px의 12항목, 브라우저 오류 0건으로 통과했다. 증거는 `output/globe-touch-20261022/portal/`이다. 기존 독도 지명 UI 검증의 제스처 입력에도 시작 좌표를 제공하도록 보완했으며 해당 검증을 통과했다.
- 전체 `npm run build`를 prebuild 포함 통과했다. 수정 TSX·검증 스크립트 4개의 Prettier 검사와 `git diff --check`도 통과했다. Vite의 기존 500kB 청크 크기 경고는 남는다.
