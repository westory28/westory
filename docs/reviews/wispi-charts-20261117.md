## 자료와 조회 경계

투자 현황의 기존 API는 현재 학기·선택 학급의 opaque studentKey 1~5개를 받는다. 기본 비교는 다섯 명, 개인 보기는 한 명만 조회한다. 날짜 인자는 없으며 이미 받은 해당 학생의 기록에서 표시 기간을 전환한다. 학생 선택과 기간 선택을 구분해 불필요한 재조회를 만들지 않는다.

서버는 해당 계좌의 체결 거래 전체로 당시 보유량과 취득원가를 복원한다. 기간 이전 매수분도 계산에 필요하므로 이 원장 조회를 날짜나 임의 limit으로 줄이지 않는다. 전체 학생의 거래를 읽는 방식이 아니다. 자료에는 거래 시각·관련 실제 시세 시각·현재 확인 시각이 포함되며 클라이언트에서 시계열을 꾸미거나 누락 구간을 보간하지 않는다.

기존 시세 저장은 종목별 실제 가격이 바뀐 최근 120개를 보존한다. 갱신 간격은 종목별 1·6·24시간이며 보관 일수가 일정하지 않다. `전체`는 보관된 실제 기록의 전체 범위이고, 전체 학기 시세가 빠짐없이 있다는 뜻이 아니다. 이전 시세가 없는 구간은 서버의 paired null·incompleteBeforeMs를 보존한다. 현재 미보유 학생도 과거 기록을 선택할 수 있으나 현재 수익률을 0%로 만들지 않는다. 수익률은 보유분 기준이며 입출금과 실현손익을 섞지 않는다.

기존 세션·교사/직원 권한·활성 학기·학급 소속 검사는 유지한다. 완료된 수익률 기록을 다른 계정·세션에 공유하거나 영구 저장하지 않는다. 화면 안에서 재사용할 때도 live 상태, 학기, 학급, 원장 revision과 새로고침 경계를 적용한다. 실패는 빈 기록과 구분하고 늦은 응답을 폐기한다.

## 차트 표시

투자 화면의 목록은 학생 식별·현재 보유 수익률·총자산을 가까이 표시한다. 선택 학생의 계좌 현금·매수 예약·보유 종목·평가액·총자산·실현/평가 손익을 확인할 수 있다. `1일 / 1주 / 1개월 / 전체`는 같은 실제 기록의 표시 범위를 바꾸며 추가 거래 명령이나 조회를 만들지 않는다. 좁은 화면에서는 목록과 그래프가 세로로 이어지고 44px 조작·포커스·표시 항목을 유지한다.

공통 시세 차트의 기본 선차트 동작을 유지하고 교사 두 화면에서만 봉차트 모드를 지정한다. 종목과 지수는 한국 시각의 시간·일·주 구간별 첫 관측을 시가, 최대/최소를 고가/저가, 마지막 관측을 종가로 사용한다. 기본은 일봉이다. 기록 1개는 네 값이 같고 기록이 없는 구간에는 봉을 만들지 않는다. 거래량이나 실제로 없는 고저가를 생성하지 않는다. 지수의 소수 정밀도, 한국 시각 축, 관측 간 시간 간격, 키보드·터치·마우스 확인을 유지한다. 6주 기획안은 기존 가상 자료 선택으로 구분한다.
