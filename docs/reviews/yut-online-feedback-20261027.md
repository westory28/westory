# 윷놀이 온라인 응답·대기방·화면 안정화

학생 온라인 대전과 교사 체험이 공유하는 게임 컴포넌트를 최소 범위로 수정했다. 기존 게임 공개 설정, 세션·학기·학적·참가자 권한, 투척 판정과 요청 영수증을 유지한다. 새 게임 공개나 운영 방 데이터 변경은 하지 않았다.

## 변경

- 게임 명령마다 표시하던 로딩 덮개와 전체 inert를 제거했다. 최초 조회에만 로딩을 표시하고 명령 중에는 중복 게임 입력을 막는다. 복구 조회 중에도 판을 유지한다.
- 복구 완료 뒤 실시간 구독을 정확히 한 번 재개한다. 구독 세대·계정·방을 함께 검사해 과거 콜백을 차단한다. 강퇴 시 rules의 terminal permission-denied를 한 번의 권한 있는 로비 조회로 확인해 자동 퇴장한다.
- `commandYutRoomFast`를 데이터베이스 nam5에 가까운 us-central1에 추가했다. 기존 서울 callable은 구 클라이언트를 위해 유지한다. 256MiB 최소 인스턴스 1개, 최대 20개, 동시 요청 80개이며 유휴 비용이 발생한다. 독립적인 transaction 읽기를 병렬화했다. 권한 캐시나 검증 우회는 없다.
- 대기방·참가 코드의 10분 만료는 마지막 방장 활동 기준이다. 방장의 감정표현·자리 변경 등 승인된 행동으로 갱신하고, 다른 참가자의 행동·조회·동일 요청 재시도로 연장하지 않는다. 기존 방은 생성 시각을 fallback으로 사용한다.
- 방장은 대기 중 미준비 참가자만 강퇴할 수 있다. 서버에서 방장·대기 상태·대상 준비·revision을 다시 검사하고 참가자 및 학적 연결을 제거한다. 대상의 포인터만 해제하고 영수증·일일 이용 기록은 보존한다. `준비!` 감정표현을 추가했다.
- 복사·오류 메시지를 상단 오버레이로 바꿔 레이아웃 이동을 없앴다. 하단 사건 문구의 예약 공간과 실제 배경을 분리했다. 전체화면에서는 바깥 페이지로 스크롤이 전달되지 않으며 메뉴 내부 스크롤과 확대를 유지한다.

## 검증

- `npm run build`: 타입 검사와 기존 평가 XLSX hair 테두리 회귀를 포함한 필수 검사 및 번들 빌드 통과.
- `npm --prefix functions run check`: 전체 Functions 검사 통과.
- core/management 26개 테스트와 실제 Firestore 만료·통합 검사 통과. 활동 갱신·준비 경합·중복 강퇴·코드 연장·legacy 만료·현재 학기/공개/세션/학적/관전/보상 권한을 확인했다.
- `functions/scripts/verify-yut-network.cjs`: 실제 SDK와 Firestore 에뮬레이터의 4인 연결 검사 9개 통과. 강퇴 후 재입장·서버 snapshot, 15초 응답 유실 복구, fast adapter, 오프라인 복귀, 중복 차례/투척 방지, 역순 snapshot, 언마운트 후 늦은 응답을 확인했다.
- `scripts/verify-yut-online-feedback-browser.mjs`: 독립된 두 브라우저와 합성 3.1초 지연으로 로딩 덮개·전체 inert 없음, 중복 입력 차단, 판 유지, 동일 영수증 복구를 확인했다. 복구 조회 1.8초 동안 재구독 0회·완료 후 1회, 다음 상대 감정표현 수신, 강퇴 시 권한 재확인 1회도 통과했다.
- `scripts/verify-yut-interface-browser.mjs`: 390×844, 768×1024, 568×320, 844×390, 1280×800에서 복사 팝업 전후 좌표 동일·한줄/긴 한글 배경·하단 비겹침·전체화면 스크롤 경계를 확인했다.
- 기존 mobile-viewport와 board-layout 검사에서 320/390/768px 세로 회전 전체화면·native fullscreen·주소창 높이 변화·종료 복원·학생/교사 규칙 창과 포커스를 확인했다.
- 변경 TypeScript의 Prettier와 `git diff --check` 통과.

검증 자료는 `output/yut-online-20261027/`, `output/yut-online-feedback-20261027/`, `output/yut-interface-20261027/`, `output/yut-network-20261027/`에 보관하며 Git에는 포함하지 않는다. 합성 지연과 로컬 에뮬레이터 검사를 실제 운영 사용자 간 응답 속도 측정으로 해석하지 않는다.

## 운영 확인

배포 전 서울 command/lobby의 운영 yut·core·management·reward·세션 원본과 기준 HEAD 일치를 확인했다. 관리 함수의 이전 소스 차이는 기존 모니터링 알림 추가뿐이며 핵심 관리/core/권한 계약은 같다. 운영 rules도 기준 HEAD와 일치했다. 추가 만료 인덱스는 READY이며 rules와 대상 함수 5개 배포를 완료하고 ACTIVE 상태를 재확인했다. 새 endpoint는 운영 Origin CORS와 비인증 요청 거부(401)를 확인했다.

작업 중 원격 main의 교사 알림장 커밋 `1815a277`을 보존하여 fast-forward로 통합했다. 프론트엔드는 최종 커밋의 Vercel Ready·운영 승격·도메인 배포 연결과 실제 제공 자산을 별도로 확인한다. Chrome 직접 조작은 Windows 도구의 URL 판정 오류로 중단되어, 운영 로그인 후 두 실제 사용자 대전과 실기기 스크롤은 이번 검증 범위에 포함되지 않는다.
