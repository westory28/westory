# 사전 초성·테마 탐색 검증

## 변경 범위

기준 커밋은 `5410783`이다. 기존 포털 공통 레이아웃과 사전 등록·권한·출처 계약을 유지하면서 다음을 변경했다.

- 기본 사전, 학생 단어장, 교사의 등록 단어·학생 단어 목록에 같은 초성 필터를 사용한다. `0-9`와 `a-z`는 각각 10개 숫자와 26개 영문을 펼친다. 한글 된소리는 기본 자음에 포함하고 전각 문자와 영어 대소문자를 정규화한다.
- 기본 사전은 역사 분야, 관련 시대, 지역, 주제를 검색·초성과 함께 교차 적용한다. 선택 가능한 분류의 건수는 그 선택 후의 결과를 기준으로 표시한다. 한국사에서 세계사로 바꾸면 한국사 시대 조건이 해제된다.
- 배지는 기존 검색과 필터를 지우고 해당 테마 전체를 보여 준다. 상위 지역을 반복 표시하지 않고, 새 결과의 처음으로 스크롤·포커스를 이동한다.
- 배지는 12px 글자, 높이 24px, 상하 2px·좌우 6px 여백이며 인접 간격은 8px다. 출처 및 이용 조건은 12px로 줄이고 펼침 영역의 조작 높이는 유지한다.
- 실제 콘텐츠 너비가 640px 미만이면 초성은 목록 위에서 줄바꿈하고 테마 선택은 두 열로 배치한다. 수업 중 사전도 같은 컨테이너 기준을 적용한다.

분류 근거와 미지정 범위는 [별도 검토 문서](history-dictionary-classification-20261018.md)에 기록했다. UI는 원래 수업 단원 태그를 시대 배지로 재사용하지 않는다.

## 검증

- `npm run build`: TypeScript, 기존 학기·학습지·XLSX hair 테두리·지도 회귀 검사와 프로덕션 번들 생성.
- `npm run verify:history-dictionary`: 실제 카탈로그·분류 전체, 초성, 교차 필터, 배지 초기화, 탐색·세션·저장 계약. 앞으로 기본 빌드에서도 실행한다.
- 생성기 `--check`, 변경 TypeScript/TSX Prettier 검사, `git diff --check`.
- Chrome의 실제 React 컴포넌트 fixture에서 320·390·768·1280·1440px와 폭이 좁은 사전 대화상자를 확인했다. 가로 넘침 없이 재배치됐다.
- 숫자 0~9와 영문 a~z 전체 펼침, `4` 단일 필터, 검색 결과 없음과 초기화, 한국사+조선 전기+경기도 교차 결과, 배지 클릭 후 전체 테마 전환을 확인했다.
- `한국사+조선` 상태에서 세계사 옵션과 선택 결과 모두 1,410개로 일치한다. 분류 전환 때 시대가 해제되지만 개수에는 남던 오류를 수정했다.
- 검색한 집현전의 `관직·통치 기구` 배지를 선택하면 검색어가 지워지고 14개 테마 결과로 이동한다. 결과 영역에 포커스가 있고 상단 여유 96px를 확보한다.
- 가상 학생 계정에서 Agora를 직접 저장한 후 a-z 및 a 필터로 다시 찾았다. 학생 데이터는 운영 Firebase에 쓰지 않았다.
- 교사 등록 화면의 초성 선택과 전체 복귀, 수업 중 사전의 분류 기준 도움말, Escape로 도움말과 사전을 차례로 닫고 열기 버튼으로 포커스 복귀를 확인했다.
- 계산된 실제 배지 치수는 24px 높이·12px 글자·2px 6px 패딩, 출처 글자는 12px였다.
- 사전 앱 런타임 오류는 없었다. Chrome 확장 프로그램 자체에서 발생한 오류 1건은 앱 오류와 구분했다.

검증 fixture는 메모리 저장소를 사용한다. 운영 학생 기록을 생성하거나 삭제한 검증은 아니다. 최종 커밋과 운영 도메인 연결·실제 교사 화면 확인 결과는 배포 후 작업 보고에 남긴다.
