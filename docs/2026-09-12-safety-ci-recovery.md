## 수정

- 역사교실은 서버의 최종 답안 저장 성공 후에만 이동합니다. 저장 실패·오프라인·응시 변경 시 현재 화면을 유지하고 재시도할 수 있습니다. 확인되지 않은 저장 뒤 뒤로 가기·새로고침도 차단합니다.
- 실제 저장/이탈 함수를 추출한 31개 행동 검증을 안전 검사에 포함했습니다. 기존 정규식은 추출된 저장 helper 연결을 확인하도록 갱신했습니다.
- 상단 메인 메뉴와 떠 있는 하위 메뉴, 메뉴 화살표 제거, 결과창 겹침 수정, 노트북 필터 줄바꿈을 현재 사용자 요구와 일치하도록 검증합니다. 기존 화면 전체를 새 기준으로 덮어쓰지 않고 해당 변경만 명시했습니다.
- 위스 인덱스는 기존 페이지 조회 5개와 추가된 보상 조회 2개의 필드·범위·정렬을 정확하게 대조합니다.
- 교사 지도·원자료 저장은 과거 handoff 대신 현재 Gateway 연결, revision/hash, 업로드 참조, 미확정 요청 유지 및 직접 쓰기 차단을 검사합니다.
- 검사 비활성화, 실패 무시, 알림 끄기, 권한 완화는 적용하지 않았습니다.
