# 교사 학생 단어 삭제의 대상 연결 검증

기존 교사 삭제 callable은 클라이언트가 보낸 학생·단어·요청·학기를 각각 사용했습니다. 서로 다른 항목의 식별자를 조합해도 학생 단어를 삭제하고, 요청을 반려하고, 지정 학기의 보상을 회수할 수 있었습니다. 현재 단어와 요청이 모두 없을 때에도 요청 문서를 만들거나 원장을 찾는 경로가 있었습니다.

## 처리 기준

- 문서 경로를 만들기 전에 UID·단어 ID·요청 ID의 원래 값을 검증합니다. 슬래시를 포함한 경로나 잘린 ID로 다른 문서를 선택하지 않습니다.
- 같은 Firestore transaction에서 현재 단어·요청·학생 프로필을 읽습니다. 문서에 명시된 UID·단어 ID·요청 ID·단어·학기가 대상과 다르면 삭제·반려·보상 회수 전에 거절합니다.
- 보상을 회수할 때 결정적 보상/회수 원장의 UID·종류·출처·금액을 확인합니다. 저장된 `rewardTransactionId`로 경로를 우회하지 않습니다.
- 없는 요청을 복구하려면 현재 학생 단어의 명시적 UID·학기·단어 ID·요청 ID와 결정적 요청 ID가 일치해야 합니다. 요청 ID만으로는 새 반려 문서를 만들지 않습니다.
- 단어가 없으면 보상을 추정해 회수하지 않습니다. 기존 미처리 요청은 연결 검증 후 반려할 수 있지만, 이미 완료·반려된 요청의 재시도는 문서·원장·알림을 다시 쓰지 않습니다.

## 기존 자료와의 호환

공식 풀이 저장과 승인 resolver가 만든 정상 saved 단어에는 UID·학기가 없을 수 있습니다. 명시된 값의 모순을 검사하되, 학기와 보상 증거가 모두 없는 공식 단어는 삭제를 허용하고 호출자가 지정한 학기의 원장을 임의로 찾지 않습니다. 학기는 없는데 보상 증거가 있는 자료는 연결을 확인할 수 없어 거절합니다.

교사가 단어 이름을 바꾸면 현재 단어 ID는 바뀌지만 요청 ID와 원래 보상 ID는 남습니다. 교사 검토 기록과 현재 단어의 명시적인 요청 ID, 기존 요청의 원래 단어 참조로 이 연결을 검증합니다. 정상 legacy 단어 ID도 원래 요청의 matched/resolved 참조가 일치하면 허용합니다. 승인용 pending 검증을 그대로 적용하지 않습니다.

## 검증과 배포 범위

`functions/historyDictionaryDelete.js`는 쓰기 없는 입력·대상·원장 검증을 담당합니다. 기존 `deleteStudentHistoryDictionaryWordByTeacher`에만 연결하며 학생 삭제 helper나 다른 보상 writer는 바꾸지 않습니다. `functions/scripts/verify-history-dictionary-delete-binding.cjs`는 실제 검증 모듈을, `scripts/verify-history-dictionary-delete-binding-integration.mjs`는 격리된 demo Auth/Functions/Firestore 에뮬레이터의 실제 callable과 전체 업무 데이터 전후 상태를 검사합니다.

정확한 검사 결과·소스·Staging 배포 증거는 외부 PATCH13 인수인계에 기록합니다. 프런트·Rules·의존성과 기존 Hosting 배포는 유지하며 검증을 통과한 교사 삭제 함수만 전용 Staging에 반영합니다.

## 남은 한계

- 동일 ID의 이전 화면과 이후 화면을 구분하는 서버 revision/CAS 및 Gateway receipt는 후속 작업입니다.
- 기존 writer가 학생 단어의 현재 학기를 바꾸면서 원래 보상 메타데이터를 유지할 수 있습니다. 별도 보상 학기 이력이 없으므로 이번 검증이 모든 과거 보상의 학기 출처를 증명하지는 않습니다. 모든 writer의 보상 출처 migration이 필요합니다.
- 삭제·반려·원장 회수는 같은 transaction이지만 알림은 이후 별도 작업입니다. 알림 실패의 영구 복구는 미완료이며 완료 재시도에서 알림을 재전송하지 않습니다.
- 여러 이름으로 이동한 단어의 삭제 후에는 원래 연결 증거가 사라집니다. 완료 재시도에서 이를 추정해 다시 회수하지 않습니다.
- 실제 Google 계정·전체 앱·운영 사이트 수용과 운영 승격은 별도입니다.
